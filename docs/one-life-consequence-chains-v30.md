# 《단 하나의 인생》 3.0 — 인생의 흔적·후속 갈림길 1차 구현

## 범위

기존 `joseon-v9-village.js`의 선택, 가족·이웃·가축, 조선 경제 모듈을 연동하는 공통 후속 사건 관리 모듈 `consequences-v30.js`를 구현했다.

### 3.1 오래 남는 인생의 흔적

- **선택이 실제로 성공한 직후** 기록: 사람 ID/이름, 발생 연도, 행동과 물건, 확인 가능한 단서, 다시 만날 시점, 미해결·완료·종결 여부
- 기존의 `Life.snapshot()/restore()`를 확장하되, **구 저장에는 빈 상태로 호환**
- 관련된 이웃은 기존 `joseon9.homes[]`의 동일한 ID를 사용. 가상의 보상 인물을 새로 생성하지 않는다.
- 플레이 화면의 **‘내 삶의 흔적’**에서 아직 남은 일, 끝난 일과 관련 인물을 본다.
- 배우자·자녀·족보와의 장기 직업 연계는 **다음 단계**로 분리한다.

### 3.2 네 가지 장기 사건

| 출발 사건 | 시간 경과 | 다른 인생을 만드는 갈림길 |
|---|---|---|
| 명절에 곡식을 나누거나 일손을 보탬 | 3년 | 해당 이웃이 마을에 있고 살림에 여유가 있어야만 곡식을 돌려줄 수 있다. 그렇지 않으면 품일·안부 중심으로 이어진다 |
| 물꼬를 협상하거나 몰래 열거나 중재 요청 | 2년 | 물 대는 약속 재확인, 도랑 보수의 실제 비용·노동, 다른 일 선택 |
| 부족한 괭이 빌리기·품삯 지급·집안 도구 손질 | 4년 | 빌린 물건 반환·수리·교대 품일, 도구 종류와 실제 처음 행동에 맞춘 문장 |
| 병든 소·돼지·닭 돌보기 | 3년 | 돌봄 선택과 실제 가축 보유에 따라 생존 또는 상실. 이미 없는 가축을 되살리지 않음 |

### 부자연스러운 강제 보상 방지

- 도왔다는 이유만으로 이웃의 보상이나 가족의 귀환을 **보장하지 않는다**.
- 이웃이 마을을 떠났거나, 이전에 농사지었던 논을 더 이상 일구지 않거나, 가축이 이미 없다면 후속 선택지를 강행하지 않고 관계가 끝난 **구체적인 이유를 기록**한다.
- 돈이 부족하면 돈 대신 일을 더 해야 하며, 곡식이 없는 이웃은 곡식을 그냥 만들어 내지 않는다.
- 결과에는 선택 당시 단서(`causeId`)를 남겨 원인-후속 사건을 찾을 수 있다.
- 아직 자연사의 NPC 확률, 도구별 재고, 긴밀한 가족 직업 승계 등을 시뮬레이션하지 않는다. 그런 사실을 꾸며 쓰지 않는다.

### 코드 검증

`tests/one-life-consequences-v30.test.cjs`에서 네 가지 사건의 실제 선택→연도 변경→후속 선택→해결과 저장·복원, 동일 출생 조건 대조, 이웃의 이동, 토지 상실, 양식 부족, 가축 상실을 테스트한다.

**제약:** 새 모듈은 현재 조선 마을 생활 일부에 연결되어 있다. 조선의 모든 선택, 청·일본 피로인 후손, 대한제국·현대 전체를 통합했다는 주장이 아니다.
