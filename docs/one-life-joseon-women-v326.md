# 《단 하나의 인생》 3.26 — 조선 여성 생애 분기

## 목적
조선 여성의 삶을 혼인·출산·육아만으로 환원하지 않고, **어릴 때 익힌 솜씨 → 가족 및 이웃과의 관계 → 생업 → 친정의 문서와 재산 논의 → 노년의 전수**로 잇는다. 남녀 공통 사건과 중복해 혼인·출산·사망을 새로 생성하지 않는다.

## 실제 추가한 선택

| 단계 | 출현 조건 | 주요 선택 |
| --- | --- | --- |
| 배움 | 여성, 조선기 생존, 15세 이후 | 길쌈·바느질 / 한글·셈 / 돌봄·약재 |
| 가족 | 22세 이후 | 친정·시가 및 가족의 연락 / 개인의 생업 / 품앗이 |
| 생업 | 27세 이후 | 옷감 장사 / 편지·장부 일 / 마을 돌봄 |
| 문서·재산 | 37세 이후 | 상속·재산의 증거 확인 / 친척과 조율 / 물건 보전 |
| 사별 | 가족 연대기에서 배우자의 실제 사망이 있을 때만 | 생업 지속 / 친척과 의논 / 이웃과 품앗이 |
| 노년 | 54세 이후 | 솜씨 가르치기 / 기록 정리 / 생업 나누기 |

여성 전용 상태에 기술, 글, 돌봄, 거래 경험과 가족관계의 선택, 물건·문서 처리 선택을 영속 저장한다. 3년 후 과거 선택을 돌아보는 후속 기록을 남긴다. 사건 간 직접적인 인과는 일부 상태/대사에 적용했지만, 이것이 역사적 직업별 성공률이나 정확한 상속법을 복원한다는 뜻은 아니다.

## 역사·게임 규칙

- **가족 엔진이 진실의 원천:** 혼인 여부, 자녀, 배우자 사망은 기존 `joseon-v1/v4`를 읽는다. 임신·출산·재혼을 임의 발생시키지 않는다.
- **시대 차이:** 재산 문서 사건은 1700년을 간단한 전환점으로 사용하지만, 여성의 실제 상속 관습 변화는 지역·가문·시대에 따라 점진적이었다. 특정 인물이 법적 상속을 받았다고 임의 확정하지 않는다.
- **신분 제약:** 노비 가계의 자유로운 일·이동에 제약이 있음을 서술하며, 속량은 기존 신분 엔진에서만 발생한다. 심화된 관청 의녀·궁녀·기녀 제도는 이 단계에서 실제 직업으로 개설하지 않았다.
- **구금·포로·해외 체류:** 기존 법적 구금·유배·포로와 해외 이동 중에는 일반 생활 분기를 보류한다.
- **성별 직역 검증:** 3.25 직업 중 `포졸`을 여성에게 잘못 제시하지 않도록 자격을 제한한다. 다른 기술·예술 활동은 그 시대 실제 출신·직업과 경로에 따라 기존 조건을 따른다.
- 모든 사건·수치·개별 가족사는 창작이다. 역사적 인구의 성별 재산·문해율 통계로 해석하지 않는다.

## 게임 표시와 저장
- `joseon-women-v326.js`: 여성 생애 분기, 대사, 후속 기록, 저장·복원.
- `joseon-branches-v325.js`: 포졸 직역 성별 조건 보정.
- `index.html`, `game.js`: **살아온 길과 배운 솜씨** 패널. 조선 여성에게 실제 전용 선택 기록이 생긴 경우에만 보임.
- `tests/one-life-joseon-women-v326.test.cjs`: 신분·사별·구금·성별 제한, 선택지 형식, 저장·복원, 200명 생애 실행.
- `scripts/run-ci-tests.cjs`: 테스트 등록.

## 검증 기록
연결된 최소 핵심 모듈(조선 1·2·3·4·5·6, 3.25, 3.26 및 기초 엔진) 대상으로 여자 200명 자동 생애를 실행해 **여성 선택지 959건**, 단계별 발생(배움 199 / 가족 196 / 생업 193 / 문서 191 / 노년 172 / 사별 8), 저장·복원 대조 25건, 빈 선택지 0건을 확인했다. 이 값은 **테스트 시드와 게임 난수에 따른 내부 QA 결과**이며 역사적 발생률이 아니다. 전체 브라우저 플레이와 배포 확인을 대신하지 않는다.

## 아직 남은 일
1. 의녀·궁녀·기녀·산파 등은 신분과 시대별 실제 진입 조건을 조사한 다음 독립 생업으로 세분화한다.
2. 출산 관련 위험과 산후 회복은 기존 가족·건강 모델을 일관되게 확장할 때 추가한다. 이번 업데이트에서는 추정 사망률을 만들지 않는다.
3. 여성 재산 관리·상속은 실제 문서·가계 연대기와 연결해 증빙이 있을 때만 금전·토지 변화를 일으키도록 심화한다.
4. 게임 전체의 UI 및 다른 조선 연대기 이벤트가 겹칠 때 보류된 사건이 정상적으로 이어지는지 브라우저에서 재확인한다.
