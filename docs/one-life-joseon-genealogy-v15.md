# 《단 하나의 인생》 · 펼쳐 보는 가상의 가족 족보 (v15)

## 구현 범위
- 플레이 화면의 '우리 집 족보 펼치기'와 인생 엔딩의 '우리 집 족보 펼쳐 보기'로 **같은 족보**를 열 수 있다.
- 세대별로 분류한 인물 버튼을 누르면 이름·태어난 해·사망 기록(존재하는 경우)·부모·배우자·자녀·생업을 확인한다.
- **상태 변화**: 조선 v13의 가족 실종과 귀환을 서로 다르게 표시하며, 확인되지 않은 사람을 사망자로 단정하지 않는다.
- 본관 표기는 기존 v8의 '어느 지역에 본관을 둔 성씨'를 사용하는 가상 집안 표식이다. **실제 존재하는 문중의 등록 족보나 실존 인물의 혈연관계를 재현하지 않는다.**
- 이름이 확인되지 않은 윗세대 사람을 상상으로 생성하지 않고 현재 가족 명부에 존재하는 인물로부터 그린다.
- 자녀의 시점으로 인생을 이어 갈 때 그 자녀의 **기존 인물 ID를 계승**해 이전 기록과 같은 사람이 이어지도록 한다. 부모·형제·자녀 이름과 생몰·생업 기록이 후손의 기록에 남는다.
- 계승한 자녀는 여자·남자 모두 족보에서 같은 방식으로 나타나며, 누구를 주인공으로 선택했는지도 표시한다.
- 족보 파일은 **각 저장 데이터 안에** 포함되며 별도 서버나 DB를 설치하지 않는다. 새 창·외부 서비스로 이동하지 않고 보이는 페이지 안에서 펼쳐진다.
- 모바일에는 화면 전체를 활용하는 종이 문서형 화면을 사용한다. 인물 카드는 터치·키보드로 선택할 수 있고 Esc/닫기/배경으로 닫을 수 있다.
- 족보 열람 중 인생 시간은 일시정지되며 이전에 진행 중이었다면 닫았을 때만 자동 진행을 이어 간다.

## 사실성과 한계
- 이 족보는 **게임 안의 가상 가족 기록**이다. 사료 기반으로 검증된 실제 조선 시대 족보를 생성하지 않는다.
- '생존' 표시는 해당 인물이 마지막으로 기록된 연도의 상태일 뿐, 먼 후손의 시대까지 생존한다고 주장하는 의미가 아니다.
- 가족 명부가 제공하지 않는 인물(사촌, 먼 친척, 증조부모 등)은 족보에 표시할 수 없다.
- 현재 v14 후계 시스템이 지원하는 조선 출생 연도 범위에 맞춰 기록을 연결한다. 1898년 이후 출생자의 후계 플레이는 별도 시대 모듈을 요구한다.
- 한 세대에서 가문이 두 갈래로 분리돼 각자 독립 저장을 만드는 기능, 수백 년 뒤 잃어버린 친척을 찾는 탐색, 인물마다 독립 생애를 완전히 시뮬레이션하는 기능은 포함하지 않았다.
- 조선의 실제 족보 관습에서는 성별·신분·시대에 따른 기재 방식이 달랐다. 이 화면은 현대 이용자가 **가족 모두를 확인하는 가상 가계도**로, 당대 양반 가문의 족보 양식을 그대로 재현하는 것은 아니다.

## 회귀 검사
- 저장한 가족 명부에서 실제 확인되는 부모·형제만 표기하는지.
- 자녀의 성별과 부모 연결, 결혼 관계, 실종/귀환의 구분.
- 조부모 → 자녀 → 손자녀로 이어져도 인물을 복제하지 않고 같은 식별자와 이름을 유지하는지.
- 이전에 족보 기능이 없던 세이브에서도 알려진 사람만 복구하는지.
- 120회 조선 인생 자동 진행 중 ID 중복과 저장·복원 오류가 없는지.
