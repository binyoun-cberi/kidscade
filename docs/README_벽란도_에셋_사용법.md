# 벽란도 상행기 CC0 선별팩 v1

## 사용 방향
기존의 2D 삽화는 유지합니다.

- 삽화: 지역 도착, 사건, 인물 소개, 상인 대화, 역사 설명
- 3D: 항구 이동, 배 접근, 부두 하역, 시장/창고 공간, 배경 생활감

즉, 이 팩은 삽화를 교체하기 위한 것이 아니라
**삽화 사이의 플레이 공간을 풍성하게 만드는 용도**입니다.

## 권장 경로
이 ZIP의 `assets/` 폴더를 Kidscade 저장소 루트에 그대로 합치면 다음 경로가 생깁니다.

`assets/game/3d/byeokrando/`

### ships
- 노젓는 배 2종을 기본 사용
- 돛배/어선은 `optional_review`에서 형태 확인 후 사용
- 현대 화물선, 예인선, 모터보트, 컨테이너는 제외함

### port_props
- 자루, 수레, 상자, 울타리, 건초, 우물, 길, 돌, 연기 등
- 유럽풍 완성형 건물은 전부 제외함

### trade_props
- 밧줄, 목제 물통, 도기 후보, 보따리, 문서, 작업대 등
- Fantasy Props는 glTF라서 `.gltf + .bin + .png`를 같은 폴더에 유지해야 함

### animals
- 말, 당나귀, 소, 황소만 기본 사용
- 알파카/허스키/시바/늑대 등은 제외함

### optional_review
시대감이 애매하지만 게임적으로 쓸모 있는 후보.
시장 좌판이나 돛배는 여기서 먼저 외형을 확인하고 쓰는 것을 권장합니다.

## 벽란도에서 우선 배치하면 좋은 조합
1. 부두: row boat + rope + crate + bags + cart
2. 창고: crate + package + table + workbench + candle
3. 시장: bags + pottery(vase/pot) + cart + optional market stand
4. 육상 운송: horse + donkey + cart + hay
5. 야간 장면: smoke + candle + optional bonfire

## 의도적으로 제외한 것
- 서양식 판타지 주택/여관/병영/대장간 완성형 건물
- 종탑
- 현대식 선박/컨테이너/예인선/모터보트
- 해적 대포·해적기
- 서양 검·방패·포션
- 금화 더미
- 알파카·허스키·시바견 등 벽란도 항구 연출에 굳이 필요 없는 동물
