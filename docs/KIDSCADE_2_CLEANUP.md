# Kidscade 2.0 정리 기간

2026-09-24부터 Kidscade는 당분간 **게임 수 확장보다 플랫폼 품질과 기존 게임 완성도**를 우선한다.

## 왜 지금 정리하는가

Kidscade는 이미 100개가 넘는 게임과 공용 계정·저장·랭킹·오디오·멀티플레이·Seed World를 가진 플랫폼이 되었다. 이제 병목은 콘텐츠 부족이 아니라 다음 문제다.

- 레거시 루트 게임과 `games/<game-id>/` 구조가 공존한다.
- 소스 카탈로그와 빌드 override가 동시에 진실을 가지고 있다.
- 게임마다 플랫폼 연결 방식이 달라 공통 기능을 빌드 후 삽입하는 경우가 많다.
- 게임 수가 많아져 단순 학년/과목 필터만으로 탐색하기 어렵다.
- 한 게임의 회귀 실패가 전체 CI의 뒤쪽 검사를 건너뛰게 만들 수 있다.
- 에셋 규모가 커져 중복·대용량·미사용 자산의 관리 비용이 커졌다.

## 정리 기간 운영 원칙

1. 새 게임은 예외적으로만 추가한다. 같은 시간이라면 기존 상위 게임의 완성도와 플랫폼 공통 기능을 먼저 개선한다.
2. 새로 손대는 게임은 가능하면 `games/<game-id>/` 아래 표준 구조로 옮긴다.
3. 새 게임/리워크는 루트 HTML을 새로 만들지 않는다.
4. 공통 기능은 게임별 복붙보다 플랫폼 런타임/API로 올린다.
5. `data/games.json`을 최종적으로 게임 메타데이터의 단일 원본으로 만든다.
6. 빌드 스크립트는 게임 로직을 고치는 장소가 아니라 배포 산출물을 만드는 장소로 축소한다.
7. CI가 빨간 상태에서 새 기능을 계속 쌓지 않는다.

## 기준선

정리 시작 시점의 대략적인 기준선:

- 카탈로그 게임: 112개
- 루트 HTML: 112개
- 루트 JS: 70개
- 저장소 파일: 약 10,000개
- 게임 대문은 빌드 시 WebP 최적화를 적용
- 정리 시작 당시 분류 일부가 빌드 override에서 보정되었으나 1차 정리에서 원본 `data/games.json`으로 흡수 완료
- 공통 오디오/터치 런타임 일부는 빌드 시 게임 HTML에 삽입

정확한 현재 값은 다음 명령으로 확인한다.

```bash
npm run health
```

심각한 카탈로그 오류까지 실패 코드로 검사하려면:

```bash
npm run health:strict
```

## 단계

### 0. 안정화

- main CI를 다시 초록색으로 만든다.
- 공통 런타임 탐지는 절대/상대 경로와 쿼리 버전에 의존하지 않게 한다.
- 카탈로그 진입 파일 누락, 중복 ID 같은 치명적 오류는 자동 검사한다.

### 1. 단일 원본 정리

- [완료] 분류 override를 `data/games.json`에 흡수했다.
- [완료] 설명 override 5개를 원본 카탈로그로 흡수했다.
- 게임 로직을 바꾸는 빌드 후 패치를 원본 게임 코드로 이동한다.
- 빌드 결과와 소스 결과가 다르게 보이는 경우를 줄인다.

### 2. 카탈로그와 메인 UX

학습 영역과 게임 장르를 분리한다.

- 학습: 수학 / 국어 / 영어 / 사회 / 과학 / 예술 / 진로 / 사고력
- 장르: 액션 / 퍼즐 / 전략 / 시뮬레이션 / 경영 / 퀴즈 / 리듬 / 스포츠 / 샌드박스
- 추가 태그: 난도 / 예상 플레이 시간 / 입력 방식 / 인원

메인 화면은 모든 기능을 동시에 강조하지 않고 **게임 발견과 즉시 실행**을 1차 목표로 둔다.

추천 묶음 예시:

- 오늘 추천
- 최근 좋아진 게임
- 5분 안에 한 판
- 친구와 하기
- 깊게 하는 게임
- 수업에서 함께 하기

### 3. 게임 품질 정리

각 게임을 삭제/유지의 이분법으로 보지 않고 다음 상태로 관리한다.

- 대표작: 메인에서 적극 추천
- 정식: 기본 품질 기준 통과
- 개선 필요: 동작은 하지만 UI/밸런스/모바일/교육 연결 개선 필요
- 보관 후보: 중복되거나 가치가 낮아 숨김 검토

평가 항목은 첫 30초 이해도, 조작감, 모바일, 시각 일관성, 재플레이성, 교육 내용과 게임 규칙의 결합 정도를 중심으로 한다.

### 4. 공통 Game SDK

최종 목표는 게임이 플랫폼 기능을 직접 구현하지 않는 것이다.

예시:

```js
KidscadeGame.init({ id: 'high_disaster_city' });
KidscadeGame.start();
KidscadeGame.sound('success');
KidscadeGame.score(1200);
KidscadeGame.gameOver();
KidscadeGame.exit();
```

SDK가 담당할 항목:

- iframe 종료
- 일시정지/재개
- 오디오/음소거
- 모바일 입력 보호
- 플레이 기록
- 최고 점수
- 보상
- 화면 방향
- 부모 페이지 통신

### 5. 레거시·에셋 정리

- 리워크하는 루트 게임부터 `games/<game-id>/`로 이동한다.
- 경로 호환은 alias/redirect로 유지한다.
- 중복 텍스처와 대용량 원본을 조사한다.
- 공용 / 게임전용 / 후보 / 미사용 자산을 구분한다.
- 대문 이미지는 원본 단계부터 표준 규격으로 관리하는 방향을 검토한다.

## 정리 기간 종료 조건

게임 개수를 목표로 삼지 않는다. 아래 상태가 되면 다시 신작 비중을 높인다.

- main의 핵심 CI가 안정적으로 초록색을 유지한다.
- 새 루트 게임 파일이 더 이상 증가하지 않는다.
- 카탈로그의 핵심 분류가 빌드 override 없이 원본에서 정확하다.
- 대표 게임들이 공통 종료·오디오·저장 규약을 사용한다.
- 메인에서 많은 게임 중 좋은 게임을 쉽게 발견할 수 있다.
- 플랫폼 건강검사에서 주요 경고 수가 지속적으로 감소한다.
