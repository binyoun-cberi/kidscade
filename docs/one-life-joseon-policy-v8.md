# 《단 하나의 인생》 조선사 역사 제도 검증표 v8

이 문서는 **역사적으로 확인된 제도 시행 사실**과 **시뮬레이션용으로 임의 설정한 발생률·점수**를 구분한다. 전국 인구 구성·신분·직업 확률은 역대 인구 통계로 검증되지 않았으므로 정확한 조선 인구 분포로 해석하지 않는다.

## 1. 지역별 공납과 대동법

| 지역 | 게임에서 적용하는 시작 시기 | 근거 / 예외 |
|---|---|---|
| 경기도 | 1608 | 선혜법·대동법 |
| 강원도 | 1623 | 대동법 확대 |
| 충청도 | 1651 | 대동법 정착을 대표하는 시행 시기 |
| 전라도 | 1662 | 1658년 해읍, 1662년 산군으로 단계적 적용. **게임은 보수적 기준인 1662년을 전라도 전체에 사용** |
| 함경도 | 1666 | 지역별 시행과 운영 차이가 존재 |
| 경상도 | 1678 | 대동법 확대 |
| 황해도 | 1708 | 대동법 확대 |
| 평안도 | 전국 공통 연도 적용 불가 | 지역 재정과 관향 부담을 별도로 표현. 대동미를 획일적으로 부과하지 않음 |
| 한양 | 지방 공납의 일괄 적용 대상 아님 | 도성의 시장·호역·관청 부담과 구별 |

대동법 납세 방식은 지역과 조건에 따라 쌀·베·돈 등으로 이루어졌다. 개인 토지/곡식 숫자는 **게임 단위**이며 역사적 정확한 세율·실질소득이 아니다.

자료: [대동법 — 한국민족문화대백과사전](https://encykorea.aks.ac.kr/Article/E0014246)

## 2. 군역·균역법·호포법

- 조선 전기: 양인 남성의 군역이 여러 역종과 번상 형태로 나타날 수 있었음. 문반/무반도 이 시기에는 군역과 무관하다고 단순화할 수 없음.
- 16세기 이후: 군역 대립과 방군수포·군적수포의 확대. **일반 양인 남성과 양반층의 실제 부담을 구별**하고, 양반의 면역/회피를 설명.
- 1750년 균역법: 종래 2필의 군포를 1필로 감액. 법의 정식 시행과 후속 보전 재정은 단계적 진행.
- 1871년 호포법: 개인 군포를 그대로 모든 사람에게 나눠 매기는 방식이 아니라 **호 단위 부담**. 양반 가구에도 확대되며 성인 남성 개인에만 부과되지 않음.
- 게임의 22·37·52세 분기와 세금 수치는 연속적인 국가 의무를 표현하기 위한 가상 체험 장치이며 실제 특정 연령만의 부담을 뜻하지 않음.

자료: [균역법](https://encykorea.aks.ac.kr/Article/E0007303), [호포](https://encykorea.aks.ac.kr/Article/E0063881), [군역](https://encykorea.aks.ac.kr/Article/E0006677)

## 3. 노비의 해방과 부모·자녀의 법적 처지

- 1801년: 중앙 관서의 내노비·시노비 혁파. 지방 관아 노비와 사노비 전체를 동시에 해방한 조치는 아님. **게임은 소속 중앙 관서 / 지방 관아를 먼저 결정하여 중앙 관서 가계에만 적용**함.
- 1731년: 노비 남성과 양인 여성 사이에서 태어난 자녀의 종모종량 원칙을 영구적으로 시행한 중요한 시점. 세습 규칙은 세기 전반에 걸쳐 변했고, 게임의 출생 처지는 이를 단순화함.
- 1886년: 노비 신분의 세습 폐지. **부모가 노비 출신인 양인 자녀**라는 분기와, 여전히 사회적 차별을 겪는 가문을 구분.
- 1894년: 법적 노비제·신분제 폐지. 실생활의 차별·예속 관습이 즉시 모두 사라졌다는 뜻은 아님.

자료: [노비 — 한국민족문화대백과사전](https://encykorea.aks.ac.kr/Article/E0012757), [노비제의 제도적 변화 — 우리역사넷](https://contents.history.go.kr/mobile/nh/view.do?levelId=nh_039_0040_0040_0010_0010)

## 4. 직역·왕실·관직

- 1423년 이전 백정 가계는 **화척·재인 계열**이라는 맥락으로 표기. 명칭과 실질 처지를 동일시하지 않음.
- 조선 전기 역관·의관·서리 가계를 곧바로 후기의 '중인' 신분 체계와 동일하게 묶지 않음. 기존 네 분류는 내부 게임 가중치로 남겨 둠.
- 역관 가계 출생 및 통역 기술을 익힌 사실만으로 잡과 급제한 **공식 역관 직위**를 얻지는 않음. 시험·임명과 일상 기술을 구별.
- 암행어사는 실제 관료에게 임무로 주어지는 직위로 한정하고 **영구적인 평생 직업이 아니라 기간이 끝나면 본 관직으로 복귀**.
- **기록된 국왕 재위 기간에 무작위로 가상 국왕이 즉위하는 분기 폐지.** 실제 왕의 삶은 실록과 계보로 확인한 실존 인물 모드가 필요하며 이번 버전에는 아직 생성하지 않음.

자료: [백정](https://encykorea.aks.ac.kr/Article/E0022352), [연산군](https://encykorea.aks.ac.kr/Article/E0036803), [숙종](https://encykorea.aks.ac.kr/Article/E0031837), [정조](https://encykorea.aks.ac.kr/Article/E0050867)

## 5. 남은 검증 한계

- 출생 신분·가구 재산·관직·직업 등장 확률은 여전히 게임 가중치. 역사적 인구 비율이나 특정 개인의 실제 인생 확률이 아님.
- 전라도는 1658년 연해, 1662년 산간을 나누는 **고을 단위 정보가 아직 없어 1662년 단일 기준으로 단순화**함.
- 어업·주막·공방의 월별 장부, 지역별 실제 직역 목록, 황해/함경/평안 재정 특례, 노비 소유 관계, 왕실 실존 인물 연대기, 시대별 주민 호적 분포 자료는 추가 연구가 필요함.
- 공노비의 소속지와 노비 후손 출생 가중치도 **게임용 상정**이며 호적에 근거한 정확한 비율이 아님. 다만 1801·1886·1894의 법적 적용 범위는 다른 사건으로 처리함.
- 16세기 이전 왜구·여진의 소식은 지역 위험을 설명하는 가상 개인 사건이다. 역사에 없던 특정 고을의 약탈을 실제 사건이라고 주장하지 않음.
