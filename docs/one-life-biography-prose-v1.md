# 생애 전기 편집 · 2026-10-23

## 이전 문제

사망 화면의 `chapters()`는 시간 구간마다 사건 한 개를 골라 최대 여섯 줄의 “N세 무렵”을 출력했다. 선택 제목과 행동을 ` — `로 저장한 역사 시대 기록은 통째로 제외했다. 탄생과 몇 가지 사건은 있었지만, 실제로 선택한 일과 뒤에 일어난 일이 이어지는 문단은 없었다.

## 이번 변경

- `biography-v328.js`: 이름과 출생으로 시작하고, 성장·젊은 날·중년·노년의 실제 사건을 여러 문장으로 엮는다. 모든 나이 구간을 강제로 채우지 않는다. 이주·귀환 같은 전환, 생업, 배움과 관계를 골고루 고르며 반복되는 연간 문장은 줄인다.
- 선택한 행동은 의도로 쓴다. “삼베와 모시 짜는 일을 배운다”를 선택했다면 “배우기로 했다”가 되며, 그것만으로 기술을 습득했다고 단정하지 않는다. 명시적인 원인 ID가 있는 실제 결과만 해당 선택과 연결한다. 단순히 같은 나이였다는 이유로 인과관계를 만들지 않는다.
- 같은 해·이듬해·실제 경과 연수로 문장을 연결한다. 제목과 행동의 구분자, 수치 변화 HUD, 반복되는 추상적 감상은 본문에서 걷어낸다. 과거형, 주어의 조사, 이미 “하기로 한다”인 문장의 중복 변환을 확인한다.
- 마지막 문단에는 실제 사망 연도·나이·원인을 쓴다. 짧은 삶에 결혼·직업·노년을 만들거나 가족이 곁을 지켰다는 장면을 추가하지 않는다. 사망 원인이 없으면 없다고 밝힌다.
- `index.html`, `life-ui-v2.css`: 문단들을 담는 요소를 article로 바꾸고 명조 계열 글꼴, 읽기 폭과 행간, 도입·마지막 문단의 간격을 조정한다. 외부 폰트 요청은 추가하지 않는다. 기존 픽셀 에셋을 그대로 사용한다.
- 새 전용 검사를 기존 CI 실행 목록에 등록한다. 게임 ID·URL·저장 형식·사건 효과·RNG·학생 기록은 변경하지 않는다. 외부 AI API와 요금은 추가하지 않았으며 Secrets 열람·결제 설정 변경·서비스 배포를 하지 않는다.

## 편집 원칙과 한계

문학성은 수식어를 늘리는 것으로 대신하지 않는다. 인물에게 실제로 일어난 구체적인 일, 그 사이의 시간, 선택과 결과의 간격이 보이도록 편집한다. 원문에 없는 대사·날씨·내면·화해·성공·유산은 쓰지 않는다. 출생 정보가 부족한 과거 저장을 현재 직업이나 최종 가족 구성으로 보충하지 않는다.

이 기능은 외부 생성 모델을 호출하는 작가가 아니라 기록에 근거한 결정적 편집기다. 원본 사건의 표현과 정보량이 글의 품질에 영향을 미친다. 모든 조합이 전문 작가의 전기와 동등하다는 뜻은 아니며, 장기적으로 중요한 사건 자체의 집필 품질을 더 높일 여지가 있다.

## 검증

새 검사는 의도와 성과 구분, 연결 ID, 시대 배경의 개인 체험화 방지, 짧은 생애, 원인 미상의 사망, 반복 억제, 연대순, 이전 저장, 렌더 전후 데이터 불변을 확인한다. 실제 엔진 전체 모듈을 로드해 고려·조선·일제강점기·현대의 100개 생애를 완주하고 전기를 생성한다. 100개 글은 서로 달랐고, 어린 생애 5개와 30세 이상 생애 93개가 포함됐다. 4,234개 선택이 실행됐다.

시대별 다섯 생애의 글을 직접 읽으며 중복 제목·아버지 조사·과거형·선택 결과·반복되는 사망 문장과 연도 연결을 검토했다. 이는 모든 가능한 문장의 문학적 완성도를 증명하는 검사는 아니다. 실제 브라우저의 수정본 서체·줄바꿈 검수는 포함하지 않는다.

실행: `node --test tests/one-life-*.test.cjs` — 로컬에 준비된 관련 테스트 16개 파일의 107개 검사 통과, 실패 0개. `node --check games/high_one_life/biography-v328.js`, `node --check scripts/run-ci-tests.cjs`, `git diff --check`도 통과했다. 전체 저장소 CI·전체 빌드와 수정본 브라우저 시각 검수는 별도로 남아 있다.
