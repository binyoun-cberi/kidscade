# 단 하나의 인생 UI 검수 · 2026-10-23

## 비평과 확인한 근거

1. 홈 화면이 출생·플레이 중에도 남는다. 실제 배포 페이지에서 시작 버튼을 누른 뒤 `#intro`에 `hidden`이 붙었지만 계산된 display는 `block`이었다. `pixel-home-v1.css`의 `#intro.home-intro{display:block!important}`가 공통 숨김 규칙을 이긴다. 마지막 UI 스타일에서 홈의 hidden 상태를 명시적으로 우선한다.
2. 사건 제목이 이야기 제목과 선택 제목에 중복된다. 선택 또는 회고 중에는 일반 이야기 헤더를 숨겨 실제 질문만 읽게 한다.
3. 기존 스타일은 선택을 그림 위로 옮겼지만 DOM은 그림·배속·생활 방향 다음에 선택이 있었다. 키보드 순서도 문서 순서를 따르므로, 실제 마크업을 조작부→이야기/선택→그림→최근 기록→생활 방향→상세 기록 순서로 옮긴다.
4. 최근 연대기는 긴 역사·마을·가족 설명 뒤에 있었다. 최근 기록을 앞으로 옮기고 부가 자료는 기본적으로 닫힌 네이티브 details에 넣는다. 기록·가족 살림 행동·자료 링크의 ID와 이벤트 연결은 유지한다.
5. 고려 화면은 별도 렌더러여서 공통 CSS 수정이 적용되지 않는다. 실제 선택을 그림 앞으로 옮기고 엔진이 제공하는 선택 설명을 표시한다. 가족의 일·생업·역사 기록은 펼쳐 볼 수 있게 하며 재렌더 후에도 펼침 상태를 유지한다.

## 구현 범위

- `index.html`: 실제 읽기 순서 정리, 기존 조작부 이동, 상세 정보 접기, 캐시 버전 갱신.
- `life-ui-v2.css`: 숨겨진 홈 표시 오류 수정, 조작부와 접기 UI, 기존 시대별 색상 유지. 키보드 포커스와 44px 이상의 주요 조작 영역.
- `game.js`: 질문 중 제목 중복 제거, 자동 선택 진행 상태 표시, 새 선택으로 이동할 때 움직임 감소 설정 반영.
- `goryeo-view-v343.js`: 선택 우선 표시, 설명과 기존 콜백 보존, 상세 기록 펼침 상태 보존.
- 관련 테스트 6개 파일: 동작 검증 및 바뀐 파일 캐시 버전에 대한 기존 검사 갱신.

기존 픽셀 장면과 인물 에셋을 그대로 사용한다. 신규 이미지·외부 서비스·유료 API를 추가하지 않는다. 게임 ID, URL, 저장 포맷, 사건 효과, 학생 기록과 경제/수명 로직을 변경하지 않는다. 키나 Secrets를 열람하지 않았으며 결제·배포 설정 변경이나 배포를 실행하지 않았다.

## 제한과 다음 검수

실제 서비스는 클라우드 브라우저에서 출생·플레이 진입과 홈 잔류 오류를 확인했다. 수정본은 로컬 Chromium 실행 파일이 없고 다운로드가 실패해 실제 브라우저 화면 검수를 완료하지 못했다. 위 모의 실행은 실제 화면 검수와 다르다. PR의 CI 전체 빌드·health·전체 테스트 및 360px/390px/PC 수정본의 시각 검수가 남아 있다. 배포하지 않았으므로 서비스 화면은 아직 기존 버전이다.

특히 긴 선택지, 회고 입력, 자동 선택 설정, 접힌 자료 열기, 족보, 고려 가족 일 배정과 저장 후 재접속을 화면에서 확인해야 한다. 사용성 개선이 재미를 입증하지는 않으며 실제 학생 플레이 피드백이 필요하다.
