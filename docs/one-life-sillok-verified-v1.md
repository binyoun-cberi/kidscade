# 조선왕조실록에 근거한 역사 사건 — 단 하나의 인생
## 자료 원칙
- **사료**: 국사편찬위원회 조선왕조실록의 실제 기사 ID, 날짜, 왕대, 국역문을 확인해 기록한다.
- **게임 창작**: 각 기사가 각 가정에 미친 영향은 실제 역사 기록이 아니며 생활 모형의 선택·결과로 구성한다.
- **지역·연도**: 기사에 특정 지역이 있는 사건은 그 지역으로 제한한다. 전국 논의는 모든 지역에서 *소식을 듣는 형태*로 연결하며, 모든 고을에 동일한 행정이 시행되었다고 표현하지 않는다.
- **정책 논의 ≠ 정책 시행**: 1750년 균역 논의와 1778년 해안 방어 상소는 당시 주장과 검토를 기록한 것이지, 전국에 시행된 제도의 증명이 아니다.
- **사관의 관점**: 실록은 조정 중심의 편찬 기록이며, 여성·노비·하층민의 실제 목소리와 사망 통계 등에는 한계가 있다. 평범한 사람의 일상 재구성에는 승정원일기·일성록·지역 읍지·고문서·호적·계약문서 등도 대조해야 한다.
- **연도·기사 정확성**: 음력 일자를 서력 생월일로 허위 변환하지 않고, 서력 연도에 맞춰서만 사건을 제시한다.
- **게임 플레이 화면**: 긴 출처 설명은 접힌 '이 시절의 조선왕조실록 기록 보기'로 제공하고, 게임 속 주인공이 듣는 말은 자연스러운 생활 언어로 쓴다.

### 구현상 안전장치
- 사건이 실제 그해 일어났다고 해도, 캐릭터가 **그 사건에 직접 참여했다고 자동 단정하지 않는다**. 지역이 다른 인물에게는 사건을 제시하지 않는다.
- 노비 문권 소송·장시·군포는 최소 연령을 높였으며, 노비·상인·어부/수군/조운 관련 생업이나 농사 환경에 따라 도입 문장이 달라진다.
- 실록 기사는 출처를 밝히는 별도의 접힌 칸에만 두고, 실제 게임 선택에는 그 시대 사람이 쓸 법한 생활 문장을 사용한다.
- 시뮬레이션의 개인적 질병·사망 확률과 자원 수치는 별도 게임 규칙으로 유지하고, 기사에서 임의로 통계를 추정하지 않는다.

## 후속 확장
- 더 많은 연도의 실록 기록을 **기사 단위로 검증한 뒤** 추가한다. 검색 결과만 보고 전체 내용을 추측하지 않는다.
- 16세기 조운·역병·농사 용수, 17~18세기 전염병·호환·신분과 재판, 19세기 고을별 부세·피란 등으로 확대한다.
- 인물별 사건은 실제 문헌과 허구적 개인 생활을 엄격히 구분한다. 지역별 피해 비율과 생존률을 실록 수사 표현에서 숫자로 역산하지 않는다.
