# 《단 하나의 인생》 역사 시뮬레이션 검수와 확장 기준

검수일: 2026-10-16 · 기준: GitHub main a46d693 이후

## 검수 결과

|---|---|---|---|

### 이번 검수에서 고친 사항
1. 조선 및 식민지기의 모든 7세 아동이 학교에 다녔다고 확정 서술하던 공통 연령 기록을 교정함.
2. 1919년·1929년·1945년의 시대 사건이 `age % 4` 조건 탓에 빠질 수 있던 부분을 보완함. **사건을 듣는 것과 실제 시위에 참여하는 것은 구분**함.
3. 조선토지조사사업, 산미증식계획, 소작료 갈등, 학생운동, 한글 탄압, 전시 동원, 1945년의 가족 소식을 사건으로 추가함.
4. 징병 관련 선택은 1944~1945년의 해당 나이 남성으로 한정함. 당시 개인의 동원 여부를 임의로 확정하지 않음.
5. 일제강점기 선택 중 저장한 인생을 다시 열 때 중단된 사건이 사라지는 복원 오류를 수정함.
6. 출생 연도·성별·가계·영아 사망과 같은 값은 사료의 실제 개인 통계가 아닌 **게임용 모형**임을 유지함.

## 다음 단계: 국경을 넘는 생애의 공통 상태

지금의 `country[0]`은 출생 국가를 나타내는 값으로 사용되므로, 이를 도착 국가로 덮어쓰지 않는다. 새 이동 모듈은 다음을 별도로 가진다.

- `birthplace`: 고향과 최초의 가족·신분 (고정)
- `residence`: 실제 거주 지역, 고을/도시, 거주 시작 연도
- `movementReason`: 사행 / 상업·노동 이주 / 피란 / 피랍·포로 / 강제동원 / 가족 동반 / 귀환
- `legalAndSocialPosition`: 해당 지역의 지위 및 노동 조건; 조선의 양반·노비 신분을 외국에 그대로 적용하지 않음
- `familySeparation`: 현지 체류, 미확인 가족, 귀향·송환 시도, 고향 소식
- `historyOfMoves`: 이동 사유·길·시기·결과를 보관하여 족보와 후대 기록에 연결
- `returnRules`: 해당 시기의 입출국·사행·쇄환/속환·귀향 가능 조건을 검증
- `sourceRef`: 역사적 제약을 뒷받침하는 출처

### 허용 가능한 역사적 이동의 예

| 시기 | 방향과 이동 성격 | 필수 제약 |
|---|---|---|
| 15~16세기 조선 → 명 | 사행, 통역, 동행, 교역, 불가피한 표류 | 사행과 일반인의 자유로운 해외 정착을 혼동하지 않음 |
| 15~17세기 조선 ↔ 여진 지역 | 변경 무역·접촉·피랍·이주 사례 | 여진을 단일한 국가로 고정하지 않고 시대와 여러 집단을 구별 |
| 1592~1598 조선 → 일본 | 임진왜란 피로인, 장인·민간인 납치 | 자발적 이동으로 표시하지 않고 귀환 시도와 현지 정착의 차이를 기록 |
| 1627 조선 → 후금, 1636~1637 조선 → 청 | 포로, 속환, 도피 또는 일부 공식 접촉 | 후금과 청의 명칭·형성 시기 구분, 귀환을 자동 보장하지 않음 |
| 1902년 말~1905 대한제국 → 하와이 | 모집을 통한 노동 이민, 가족 이주 | 1903년 1월 도착·계약노동·편지·임금·가족 이산, '일제강점기 강제동원'과 별개 |
| 1939~1945 식민지 조선 → 일본 등 | 정책의 변화에 따른 노동 동원·강제동원 | 연도별 법령과 강제의 양상, 젠더·나이·가족의 선택권을 섞지 않음 |

`residence`가 해외일 때는 조선 농사·마을·관아·군역 등의 국내 사건을 그대로 진행시키지 않아야 한다. 국내의 역사 연표는 고향 소식으로만 전달할 수 있으며, 현지 노동·차별·언어·거주지·돈·가족 관계를 별개로 처리한다. 귀환 여부는 플레이어 선택에 따라 무조건 성립하지 않는다.

## 고려 918~1391 출생 구현 순서

1. 먼저 고려 전용 연표와 사회 상태(`OneLifeGoryeo`)를 만들고, 조선용 `J.isJoseon`과 별개의 활성 조건을 사용한다.
2. 시대를 최소한 고려 전기(918~1170), 무신정권(1170~1270), 원 간섭기와 후기(1270~1392)로 나눈다.
3. 고려의 신분·향리·문벌·무신·전시과·농민·노비·불교·장인·상인 등은 **조선의 양반·삼정의 문란·암행어사**를 붙여 넣지 않는다.
4. 958년 과거제, 993~1019년 거란과의 전쟁, 1170년 무신정변, 1231년 몽골 침입, 1270~1273년 삼별초, 1388년 위화도 회군, 1392년 왕조 교체를 연도·지역과 연결한다.
5. 1392년 이후 생존한 고려 출생 인물은 그 이전의 가족·재산·법적 처지를 지닌 채 왕조 교체를 경험해야 한다. 시대 이름만 바꾸면 안 된다.
6. 전용 출생 설정, 주거·의복·인물 이미지, 결과 기록, 세대 계승, 저장·복원, 자동 선택 검사를 통과한 이후에만 시작 연도 최소값을 918로 내린다.

## 검수 완료 판정 기준

- 시대·지역·나이·성별 제약이 사건별로 유효하고, 역사 연표는 개인의 확정 행위로 오인되지 않을 것.
- 사료의 확인 가능한 연도와 등장인물의 상상 속 사연을 분리할 것.
- 출생 → 혼인·출산 → 사망 → 자녀 승계에서 이름과 가족관계가 안정적일 것.
- 국내·국외 생활 사건이 동시에 충돌하지 않을 것.
- 강제동원, 피랍, 포로, 장애·부상·낙인과 같은 소재를 가볍게 보상·벌점으로 단순화하지 않을 것.
- 신구 저장파일 복원, 시대 전환, 모바일 선택 UI, 100회 이상 연속 자동 진행을 확인할 것.
