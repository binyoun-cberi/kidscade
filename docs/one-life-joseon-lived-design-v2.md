# 단 하나의 인생 — 조선 시대 몰입형 서사 검수 (2026-10-14)

## 디자인 원칙
- '왜 조선에 고춧가루가 없었는가' 설명 대신, 당시 식탁에 등장했을 법한 음식을 실제 장면으로 묘사한다.
- 앞날을 알고 있는 게임 개발자의 문장을 주인공 삶에 끼워 넣지 않는다.
- 직업의 성실한 지속이 기본이고, 유학·이주·신분 변화·가족 사정·빚·재난 등의 맥락이 있을 때 새로운 일의 갈림길이 생긴다.
- 직업 선택 수를 부풀리기보다 동일한 생업에서 맞닥뜨리는 인물·기술·가족·부세·농사·겨울·질병·상속에 선택을 배분한다.
- 선택에 따른 건강/살림 점수는 엔진 내부에 유지하되, 조선 인생 기록은 심정과 일상을 서사 문장으로 보여 준다.
- 모바일 화면은 위아래 서책 흐름으로 읽히도록 하고, 장황한 이중 그리드·비좁은 측면 칸·한 글자씩 세로로 깨지는 현상을 방지한다.

## 토지 표시 원칙
- 전근대 국가의 결부법: 1결 = 100부; 1부 = 10속, 1속 = 10파.
- 결은 영구 불변한 면적이 아니라 수확/세 부담 능력과 토지 등급을 반영해 계산하는 단위다.
- 기존 엔진의 `j.land`는 추상적 생계 자원으로서 **토지 면적이나 실측값이 아니다**.
- 이번 화면은 이야기 속 가구 규모 예시를 위해 내부 토지 단위 하나를 10부에 대응시킨 **창작형 전답 장부**를 사용한다. 기존 숫자 5를 5결이라고 직접 표시하지 않는다. 실재 조선 가계의 소유면적, 양안 기록, 통계에 대한 주장이 아니다.
- 더 정밀한 재구성을 위해선 토지 종류/비옥도/경작권/소유권/지역별 양안 사례를 별도 모델로 만들어야 한다.
