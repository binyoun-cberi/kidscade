# 《단 하나의 인생》 v17 — 족보에서 가족의 삶으로 갈아타기

## 이번 기능
- 게임 중 또는 인생 종료 화면에서 **족보 → 가족 이름 → '이 인물의 삶으로 갈아타기'**로 시점을 변경한다.
- 살아 있고 실종 상태가 아니며, 현재 연도에 만 12~95세인 가족을 선택할 수 있다. 이 기능은 조선 시대(1392~1897년)에서만 작동한다.
- 딸·아들·형제자매·방계에서 생긴 가상 후손을 포함하되 배우자·사망자·미래에 태어날 사람을 살아 있는 혈연 후계자로 잘못 표시하지 않는다.
- 플레이 중이던 인물은 독립된 `Life.snapshot()`으로 보관한다. 다른 식구의 관점에서 다시 돌아올 때 건강·선택·직업 등 **개인 기록을 섞지 않는다**. 족보의 사람 ID 및 관계는 공유한다.
- 방계의 가상 인물로 처음 전환할 때에는 해당 인물의 태어난 해·이름·성별과 족보에 기록된 부모·형제·배우자·자녀를 사용해 새 Life를 만든다. 그 이전의 인생에서 실제로 선택하지 않은 역사 이벤트를 임의로 재생하지 않는다.
- 누군가를 플레이하는 동안 다른 사람의 인생에 수년이 흐르면, 나이는 **현재 연도로 맞추되** 비플레이 기간의 일은 '상세히 기록되지 않았다'고 표시한다. 미래에서 과거로 되돌아가 선택을 다시 쓰지 않는다.
- 돌아오는 인물마다 실제 기록한 로그와 능력치를 독립적으로 불러온다. 게임의 **한 개 저장 칸 안에 최대 10개의 과거 인물 별도 저장본**을 보관한다(용량·성능 제한). 10개 초과 시 가장 오래된 플레이어 인물 저장본을 제거하지만 족보 자체는 남는다.
- 선택한 인물이 생을 마치고 자녀의 인생을 이어 갈 때도 다른 친척의 인물별 저장본이 유지되도록 `carryToSuccessor` 경로를 추가했다.
- 서버를 추가하지 않고 기존 브라우저 저장 구조에 호환한다. 옛 저장에 인물별 보관함이 없어도 이전처럼 인생을 재개할 수 있다.
- 버튼은 실제 전환 가능한 인물에게만 노출하며, 사망·실종·연령·시대 제한에 따라 이유를 안내한다.

## 역사·시뮬레이션의 범위
- 캐릭터별 상태는 **역사 속 가상의 삶**이며 실존 조선 인물의 전기가 아니다.
- 시점을 바꾸어도 다른 가구가 해마다 독립적으로 복잡한 사건·혼인·질병·국가 정책을 경험하는 완전한 병렬 세계 시뮬레이션은 아니다. 해당 기간의 개인 기록에는 공백이 생긴다.
- 한 가문의 재산과 직업 상태를 두 명이 완전히 동일하게 공유하지 않는다. 방계의 초기 재산은 이야기용 가상 출발값이며, 현실의 재산분할 비율이나 역사 통계가 아니다.
- 부모나 후손으로 전환 시 기존 가족관계는 족보에서 확인되는 관계만 사용하며, 유전적 질환·정신적 피해를 확정적으로 복제하지 않는다.
- 1898년 이후 탄생한 인물이나 근대·현대 시대로의 전환은 시대별 가족·사회 제도 규칙의 추가 정비가 필요해 현재 제한한다.

## 검수
- 일대일 전환과 다시 돌아오기, 3인 사이 반복 전환, 타인 기록과 본인의 건강·기록의 독립성.
- 저장/불러오기 후 인물 보관함 복원 및 중첩 보관함 생성을 막는 검사.
- 사망·실종·미성년·시대 밖 상태의 비활성화.
- 플레이 중 자녀로 이어갈 때 이전 친척의 저장본 보존.
- 150개 조선 생애 자동 진행, 기존의 족보·전쟁·포로·세대 계승 회귀 테스트.
