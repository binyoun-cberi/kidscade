# 상황·선택·결과 서술 3.34

## 가족 사건

부모 돌봄, 자녀의 배움과 생업, 배우자와의 살림, 형제자매의 부탁에 상황 설명과 행동별 결과를 작성했다. 이름·성격·직업 상태를 이어 붙인 설명과 ‘사건 제목 — 선택지’ 형태의 결과를 교체했다.

- 일손을 돕는 선택은 자기 일을 비우는 비용을 살림에서 실제 차감한다.
- 곡식과 돈을 보내면 가진 양까지만 보내고, 무엇을 보냈는지 저장한다. 둘 다 없으면 형편을 설명하고 안부를 살피는 선택으로 바뀐다.
- 문해 경험이 없는 부모는 아이에게 직접 글을 가르치는 대신 가르침을 구한다.
- 단순 대화·선물·격려에는 자동 후일담을 붙이지 않는다. 전달 물품·자녀 학습·거처·집안 일손처럼 확인할 상태가 있는 분기에서 후속 기록을 남긴다. 과거 저장의 기존 기록은 보존한다.

## 생업 사건

서당·주막·어업·대장간·장사·의료에서 51개 선택에 구체적인 결과 문장을 작성했다. 예를 들어 ‘그물을 손질한다’의 결과는 ‘고기가 빠져나가던 그물의 구멍을 기웠다’로 기록한다. 사건 제목과 고른 선택은 별도 기록 항목에 유지한다.

재료·비용·벌이 변화는 기존 계산 결과를 사용하여 한 결과에 합친다. 손해가 났는데 성공 문장을 붙이지 않는다. ‘식재료을’ 같은 조사를 받침에 맞게 처리한다. 모든 생업 선택을 개별적으로 다시 쓴 것은 아니며, 나머지 선택에는 실제 자원 변화 중심의 서술이 남아 있다.

## 결말

모듈별 최종 요약과 자원 개수를 이어 붙이던 본문을 실제 사건의 시간순 발췌로 교체했다. 생애를 여섯 시기로 나누고, 각 시기의 주요 사건을 하나씩 골라 최대 여섯 장면을 보여준다. 같은 원인·같은 문장 중복을 줄이고, 선택 제목만 있는 옛 로그나 미래형 예고 문장은 결말 본문에서 제외한다. 원본 기록을 지우지는 않는다. 상세 선택·족보·재산은 각각의 화면에서 확인할 수 있다.

출생 배경의 잘못된 조사 결합과 취미를 고를 때의 ‘훗날 기억하게 될 것이다’ 예고도 정리했다.

## 검증

- 실제 페이지 순서의 엔진으로 704명 완주, 진행 오류 0건.
- 가족 자원 전달량·자원이 없는 경우·일손의 비용·부모 문해·저장 복원 및 결말 시간순/중복 검사를 추가했다.
- 기존 가족·생업·화면 검증 25개 통과, 새 서술 검증 4개 통과. 전체 검사 결과는 PR에 기록한다.
- 모든 시대의 모든 모듈에 대한 문장 개편은 아니며, 이번 범위 밖의 전쟁·관아·신분·근현대 사건에는 기존 문장이 남아 있다.
