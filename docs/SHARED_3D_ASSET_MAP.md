# Kidscade 공용 3D 자산 정리

2026-09-29 추가된 GLB 69개를 게임별 복사 없이 공용으로 재사용하기 위한 기준입니다.

## 원칙
- 원본 GLB는 현재 `assets/`에 보존합니다.
- 게임 코드는 `assets/game/manifest/shared-community-3d.js`의 논리 ID를 통해 참조합니다.
- 같은 나무·바위·가구를 여러 게임 폴더로 복사하지 않습니다.
- 필요한 자산만 지연 로딩합니다. 특히 `prop.tinCan`은 약 16.6MB라 최적화 전 자동 로딩 대상에서 제외합니다.
- 1MB 이상 동물/캐릭터는 한 화면에 대량 생성하지 않고 필요 시 로드·복제합니다.

## 핵심 묶음
- `ecopolis`: 식생, 바위, 수생생물, 야생동물, 풍차·물탑
- `farm`: 헛간, 닭장, 사일로, 울타리, 우물, 작물, 가축
- `world`: 집, 문, 계단, 침대, 욕실·주방·가전
- `npc`: 남녀 NPC 7종
- `enemies`: 외계인, 악마, 슬라임, 뱀, 거미
- `trade`: 범선, 상자, 당나귀, 말

## 우선 적용
1. 에코폴리스 — 생태 수치를 실제 개체 수와 식생 변화로 시각화
2. 키즈케이드 월드 — 가구·가전 확장
3. Ranch 계열 농장게임 — 이번 묶음을 기본 자산팩으로 사용

## 출처/라이선스 메모
사용자가 Pixabay에서 수집해 업로드한 자산 묶음이며 파일명에는 Quaternius/Plaggy 및 cc0 표기가 보존되어 있습니다. 정확한 개별 원문 URL이 없는 파일은 자산 자체를 별도 팩으로 재배포하지 않고 Kidscade 게임 구성요소로만 사용합니다.


## 시각 QA 원칙
새 GLB는 파일이 존재한다는 이유만으로 자동 배치하지 않습니다.

1. X/Z 중심점 보정 후 바닥면을 Y=0에 맞춤
2. 게임 장면에서 크기와 회전을 확인한 자산만 `approved`
3. 재질이 무채색으로 보이거나 피벗/바운드가 이상한 자산은 `review`로 격리
4. 스킨/애니메이션 동물은 일반 `.clone(true)`로 대량 배치하지 않고 별도 검증
5. 지나치게 큰 파일은 `blocked` 처리
6. 기존 검증된 Kenney 자산을 무리하게 새 모델로 교체하지 않음


### repair 상태
재질이 비어 있거나 무채색이지만 메시 구조를 게임에서 활용할 수 있는 자산은 `review`가 아니라 `repair`로 승격합니다.

- `vehicle.schoolBus`: Kidscade 스쿨버스 팔레트로 차체/유리/타이어/금속/조명을 런타임 재채색한 뒤 사용
- `building.house`: 폐허 주택 팔레트로 벽/지붕/목재/유리/장식을 재채색한 뒤 사용
- 원본 텍스처가 있는 재질은 텍스처를 보존하고 색상 계수만 적용
- 재질/메시 이름을 이용해 부위를 판정하며 이름이 불명확하면 안전한 기본 색상으로 처리
- `blocked` 자산은 색상 보정 여부와 관계없이 자동 사용하지 않음


## 현재 실제 적용처
- 운전면허시험장: 시험 코스 바깥 식생·바위·우물·물탑 + repair 스쿨버스/주택
- 드론조종사 시뮬레이터: 비행장 외곽 수종 다양화·바위·풀·물탑·repair 주택
- 경찰차 시뮬레이터: 공원 수종 다양화·물탑·주차 스쿨버스·외곽 repair 주택
- 벽란도 상행기: 시대에 맞는 상자·우물·통나무·이끼바위만 보조 배치

현대 차량·현대 시설은 벽란도에 사용하지 않으며, 색/피벗 문제가 확인되지 않은 가구·캐릭터류는 아직 자동 배치하지 않습니다.
