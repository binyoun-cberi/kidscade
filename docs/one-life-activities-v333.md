# 생활 동작 3.33

- 300ms 간격 6자세로 생활 동작을 반복한다. 나이가 흐르는 속도와 별개이며 기존 화면 타이머에서 픽셀 장면만 갱신한다.
- 농사 생업의 인물은 밭 쪽에서 몸을 굽혀 호미질한다. 손·자루·날을 같은 자세 좌표로 그린다.
- 포구의 어부는 그물을 손질하고, 글을 배운 인물은 배움 장면에서 책장을 넘긴다.
- 성인 식구는 바구니를 들고 손을 움직인다. 관직·군역 인물은 마당 안에서 짧게 걸으며 양발과 팔을 교대로 움직인다.
- 아이는 손짓과 발 움직임, 영아와 노년은 쉬는 자세를 사용한다. 포로의 성인 동작도 쉬는 자세로 제한한다.
- 선택 대기·일시정지·화면 비활성 중에는 새 프레임을 그리지 않는다. 운영체제의 동작 줄이기 설정에서는 정지 그림을 유지한다.
- 이 동작은 분위기를 위한 짧은 반복 표현이다. 실제 이동 경로 찾기나 물품 생산·수확을 수행하는 시스템은 아니다.

검증: 관련 13개 검사 통과. 농사/어업/문해/나이별 동작 및 반복 주기, 호미질 발 고정, 프레임 사이 실제 상태 불변, 화면 컨트롤러 완주를 확인했다. 전체 검사는 419개 중 399개 통과/20개 기존 실패였으며 이후 추가한 상태 불변 검사는 관련 검사에서 별도로 통과했다. 손·소품 변경 후 픽셀·화면 검사도 다시 실행했다. 실제 캔버스 명령으로 호미질·책 읽기·그물 손질·짧은 걸음의 여러 프레임을 렌더링했다. 운영 사이트 브라우저/배포 확인은 하지 않았다.
