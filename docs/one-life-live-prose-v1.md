# 플레이 중 문장 편집 · 2026-10-23

## 확인한 문제와 변경

1. 고려 생활문이 직업 이름 뒤에 조사를 고정해서 붙였다. 그래서 “삼베 짜기과”가 나왔고, 직업이 없는 어린아이에게도 “아직 정해지지 않음과 식구들의 일”이 붙었다. 연간 살림은 들어온 곡식과 쓴 곡식으로 명확히 쓰고, 가족 사망은 이름의 받침에 맞게 “아버지가 / 어머니가”를 구분한다.
2. 고려의 선택은 “사건 제목 — 버튼 문구”를 그대로 출력했다. 51개 행동을 각각 과거형으로 집필했다. 비용이 모자라 실행하지 못한 선택은 완료했다고 쓰지 않는다. 청원과 혼인 허락 요청을 승인으로, 목화 시험을 수확으로 바꾸지 않는다.
3. 조선 여성 직업은 어떤 행동을 해도 “제목 일을 마쳤다. 경험을 쌓았다”가 붙었다. 산파·의녀·궁녀·관기 12개 장면의 36개 선택에 별도 결과 문장을 썼다. 환자가 나았다거나 해산이 무사히 끝났다는 결과를 추가하지 않는다.
4. 근현대 선택은 행동 뒤에 현재형 설명을 붙였고, 후일담은 제목과 “경험이 영향을 주었다”를 결합했다. 10개 주제의 20개 행동을 과거형으로 집필했다. 후일담은 실제 선택 연도와 행동을 되짚는다. 옛 저장의 후일담도 식별자로 알아볼 수 있을 때는 같은 방식으로 출력한다.
5. 일부 사건 설명과 실제 선택이 맞지 않았다. 주거를 고친다는 설명에 돌봄 선택지가 붙는 경우 등을 고쳐 선택에서 실제로 정하는 일을 설명한다. 사건 ID·선택 순서·효과는 유지한다.
6. 조선 직업의 후일담에서 제목을 문장에 끼워 넣어 “짐을 잃다을”처럼 틀어지는 부분을 없앴다. 위험·학습·방법 변경의 후일담도 셈·확인·질문처럼 행동이 보이게 썼다. 실패한 일은 뒤늦은 성공담으로 바꾸지 않는다.
7. 현대 일상에서 갑자기 “나도 / 내 시간 / 아껴 써야겠다”로 바뀌던 서술 시점을 정리했다. “유동성 보존 / 순자산 감소” 같은 선택 안내를 일상적인 말로 바꾸고, 추상적인 작은 성취는 실제 행동으로 썼다.

## 문장 예시

- 이전: `몸조리를 도울 사람 일을 마쳤다. 배운 방법을 확인하고 경험을 쌓았다.`
- 변경: `가족이 번갈아 산모 곁을 지키도록 돌볼 시간을 나누었다.`
- 변경: `의서를 펼쳐 스승에게 들은 설명과 맞춰 보았다.`
- 변경: `장부와 약재 수량을 다시 맞춰 보고 차이 나는 부분을 보고했다.`
- 변경: `통장에 예상보다 돈이 적게 남아 있었다. 다음 달에는 어디서 지출을 줄일지 적어 보았다.`

문장만 바꾸는 3회 이내의 검수 흐름으로 진행했다. 1차는 조사·시제·공통 틀, 2차는 행동별 집필과 설명/선택 일치, 3차는 실제 생성문·상태 비교와 회귀 검사였다. 별도 에이전트나 외부 AI API를 실행하지 않았다.

- `node --test --test-concurrency=2 tests/one-life-*.test.cjs` — 84개 파일, 675개 검사 통과, 실패 0개. 생애 전기와 컨트롤러 출생→사망 모의 검사도 포함한다.
- 신규 8개 검사는 고려 행동 문장 51개, 미실행 선택, 조사/어린이 살림 문장, 여성 직업 36개 선택의 실제 처리와 비용·숙련·진행, 근현대 20개 문장, 옛 저장 후일담, 문장 검수기와 현대 안내를 확인한다.
- `node scripts/audit-one-life-live-prose-v1.cjs 7c261273b35fb94740c9930a8568389a3b1488b0 /tmp/live-prose-report.json` — 1210·1270·1350·1580·1740·1880·1919·1950·1980·2026년생 각 12명, 일부 인도 출생 포함. 편집 전과 동일한 시드·선택 방식으로 120개 생애를 각각 완주해 비교했다. 그 기준 커밋의 대상 6개 게임 모듈은 이번 편집 전 main과 동일하다.
- 선택 4,090회, 로그 26,997개 중 2,784개 문장 출력이 달라졌다. 문장·메모의 서술 문자열을 제외한 저장 스냅샷 필드는 모두 같았다. 난수, 생사, 직업, 가족, 재고, 비용, 상태와 선택 순서는 변하지 않았다. 지정한 잘못된 문장 틀 검출은 0건이다. 이는 모든 문장이 완벽하다는 뜻이 아니다.
- 수정한 JS와 CI 목록의 `node --check`, `git diff --check` 통과.

검수기에는 고친 문장 틀을 후보로 추가했다. 문맥을 판단해 읽어 볼 후보만 찾으며 자동으로 문장을 고치지 않는다. 전기 편집기 안의 제외 규칙도 문자열 후보로 잡히므로 검수 후보 수를 오류 수로 단정하지 않는다.

## 범위와 한계

게임 ID·URL·저장 형식과 사건 효과를 바꾸지 않았다. 원래 픽셀 장면과 에셋을 재사용하며 새 이미지·유료 호출을 추가하지 않았다. Secrets 조회, 결제 변경, 학생 기록 수정과 서비스 배포는 하지 않았다.

기존 저장에 이미 들어 있는 과거 로그를 일괄 수정하지 않는다. 이후 생성되는 문장과 식별 가능한 예약 후일담부터 개선된다. 임의의 역사 기록이나 다른 인물의 생존·화해·성공을 새로 사실화하지 않는다. 전체 저장소 CI·전체 빌드·실제 수정본 브라우저 화면 검수는 별도로 남아 있다. 모든 시대의 모든 사건 문장을 이번에 재집필했다는 뜻은 아니다.
