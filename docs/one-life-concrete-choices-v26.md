# 《단 하나의 인생》 선택지 문장 기준 v26

선택지의 목적은 **친절한 사람을 고르게 하는 것**이 아니라, **한 인물이 처한 문제를 이해한 뒤 실제 행동과 대가를 결정하게 하는 것**이다.

## 새로운 작성 기준

1. **사건: 무엇이 문제인가?** 위치·당사자·부족한 자원·갈등을 구체적으로 묘사한다. '힘든 일이 있었다'처럼 상황이 없는 사건을 피한다.
2. **버튼: 누구에게 무엇을 어떻게 할 것인가?** '이웃을 돕는다' 대신 '기다리는 이웃집에 쌀과 장작을 가져간다', '기록한다' 대신 '납부한 세곡의 수량과 날짜를 장부에 적는다'.
3. **보충 설명: 왜 그 일을 하나? 무엇을 잃을 수 있나?** 바로 해결하지 못하는 문제, 이동 시간, 노동력·곡식·돈·관아의 압박을 명시한다. 위험하지 않은 선택까지 무작정 위험하다고 하지 않는다.
4. **선택 결과: 실제로 무엇이 생겼나?** 문서·전달한 주소·나눈 곡식·교대 순번·달라진 관계처럼 확인 가능한 변화를 기록한다. 편지를 쓴 것과 답장을 받은 것은 별개로 처리한다.
5. **훗날의 의미: 당시 생긴 상태를 나중에 불러오는가?** 이전 PR의 지속 기록(문서·이웃·배움·식량·가족 소식), 포로 인맥·손기술, 관아 증거 등을 사용한다. 사건 한 번으로 모든 문제가 해결되었다고 쓰지 않는다.

## 좋지 않은 문장과 교정

| 피할 표현 | 선택 문구 | 이유와 부담 |
|---|---|---|
| 가족을 챙긴다 | 떠난 뒤 식구가 먹을 곡식과 품일을 나누어 정한다 | 한 명의 일손이 줄어 무엇부터 해야 할지 정해야 한다 |
| 이웃을 돕는다 | 징용 통보를 받은 집에 쌀과 장작을 가져간다 | 이웃의 빈 일손을 메우는 대신 자기 집 양식이 준다 |
| 기록을 남긴다 | 토지 문권과 신고 장부의 이름·경계를 대조한다 | 향후 소작료 분쟁 때 앞서 낸 내용을 확인하려 한다 |
| 귀향을 돕는다 | 사절이 왔을 때 전할 고향별 희망자 명단을 모은다 | 누가 실제로 돌아갈지는 교섭과 상황에 달려 있다 |

## 이 단계의 실적과 범위

- 식민지 생활: 20개 사건, 60개 선택지 전면 교정
- 일본·후금·청 피로생활: 11개 사건, 33개 선택지 교정
- 조선 마을 생활: 12개 사건, 36개 선택지 교정
- 조선 관아 생활: 12개 사건, 36개 선택지 교정
- 합계 **55개 사건·165개 선택지**에 구체적인 행동·이유·지속 결과를 작성했다.
- 선택지 설명의 명도·행간·글자 크기를 올려 모바일에서 읽기 쉽게 조정했다.
- 현장 선택과 모순되던 가축 감소, 곡식 감소, 귀환자의 선택 탓으로 낙인을 부여하는 처리를 수정했다.

## 아직 점검할 내용

다른 조선 사건 모듈(v3, v5~v7, v11~v13, v18)에 남은 추상적 선택 문구는 단계별 검수 대상이다. 무작위 연령/지역/신분, 가족 존재·임신 상태, 전쟁과 포로, 저장 복원, UI 노출을 매 버전의 회귀 검사로 점검한다. **문장 길이를 늘리는 것만으로 게임의 인과관계가 생기지는 않는다.** 후대의 직업·혼인·생존·재산·이주 등 굵직한 변화로 이어지는 시스템은 이어서 보강할 과제다.
