# 키즈케이드 게임별 개선 이력

이 폴더는 일반 Chat에서 작업이 끝난 뒤 **다음 Chat이 이어서 개발할 수 있도록** 근거와 남은 문제를 남기는 곳입니다. 자동 실행 서비스가 아니며, 모델/API 호출을 추가하지 않습니다.

## 파일 규칙

- 게임을 특정할 수 있으면 `data/games.json`의 **실제 게임 ID**를 찾아 `docs/improvement-logs/<game-id>.md` 파일을 만듭니다.
- 이름만 알 때는 먼저 카탈로그/기존 코드를 확인하고 ID를 찾습니다. 추정 ID로 중복 로그를 만들지 않습니다.
- `TEMPLATE.md`를 복사해 시작합니다. 기존 로그가 있으면 새 파일로 덮어쓰지 말고 맨 위의 '현재 상태'와 맨 아래 '작업 기록'을 업데이트합니다.
- 다수 게임에 공통인 변경은 작업 범위와 영향을 받은 게임 ID를 기록하고, 필요하면 각 게임 로그를 연결합니다.

## 모든 키즈케이드 개발 요청에서

1. 먼저 `AGENTS.md`, `docs/CHAT_AGENT_WORKFLOW.md` 및 기존 게임 로그를 읽습니다.
2. 실제 코드/테스트 결과를 기준으로 작업합니다. AI의 비평은 가설이며 테스트 성공을 대신하지 않습니다.
3. 하나의 Chat에서 **최대 3회의 이유 있는** 수정→검증 사이클을 진행합니다. 코드를 못 고쳤거나 검증할 수 없었다면 그 사실을 남깁니다.
4. 작업 마지막에 요청, 기준 상태, 개선 내용, 테스트 명령과 실제 결과, 미완료 사항, 다음 한 걸음, PR URL을 기록합니다.
5. 로그 작성 자체를 게임 구현·테스트 완료로 간주하지 않습니다. 사용자 허락 없이 main에 병합하거나 배포하지 않습니다.

## 상태 값

- **검증됨**: 실행된 검증의 명령/환경/결과가 기록됨 (검증 범위만 유효)
- **부분 검증**: 특정 범위만 통과, 다른 검증은 미실행
- **미검증**: 코드 또는 문서 변경은 했으나 실행 검증 없음
- **차단됨**: 환경/권한/실패 등으로 진행 불가, 원인 기록

## 기록 금지

학생 개인정보, 계정 정보, API 키, GitHub/Cloudflare 비밀정보, 유출 가능한 실행 로그, 결제정보를 기록하지 않습니다. GitHub Actions 및 Cloudflare 기존 배포 경로를 유지합니다.
