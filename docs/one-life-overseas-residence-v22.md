# 《단 하나의 인생》 해외 거주와 가족 이산 v22

## 실제로 플레이 가능한 1차 경로

- **조선 → 명나라 사행**: 1420~1590년, 관청·글공부·통역 연계 인물 가운데 성인에게 드물게 제안. 참여는 자발적으로 선택하며 정해진 공무 뒤 귀환한다. 사신·수행원은 일반인의 자유로운 해외 정착과 다르다.
- **대한제국 → 하와이 초기 노동 이민**: 1903~1905년에만 신규 출발 선택이 나타날 수 있다. 현지에서 노동, 동포 모임, 편지와 귀국 경로를 경험한다. 수입·품삯 숫자는 게임용 수치이며 실제 달러 임금과 다르다.
- **임진왜란 일본 피로인 / 정묘·병자호란 후금·청 포로**: 기존 `joseon-v14-captivity-generations.js`가 사건·선택·귀환을 담당하고, 새 거주 기록창은 **읽기 전용**으로 동일 인물을 보여준다. 포로의 이동 이유를 노동 이민이나 사행으로 바꾸지 않는다.

## 생활 분리 규칙

1. 출생 국가 `country[0]`, 출생연도, 집안 성씨는 이동해도 바뀌지 않는다. 새 `travel22.residence`에 현재 지역과 이동 사유를 둔다.
2. 자발적 해외 체류 중에는 `Sim.advanceCoreYear`로 기본 연령·생존만 진행한다. 국내 조선 농사·군역·관아·세금·세계9형 국내 주택·직업과 연례 경제 사건은 건너뛴다. 기본 엔진의 일반 생활 서술은 기록에서 제외하고 현지 생활 이야기를 기록한다.
3. 명나라 사행은 정해진 때 귀환한다. 하와이는 귀향을 시도할 수 있지만 무조건 성공하지 않는다. 장기 체류와 귀향은 가족 기록에 남는다.
4. 일본·후금·청 포로생활은 기존 전쟁 모듈에 보관된다. 귀환 이후의 낙인·생업·몸 상태를 해외 이민 수치로 바꾸지 않는다.
5. 전용 `travel22:` 선택지는 시점과 경로를 검증해 저장·불러온다. 이전 저장 파일에는 영향이 없다.
6. `residence` 필드가 있는 기존 혹은 새 저장 파일은 출생 국가나 현대 국가의 국경을 덮어쓰지 않는다.
7. 이동·소식·현지 노동은 확률적 이야기로서 실제 역사 인물의 개인 사실을 증명하지 않는다.
