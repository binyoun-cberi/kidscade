# 생애 기록과 역사적 역할 구분 3.28

## 수정 내용

- 근현대 인물에 조선 수감 처리 코드가 실행되어 기록을 삭제하고 예외를 일으키던 조건을 수정했다.
- 혼인 선택 직후 배우자를 가족 및 족보에 반영한다.
- 수군 가계는 가족 배경으로 유지하되 여성 본인의 군역 직업으로 변환하지 않는다.
- 조선 여성에게 전문 서당 훈장 경로를 배정하지 않는다. 문해와 학습 경험이 있는 경우 집안에서 글을 알려주는 선택을 별도로 제공한다. 여성의 모든 교육 활동을 부정하는 규칙이 아니라, 현재 남성 훈장용으로 구성된 사건 경로를 제한하는 규칙이다.
- 기존 여성 훈장 저장은 현재 직업과 대기 사건을 정리하되 과거 기록은 새로 만들지 않는다.
- 남아 복식을 바지로 구분하고, 관계 점수 상승을 새 인물 등장으로 표현하지 않는다.
- 결말에서 새 모듈의 선택과 사건을 포함하고 생애 전반을 추린다. 누락된 과거 기록은 복원한 것처럼 꾸미지 않는다.
- 선택 카드를 기록 및 보조 메뉴 위에 배치하고 모바일 출생 제목과 결말 문단을 줄인다.
- 후계자 전환의 존재하지 않는 clamp 호출을 기존 clip 함수로 수정한다.

## 검증

실제 index.html의 스크립트 순서를 읽는 통합 회귀 검증을 추가했다. 1905·1919·1950·2026년생의 완주와 35세 저장 복원, 혼인 직후 배우자 및 족보, 여성 수군/훈장 방지, 이전 저장 이행, 복식과 신형 사건의 결말 수록을 검사한다.

관련 검사 47개 통과. 전체 검사와 수정 전 기준 검사를 비교해 기존 실패와 신규 실패를 구분했다. 전체 검사 410개 중 389개 통과, 21개 실패였다. 그중 문단 렌더링 변경을 반영하지 못한 정적 검사 1개를 수정했으며, 나머지 20개는 수정 전에도 실패한 항목이다. 수정 전은 406개 중 377개 통과, 29개 실패였다. 실제 모바일 화면의 변경 후 브라우저 시각 검수와 운영 배포 확인은 별도 필요하다.
