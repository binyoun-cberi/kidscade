# Kidscade 게임 분류 기준

Kidscade의 연령 필터는 게임의 그림체가 아니라 **학습 내용, 조작 복잡도, 읽기 부담, 전략 깊이**를 함께 보고 주 이용층을 정한다.

## 연령/모드 기준

### `toddler` · 유아 (3~6세)
- 글을 읽지 않아도 핵심 규칙을 이해할 수 있다.
- 한두 번의 터치·드래그·관찰·색/모양 맞추기가 중심이다.
- 여러 단계 추론, 복잡한 수 계산, 긴 설명, 모드 전환이 핵심이면 유아로 두지 않는다.

### `low` · 초등 저학년 (1~3학년)
- 기초 수 개념, 덧셈·뺄셈·구구단·초기 나눗셈, 돈·길이·무게 등 생활 수학을 다룬다.
- 기초 한글·타자·알파벳·초급 한자와 단순한 리듬/미술 활동을 포함한다.
- 조작은 비교적 직관적이고 긴 전략 설명 없이 시작할 수 있는 게임을 우선 배치한다.

### `high` · 초등 고학년 (4~6학년)
- 분수·소수·약분/통분·도형 성질·각도·넓이·약수/배수 등 심화 개념을 다룬다.
- 역사·지리·경제처럼 배경지식이 많이 필요하거나, 여러 자원을 동시에 관리하는 전략/시뮬레이션을 포함한다.
- 학습 내용이 쉽더라도 조작과 규칙이 여러 단계이고 실패 원인을 스스로 분석해야 하는 고난도 퍼즐은 고학년에 둔다.

### `job` · 직업체험
- 핵심 플레이가 특정 직업이나 가게/서비스 운영을 체험하는 게임이다.
- 단순히 생활 소재가 등장한다고 직업체험으로 분류하지 않는다. 예: 모기 생존 게임은 직업체험이 아니다.

## 분류 원칙

1. **교육 내용이 명확한 게임은 교육 내용의 학년을 우선**한다.
2. 교육 내용이 없는 창작·액션·퍼즐은 조작과 규칙의 복잡도로 판단한다.
3. 귀여운 그림체만으로 `toddler`에 넣지 않는다. 4×4 슬라이딩 퍼즐이나 지뢰찾기처럼 추론이 필요한 게임은 상위 그룹으로 보낸다.
4. 게임 ID의 `low_`, `high_`, `tod_` 접두사는 과거 파일 식별자일 뿐이다. 즐겨찾기/최근 기록 호환 때문에 ID를 바꾸지 않고 `age`가 실제 분류의 기준이다.
5. 한 게임은 현재 하나의 대표 연령 그룹에 둔다. 여러 학년이 즐길 수 있어도 **처음 접했을 때 가장 자연스러운 주 이용층**을 선택한다.
