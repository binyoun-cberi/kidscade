# 《단 하나의 인생》 조선 여성 생애 3.27 — 전문적인 일·사별 이후·재산 문서

## 범위
조선기 출생 여성에게만 적용. 기존 3.26의 배움·길쌈·장사·친족·기록을 유지하면서 **여성 전문 생업 4개**, 재혼을 포함한 **사별 이후 단계적 선택**, **증빙 기반 재산 분배**, **실제 출생 기록에 연계된 산후 돌봄**을 연결한다. 기존 가족 생사·출생은 `joseon-v4.js`가 관리한다.

### 생업과 진입

| 일 | 선발 / 학습 조건 | 전개 |
|---|---|---|
| **의녀** | 1406년 이후, 어린 공노비 가계 및 중앙 관서 소속; 11~14세 기회 | 관청이 배치할 수도 있고 실패할 수도 있음 → 의술·여성 환자·약재 장부 |
| **궁녀** | 조선기 중앙 관서 소속 공노비 가계; 청소년기 배치 | 궁중 의복·물품·궁녀 교육. 근무 중 보통 혼인 분기 제한 |
| **관기** | 지방 관아에 소속된 공노비 가계; 13~18세 선발 사건 | 소리와 춤·동료와 행사·가락 전수 |
| **마을 출산 돌봄(산파 역할)** | 성년 양인 여성, 실제 돌봄 경험 등; 청소년기에 관직 자동 임명 금지 | 배우기 → 출산 돌봄과 산후 조력 → 경험 전수 |

특히 **관기·의녀·궁녀는 단순히 여성이라서 임의 전직하거나 출생 시 모두 배정되는 직업이 아니다.** 역사적 신분과 관청 제약을 게임 규칙으로 반영한 것이다. 관아의 결정권을 묘사하며, 희박한 기회·선발 결과는 게임의 창작 난수다. 궁녀가 왕비·후궁이 되는 무작위 사건이나 미성년자에게 성적 장면을 제시하는 일은 구현하지 않는다.

### 인생의 후반부
- **사별:** 기존 배우자가 실제로 죽고 `v326` 사별 선택을 거친 경우에만 거처·생업·친정 연락 문제 제시.
- **재혼:** 사별 뒤 재혼 의사를 선택하고 **2년 후** 혼담을 검토해야 가능. 첫 배우자는 가족 기록에 사망 상태로 보존하고 새 배우자를 별도 인물로 추가. 자동 혼인·자동 신분 상승 금지.
- **재산 분배:** 37세 이후 부모 사망 기록 + 3.26 문서 관심이 있을 때만 분재기·친족 증거 → 2년 뒤 확인. 증거가 충분한 경우 소량의 살림 재화만 이동; 토지·법적 소유권은 자동 창출하지 않음.
- **산후 돌봄:** 기존 가족 연대기에 **실제로 해당 연도에 자녀가 태어난 경우**에만 한 번 나타남. 별도 임신, 유산, 사망률 등을 창작하지 않고 일손·휴식·산모 도움 선택을 추가.
- **장기 경력:** 직업마다 3개 사건을 수년 간격으로 진행하고 솜씨·사람들과의 관계를 축적. 관아 소속 경력은 일정 연령 이후 근무를 마칠 허락을 청할 수 있지만 자동 퇴역·속량하지 않는다.

### 구현
- `games/high_one_life/joseon-women-v327.js`: 직업·상속·사별·기록의 실제 연도별 상태와 저장·복원.
- `games/high_one_life/joseon-v4.js`: 2차 혼인을 명시적으로 허락한 경우만 새로운 배우자 생성. 사망자 복원 금지.
- `games/high_one_life/joseon-v1.js`: 관아 소속 중 청소년 직업 및 혼인 기본 분기가 그 직책을 덮어쓰지 않도록 보호.
- `games/high_one_life/joseon-women-v326.js`: 직역 근무 중 집안 사건 잠시 정지; 재혼 후 생존 배우자를 우선 조회.
- `games/high_one_life/index.html`, `game.js`: 기존 **살아온 길과 배운 솜씨** 한 패널에서 v326·v327 직업·혼인·문서 결정과 후일담을 통합해 표시.
- `tests/one-life-joseon-women-v327.test.cjs`: 직역 권한·연령·신분, 직업 성장, 사별·재혼 연대기, 분배 증빙, 실제 출산, 저장·복원, 여성 400명 생애 QA.
- `scripts/run-ci-tests.cjs`: 새 테스트를 정규 검사에 등록.
