# 《단 하나의 인생》 조선 후기 v18 — 세도정치와 삼정의 문란

## 역사적 근거
이 모듈은 한 가정의 정확한 당시 세액을 복원하지 않습니다. 국가 제도와 실제 부당한 운영 사례를 참고한 **가상의 개인 인생**입니다.

- [한국민족문화대백과 「삼정이정절목」](https://encykorea.aks.ac.kr/Article/E0026799): 1862년 삼정이정청의 운영, 도결·부가세, 백골징포·황구첨정·족징, 환곡 허록과 개혁의 한계.
- [한국민족문화대백과 「삼정책」](https://encykorea.aks.ac.kr/Article/E0074112): 임술민란 뒤 다양한 개혁 건의.
- [한국민족문화대백과 「임술민란」](https://encykorea.aks.ac.kr/Article/E0047507): 단성·진주에서 삼남으로 확산된 항쟁과 개혁의 한계.
- [국가기록원 조선왕조실록 교육자료](https://theme.archives.go.kr/next/sillok/sub3_3.do): 19세기 중앙 권력·지방사회의 변화.

모든 지방관이 부패한 것도, 모든 고을이 같은 시기에 같은 횡포를 겪은 것도 아닙니다. 세도정치는 지방 재정 문제의 여러 배경 중 하나로 다루며 단일 원인으로 단정하지 않습니다.

## 21개 분리된 사건
| 구분 | 장면 |
|---|---|
| 전정 4 | 황폐한 논밭 징수, 도결·부당한 추가 징세, 다른 집 부담 전가, 면세지 불균형 |
| 군정 5 | 백골징포, 황구첨정, 족징, 인징, 노인의 연령을 왜곡한 군포 |
| 환정 5 | 강제 배정, 실제 분량 부족, 상한 곡식, 창고에 없는 곡식의 허위 장부, 곡식·돈의 불리한 환산 |
| 관아 3 | 아전에게 장부 조작 요구, 관아 비용 부당 징수, 증언·장부 조사 |
| 세도정치 1 | 권세가와 관직 인사·매관매직에 관한 소문 |
| 1862 2 | 임술민란과 삼정이정청 개혁 논의 |
| 1863~1865 1 | 개혁 이후에도 남은 지방 관행 |

백골징포와 황구첨정은 남자에게 매긴 부당한 군포를 가족이 떠안는 문제로 표현합니다. 소작료는 법적 토지세와 구분해야 합니다.

## 실제 시스템 구현
- 연도와 계층에 따른 별도 사건과 세 가지 누적 부담 (전정·군정·환정), 증언과 장부, 이웃의 신뢰, 탄원, 관청의 부정 가담·청렴한 선택.
- 사후 결과는 몇 년 후에도 나타나며 누적 부담은 가상의 경제·곳간 자원에 영향을 줍니다. **실제 조세율·통계값으로 오해하면 안 됩니다.**
- 아전·관료 출신의 다른 선택지와 1862년 지역별 봉기·전국 개혁 논의를 분리합니다. 개혁 이후 모든 부담이 자동으로 사라지지는 않습니다.
- 새로운 접이식 게임 UI에 전정·군정·환정 상태 및 자료 링크를 표시합니다.
- 부모의 인생에서 자녀의 인생으로 이어 갈 때 일부 미해결 부담과 남긴 기록이 계승되지만 도덕적 성향은 유전되지 않습니다.
- 기존 저장은 새 모듈 기록이 없는 경우에도 복원됩니다. 이전의 세도정치·환곡 장면은 삭제하지 않습니다.

## 앞으로 필요한 보완
1. 지방 관리 교체·고을별 재정 상태·중앙 권력의 연결을 실시간 상호작용으로 심화.
2. 기존 환곡 장부(v11)와 새 세부 장부(v18)를 합산·상계할 수 있도록 **중복 계산 방지**.
3. 각지의 1862년 봉기 경로와 지방관·아전의 구체적인 행위, 삼정이정청 개혁안의 사료 대조 강화.
4. 관리의 부정 행위나 청렴한 거절이 이후 경력·가문 관계에 미치는 장기적인 결과 확대.
