# 《단 하나의 인생》 v16 — 가지가 뻗어 나가는 족보

## 구현
- 기존 족보가 세대별 카드 명단이었다면, 이제 **부모·부부·형제와 자녀가 부모-자녀 관계선으로 갈라지는 가계도**로 표시된다.
- 모달 안에서 세대의 자녀들이 각각 하나의 독립된 가지로 이어진다. 각 가계는 **후손 접기/펼치기** 버튼으로 간단히 탐색하고, 상단의 '모든 가지 펼치기'로 초기화한다.
- 모바일은 인물 이름을 읽을 수 있는 크기를 유지한 채 **좌우 스크롤**로 여러 갈래를 탐색한다. 이름을 누르면 기존처럼 생애·부모·배우자·자녀 정보를 읽는다.
- 실제 플레이 가능한 조선 가족(v4) 및 전쟁 이력(v13)과 본관(v8), 후손 선택(v14)을 계승한다. 플레이어가 사망하고 다음 세대의 **딸 또는 아들** 중 한 명의 삶으로 넘어가면, 선택되지 않은 다른 자녀의 ID를 방계 시작점으로 등록한다.
- 방계 가족은 **간략한 게임용 가상 기록**으로, 독립된 배우자와 자녀, 다음 세대 손자녀를 제한적으로 생성한다. 직접 플레이한 인생과 구분하여 '방계의 가상 인물'로 표시한다. 새로운 배우자 및 후손의 이름은 가계 초기 seed와 기존 인물 ID를 토대로 안정적으로 생성한다.
- 원래 가족의 실존 기록처럼 주장하지 않으며, 조선 시대 문중의 실제 족보에 등재된 인물로 간주하지 않는다. 성씨·혼인·자손 기록은 시대 차이가 큰 만큼 상세한 족보 제도 재현과 구별한다.
- **세대별 기록 저장**: `genealogy15.branches`와 `familySeed`를 추가하고 기존 버전 1 저장 형태에 호환되도록 기본값을 부여한다. 게임을 저장해 다시 열거나 후손 시점에서 계속 플레이해도 기존 형제·사촌 가지를 다시 이름 지어 넣지 않는다.
- 서버 없이 로컬 게임 저장 데이터에서 확장한다. 방계 가계 자동 생성은 최대 2단계, 전체 최대 140인 기록으로 제한한다.

## 의도적인 한계
- **선택하지 않은 자녀의 삶**은 직업·질병·혼인·전쟁 등 매년의 상세한 실제 플레이 엔진을 독립 실행하는 것이 아니다. 본줄기와 대조해 볼 수 있는 가상 가족사 윤곽만 구성한다.
- 모든 방계 가문에서 자녀가 무조건 태어나는 것은 아니다. 가상 혼인·가계 확장 여부를 안정적인 seed로 정한다.
- 출생 연도와 가족 링크는 현재 게임의 데이터 범위에 기반한다. 근대 이후의 제도 차이(식민지 시기, 현대 호적·가족관계등록)는 미래 전용 모듈에서 고도화할 필요가 있다.
- 조선의 장남 중심 상속 관행을 딸이나 둘째 아들의 삶의 가치·게임 접근성을 제한하는 규칙으로 적용하지 않는다. 본관이 같다는 이유로 혈연관계를 무작정 만들어 내지 않는다.
- 일부 배경 인물의 사망 연도는 역사적 사망률이 아닌 **게임 속 가상의 이야기 수치**다.

## 새 검수
- 장남·딸·차남 각각의 집안 가지 등록, 여성 방계의 어머니 혈연 연결과 배우자 연결.
- 조상·부모·자녀 ID 중복 없음, 부모-자녀 출생연도 정합성.
- 3세대의 사이드 브랜치 영속성과 seed 안정성, 저장/불러오기 완전 동일성.
- 기존 족보 저장 파일의 무중단 복원.
- 180개 전 시대 조선 생애를 통한 회귀 테스트.
