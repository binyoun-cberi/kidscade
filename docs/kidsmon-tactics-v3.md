# 키즈몬 v3 — 개체 육성·전술 심화

## 구현한 기능

### 1. 종족 능력치 6종, 물리/특수 구분

전투 계산을 HP, 공격, 방어, 특수공격, 특수방어, 속도로 확장함.
기존 102종은 **4종 종족값이 원본**이며, 특수공격·특수방어는 타입과 역할로 파생해 생성함. 나중에 개체별 특수 종족값을 명시하면 기존 파생값보다 우선함.

- 식물·물·불·전기·얼음·정신 기술은 특수공격/특수방어 사용
- 그 외 기술은 물리공격/방어 사용
- 기존 공격 상성, PP, 레벨 1–60 범위 유지

### 2. 개체별 잠재력, 성격, 노력 훈련

- 개체값(IV) 6개, 0~15, 개체 UID에서 안정적으로 생성
- 같은 종류라도 다른 개체마다 개체값과 성격이 달라짐
- 성격 5종: 균형, 용감(공격↑ 속도↓), 신중(특수방어↑ 특수공격↓), 쾌속(속도↑ 방어↓), 집중(특수공격↑ 공격↓)
- 전투 승리 시 상대의 역할과 속성에 따라 훈련 포인트(EV 성격의 간소화) 2점까지 획득
- 훈련 상한: 능력치별 24점, 전체 72점. 효과 최대 약 7% 이내
- 파티 화면에서 실제 능력치, 잠재력, 훈련값을 확인할 수 있음
- 옛 저장 파일에 개체값이 없으면 동일한 UID에 동일한 개체값이 생성되어 재접속 시 바뀌지 않음

### 3. 전투 특성 3종

- 견고함: 처음 받는 직접 피해 20% 감소 (방어형)
- 기민함: 기술 우선도가 같을 때 속도 12% 상승 (민첩형)
- 회복 본능: HP 35% 이하에 도달하면 전투당 한 번 최대 HP 12% 회복 (균형형)

특성은 현재 종족 역할로 정해지며, 각 종족의 2개 중 선택하는 고유 특성 시스템은 차기 과제임.

### 4. 실제 전투 효과

- **받아치기:** 우선도 +2의 반격 준비. 피해 50% 차단 후 실제 받은 피해의 130%를 되돌림. 상대가 보조기를 쓰면 반격은 실패
- **덩굴 포박:** 둔화와 별도로 1회 교체 행동을 방해하는 속박 부여
- **정전기:** 기존 둔화에 18%의 1회 행동 차단(감전) 추가, 감전 연쇄 방지
- 기술 도감에 물리/특수, 반격/감전/속박 사용 조건 표기

기술 수는 **140개 유지**. 기존 기술에 전술을 추가하되 저장된 기술 ID를 변경하지 않음.

### 5. 이로치·진화 결정

- 신규 야생/스타팅 개체 생성 시 **1/256** 확률로 `shiny=true`
- 기존 스프라이트 파일을 바꾸지 않고 화면에서 색조 변형과 ✨ 표시. 시각 검수 및 종족별 고유 팔레트는 후속 과제
- 이로치는 개체값을 보장하거나 강화하지 않음
- 결정 4종: 생명의 결정(식물/물/중립), 에너지 결정(불/전기/땅), 기후 결정(바람/얼음), 사고의 결정(정신/어둠)
- 연구소에서 결정 1개를 120코인에 구매, 승리 5·10·15·20회에 각 결정 한 번 보상
- 레벨 10 이상인 **1단계** 키즈몬만, 원래부터 허용된 진화 관계에 한해 결정으로 일찍 진화 가능. 이후의 마지막 진화를 결정으로 연쇄 통과할 수 없음
- 출처가 검증되지 않아 잠긴 진화 관계는 계속 비활성
- 미리 진화한 개체도 진화형 기술은 원래 레벨 조건을 충족해야 배움

## 검증

- 개편 후 실제 엔진으로 **19,584회** 자동 대전: 실행 오류 0, 20턴 제한 9회
- 승률: 전략형 56.1%, 공격형 54.9%, 방어형 52.4%, 초보형 40.6%
- 기본 장착 기술 125개, 전체 습득 가능 기술 140개
- 관련 회귀 테스트 **37개 로컬 엔진 실행 통과**: 유전자 데이터·기술 실행·저장 호환·한 번 감전·속박·반격·진화 결정 포함
- 실제 브라우저/iPhone UI 수동 시각 검수 및 전체 GitHub CI는 별도 확인 필요
