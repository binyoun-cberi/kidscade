# 전쟁·피란·관아 결과 서술 3.35

## 전쟁·피란

전쟁 모듈의 선택 78개에 당시 행동을 담은 결과를 작성했다. 피란을 떠났다고 몇 년 뒤의 무사 귀환이나 재회를 약속하지 않는다. 실제 재회는 가족 상태가 바뀌는 기존 재회 처리에서 기록한다. 사망 위험이 현실화되면 무사히 일을 마쳤다는 문장 대신 사망 결과를 남긴다.

곡식을 나누는 선택에서 집안에 곡식이 없으면 짐을 나르는 일손 선택으로 바뀌고 몸의 비용을 낸다. 남은 곡식을 보관하는 선택에서는 곡식이 새로 생성되지 않는다. 손실·지출은 선택 전후의 실제 값을 비교해 결과에 붙인다.

피해를 나타내는 fields 값에 밭 복구량을 더하던 모순을 고쳤다. 전란의 피해는 피해를 늘리고 복구는 피해를 줄인다. 집 수선도 실제 피해를 줄이며, 수선 이후의 연간 상태 변화가 있을 때만 복구 경과를 기록한다. 밭을 고른 결과에 즉시 수확을 보장하지 않는다.

## 관아

기존에 지연 회상으로 보관하던 구체적 행동 서술을 선택 직후의 결과로 사용한다. 사건명과 선택지는 별도 기록 항목으로 보존한다. 같은 글을 2~3년 뒤 다시 붙이는 예약은 새로 만들지 않는다. 과거 저장에 남은 예약 문장도 기한이 되면 반복 출력하지 않으며, 이미 기록된 과거 문장은 지우지 않는다.

구휼을 요청하는 것만으로 식량이 생기던 보상을 제거했다. 실제 장부 부담이 줄었을 때에는 그 감소를 결과에 덧붙인다. 감찰의 진행·보고와 실제 징수 변화는 기존 연간 상태 처리에서 계속 기록한다.

## 검증

- 704명 실제 스크립트 순서 생애 완주: 오류 0건.
- 새 서술·관아 검사 20개 통과: 78개 결과 누락 여부, 빈 곳간의 대체 행동, 곡식 보관 시 증가 금지, 복구의 피해 감소, 구휼 요청의 물자 미지급, 사망 결과 일치.
- 전체 검사 428개 중 408개 통과·20개 기존 실패. 이후 추가한 사망 결과 검사는 관련 검사에 포함해 별도 통과했다. 새 전체 실패 항목은 없었다.
- 운영 사이트의 배포·브라우저 확인은 하지 않았다.

다른 신분·근현대 모듈과 나머지 생업의 기존 문장까지 모두 바꾼 것은 아니다.
