# 최근 생애 분기의 문장 검수 (v342)

검수 범위는 장기 생업·공동 작업(v339), 해외 생활·독립운동(v340), 식민지 협력과 해방 후 책임(v341)의 제목, 상황 설명, 선택지와 결과다. 기존 저장 기록의 글은 그대로 두고 이후에 생성되는 문장을 고쳤다.

## 읽히는 데 걸렸던 부분

- **추상적인 말의 반복**: ‘조건을 확인한다’, ‘생계를 마련한다’, ‘기록은 남았다’가 장면과 관계없이 되풀이됐다. 돈을 부치고 편지를 쓰는 일, 문권을 들고 장부와 대조하는 일처럼 실제 행동을 드러냈다.
- **매번 붙는 해설**: ‘자동으로 수익을 얻지는 않는다’, ‘훈련을 받았다고 전투에 참가한 것은 아니다’처럼 게임 규칙을 설명하는 문장이 일상 속에 끼어 있었다. 결정에 필요한 비용·허가·자격 정보는 남기고, 결과 장면에 덧붙인 일반론은 줄였다.
- **같은 리듬**: 짧은 사실 두세 개를 나란히 쓰고 마지막에 교훈이나 기록 보존을 덧붙이는 구조가 많았다. 같은 행동의 원인과 결과는 한 문장 안에서 잇고, 장면이 바뀔 때 문장을 나눴다.
- **문장 조립 오류**: ‘서독 광산 취업에서 보낸 한 해’, ‘임시정부를 돕는 사람들에서 할 일’, ‘만복와’ 등을 발견했다. 제목을 직접 쓰고 이름 뒤 조사는 받침에 맞췄다.

| 이전 | 수정 |
| --- | --- |
| 이웃이 가져온 문권과 장부를 다시 대조해 잘못된 곳을 고치려 했다. 상관에게서 꾸지람을 들었다. | 이웃이 가져온 문권을 장부와 대조해 잘못된 곳을 짚었다가 상관에게 꾸지람을 들었다. |
| …에게 보낼 돈을 현지 자금에서 떼어 송금하고 소식을 적었다. 남겨 둔 돈은 그만큼 줄었다. | …에게 모은 돈의 일부를 부치고 안부 편지를 썼다. |
| 모임의 일을 그만두고 생계를 다시 꾸렸다. 전에 함께한 활동과 사람들은 기록에 남겼다. | 모임의 일을 내려놓고 먹고살 일을 다시 찾았다. |

탄광·병원·멕시코 농장·중동 건설 현장의 연간 결과는 각 일터에 맞춰 두 가지씩 작성했다. 문장을 고르기 위해 생애의 난수를 더 소비하지 않는다.

## 서술과 실제 선택의 일치

- 피해 행위가 없는 인물이 해방 후 과거를 밝힐 때, 없던 피해자에게 사과하거나 돈을 내는 결과를 만들지 않는다. 피해 기록이 있을 때만 기존 배상 선택을 적용한다.
- 과거를 감추기로 했는데 가족에게 털어놓았다고 나오던 결과는 말하지 않은 결과로 바꿨다.
- 국내에서 활동한 독립운동 참여자에게 해방 후 귀국 여비나 뱃길을 묻지 않는다. 국외 체류자의 귀국 선택과 비용은 유지한다.

이 검수는 게임의 모든 시대·모듈을 대상으로 한 문체 통일 완료를 뜻하지 않는다. 해당 세 모듈의 문장과 실제 선택 결과를 중심으로 고쳤다.
