# 《단 하나의 인생》 v27 선택지 개연성 실플레이 검수

## 검수 관점

선택지가 길거나 좋아 보이는지보다 **등장 조건 → 플레이어가 실제 누른 행동 → 자원·관계 변화 → 훗날 기록 → 저장 후 재현**의 인과관계가 맞는지 확인한다.

## 재현 후 교정한 문제

| 사건 | 기존 모순 | 조치 |
|---|---|---|
| 포로의 귀환 교섭 | **남겨진 동료의 귀향을 돕는다**를 선택해도 자신의 쇄환·속환 확률을 굴려 갑자기 집으로 돌아옴 | 동료 지원은 개인 귀환 시도로 계산하지 않음. 개인 귀향 확률 0, 귀환 시도 횟수 증가 없음 |
| 포로 귀환 후 생업 | 실제 자녀가 없어도 자녀에게 기술을 전했다고 서술하고 자녀에게 남는 솜씨가 증가함 | 자녀가 실제로 있을 때만 가족 기술을 전함. 없으면 배우려는 이웃에게 가르치고 집안 기술 계승 수치는 올리지 않음 |
| 외양간의 송아지 | 이미 태어난 송아지가 보살피는 선택 ①을 골라야 생기고, 이웃에게 도움을 청한 선택 ②를 고르면 없어짐 | **남겨서 키우는 선택 ①·②에 모두 한 마리 추가**, 판매 선택 ③에는 늘지 않음 |
| 명절·시주 | 식량이 0인 집도 곡식을 나누면서 관계 점수 획득 | 곡식이 부족할 때는 실제 할 수 있는 일손 돕기로 바뀌며, 선택 화면과 결과가 일치함 |
| 거절한 시주 | 스님을 돌려보낸 것만으로 곳간의 곡식이 +1 됨 | 곡식 자동 증가 제거 |
| 논 물꼬 | 물꼬를 열자마자 다음 추수 없이 곡식이 즉시 증가함 | 물 수치·이웃 신뢰만 변화, 추수 이전의 공짜 곡식 증가 제거 |
| 농사 없는 가계 | 땅도 소작 논도 없는 어부 가계에 **우리 집 논 물꼬**와 **우리 집 밭 멧돼지** 사건이 나타남 | 토지나 실제 소작 생활 조건과 연결 |
| 산파 | 이웃집의 출산을 돕는 이야기인데 플레이어가 이미 혼인하거나 자녀가 있어야만 발생 | 성인 인물이 지역 산파를 돕는 맥락으로 조정 |
| 송아지 거래 | 값을 물어본 것뿐인데 판매 수입을 즉시 얻음 | 버튼에 **실제로 판다**를 명시 |

## 계속 남은 문제

- 도시·농촌/신분별 자원·생업 연결의 모든 사건을 전수 검증한 것은 아님
- 일부 사건은 일손·곡식을 썼는데 추후 관계나 다음 해 사정까지 실제 변화하지 않으며 **2년 뒤 기록 문장**만 남음
- 관아의 증거 제출과 감찰 결과, 가족의 실종·귀환, 직업 선택의 장기 상태 연결은 확장 필요
- UI 직접 클릭·브라우저 플레이와 대량 자동 시뮬레이션은 다른 검증: 해당 검사를 통과한 범위만 완료라고 기록할 것
