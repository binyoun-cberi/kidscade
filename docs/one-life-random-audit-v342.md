# 무작위 생애 검수 — v342 저장·포로 경로

## 방법

`audit-random-lives-v342.cjs`는 게임의 실제 스크립트 순서로 엔진을 로드한다. 출생 연도는 1392~2026년 사이에서 고르고, 성별·출신·현대 가정 형편·사건 선택·가족의 일·제작품·살림 행동을 별도 난수로 선택한다. 생애 엔진 자체의 난수와 검수 선택의 난수는 분리한다. 중간에 저장을 JSON으로 직렬화하고 다시 불러와 선택창·가구 기록을 비교한다. 사망까지의 진행과 능력치·피로·소지금·물건 식별자의 일관성도 확인한다.

반복 실행:

```
node scripts/audit-random-lives-v342.cjs 512 20261019 /tmp/random-lives-v342-final.json
node scripts/audit-random-lives-v342.cjs 256 20261020 /tmp/random-lives-v342-final-holdout.json
node --test tests/one-life*.test.cjs
```

이것은 엔진 시뮬레이션이다. 768회의 브라우저 플레이를 뜻하지 않으며, 게임용 확률로 생긴 출생·사망 분포는 실제 인구 통계의 검증 자료가 아니다. 무작위 실행은 일부 희귀 경로를 거치지 않을 수 있다.

## 발견과 수정

1. **대기 선택 복원 누락**: 포로·귀환 뒤 생활(v14), 후기 조세(v18), 지방 관청(v19) 모듈은 저장된 유효한 active 사건을 읽었지만 pending 선택창에 다시 연결하지 않았다. 검증된 active 사건만 원래 선택창으로 연결한다. 첫 512명 탐색에서는 이 누락을 81개 생애에서 발견했다. 이 수치는 검수의 선택·저장 방식에 따른 결과이며 실제 이용자 오류율이 아니다.
2. **시대 전환 후 빈 재배 값 누락**: 1900년 이후 저장을 복원하면 가구 기록에서 `crop: null`이 누락됐다. 빈 값을 명시적으로 유지한다. 첫 탐색에서 37개 생애가 이 비교에 걸렸다. 작물이나 수입이 실제로 사라진 오류와는 구분한다.
3. **서술만 존재하던 전쟁 포로**: 1525년생 남성(엔진 seed 2847922975)은 1597년 전쟁 선택에서 포로가 됐다는 기록이 생긴 뒤에도 고향의 농사·집안일을 계속하고, 3년 뒤에는 자동 귀향 문장이 나타났다. 기존 전쟁 선택과 포로 모듈이 별개였기 때문이다. 지원하는 전쟁의 포로 결과는 실제 체류·노동·귀환 상태에 연결한다. 무작위 연간 피랍의 기존 나이 조건과 별개로, 이미 전쟁 선택에서 발생한 고령 인물의 피랍도 실제 상태를 가진다. 다른 국내 선택이 다시 열리지 않게 체류 경계에서 정리한다. 상세 경로가 없는 시기의 위험 결과는 포로가 됐다고 단정하지 않고 피신·부상·재산 손실로 서술한다. 포로 모듈이 로드되지 않는 단독 구형 엔진의 요약 동작은 유지한다.
4. **문장 오류**: 출생지의 받침에 맞춰 이/가를 붙이고, ‘물을 길을 차례’를 ‘물을 길어 올 차례’로 고쳤다. 선택지 뒤에 무조건 ‘을’을 붙이던 회상 문장도 정리했다.

## 회귀 방지

열린 세 종류의 선택창을 실제 전체 저장·복원 경로로 비교한다. 알 수 없는 사건은 복원하지 않는다. 선택 결과는 한 번만 처리한다. 1900년 이후 가구 기록의 전체 구조를 비교하며, 고령 인물의 전쟁 피랍 이후 실제 해외 체류와 국내 노동 차단도 검사한다. 무작위 검수 역시 포로 상태에서 국내 선택창이 열리지 않는지 확인한다.

## 수정 후 최종 결과

두 난수 시작값으로 512명과 256명, 합계 768명이 모두 사망까지 진행됐다. 사건 선택 46,763회, 가구 행동 57,956회, 중간 저장·복원 10,553회에서 검수 조건 위반은 없었다. 마지막 실행에는 실제 포로 상태에서 국내 선택창이 열리지 않는지도 검사했다.

실제 기록의 예로 1525년생 남성은 1597년의 피랍 뒤 국내 농사 대신 해외 포로 상태로 이어졌다. 1762년생 여성 가구에서는 1791년에 가족들이 짚 바구니·삼베옷을 완성하고 다음 해 옷을 팔았다. 이 사례들은 생성된 허구 인물의 게임 기록이다.
