# 쌓은 경험이 다음 삶으로 이어지는 경로

인물 조사에서 드러난 빈틈 가운데 공동 작업·거래, 경험의 저술, 재교육과 직업 이동, 동료들과의 개선 요청을 구현한다. 실제 인물의 업적이나 정치 성향을 가상 인물에게 부여하지 않는다.

| 경로 | 시작 근거 | 여러 해의 과정 | 결과 |
| --- | --- | --- | --- |
| 공방 | 실제 장인 생업, 4년 이상 경력과 숙련 | 공구·재료와 일손 의논 → 2년 뒤 소규모 작업 → 다음 해 정리 | 공동 작업 기록, 기존 장인 경력의 연습·평판 증가. 자동 면천·관직 없음 |
| 공동 거래 | 실제 상업 생업과 3년 경력, 여성 생업 경험 또는 성공한 거래 기록 | 물량·운반비 협의 → 소규모 거래 준비 → 정산 | 공동 장부, 기존 상인 경력의 거래 인연 증가. 별도 무료 수익 없음 |
| 글쓰기 | 35세 이상, 실제 문해 경로, 지식과 누적 경험 기록 | 직접 겪은 일 선정 → 다른 기억과 전언 구분 → 원고 정리·필사 | 실제 완성한 원고와 필사본 2부 저장. 출판 성공·명성·수입을 자동 지급하지 않음 |
| 재교육 | 1900년 이후, 실제 직업 경력 4년 이상 | 생업과 학습 병행 → 기초 공구·수리 연습 → 일감 탐색 | 기존 World6 직업 변경 API와 시대별 명칭 사용. 전문 면허를 주지 않음. 취업 실패 가능, 1950~1953년 취업 보장 없음 |
| 일터 모임 | 1910년 이후 실제 수공업·제조 생업 2년 이상 | 동료와 근무 내역 확인 → 동의한 요구 전달 → 답변 확인 | 휴식 차례에 대한 제한적 합의 또는 변화 없음. 자동 파업·체포·정치적 소속 부여 없음 |

각 경로는 시작 비용과 실제 시간이 필요하다. 비용은 기존 게임 자원 단위(조선 2, 근현대 100)이며 역사적 화폐 환산이 아니다. 빈곤하면 비용 없이 준비한 기록을 보관하며, 거절하면 만난 적 없는 동료나 완성하지 않은 원고를 만들지 않는다. 새로 만나는 가상 인물은 첫 만남을 기록한 뒤 고유 ID·이름·만난 해·출생 해로 보존한다. 가족으로 추가하지 않는다.

이사·생업 변경·구금·포로·국외 체류로 공동 작업이 끊기면 중단 사유를 기록한다. 전란과 식량 부족 중에는 준비만으로 납품 성공을 기록하지 않는다. 글쓰기는 유배 중에도 가능하지만 구금 중에는 중단한다. 이미 만든 원고와 경력 기록은 시대 전환 뒤에도 남는다. 1894·1910·1945·1950·1953·1987·1997년에 누적 경험이 있는 인물만 개인 기록을 덧붙이며 추가 역사 피해나 보상은 적용하지 않는다.

`쌓아 온 일과 기록` 접이식 목록에서 진행·보관·완료한 일, 함께 만난 인물, 완성 원고를 본다. 사후 생애 기록도 시작 선택뿐 아니라 실제 완료·중단 결과를 남긴다. 이전 저장 파일에는 과거 성과를 소급 생성하지 않는다. 생애별 상태이며 후손에게 원고 소유권이나 숙련을 자동 상속시키지는 않는다.

## 범위

이번 변경은 장기 생애 연결의 기반과 다섯 경로다. 김만덕의 특별 출륙 허가, 장영실의 왕실 기술 관직, 상업 독점권, 여성 유람, 독일 취업, 독립운동 조직, 기업의 전쟁 협력과 해방 후 책임을 완성한 것은 아니다. 장인에 대한 실제 추천·임명, 해외 계약과 귀환, 가족 간 원고의 소유·상속과 전승은 추가 구현이 필요하다. 재교육의 취업과 일터 답변 판정은 가상 게임 결과이며 실제 역사적 확률이 아니다.
