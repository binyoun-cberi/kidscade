# 키즈몬 월드 v5 — 마을 체육관·과학 연구 의뢰·환경 희귀종

## 핵심 진행 방식

새로 추가한 **수정마을 → 해류항 → 설빛마을**은 각각 연구 의뢰, 3대3 체육관, 환경 희귀종을 제공한다.

1. 지역에 도착해 연구원과 대화한다.
2. 이웃 서식지에서 **서로 다른 키즈몬 3종을 만나 기록**한다.
3. 해당 지역의 대표 키즈몬을 **포획**한다.
4. 마을 연구원에게 돌아가 **의뢰 보상을 직접 수령**한다.
5. 원하는 키즈몬 세 마리를 선발해 **3대3 체육관장과 대결**한다.
6. 배지를 획득하면 해당 서식지의 특정 환경 현상에서 희귀 키즈몬이 출현한다.

이는 기존 지역 조사 3종 보상과 별개인 **마을 의뢰 3개**다. 의뢰는 첫 수령 한 번만 보상이 지급되고, 체육관 대결은 재도전할 수 있다.

## 마을별 특징

| 마을 / 인접 지역 | 연구 과제 | 포획 대상 | 완료 보상 | 체육관장 / 배지 | 특별 환경 / 희귀종 |
|---|---|---|---|---|---|
| 수정마을 / 번개발전소 | 전기가 흐르는 까닭 | 암페각 | 에너지 결정 + 연구코인 70 | 수정 체육관장 테슬라 / 전류 배지 | 전력 폭주 / 암페갑 |
| 해류항 / 물결갯벌 | 해류와 부력 조사 | 부력치 | 생명의 결정 + 연구코인 70 | 해류 체육관장 아르키 / 해류 배지 | 만조 / 날치온 |
| 설빛마을 / 서리고원 | 빙점과 기후 기록 | 켈빈털 | 기후 결정 + 연구코인 70 | 설빛 체육관장 켈빈 / 서리 배지 | 눈보라 / 절대랑 |

체육관은 순차 해금이다. 각 마을 연구 과제를 완료한 뒤, 첫 번째 체육관의 전류 배지 → 두 번째 해류 배지 → 마지막 서리 배지 순서로 도전한다. 체육관을 처음 깨면 **180코인**, 재도전 승리 시 **45코인**과 참가자 경험치를 얻는다.

체육관 배지는 기존 `trainerWins`에 기록되므로 기존 저장키와 모든 기존 3대3 트레이너는 유지한다.

## 환경 이벤트는 게임 속 걸음 수를 사용한다

아이폰의 현재 시간이나 실제 날씨를 요구하지 않는다. 18걸음마다 환경 단계가 바뀌는 72걸음 순환 구조다.

- 번개발전소: 환경 단계 1에서 **전력 폭주**
- 물결갯벌: 환경 단계 2에서 **만조**
- 서리고원: 환경 단계 3에서 **눈보라**
- 각 배지를 소유하고 현상이 활성화됐을 때, 해당 지역의 야생 조우에서 **12% 확률**로 특별한 키즈몬을 만날 수 있다.

기존 아트와 종족 번호를 활용한 특수 출현이다. 희귀색(이로치) 확률 1/256과는 **독립적인 시스템**이다. 기존 일반 종족의 진화 단계도 조정하지 않는다.

세계 지도에서는 지역별 연구 진행·체육관 배지·활성 환경을 확인할 수 있다. 마을 연구원 대화창에서는 의뢰 목표·포획 현황·보상 버튼·체육관 참가 조건을 확인한다.

## 저장 호환성 및 안전 조건

- 기존 `kidscade.openmon.expedition.save.v1`과 저장 스키마 버전 1 유지
- 새 `regionQuests`는 보상 청구 기록만 저장하며, 누락된 구 저장 데이터는 안전하게 미완료로 초기화
- `trainerWins`에 `gym_energy`, `gym_tide`, `gym_frost`를 추가하고 기존 3개 트레이너 기록 유지
- 지역 방문 확인 없이 퀘스트 보상을 청구할 수 없고, 3종 관찰 + 지정 종 포획 없이 청구할 수 없음
- 같은 의뢰 보상은 1회만 청구 가능
- 배지나 환경 단계가 맞지 않으면 특별 희귀종을 추첨하지 않음
- 기존 102종 포획 경로, 초반 튜토리얼, 월드 v4 10개 지역, 3대3 3명 기본 트레이너 유지

## 검증 범위

`tests/kidsmon-regional-gyms.test.cjs` 회귀 검사 10개: 3개 체육관, 과제 청구 방지와 단 한 번 보상, 단계별 해금, 실제 3대3 엔진, 걸음 수에 따른 환경, 배지 전/후 희귀종, 포획 보존, 구 저장파일, 첫 튜토리얼.

`tests/openmon-expedition-browser-audit.cjs`에서 iPhone 세로/데스크톱: 수정마을 NPC 대화 → 연구 의뢰 조건 만족 → 보상 청구 → 체육관 활성화 → 세 마리 출전 및 실제 배틀 HUD 진입을 확인하고 스크린샷을 남긴다.

324회(3체육관 × 3 AI × 36전) 자체 대전을 실행하여 오류 없이 종료되는 것을 확인했다. 해류 체육관이 쉽게 클리어되는 현상을 발견해 상대 레벨을 조정했다. **조정 후 세부 승률은 전체적으로 다시 검증하는 것이 좋다.**
