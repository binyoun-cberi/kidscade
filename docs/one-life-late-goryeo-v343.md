# 단 하나의 인생 — 고려 후기

1200–1391년 출생을 지원한다. 기존 조선·근현대 연간 처리기를 고려 인생에 적용하지 않고, 별도의 연간 생업·가족·사건 처리를 사용한다. 1392년 이후에도 같은 인물과 식구, 자원, 생업을 유지한다. 조선 출생 인생의 전체 관직·가계 시스템으로 전환하는 기능은 이번 범위에 포함하지 않는다.

## 플레이

- 관료·향리·농민·수공업·사공·향/부곡/소·노비 가구, 7개 지역과 성별 선택.
- 어린 시절 채집·심부름·배움·군것질. 14세 이후 생업 학습, 식구의 배움·돌봄·생산 배분. 혼인과 자녀, 노쇠와 사별.
- 삼베·모시·바구니·나루 노동, 옷·솜이불 제작과 판매. 소출·식비·피로를 매년 처리한다. 예속·피란·부재가 노동과 소출을 제한한다.
- 양쪽 친족의 왕래, 배우자 집 근처의 혼인 생활, 보시. 보시를 출가나 자동 승려 전직으로 취급하지 않는다.
- 몽골 침입·강화 천도·환도·삼별초·일본 원정 동원·홍건적·토지/신분 청원·인쇄 보조·조선 건국. 사건은 연도, 나이, 지역과 생업에 따라 선택 또는 소식으로 나타난다.
- 목화는 1364년 도입 소식과 경상 지역의 시험 재배를 구분한다. 재배 시험 3년과 추가 시기/지역 조건을 거친다. 전국 보급 연도와 비용·성공 확률은 사실 통계가 아닌 게임용 단순화다.
- 저장에는 가족별 연간 계획과 자원, 부재·피란·목화 시험을 포함한다. 진행 중 선택은 저장된 효과를 실행하지 않고 해당 연도의 유효한 선택 정의를 다시 만든다.

## 고증 원칙과 자료

당대 모든 집안이 같은 혼인·재산 관행을 가졌다고 단정하지 않는다. 향·부곡·소 주민을 일괄 노비로 분류하지 않는다. 전민변정도감에 청원했다고 모든 노비가 해방되는 것으로 해석하지 않으며, 억울한 예속에 대한 문서·증언 심사로 묘사한다. 과전법은 전 농민에게 토지 소유권을 나누는 정책으로 묘사하지 않는다. 인쇄·화약 발명을 플레이어 개인의 공적으로 만들지 않는다. 군량·선박·인쇄 보조 등의 허구 경험과 역사적 사건을 구별한다.

- [고려 — 한국민족문화대백과사전](https://encykorea.aks.ac.kr/Article/E0003424): 사회·생활과 친족.
- [친족 — 한국민족문화대백과사전](https://encykorea.aks.ac.kr/Article/E0058438): 양측 친족 관계.
- [소 — 한국민족문화대백과사전](https://encykorea.aks.ac.kr/Article/E0029904): 생산역 부담과 신분 해석.
- [삼별초 — 우리역사넷](https://contents.history.go.kr/mobile/kc/view.do?levelId=kc_o200400): 전쟁·환도·항쟁.
- [몽골제국의 일본 원정 — 우리역사넷](https://contents.history.go.kr/front/hm/view.do?levelId=hm_052_0010): 1274·1281년 동원.
- [문익점 — 한국민족문화대백과사전](https://encykorea.aks.ac.kr/Article/E0019627): 목화 도입과 시험 재배.
- [전민변정도감 — 한국민족문화대백과사전](https://encykorea.aks.ac.kr/Article/E0049408): 권세가의 토지 탈점·노비 문제.
- [직지와 흥덕사지 — 국가기록원](https://theme.archives.go.kr/next/koreaOfRecord/heungDuck.do): 1377년 인쇄.
- [진포대첩지비 — 우리역사넷](https://contents.history.go.kr/mobile/kc/view.do?code=kc_age_20&levelId=kc_i201320): 화통도감과 진포 전투.
- [과전법 — 우리역사넷](https://contents.history.go.kr/front/kc/printViewPopup.do?levelId=kc_i301300): 수조권과 1391년 시행.
