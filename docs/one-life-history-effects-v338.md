# 연표에서 개인의 선택으로

역사적 사실의 날짜는 `history-calendar-v337.js`, 개인의 가상 선택과 후속 결과는 `history-life-v338.js`가 담당한다. 인물의 만남·수확량·돈·확률·사법 결과는 게임에서 구성한 것으로 실제 역사 속 개인의 경험이나 당시의 수치가 아니다.

## 기근 빚

부족한 식량에 대한 선택 하나를 무료 식량 지급에서 명시적인 차용으로 바꾸었다. 세 몫을 받고 네 몫을 갚는 계약은 게임의 작은 자원 단위이며, 역사적 이자율 재현이 아니다. 미상환 잔액은 저장·불러오기·이주 뒤에도 남는다. 예속된 인물에게는 허락 없이 자유롭게 다른 고을로 떠나는 선택 대신 주인집에 식량 사정을 알리고 노동하는 선택을 준다. 이웃에게 빌린 곡식을 관아의 환곡으로 잘못 부르지 않는다.

## 중복과 안전한 진행

- 새 모듈은 기존 전쟁·기근 피해, 연간 조세를 다시 차감하지 않는다.
- 1608·1750년이라는 이유만으로 지급하던 v1의 현금 여섯 몫을 삭제했다. 지역·대상별 실제 조세 계산에 반영한 효과만 유지한다.
- 함경도의 1666년 제도는 통상적인 대동미와 구분해 `sangjeong`으로 표시한다.
- 선택 중에는 시간이 진행되지 않는다. 기존 대기 선택을 덮어쓰지 않고, 새 선택은 최대 네 개만 보관한다. 오래되었거나 처지가 달라진 선택은 열지 않는다.
- 수확·거래·답신은 다음 해 또는 두 해 뒤에 확인한다. 가족의 생사, 거처, 생업, 전란·흉년을 다시 확인한다.
- 한글로 편지를 쓰는 선택은 학습 상태를 먼저 복원한 뒤 유효성을 검사한다. 살아 있지 않은 가족에게 답신을 만들어 주지 않는다.
- 개인 선택의 원인 ID를 저장해 불러온 뒤에도 후속 기록과 자료 링크가 연결된다.
- 사망 후에는 새로운 살림·선택 기록을 붙이지 않는다.

## 연표 연결 확장 (2026-10-18)

- 연표에 원산 개항(1880), 인천 개항(1883), 독립신문 창간(1896)·폐간(1899)을 추가했다. 개항 연도는 우리역사넷의 지역별 시기를 따른다.
- 개항장으로 보내는 물건을 맡는 선택은 실제 상업·운송 생업에 한정한다. 원산은 함경도에서 1880년 이후, 인천은 한양·경기도에서 1883년 이후 접근한다. 부산 관련 새 거래는 기존 1876~1879년 장면 이후인 1880년부터 연결한다. 도 단위 거주를 항구 거주로 간주하지 않고, 항구로 이어지는 거래를 소개받는 장면으로 쓴다. 기존 1876년 직접 거래 장면도 경상도로 범위를 좁혔다.
- 1861년 이후 지도를 접할 경로가 있는 운송 종사자는 지도와 실제 길을 대조할 수 있다. 돈과 품을 쓰고 다음 해에도 같은 지역에서 운송 일을 이어 가야 `routes`에 경험이 남는다. 여비가 없으면 질문만 하며 답사했다고 기록하지 않는다.
- 동전·개항장·철도 거래를 성공적으로 정산한 경우에도 지역·연도·종류를 `routes`에 남긴다. 이전 해까지 얻은 같은 지역 경험이 있으면 다음 거래의 실패 판정을 35%에서 20%로 줄인다. 이는 게임의 위험 조정이며 역사적 수익률이나 손실률이 아니다. 시도·관찰·실패만으로 경험 효과를 주지 않는다. 이사하면 이전 지역의 효과를 쓰지 않는다. 원금과 수익은 보장하지 않는다.
- 1896~1898년 한양에서는 독립신문을 읽거나 들을 기회가 있다. 앞서 한글 공부를 마친 사람은 직접 읽고, 그렇지 않으면 읽어 주는 사람에게 묻는다. 듣기만 해도 한글 문해력을 얻었다고 처리하지 않는다. 폐간 연도인 1899년은 월 단위 구분이 없는 게임에서 새 구독 장면을 열지 않는다. 이전 기사를 다시 읽는 후속 장면은 가능하다.
- 선택이 밀려 대기열에 들어가지 못한 사건은 `seen`에 넣지 않는다. 같은 기회가 다음 해에도 유효하다면 다시 검토한다. 실제 선택 기록과 후속 기록의 원인 ID 및 출처 링크는 유지한다.
- 새 상태가 없는 기존 저장 파일은 빈 `routes`로 복원한다. 실제 과거 거래 경험을 소급해서 만들지 않는다.
