# 에코폴리스

테라 닐의 "복원하고 떠나는 역도시건설" 아이디어를 참고하되, 키즈케이드 과학·환경 학습에 맞춰 단순화한 3D 생태 복원 전략 게임입니다.

## 핵심 루프

1. 바람 지도를 읽고 풍력 발전기를 배치합니다.
2. 전력 범위 안에 토양 정화기와 하천 정화기를 설치해 오염을 줄입니다.
3. 되살아난 초원을 습지·숲·꽃초원으로 나눠 생물다양성을 높입니다.
4. 서식 조건이 맞으면 벌·개구리·고라니·수달이 스스로 돌아옵니다.
5. 깨끗한 강에 회수선을 보내 모든 시설을 회수하면 복원이 완료됩니다.

## 학습 요소

- 재생에너지는 입지 조건이 중요하다는 점
- 오염 정화와 생태계 복원이 다른 단계라는 점
- 단일 녹지보다 다양한 서식지가 여러 생물을 지탱한다는 점
- 건설 자체가 목표가 아니라 지속 가능한 상태를 남기는 것이 목표라는 점

## 조작

- 클릭/탭: 도구 사용
- 드래그: 카메라 이동
- 휠/두 손가락: 확대·축소
- 숫자키 1~8: 도구 선택
- 저장: 자동 저장 + 수동 저장

진입점: `games/high_ecopolis/index.html`
게임 ID: `high_ecopolis`
저장 키: Game SDK storageKey 또는 `kidscade_game_v1:high_ecopolis:world`
외부 API/CDN 없이 저장소의 Three.js 런타임만 사용합니다.


## v2 생태계·에너지 확장

- 풍력: 바람이 강한 곳에서 효율이 높음
- 태양광: 햇빛이 충분한 곳에만 설치 가능
- 지열: 지열 핫스팟에만 설치 가능
- 원자력: 큰 저탄소 전력을 제공하지만 비용이 크고 냉각수 접근과 사용후 연료 관리 부담이 있음
- 화력: 싸고 강력하지만 지속적으로 탄소와 주변 오염을 늘리는 함정 선택지
- 자동차 공장: 에코 포인트를 계속 벌지만 전력을 소비하고 탄소·토양오염을 늘리는 산업 선택지
- 숲은 시간이 지나며 탄소 부담을 조금씩 낮춤
- 오염이 다시 높아지면 조성한 생태계가 초원·황무지로 후퇴하고 야생동물이 떠날 수 있음
- 바람·햇빛·지열·오염 지도를 비교해 입지를 판단함


## v3 다양한 오답·함정 선택지

오답을 산업시설 하나로 표현하지 않고 서로 다른 환경 문제를 경험하도록 확장함.

- 화력 발전소: 싼 대용량 전력 ↔ 탄소·주변 오염
- 자동차 공장: 지속적인 예산 수익 ↔ 전력 소비·탄소·토양오염
- 쓰레기 매립지: 즉시 처리 예산 확보 ↔ 토양·수질 오염과 서식지 압박
- 채석장: 자원 수익 ↔ 땅 자체가 황폐화되고 서식지가 사라짐
- 대형 주차장: 개발 수익 ↔ 토양 포장·빗물 침투 감소·서식지 손실
- 콘크리트 하천: 수질 수치가 빠르게 좋아 보임 ↔ 습지 제거·개구리와 수달 감소
- 잔디공원: 빠르게 초록색 경관을 만듦 ↔ 높은 물 사용·낮은 먹이/은신처 다양성
- 단일수종 조림: 빠른 녹화와 일부 탄소 흡수 ↔ 자연 숲보다 낮은 생물다양성

이 선택지는 처음부터 빨간 오답으로 표시하지 않고 비용·수익·즉시 효과만 보여 준 뒤 장기 생태 결과로 판단하게 함.

## 3D 자산 QA
공용 GLB는 모두 즉시 투입하지 않습니다. 현재 에코폴리스 v4는 멸망에서 살아남기에서 색과 피벗이 비교적 안정적으로 확인된 식생·바위 계열만 사용합니다.

- 사용: common/pine tree, grass, plant, rock/mossy rock
- 보류: deer/stag/fish 등 동물 GLB, 건물·차량 GLB
- 모든 공용 모델은 X/Z 중심 보정과 바닥 정렬 후 배치
- 분석 지도 모드에서는 3D 장식을 숨겨 색상 해석을 방해하지 않음
- 검수되지 않은 자산은 shared3DIsApproved()를 통과하지 못해 자동 로딩되지 않음
