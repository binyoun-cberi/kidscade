# 하루 한 입 영어

입문 생활 영어를 매일 짧게 익히는 1인용 학습 게임입니다. 빵집·학교·공원의 18개 레슨, 각 8문항으로 구성됩니다. 기존 `assets/game/2d/animals/round`의 토끼·곰·개 에셋을 사용합니다.

- 한국 시간 자정에 에너지 30으로 초기화합니다. 이월 누적은 없습니다.
- 새 레슨 시작에 5, 오답에 2를 사용합니다. 하루 새 레슨 시작은 최대 6회입니다. 새로고침은 이미 지불한 시작 비용을 다시 청구하지 않습니다.
- 6번째 레슨은 시작 비용으로 에너지가 0이 되어도 풀 수 있습니다. 오답으로 에너지가 소진되면 현재 레슨을 무료 연습으로 전환합니다. 연습 완료는 다음 레슨을 열지 않습니다.
- 배운 레슨과 현재 도전할 레슨은 에너지 없이 연습할 수 있습니다. 오답 원문항은 두 문제 뒤 쉬운 선택형으로 한 번 더 등장합니다.
- 레슨 또는 무료 연습을 완료한 날에 연속 학습을 인정합니다. 같은 날 여러 번 완료해도 연속 학습일은 한 번만 증가하고, 오늘의 콤보만 증가합니다. 하루를 건너뛰면 연속 기록이 초기화됩니다.
- 새 레슨을 3개 완료할 때마다 기념품 하나를 받습니다. 마지막 레슨까지 총 6개입니다.
- 문제 순서, 현재 답안의 채점 상태, 오답 복습 대기열을 저장합니다. 입력 중인 철자·문장 조립은 다시 선택합니다. 날짜가 바뀐 채로 이어가는 레슨은 무료 연습으로 전환하고 새날의 에너지를 보존합니다.
- 저장 키: `kidscade_game_v1:daily_english:progress`. **기기·브라우저별 기록**이며 계정별 분리나 서버 동기화는 제공하지 않습니다. 공용 기기 안내를 화면에 표시합니다. `navigator.locks`를 지원하면 여러 창의 동시 변경을 직렬화합니다.
- 발음은 브라우저의 영어 음성 합성 기능을 사용합니다. 지원하지 않거나 재생할 수 없으면 글자로 보기로 진행할 수 있습니다. 음성 인식·발음 채점은 없습니다.
- SDK `start`, `result(scope:stage)`, 기념품 `milestone`을 연결합니다. 자동 클릭·출석만으로는 완료 이벤트를 보내지 않습니다.

검증:

```sh
node --test tests/daily-english.test.cjs tests/catalog-discovery.test.cjs
node tests/daily-english-browser-audit.cjs
```

브라우저 감사는 Playwright와 설치된 Chromium을 사용합니다. `CHROME_PATH`로 실행 파일, `DAILY_ENGLISH_AUDIT_OUT`으로 스크린샷 폴더를 지정할 수 있습니다. 144개 기본 문항 전체 풀이, 3일 충전, 에너지 소진 후 오답 복습, 새로고침, 390px 화면 넘침을 확인합니다.
