# 말랑말랑 모래섬

유아(만 4~7세)가 시간 제한과 패배 없이 즐길 수 있는 2D 협동 물리 놀이. 키즈케이드 Game SDK v1을 사용합니다.

## 하는 방법

- **혼자:** 모래섬의 공을 누르면 주인공이 이동해 바구니 쪽으로 공을 밀어줍니다. 빈 모래를 눌러 이동할 수도 있습니다. 두 번째 친구는 섬을 돌아다니다가 가끔 공을 모으는 것을 돕습니다. 키보드에서는 방향키나 WASD를 사용할 수 있습니다.
- **둘이:** 같은 PC에서는 첫 번째 친구가 WASD, 두 번째 친구가 방향키. 터치 화면에서는 왼쪽과 오른쪽 가상 조이스틱을 각각 사용합니다.
- 중앙 바구니에 공 6개를 모으면 한 판 성공입니다. 다음 판은 8개, 그다음부터는 최대 10개입니다. 별도 실패 시간 제한이 없습니다.
- 일시정지, 다시 시작, 결과 화면을 제공합니다.

## 원본 게임 분석 경위

제공된 `BeachBuddies.zip`은 소스 프로젝트가 아니라 Windows 자동 압축 해제 프로그램입니다. 내부 CAB을 추출해 GameMaker Studio 빌드인 `Double Down.exe`, 게임 데이터 `data.win`, 사운드 파일을 확인했습니다. `data.win`의 GameMaker FORM 청크 분석 결과, 스프라이트 51, 사운드 레코드 39, 오브젝트 26, 룸 2, 코드 이벤트 84, GML 스크립트 1개가 확인됩니다.

- `obj_player`: 이동/관성/충돌, 밀치기, 게임패드, AI 관련 상태 변수와 Step/Draw/Alarm 이벤트
- `obj_push`: 밀치기 판정 및 충돌 이벤트
- `obj_stage_mask`: 섬 경계 충돌
- `obj_controller` / `obj_score`: 점수·라운드·카운트다운
- `obj_crab`, `obj_tree`, `obj_splash`, `obj_dust`: 무대 생동감 및 효과
- `rm_start` / `rm_stage`: 메뉴/플레이 공간
- `scr_spawn_players`: 플레이어·AI 생성

이것은 바이트코드에서 **이벤트명·변수명·리소스 구조를 확인한 정적 분석**이지, 손실 없는 GML 소스 복원이나 게임 전체 실행 테스트는 아닙니다.

원작 공식 설명: https://kingpenguin.itch.io/beach-buddies-brawl — 한 게임패드의 두 스틱으로 두 캐릭터를 움직여 경쟁 상대를 섬 밖으로 밀어내는 로컬 대전 프로토타입. 최대 4인/컴퓨터 대전 지원.

## 적용/독립 구현

유아에게 알맞지 않은 '상대를 밀어 바다에 빠뜨리기'는 제거하고, 관성 움직임과 밀치기 접촉을 **공을 중앙 바구니로 협력해서 이동시키는 행동**으로 대체했습니다. 보행, 자동 목적지 이동, 공 반사/속도 제한, AI 도움 행동, 축하 파티클, 해변 장식 등을 독립 구현했습니다.

**저작권:** itch.io의 무료/기부 다운로드는 오픈소스 라이선스가 아닙니다. 제공 원본에 재배포를 허용하는 소스/에셋 라이선스가 확인되지 않아 EXE, DLL, data.win, 음원, 원본 그래픽은 포함하지 않았습니다. 게임 HTML/Canvas·SVG 표지는 독립 작성입니다.

## 검증

- 자바스크립트 구문 검증 통과
- Chromium CDP에서 메뉴/실제 플레이를 렌더링한 화면 확인
- 테스트 진입점에서 시작 → 공 6개 수집 → 판정 → 2판(8개) → 일시정지/재개 확인
- 정식 키즈케이드 배포 환경의 모바일 터치/SDK 통합/실기기 장시간 게임 검증은 PR 검수 항목으로 남겨둡니다

## 파일
