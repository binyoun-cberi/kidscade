# 청소 특공대

학교를 돌아다니며 쓰레기와 얼룩을 제거하는 저학년용 3D 1인칭 청소 액션 게임입니다.

- 워드 블라스터의 Three.js FPS 조작 감각과 기존 청소/분리수거 자산을 재활용합니다.
- PC: WASD 이동, 마우스 조준, 클릭 발사.
- 모바일: 왼쪽 방향 버튼 이동, 화면 오른쪽 드래그 조준, CLEAN 버튼 발사.
- 시작 화면에서 `튜토리얼부터` 또는 `바로 시작`을 선택할 수 있습니다.
- 튜토리얼은 이동 → 쓰레기 제거 → 얼룩 반복 청소 → 악당 일시 정지 순서의 실제 조작 연습입니다.
- 악당은 쓰러뜨리는 대상이 아니며 청소총을 맞으면 잠시 투기를 멈춥니다.
- 서버 없이 브라우저에서 전부 실행됩니다.

진입점: `games/low_cleanup_squad/index.html`
저장 키: `cleanupSquadBestScore`

## 청소 장비

- 1 물줄기: 누르고 있는 동안 빠르게 연사하며 넓은 범위를 즉시 씻습니다.
- 2 거품 분사기: 바닥에 거품을 남겨 잠시 동안 얼룩을 계속 녹입니다.
- 3 비누폭탄: 재충전 시간이 있는 대형 광역 청소 공격입니다.
- 4 강력흡입청소기: 캔·병·봉투 같은 입체 쓰레기를 넓은 시야 안에서 한꺼번에 빨아들입니다.

튜토리얼은 이동과 네 장비, 악당 방해까지 6단계로 직접 연습합니다.
