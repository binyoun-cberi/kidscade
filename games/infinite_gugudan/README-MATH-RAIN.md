# 무한루: 하늘에서 내려오는 연산

## 현재 게임 조사

- 기존 `무한 구구단： 무한루.html`은 CPU 에너지 대전과 2인 로컬 대전만 지원한다.
- 구구단, 소수, 분수, 혼합 연산을 지원하고 성공 시간에 비례한 에너지 출력, 콤보 등급, 충돌 연출이 이미 있다.
- 낙하하는 계산 문제를 정답으로 없애는 플레이는 없었다. 별도 `math-rain.js` 모드를 추가하면서 기존 HTML 내 대전 상태 및 설정은 유지한다.

## Combine 참조 내용

원작: [Combine (rockyjam / Jussi Kallio)](https://rockyjam.itch.io/combine), [소스](https://github.com/jkallio/combine), [MIT 라이선스](https://github.com/jkallio/combine/blob/main/LICENSE).

실제 확인한 구현 지점:

1. `src/in_game.rs`의 `Operation`은 ADD/SUBTRACT/MULTIPLY/DIVIDE를 구분하며 0으로 나누는 블록이 생성되지 않도록 처리한다.
2. `handle_dropping_block_movement`는 낙하 타이머, 좌우 이동 제한, 고속 낙하, 착지, 다음 블록 생성을 구분한다. 착지할 때 속도 계수를 `0.99`배로 조정한다.
3. `perform_calculation`은 서로 다른 사칙연산 처리를 분리하며 결과를 -99~99에 제한한다. 나눗셈은 양수에 올림, 음수에 내림을 적용한다.
4. `update_block_number`는 연산 결과가 10의 배수인 경우 점수를 지급하고 블록을 보드에서 제거하며 점멸 애니메이션을 예약한다.
5. `src/board.rs`의 `find_same_color_neighbors`는 상하좌우 같은 색 연결 영역을 재귀 탐색하며 `handle_block_dropped`에서 연산을 전달한다. `drop_floating_blocks`는 소멸 뒤 빈자리를 채운다.

원작의 Bevy ECS 구조 및 에셋을 그대로 복제하지 않고, **연산/낙하/소멸/연쇄 피드백의 상태 분리**만 개념적으로 재설계했다. 브라우저용 코드는 새로 작성했다. 원작 코드를 참조했다는 기록과 라이선스 링크를 유지한다.

## 신규 플레이

- 독립 진입 버튼: 기존 CPU/2인 대전과 설정을 보존한다.
- 여러 문제 블록이 하늘에서 내려오고, 블록을 누르거나 좌/우 화살표로 선택한다.
- 숫자 키패드 또는 키보드로 정답을 입력하고 확인하면 블록을 없앤다.
- 가까이 연결된 같은 답의 블록도 연쇄 제거한다. 거리가 멀거나 답이 다른 블록은 제거하지 않는다.
- 정답 횟수 콤보, 높은 위치에서 해결한 속도 보너스, 연쇄 보너스, 최고 점수를 별도로 계산한다.
- 세 번 바닥에 닿으면 결과를 표시한다. 오답 시 현재 문제에 재도전할 수 있고 콤보만 끊긴다.
- 쉬움(20까지 덧셈/뺄셈), 보통(덧셈/뺄셈/곱셈), 도전(사칙연산)을 제공한다.
- 탭 이동을 차단하지 않으며, 화면 이탈 시 일시정지하고, 움직임 감소 설정을 존중한다.

## 원본 플레이 개선

- 연산 성공마다 별도 출력 수치와 충돌 원형 파동이 표시된다.
- 기존 3·5·8·12콤보 단계와 캐릭터/에너지파는 유지한다.
- 콤보 음향을 음계 진행형으로 조정하고, 새 라운드에 이전 라운드의 예약된 다음 문제가 덮어쓰지 않게 방어한다.
- 기존 게임 SDK 종료 기록과 신규 낙하형 모드의 기록을 분리한다.

## 검수 관점

- 실제 터치/키보드 플레이에서 화면별 UI, 애니메이션 프레임, 초당 출제 속도, 작은 화면 겹침을 추가 점검할 것.
