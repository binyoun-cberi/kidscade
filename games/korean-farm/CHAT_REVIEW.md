## 개선 반복 1/3 — 마을 주민 보행 자연스러움

### 관찰
- 주민·행인의 팔과 다리는 `Math.sin(elapsed*…)`로 움직여 실제 이동한 거리에 걸음이 맞지 않음.
- 순찰 경로의 시작점과 마지막 점이 중복되어 0거리 이동 후에도 두 번째 정지 이벤트가 발생함.
- 행인은 굽은 길에서 이동 방향으로 즉시 회전해 급한 방향 전환이 눈에 띌 수 있음.

### 이번 변경
- `npcWalkPose()`: 누적 이동거리 기반 다리·팔 교차 보행; 정지 시 제자리 걷기 없음.
- `turnNPC()`: 최단 각도 보간으로 주민과 행인의 방향 전환 완화.
- `createWaypointWalker()`: 닫힌 경로의 중복 첫 점 건너뛰기, 코너에서 짧게 정지하고 한 바퀴 후 휴식.

### 검증
- `tests/korean-farm-village-scene.test.mjs`에 최단 방향 회전, 실제 거리 기반 보행,
  중복 경로 정지 방지 케이스 추가.
- PR CI에서 이 테스트와 기존 회귀·브라우저 검수 결과를 확인해야 함.
- 브라우저에서 시각적으로 자연스러운지 최종 평가는 별도 필요.

### 후속 반복 후보 (이번 PR에서 미구현)
1. 마을 주민의 작업 도구와 실제 바닥/가판대 접촉 연출 맞추기.
2. NPC가 멀리서도 서서 손만 움직이는 반복을 줄이고 정적 작업/이동/대화 변주 추가.
3. 실제 사용자 플레이를 통해 HUD·농장 성장과 수확 보상도 평가하기.
