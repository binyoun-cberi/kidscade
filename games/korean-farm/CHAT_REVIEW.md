# 논두렁 너머: Chat 단일 게임 개선 로그

## 범위

- 대상 소스: `games/korean-farm/**`

- 다른 게임의 코드·카탈로그·학생 기록 및 배포 설정은 수정하지 않음

## 개선 반복 1/3 — 마을 주민 보행 자연스러움

### 관찰
- 주민·행인의 팔과 다리는 `Math.sin(elapsed*…)`로 움직여 실제 이동한 거리에 걸음이 맞지 않음.
- 순찰 경로의 시작점과 마지막 점이 중복되어 0거리 이동 후에도 두 번째 정지 이벤트가 발생함.
- 행인은 굽은 길에서 이동 방향으로 즉시 회전해 급한 방향 전환이 눈에 띌 수 있음.

### 이번 변경
- `npcWalkPose()`: 누적 이동거리 기반 다리·팔 교차 보행; 정지 시 제자리 걷기 없음.
- `turnNPC()`: 최단 각도 보간으로 주민과 행인의 방향 전환 완화.
- `createWaypointWalker()`: 닫힌 경로의 중복 첫 점 건너뛰기, 코너에서 짧게 정지하고 한 바퀴 후 휴식.

### 검증
- `tests/korean-farm-village-scene.test.mjs`에 최단 방향 회전, 실제 거리 기반 보행,
  중복 경로 정지 방지 케이스 추가.
- PR CI에서 이 테스트와 기존 회귀·브라우저 검수 결과를 확인해야 함.
- 브라우저에서 시각적으로 자연스러운지 최종 평가는 별도 필요.

### 개선 반복 2/3 — 도구가 보이는 마을 작업 연출

### 관찰
- 영수 할아버지는 오전 청소 중 빗자루를 들지만 오후 텃밭 돌보기에서는
  기존 빗자루가 숨겨져 빈손으로 같은 몸짓을 반복함.
- 빗자루로 길을 쓸어도 지면에는 아무 흔적이 없어 작업이 실감 나지 않음.
- 주민이 이동할 때는 작업 소품을 숨겨 걸으며 일하는 듯한 불일치를 피해야 함.

### 개선
- 오후 텃밭 돌보기 전용 괭이를 만들고, 행동에 맞는 도구만 노출함.
- 오전 빗자루질에는 주민 발치의 가벼운 먼지 효과를 더해 바닥 접촉 피드백 제공.
- 단일 메시/재질을 생성 후 재사용하며 렌더 업데이트에서 메시/재질을 새로 만들지 않음.
- 게임 진행, 재화, 저장 데이터와 다른 게임은 바꾸지 않음.

### 검수 기준
- NPC 행동/이동/도구 선택 및 효과를 검증하는 회귀 테스트 추가.
- 전체 CI, 농장 브라우저 자동 플레이 통과 여부 확인.
- 작업감과 자연스러움은 실제 화면에서 추가 육안 검수가 필요.

## 개선 반복 3/3 — 실제 텃밭 작업·작물 성장·수확 보상

### 관찰
- 영수 할아버지의 오후 괭이질이 대상 없이 반복되어 텃밭 돌보기로 인식하기 어려웠음.
- 작물은 네 가지 모델 사이에서만 외형이 바뀌고, 같은 단계 안의 성장 변화는 보이지 않았음.
- 5개 수확 구역을 모두 완료한 뒤 수확물은 창고에 들어가지만, 화면에 지급량이 명확히 나타나지 않았음.

### 개선
- 영수 할아버지 주변의 작은 실제 텃밭을 배치하고 괭이 사용 중 작물이 반응하도록 연결.
  교실용 작물 필드나 충돌 판정에는 영향을 주지 않는 배경 연출임.
- 기존 벼·당근·옥수수의 4단계 에셋을 유지하면서 단계 내부에서 크기를 보간.
  실제 성장 수치와 화면 크기가 연동되며 저장 데이터나 작물 경제 수치는 수정하지 않음.
- 실제 수확 지급량이 있는 최종 수확 시에만 `벼 +N` 등의 3D 보상 라벨 표시.
  수확 단위 계산은 기존 `grantHarvest`의 결과를 그대로 사용함.
- 표시 전용 메시/텍스처는 재사용하고 종료할 때 해제.

### 검수 기준
- 농장 순수 로직 테스트: 성장 단계별 증가·범위 제한, 수확량 텍스트 검증.
- 회귀 테스트: 작업 텃밭이 논밭이나 마을 충돌 영역을 침범하지 않는지 확인.
- CI 전체 회귀/데스크톱·모바일 농장 브라우저 시뮬레이션 결과 확인.
- 실제 학생 경험이나 장기 플레이의 재미는 별도 검수가 필요.
