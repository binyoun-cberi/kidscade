# 논두렁 너머 — PR 1: 한국 3D 테스트 농장

이 디렉터리는 한국 농촌 농사 시뮬레이터의 **첫 번째 플레이 가능한 시각 검수판**입니다.

## 이번 PR에서 가능한 것

- 48×48 논리 지형에 농가, 축사, 우물, 논 네 구획, 당근밭, 옥수수밭, 농수로를 3D로 표현
- PC WASD/방향키, 바닥 클릭 이동, 모바일 화면 조이스틱과 손가락 선택
- 휠/핀치 확대·축소, Q/E 및 화면 버튼으로 시점 회전
- 벼의 **Rice_1~4.fbx** 원본을 단계별로 로드. 실패하면 Quaternius rice GLB, 마지막으로 임시 지오메트리로 표시
- 선택한 논의 시각적 성장 단계를 변경하고, 원본/대체 사용 여부를 '에셋 검수'에서 확인
- 키즈케이드 Game SDK와 브라우저 저장 사용. 방문한 논과 시점, 캐릭터 위치 기억

## 아직 구현되지 않은 것

- 파종·모내기·물꼬 조작·수분 물리·토양·실제 생장 시간 경과
- 수확·인벤토리·판매, 주민 대화, 계절 진행
- 한국식 농가 건물 신규 디자인, 농부 작업 애니메이션, 실환경 오디오
- 모든 모델의 외형 검수 완료: **네트워크 로딩 성공은 시각적 승인과 다릅니다.**

위 기능은 PR 2 이후 별도로 다룹니다. UI에서도 '성장 미리보기'라고 표기합니다.

## 로컬 실행

정적 서버로 저장소 루트를 서비스하고 `/games/korean-farm/index.html`로 이동합니다.
파일 열기(`file://`)는 ES 모듈·GLB/FBX 보안 제한 때문에 지원하지 않습니다.

- `node --test tests/korean-farm-prototype.test.mjs`: 농장 상태, 모델 경로, SDK 연결 검사
- `npm run build:cloudflare`: 기존 Cloudflare 정적 산출물 확인

이 PR에서는 `data/games.json`에 정식 게임을 노출하지 않습니다. 그래픽 실사와 디바이스 검수 후 별도 PR에서 정식 출시합니다.

## 눈으로 확인할 항목

1. 벼 4단계가 서로 다른 형태인지(성장 순서/색/비율)
2. 농가·축사·캐릭터가 흰색으로 깨지지 않는지, 땅에 잘 서 있는지
3. 모바일 입력에서 카메라·선택·이동이 충돌하지 않는지
4. 텍스처 로드 실패 또는 에셋 대체 발생 여부('에셋 검수' 버튼)
5. 저장·새로고침 후 위치와 방문한 논 기록이 복구되는지
6. 저사양 모바일 성능과 초기 로딩 시간

## PR 2 — 실제 농사 시뮬레이션

`farming/farm-sim.mjs`에서 Three.js에 의존하지 않는 농사 규칙을 계산합니다.

- 벼·당근·옥수수 재배: 시작 작물이 생육 단계별로 서로 다르게 자라고 수확할 수 있습니다.
- 농사 행동: 괭이질, 모내기/파종, 밭 물주기, 논 물꼬 여닫기, 김매기, 거름주기, 수확
- 논 구역별 수위와 물꼬, 토양 수분·질소·잡초·작물 건강 상태를 하루 단위로 갱신
- 하루 보내기: 14일×4계절 게임 달력, 날짜에 따라 고정 시드 날씨, 농작물 생육
- 농가 창고·장터: 씨앗·퇴비 구입과 쌀·당근·옥수수 판매, 화폐·수확 기록
- 실제 3D 농장의 물 깊이, 작물 성장 모델, 토양 색과 상태 정보에 시뮬레이션 결과 반영
- 저장 포맷 v2, PR 1의 저장 포맷 v1 자동 이행, 비정상 저장값 검증
- 상태 전이 테스트: `node --test tests/korean-farm-simulation.test.mjs`

### 초기 체험 순서

1. 논을 눌러 벼 상태를 확인한 뒤 네 번째 논으로 걸어갑니다.
2. 익은 벼를 수확하고 창고에서 판매합니다.
3. 수확한 논을 다시 갈고 모를 심습니다.
4. 물꼬를 열어 수위를 관리하고 하루를 보내 새싹이 자라는 것을 관찰합니다.
5. 씨앗과 퇴비가 부족하면 창고·장터에서 구입합니다.

### PR 2 범위의 한계

- 농부의 정교한 괭이질·낫질·모내기 캐릭터 동작은 아직 추가되지 않았고 임시 위치 효과만 있습니다.
- 토양·작물 계산값은 **게임플레이 검증용 단순 계수**입니다. 농업 연구 자료를 통한 품종·계절별 보정은 다음 단계입니다.
- 3D 모델 FBX 실제 화면 검수, 모바일 성능 측정 및 햇빛/비 표현을 포함한 시각적 검수는 필요합니다.
- 새 게임 카탈로그 등록과 `main` 병합은 별도로 진행해야 합니다.

## PR 3 — 작업 애니메이션과 컬러링 안전장치

- 기존 원형 클릭 효과 대신 **절차적 관절 농부**를 연결했습니다. 밀짚모자·피부·상의·바지·장화에 독립적인 로우폴리 재질색을 적용했습니다.
- 대기/걷기와 일곱 가지 농사 작업(괭이질, 모내기, 물주기, 물꼬, 김매기, 거름주기, 수확)이 다른 몸 기울기, 팔·다리·도구 움직임을 사용합니다.
- 작업 임팩트 시점에 흙·씨앗·잎·물방울·이삭 색의 파티클이 생성됩니다.
- 논물 높이는 미세하게 출렁이며 작물은 개별 시간차로 흔들립니다.
- 농장 렌더러에 ACES 톤매핑과 더 절제된 조명 강도를 적용하여 과노출을 억제합니다.
- 모델마다 메시·재질·텍스처·정점색·직접색·중성 무텍스처 개수를 진단해 **에셋 검수** 화면에서 보여줍니다.
- FBX 벼 모델이 *무텍스처 중성 회색/흰색 재질*을 사용한 경우에 한해 성장 단계별 녹색/황금색을 보완합니다. 텍스처·정점색·기존 유색 재질은 유지하며, 원본 모델 파일은 수정하지 않습니다.
- 애니메이션·색상 회귀 테스트: `node --test tests/korean-farm-animation-color.test.mjs`

### 확인할 내용 / 아직 보장하지 않는 것

1. 농부의 일곱 가지 동작이 실제 PC·모바일 브라우저에서 부자연스럽게 관통하지 않는지
2. FBX Rice_1~4가 각기 다른 녹색·황금색 단계로 렌더링되는지, 중성색 보완 로그가 나오는지
3. Kenney/Styloo/Quaternius 모델의 원래 텍스처가 보존되는지
4. 저사양 모바일에서 농작물 흔들림과 파티클이 성능을 떨어뜨리지 않는지
5. 원본 GLB 캐릭터의 리깅은 검증되지 않아, PR 3에서는 안정적인 관절형 캐릭터로 대체합니다. 원본 캐릭터의 실제 애니메이션 이식은 추후 시각 검수 후 판단합니다.

**소스 코드 수준의 재질 점검·단위 테스트만으로 실제 브라우저 렌더링 검수를 대체하지 않습니다.**

## 4.1 — 농사 손맛: 작업 접촉 시점에만 농사 결과 적용

- 농사 행동은 `interactions/action-flow.mjs`의 4단계(이동→준비→접촉 애니메이션→회복)로 처리합니다.
- 작업을 멀리서 실행하면 농부가 논밭 경계까지 자동으로 이동합니다. 농사 버튼은 **한 번만** 누르면 됩니다.
- 씨앗·거름·체력·수확물·물꼬·잡초 등 상태 변경은 농기구 접촉 시점에만 `applyFarmAction`으로 확정합니다.
- 이동 중 직접 WASD/조이스틱/땅 클릭으로 움직이면 아직 착수하지 않은 작업만 취소됩니다. 이미 시작한 스윙은 중복 입력과 강제 변경을 막습니다.
- 중복 작업, 하루 넘기기, 가방 열기 등을 제한하여 농사 상태가 일관되도록 합니다. 접근 중 경로가 막히면 18초 뒤 자원 소모 없이 취소됩니다.
- 농사 작업 UI에 이동·동작 진행 상태를 표시하고, 작업 이펙트는 실제 도구 접촉 시점에 논밭 가까이에서 발생합니다.
- 순수 상태 전이 검증: `node --test tests/korean-farm-action-flow.test.mjs`
- 브라우저 검증: 수확 직후 자원 변화 없음 → 접촉 뒤 수확 → 작업 완료 → 재파종/물꼬 → 원거리 한 번 누르기 이동 및 작업 완료.

이번 단계는 물리 기반 IK, 낫날과 식물의 정밀 충돌 판정, 여러 개체를 구획별로 자르는 표현까지 포함하는 것은 아닙니다. 그 부분은 후속 그래픽·애니메이션 심화 작업으로 분리합니다.

## 4.2 — 솔내리 한국 농촌 풍경 리워크

4.1의 농사 작업·자동 이동·저장 상태를 유지하며, 마을 구역의 외형을 한국 현대 농촌에 가깝게 개선합니다.

### 새 풍경

- **농가**: 담백한 회벽, 나무 창틀, 푸른 양철지붕, 처마·굴뚝·현관 돌계단
- **곡물 창고**: 갈색 목재 외벽, 슬레이트 느낌의 지붕, 곡물 포대와 경첩 느낌의 문짝
- **마당**: 장독대, 평상, 고추 건조대, 파란 고무대야, 손수레, 낮은 울타리
- **논 주변**: 나무 물꼬, 둑·돌·풀숲과 갈대, 기존 농수로의 작은 물길과 건널목
- **마을길**: 자갈·흙 가장자리, 전봇대와 잡풀, 한글 마을 안내판
- **마을 장터**: 직거래 판매대, 농산물 바구니, 수레

모두 기존 Three.js와 색상 지정 로우폴리 지오메트리로 생성됩니다. 신규 네트워크 모델 파일이나 외부 저작권 이미지는 사용하지 않습니다.

### 기술적 유의사항

- 풍경은 `rendering/village-scene.js`에서 한 번만 만들고, 종료 시 지오메트리·재질·간판 텍스처를 정리합니다.
- `rendering/village-layout.mjs`에서 주요 건물의 충돌 영역을 관리합니다. 작은 장식은 플레이어의 경로를 막지 않습니다.
- 길의 작은 돌 150개는 한 번에 그리는 InstancedMesh로 렌더링합니다.
- `games/korean-farm/game.js`의 기존 가정용 Kenney 주택·Styloo 축사 대체 로딩을 제거하고 4.2 풍경을 사용합니다.
- 3D 씬의 장식은 **상호작용 가능한 물체가 아닙니다.** 마을 주민·실제 장터 방문은 4.3에서 구현합니다.
- 농사 생육·수확·저장 스키마는 변경하지 않습니다. 기존 브라우저 저장 데이터는 그대로 읽습니다.

### 검수

- `node --test tests/korean-farm-village-scene.test.mjs`: 랜드마크 배치·논밭 간섭·충돌 경로·렌더링 자원 검사
- `node tests/korean-farm-browser-audit.cjs`: 실제 Chromium/WebGL 농사 플레이 검사 + 농가·장터 화면 추가 캡처
- 저사양 모바일에서는 여러 개체 그림자와 작업 파티클이 프레임 속도에 영향을 줄 수 있으므로 별도 기기 검수가 필요합니다.
