# 논두렁 너머 — 개발 기록과 2.0 리워크

> 아래 PR 1~5.2 설명은 개발 이력입니다. **현재 구현**은 2.0 다섯 번째 '살아 있는 계절 행사' 리워크까지 포함합니다.

## 2.0 다섯 번째 리워크: 살아 있는 계절 행사

- 행사가 시작되는 **계절 7일째**부터 소담의 가판대 주변에 주민 다섯 명이 모입니다. 어른은 손뼉을 치거나 인사하고, 아이는 제자리에서 뛰고, 다른 주민은 수확물을 살펴보고 이야기를 나눕니다. 행사가 끝나면 다시 한적한 마을 풍경으로 바뀝니다.
- 봄·여름·가을·겨울마다 **가판대의 수확물 모양과 색, 종이 장식·등불의 색**이 달라집니다. 봄에는 당근, 여름에는 옥수수, 가을에는 황금빛 곡식, 겨울에는 저장 작물을 진열합니다.
- 수확물을 실제로 들고 와 납품하면 소담이 고마움을 표현하고 가판대에는 감사 리본이 나타납니다. 약 **6초간의 종이 꽃가루 연출**이 이어집니다. 저장 기록을 다시 열면 감사 장식은 남지만 한 번뿐인 꽃가루는 재생되지 않습니다.
- 기존 상점·이웃·소담 **세 명의 상호작용 위치와 농사 경로는 유지**합니다. 행사 손님은 장식용이고 플레이어를 가로막는 충돌이 없습니다. 모든 손님과 장식은 로컬 지오메트리·색상으로 제작되며 추가 다운로드·물리 엔진은 필요하지 않습니다.
- 검수: 사계절별 군중 상태·배치·구조 테스트, 실제 브라우저에서 개장 전→개장→납품 축하→새로고침 장식 유지 확인.

## 2.0 네 번째 리워크: 사계절 행사와 하루 전 일기예보

- 매 계절 **7~13일**에 다른 마을 행사가 열립니다. 봄에는 당근 모종 나눔, 여름에는 옥수수 새참, 가을에는 햅쌀 추수 잔치, 겨울에는 저장한 당근 이웃 나눔에 참여합니다.
- 새 주민 **행사 도우미 소담**과 나무 가판대·깃발을 마을길에 세웠습니다. 가까이서 실제 3D 캐릭터를 누르거나 **더보기 → 계절 행사**, 진행 중인 HUD 배너를 눌러 방문합니다.
- 행사 납품은 창고 재고를 원격 차감하지 않습니다. **창고에서 작물 싣기 → 행사에 직접 가져가기 → 소담에게 건네기**가 필요하고, 보상은 돈과 다음 농사에 쓸 씨앗으로 나뉩니다. 동일 계절의 보상은 한 번만 수령됩니다.
- 헤더의 **날씨·마을 소식** 버튼과 집의 휴식 화면에서 **다음 날 날씨**를 확인할 수 있습니다. 강한 비가 예보되면 물꼬를 미리 조절할 수 있고, 비가 지난 아침에는 논물과 잡초를 확인하라는 안내가 나옵니다.
- 3D 농장에 **흐린 하늘·비·강한 비**에 맞는 하늘빛, 밝기, 간단한 빗방울 효과가 나타납니다. 비 입자 145개를 단일 드로콜로 묶었고 강한 번개 번쩍임은 넣지 않았습니다.
- **작물에 변화가 있을 때까지 쉬기**는 이제 계절 행사 시작일이나 강한 비가 오는 날을 건너뛰지 않습니다. 한 해 4계절 × 14일이라는 기존 일력은 유지합니다.
- 저장 버전 **v6**에서 계절 행사 완료 기록과 참여 횟수를 보관합니다. 기존 v1~v5의 농사·작물·손수레·친밀도 기록은 그대로 읽으며 이미 받은 행사 보상은 새로고침해도 다시 나오지 않습니다.

검수: `node --test tests/korean-farm-*.test.mjs` (84개 회귀), `node tests/korean-farm-browser-audit.cjs` (실제 WebGL PC·모바일 체험 및 수령/저장 재확인).

다음 목표: 가뭄·장마 대비를 3D 작업으로 심화, 주민별 생활 시간표와 추가 부탁, 작물별 장기 생산 밸런스 조정.

## 2.0 세 번째 리워크: 실제 손수레와 마을 이웃

- 솔내리 장터의 순옥 아주머니와 마을길의 영수 할아버지를 독립된 **3D 주민**으로 배치했습니다. 주민은 움직이고 가까이 가면 손을 흔들며, 가까운 위치에서 주민을 누르거나 **더보기 → 이웃 만나기**로 말을 겁니다.
- 영수 할아버지의 대화는 계절과 논밭 상태에 따라 달라집니다. 하루 한 번 정을 쌓아 **세 번째 날에 당근 씨앗 두 봉지**를 받고, 저장/새로고침 후 같은 날 보상을 중복으로 받을 수 없습니다.
- 마을 납품은 장터 메뉴의 즉시 납품 버튼에서 분리했습니다. **창고에서 수확물 싣기 → 영수 할아버지 만나기 → 실제 소지량으로 전달**하며, 주문과 보상은 기존 데이터와 연결됩니다. 장터에서는 작물 판매와 농기구 구매를 계속합니다.
- 첫 판매 뒤 장터에서 **농장 손수레**를 구입할 수 있습니다. 창고에서 연결하면 바구니의 20개 대신 **60개까지 적재**할 수 있고 농부 뒤에 실제 3D 수레가 따라다니며 바퀴가 굴러갑니다. 대신 걷는 속도가 22% 느려집니다.
- 손수레는 창고에서만 연결·해제하며, 적재물이 남아 있으면 수레를 분리할 수 없습니다. 적재물은 기존 바구니와 **동일한 단일 재고**를 사용하므로 복제되지 않고, 판매·납품·창고 반납 후 수량도 일치합니다.
- 저장 버전 **v5**는 기존 v1~v4 기록을 보존합니다. 손수레 구매/연결 상태, 주민과의 친밀도와 보상 수령 여부가 저장됩니다. 비정상 저장의 수레 적재 초과분은 창고로 복귀합니다.

직전 단계의 다음 목표는 이번 리워크에서 일부 반영했습니다. 저사양 모바일 프레임 검수와 주민 의뢰의 다양화는 계속할 과제입니다.

## 2.0 두 번째 리워크: 물꼬 → 거름 → 창고 → 장터 → 휴식

- 물꼬를 직접 위아래로 끌어 조절합니다. **닫기·반쯤 열기·활짝 열기**의 세 상태를 저장하고, 물 유입량·수문 모습이 함께 달라집니다. 짧게 누르거나 가까이서 E로도 조절합니다.
- 거름 더미에서 삽질 한 번으로 퇴비를 최대 5주머니 담습니다(가방 공간·기운·더미 양을 초과하지 않음). 농부 허리에 퇴비 주머니가 표시되고 밭에서는 구역별로 실제로 뿌립니다.
- 수확물은 창고 재고로 남습니다. **창고 방문 → 바구니에 최대 20개 적재 → 장터까지 운반 → 바구니 재고만 판매·납품**하는 실제 운반 과정으로 바꿨습니다. 담거나 내려놓은 작물과 이전 저장된 재고가 중복되지 않습니다.
- 농가에서 **하루 쉬기** 또는 **최대 4일 동안 성장 변화나 돌봄 신호까지 쉬기**를 선택합니다. 여러 날 쉬더라도 매일의 날씨·물 소모·작물 성장을 빠짐없이 계산하고 중요한 변화에서 중단합니다.
- 저장 버전 v4는 기존 v1·v2·v3 농장 기록을 이전하며, 모내기 25칸·부분 작업·농기구 개선·마을 주문을 보존합니다.

남은 계획: 계절별 농촌 생활·축제·기상 사건, 장기 경제 밸런싱과 모바일 현장 관찰.

## 2.0 첫 플레이 리워크: 수확 → 장터 → 발전 → 다음 날

- 첫 농사 안내를 논 확인 → 수확 → 판매 → 첫 업그레이드의 4단계로 교체했습니다. 완료 후에는 성숙한 작물, 창고 재고, 낮은 기운, 작물 상태, 빈 밭 등에 따라 다음 행동을 안내합니다.
- 낫·괭이·수로에 돈을 투자할 수 있습니다. 업그레이드는 **첫 판매 이후** 열리며, 수확량·기운 소모·논물 증발에 실제로 영향을 줍니다. 농부가 들고 있는 낫과 괭이 재질도 달라집니다.
- 낫질한 구역에는 볏단이 남고, 수확이 끝나면 농가 헛간 앞에 수확물 자루가 쌓입니다. 당시에는 **시각적 운반 1차 구현**이었고, 위의 2차 리워크에서 실제 바구니 재고와 적재 제한을 추가했습니다.
- 모내기와 다섯 구역 농사 모두 **한 줄 드래그**로 여러 목표를 예약할 수 있습니다. 각각의 작물·토양 변경은 기존처럼 도구의 실제 접촉 순간에 하나씩 적용됩니다. 한 번 누르는 접근성 조작도 유지합니다.
- 세 개의 시작 납품 주문 이후에는 날짜별 반복 주문이 하루 한 번 등장합니다. 다음 날이 되면 주민 부탁이 새로 생깁니다.
- 집에서 하루를 보내면 새 아침의 날씨, 자란 작물, 경고와 목표를 알려 줍니다.
- 논 관리 UI는 도구를 먼저 보여주고 수분·양분 등의 상세 상태를 접었습니다. 일반 사용자에게 에셋 검수 메뉴는 숨기고 로컬 개발 환경 또는 `?farmQa=1`에서만 표시합니다.
- 당시 브라우저 저장 형식은 v3였고, 현재는 위와 같이 v4로 이전했습니다.

검수: `node --test tests/korean-farm-*.test.mjs` 및 `node --check games/korean-farm/game.js`.
남은 2.0 개발: 계절 연출, 저반복 장기 농사 밸런스, 실제 저사양 모바일 현장 검수.

## PR 2 — 실제 농사 시뮬레이션

`farming/farm-sim.mjs`에서 Three.js에 의존하지 않는 농사 규칙을 계산합니다.

- 벼·당근·옥수수 재배: 시작 작물이 생육 단계별로 서로 다르게 자라고 수확할 수 있습니다.
- 농사 행동: 괭이질, 모내기/파종, 밭 물주기, 논 물꼬 여닫기, 김매기, 거름주기, 수확
- 논 구역별 수위와 물꼬, 토양 수분·질소·잡초·작물 건강 상태를 하루 단위로 갱신
- 하루 보내기: 14일×4계절 게임 달력, 날짜에 따라 고정 시드 날씨, 농작물 생육
- 농가 창고·장터: 씨앗·퇴비 구입과 쌀·당근·옥수수 판매, 화폐·수확 기록

## 4.1 — 농사 손맛: 작업 접촉 시점에만 농사 결과 적용

- 농사 행동은 `interactions/action-flow.mjs`의 4단계(이동→준비→접촉 애니메이션→회복)로 처리합니다.
- 작업을 멀리서 실행하면 농부가 논밭 경계까지 자동으로 이동합니다. 농사 버튼은 **한 번만** 누르면 됩니다.
- 씨앗·거름·체력·수확물·물꼬·잡초 등 상태 변경은 농기구 접촉 시점에만 `applyFarmAction`으로 확정합니다.
- 이동 중 직접 WASD/조이스틱/땅 클릭으로 움직이면 아직 착수하지 않은 작업만 취소됩니다. 이미 시작한 스윙은 중복 입력과 강제 변경을 막습니다.
- 중복 작업, 하루 넘기기, 가방 열기 등을 제한하여 농사 상태가 일관되도록 합니다. 접근 중 경로가 막히면 18초 뒤 자원 소모 없이 취소됩니다.
- 농사 작업 UI에 이동·동작 진행 상태를 표시하고, 작업 이펙트는 실제 도구 접촉 시점에 논밭 가까이에서 발생합니다.
- 순수 상태 전이 검증: `node --test tests/korean-farm-action-flow.test.mjs`
- 브라우저 검증: 수확 직후 자원 변화 없음 → 접촉 뒤 수확 → 작업 완료 → 재파종/물꼬 → 원거리 한 번 누르기 이동 및 작업 완료.

이번 단계는 물리 기반 IK, 낫날과 식물의 정밀 충돌 판정, 여러 개체를 구획별로 자르는 표현까지 포함하는 것은 아닙니다. 그 부분은 후속 그래픽·애니메이션 심화 작업으로 분리합니다.

## 4.2 — 솔내리 한국 농촌 풍경 리워크

4.1의 농사 작업·자동 이동·저장 상태를 유지하며, 마을 구역의 외형을 한국 현대 농촌에 가깝게 개선합니다.

### 새 풍경

- **농가**: 담백한 회벽, 나무 창틀, 푸른 양철지붕, 처마·굴뚝·현관 돌계단
- **곡물 창고**: 갈색 목재 외벽, 슬레이트 느낌의 지붕, 곡물 포대와 경첩 느낌의 문짝
- **마당**: 장독대, 평상, 고추 건조대, 파란 고무대야, 손수레, 낮은 울타리
- **논 주변**: 나무 물꼬, 둑·돌·풀숲과 갈대, 기존 농수로의 작은 물길과 건널목
- **마을길**: 자갈·흙 가장자리, 전봇대와 잡풀, 한글 마을 안내판
- **마을 장터**: 직거래 판매대, 농산물 바구니, 수레

모두 기존 Three.js와 색상 지정 로우폴리 지오메트리로 생성됩니다. 신규 네트워크 모델 파일이나 외부 저작권 이미지는 사용하지 않습니다.

### 기술적 유의사항

- 풍경은 `rendering/village-scene.js`에서 한 번만 만들고, 종료 시 지오메트리·재질·간판 텍스처를 정리합니다.
- `rendering/village-layout.mjs`에서 주요 건물의 충돌 영역을 관리합니다. 작은 장식은 플레이어의 경로를 막지 않습니다.
- 길의 작은 돌 150개는 한 번에 그리는 InstancedMesh로 렌더링합니다.
- `games/korean-farm/game.js`의 기존 가정용 Kenney 주택·Styloo 축사 대체 로딩을 제거하고 4.2 풍경을 사용합니다.
- 3D 씬의 장식은 **상호작용 가능한 물체가 아닙니다.** 마을 주민·실제 장터 방문은 4.3에서 구현합니다.
- 농사 생육·수확·저장 스키마는 변경하지 않습니다. 기존 브라우저 저장 데이터는 그대로 읽습니다.

### 검수

- `node --test tests/korean-farm-village-scene.test.mjs`: 랜드마크 배치·논밭 간섭·충돌 경로·렌더링 자원 검사
- `node tests/korean-farm-browser-audit.cjs`: 실제 Chromium/WebGL 농사 플레이 검사 + 농가·장터 화면 추가 캡처

## 5.1 — 손으로 심는 모내기 (1차 플레이 개편)

- 새 농장은 **첫 번째 논**을 모내기 연습 구역으로 사용합니다. 두 번째~네 번째 논은 기존 생육 단계가 남아 있습니다. 이전 v1/v2 저장 데이터는 원래 심은 벼를 유지합니다.
- 첫 번째 논을 누르고 **모내기 시작**을 선택하거나 안내 카드의 버튼을 누르면 5×5=25개 심을 자리가 논 위와 오른쪽 게임 HUD에 나타납니다.
- 논 위의 빛나는 자리·HUD 25칸을 한 번 누르면 농부가 해당 위치로 이동합니다. 모종을 손에 든 농부가 허리를 숙이고, **손이 닿는 순간 한 포기만** 생성됩니다.
- 오른쪽의 **모 심기** 버튼을 한 번 누르면 선택한 자리 한 포기, 계속 길게 누르면 다음 빈 자리로 이동하며 이어 심습니다. 손을 떼면 다음 동작은 예약하지 않습니다.
- 한 묶음의 모종은 25자리에 사용할 수 있고, 포기당 기운 1을 사용합니다. 25자리 완료 시 기존 생육 단계로 전환되며 성장·논물·수확 시스템에 연결됩니다.
- 논과 밭의 다른 농사 행동·건물·주민·저장 API는 유지됩니다. 도구 HUD는 논 모내기를 하는 동안만 나타납니다.
- 단위 테스트: `node --test tests/korean-farm-rice-transplant.test.mjs tests/korean-farm-simulation.test.mjs`
- 실제 Chromium 플레이: 논에서 첫 포기 접촉 후 변이, 두 번째 모내기, 완료 처리, 저장·재열기, 모바일 HUD 캡처.
- 범위 제외: 개별 포기별 성장·비료·수확량·병해충 계산과 다른 농사 작업 재제작은 후속 단계입니다.

## 5.2 — 직접 돌보는 농사 (2차 플레이 개편)

모내기 25자리 구조는 그대로 유지합니다. 괭이질·물주기·김매기·낫질은 이제 **각 논밭의 작업 구역 다섯 곳**을 직접 돌아다니며 진행합니다.

- **괭이질:** 수확 뒤 다섯 구역을 실제로 갈아야 다음 작물을 심을 수 있습니다. 각 구역에 뒤집힌 흙이 보입니다.
- **물주기:** 밭에서 물뿌리개가 닿은 구역이 먼저 축축해지고, 수분이 조금씩 오릅니다. 하루가 지나면 다시 물을 줄 수 있습니다. 논은 기존 물꼬 조절을 유지합니다.
- **김매기:** 잡초가 자란 논밭에서 구역별로 풀을 뽑고 잡초량을 줄입니다. 이미 정리한 구역은 그날 다시 작업하지 않습니다.
- **낫질·수확:** 농부가 낫을 휘두른 구역에서만 벼·밭작물이 사라지고 그루터기가 남습니다. 다섯 번째 구역이 끝나야 수확물이 창고에 들어갑니다.
- **작업 HUD:** 5개 구역, 남은 기운, 완료 상태, 선택한 위치와 길게 누르기 연속 작업을 제공하며 PC·휴대전화 모두에서 같은 방식으로 작동합니다.
- **판정:** 도구 접촉 시점에만 구역 상태, 기운, 시간, 작물 수량이 바뀝니다. 이동 도중에는 비용을 쓰지 않습니다.
- **저장:** v1 및 기존 v2 저장 데이터를 불러옵니다. 새 v2의 `work` 필드는 선택적으로 추가되어, 부분 괭이질·부분 수확도 이어서 할 수 있습니다.
- **효과:** 전용 `rendering/field-work-grid.js`는 흙·물기·잡초·그루터기를 구역별로 표현하며, 익은 작물 모형은 이미 거둔 구역만 숨깁니다.

검증: `node --test tests/korean-farm-manual-work-v2.test.mjs tests/korean-farm-rice-transplant.test.mjs tests/korean-farm-simulation.test.mjs` 및 Chromium 데스크톱·휴대전화 플레이 검사를 수행합니다.

이번 버전은 **구역 단위의 손작업**입니다. 포기별 물·병충해·수확량 분배나 낫날과 식물의 정밀 물리 충돌은 포함하지 않습니다.

## 농사 안내와 솔내리 납품 부탁

- 논밭 상태 안내는 생육 계산에 쓰이는 물·수분·양분·잡초 기준에 맞춰 다음 행동과 영향을 설명합니다.
- 창고·장터에 마을 납품 부탁 세 건을 추가했습니다. 수확물을 직접 판매할지, 납품하고 보상금을 받을지 선택할 수 있고 진행 상태는 저장됩니다.
- 납품은 쌀 5개, 당근 3개, 옥수수 3개 순서입니다. 주문 보상은 고정 판매가보다 조금 높은 수준으로 맞췄습니다.
- 다음 단계에서는 이 부탁을 실제 마을 사람과 장소에 연결하고, 모내기 반복 부담을 줄이는 보조 방식을 검토합니다.
