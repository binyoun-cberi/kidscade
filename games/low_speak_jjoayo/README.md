# 스피크가 쪼아요!

Kidscade 저학년용 음성 영단어 스피드 게임입니다.

## 핵심 루프
- 30 / 60 / 90초 동안 한글 뜻과 그림(이모지)을 보고 영어 단어를 말합니다.
- 브라우저의 Web Speech API가 반환한 최대 5개 후보를 정규화해서 정답을 판정합니다.
- 정답은 +1, 5콤보마다 시간 보너스, PASS는 -1초, 발음 힌트는 -3초입니다.
- 음성인식 미지원/권한 거부/마이크 오류에서는 타이핑 모드로 전환할 수 있습니다.
- 게임 서버에는 음성 녹음 파일을 저장하지 않습니다.

## 파일
- `index.html`: 진입점 및 UI
- `style.css`: 모바일 세로 화면 우선 UI
- `words.js`: 기초 영단어 데이터
- `game.js`: 타이머, 음성인식, 정답 판정, 콤보, 결과 로직

## 플랫폼 연동
- Game SDK v1: `low_speak_jjoayo`
- 기록은 `KidscadeGame.gameOver({score})`를 통해 SDK 최고기록에 저장합니다.
- 외부 음성 API 키나 별도 게임 백엔드는 사용하지 않습니다.

## 참고 설계
Web Speech API 기반 오픈소스 음성 게임/데모의 공통 패턴(권한 확인, interim result, 자동 재시작, 대체 입력)을 참고해 Kidscade용으로 독립 구현했습니다.
