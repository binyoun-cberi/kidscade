# 《단 하나의 인생》 9차 개선 루프 — 고려 생업과 픽셀 동작

## 시작 기준
- 2026-10-22 병합 완료한 PR #677 (새로운 시대별 픽셀 모듈, 가족 생사·피란 반영, 12칸 비교실).
- 기존 시뮬레이션 데이터를 새로 생성하지 않고, 화면에서 읽는 **실제 계획/직업**에 맞춘 모습만 개선.
- 원작 픽셀 이미지/외부 스프라이트 소스의 코드를 복사하지 않음.

## 분석과 문제 발견
1. 고려 `g.job` 또는 `g.people[].plan`이 농사·삼베·나루·바구니·글공부로 서로 다르더라도,
   기존 `occupants()`는 하나의 `work` 포즈로 통일.
2. `actor()`는 `work`일 때 **항상 같은 바구니 소품**을 그려, 나루 일이나 농사를 하는 사람이
   바구니를 만드는 것처럼 보임.
3. 미성년자·고령자의 생업 소품이 모호하고, 비교실에서 작업 종류를 바꿀 수 없어 포즈 검증이 어려움.

## 반영한 개발 수정
- `historical-sprites-v1.js`에 순수 함수 `activityFor(work,age,away)` 추가.
  - 농사→괭이, 삼베/모시/길쌈→간이 베틀 표현, 나루→줄·노젓기 도구,
    바구니→바구니, 글과 셈/배움→책 형태.
  - 14세 미만, 68세 이상에는 성인 작업 동작을 부여하지 않음.
  - 주인공이 집을 떠난 경우 출생 가정의 일을 계속하는 것처럼 보이지 않게 `walk` 우선 적용.
- 각 작업 소품을 손목 위치를 기준으로 그려 작업 2프레임에 함께 움직이도록 함.
- 내륙 지역에서 실제 가족원이나 주인공이 `나루 일`을 할 때만 강가 물길을 표현.
  해당 지역이 해안이라는 잘못된 결론을 표시하지 않음.
- 실제 피란 상태에서는 평소 농사·나루 일을 계속하는 것처럼 연출하지 않고
  이동 자세로 전환. `g.refuge`가 해제되면 원래 기록된 직업의 연출 복귀.
- 실제 `g.job`과 가구원 `p.plan`에서 종류를 추출하며 저장 인생/수입/수확/시대 확률 무변경.
- `historical-comparison.html`에 작업 선택기를 추가해 동일 시드·연령·계층 조건을 유지하면서
  작업 소품을 직접 비교할 수 있게 함. 아동은 기존 교육 장면 유지.
- 코드 변경 후 `index.html`과 비교실의 캐시 버전 업데이트.

## 검증
- 농사/길쌈/나루/바구니/글공부에 대한 작업 분기와 색상으로 구별되는 소품.
- 손목 두 프레임과 고정된 발 기준선, 아동/고령자의 과도한 작업 표현 방지.
- 내륙에서 실제 나루 일 때만 하천 배경 생성, 피란 때 일상 작업 연출 중지.
- 실제 가구의 계획에 따라 그림이 달라지는지, 재산/인물/연도를 수정하지 않는지 확인.
- 전체 회귀 및 저장소 CI, 브라우저 검사는 각각 결과를 확인하고 보고.
- **한계:** 이 작은 픽셀 소품은 역사 복식·직업 도구의 교육용 기호적 표현이다.
  고려 시대의 실제 도구를 학술적으로 고증하거나 실제 이미지의 시각적 아름다움을
  육안 검수한 결과라고 주장할 수 없다.

## 후속 우선순위
- 12칸 비교실을 실제 브라우저에서 캡처하고 농촌/해안/피란/관료의 차이 및 겹침 재검수.
- 고려의 성별·나이·시대 지역에 따른 복식은 신뢰할 만한 사료 검토 후 별도 고증 단계에서 보완.
- 조선의 인물별 직업 동작 및 연대기 사건이 어느 시점에 픽셀로 반영되는지 검증.
- '몫' 또는 의미 없는 AI식 문장·게임 자원과 역사 실측 단위의 혼동 방지 테스트는 계속 유지.

## 10차 — 인물 크기·금빛 표식·나루터 거리 검수

### 발견
1. 고려 픽셀의 주인공 표식은 `feet - 75*scale` 등 고정된 공식으로 그렸다.
   그러나 실제 인물은 어린이와 성인의 픽셀 단위 배율을 반올림하고 머리싸개도
   나이에 따라 달라, 어린 인물에게 표식이 지나치게 떠 보일 수 있었다.
2. 내륙 나루 일의 물길이 화면 왼쪽 0~210px에서 끝났다. 중앙 주인공은
   x=330px 부근에 있어 실제 물가에서 떨어져 서 있었다.
3. 집을 떠나는 어린아이(특히 3세 미만)까지 어른과 같은 보행 자세로
   강제하던 부분을 발견했다.

### 적용
- `actor()`가 실제 픽셀 머리 위 좌표 `top`과 실루엣 높이를 반환하도록 수정.
  주인공 금빛 표식은 이 좌표를 직접 사용해 나이에 따라 일정한 간격을 유지.
- 내륙에서 **실제 나루 일을 하는 인물**이 있는 때에만 물길이 중앙 무대
  앞쪽까지 다가오며 나무 발판을 놓음. 인물의 발 아래 전체를 물로 덮지 않도록
  물의 위쪽 경계는 발 기준선보다 낮게 설정.
- 3세 미만의 가상 피란/여행 장면에는 보행 포즈를 억지로 붙이지 않고
  정지 포즈를 사용. 인물을 새로 생성하거나 이동 데이터를 바꾸지 않음.
- 확장 회귀 검사: 0·2·10·14·30·70·90세의 표식 위치, 강가 발판/수면
  위치, 영아 이동 포즈, 장면 렌더링 중 데이터 불변.

### 정직한 검수 한계
위 검사는 Canvas 명령 좌표를 비교하는 **기하학적 검증**이다.
실제 모바일 브라우저에서 만든 스크린샷의 심미성이나 픽셀 화풍
일관성을 육안으로 평가한 결과는 아니다.

## 11차 — 같은 인물의 사건 전후 장면 비교

고려 픽셀 비교실 `historical-comparison.html`에 생업과 별개로 **지역(내륙·해안)**
및 **생활 상황(평상시·피란·집을 떠남)** 선택기를 추가했다. 같은 외형 시드,
동일 연령·가구 유형에서 이 값을 바꿔 서로 다른 풍경을 비교할 수 있다.

- 피란 시 평소 집 대신 임시 거처, 생활 작업 대신 이동 자세를 사용.
- 집을 떠나면 가구원을 동행 인물로 허위 표시하지 않음.
- 내륙 나루 일일 때는 물가와 나무 발판이 인물 근처에 있는지 검사.
- 3세 미만 아이에게 강제로 성인 보행 자세를 붙이지 않음.
- 0/2/10/14/30/70/90세의 머리 높이를 계산해 금빛 표식을
  실제 머리 바로 위에 배치. 표식이 몸통에 겹치지 않는지 검수.
- 사태 변경은 비교실 내부 가상의 `g.refuge`, `g.away`, `g.region`
  값에 한하며 게임 진행과 저장 데이터·경제 수치에 영향 없음.

테스트는 픽셀 도형의 좌표와 데이터 불변 여부를 검증한다. 실제 캡처 이미지의
색 조화·복식 고증·배경의 아름다움에 대한 시각 검수는 별도로 필요하다.
