# 단 하나의 인생 — Chat 전용 개선 기록 (2026-10-22)

## 범위
- 게임 ID: `high_one_life`
- 게임 파일: `games/high_one_life/**`
- 관련 회귀 테스트: `tests/one-life-goryeo-v343.test.cjs`
- 다른 게임, 저장 포맷, 역사 확률, 인물 상태 및 배포 설정 변경 없음.

## 역할별 1차 검수 (분석 → 기획 → 구현 → 비평 → 테스트)

### 발견 1: 고려 출생 추첨의 지역 고정
- 현재 고려 지방은 7곳인데 화면 추첨은 `(loops*7)%7`로 첫 지역만 표시.
- 실제 출생 지역은 기존 엔진의 선택으로 정해지므로, 게임 결과보다 **연출의 신뢰성**을 떨어뜨리는 문제.
- 추첨 폭과 서로소인 순환 간격을 선택하여 모든 지역을 한번씩 거친 뒤 반복하도록 수정.
- 출생 결과·인물 RNG와 저장 데이터는 절대 변경하지 않음.
- 2~15개 지역을 가진 예시와 실제 고려 7개 지역 모두에서 중복 없는 순환을 검증.

### 발견 2: 선택창을 다시 그릴 때 강제 스크롤
- `showDecision()`이 호출될 때마다 선택창의 `scrollIntoView()`가 실행되어,
  같은 선택을 이미 보고 있어도 페이지가 이동할 수 있음.
- 사건의 연도·나이·대기 중인 사건 ID가 바뀌었을 때만 선택창으로 이동하도록 개선.
- 역사 자료나 인물 기록을 탐색할 때 불필요한 강제 스크롤을 줄임.
- 선택지 내용과 게임 내 사건 결과를 변경하지 않음.

### 발견 3: 움직임 감소 설정 미반영
- 설정에서 애니메이션 감소를 요청해도 출생 룰렛은 19프레임 재생.
- 감소 설정이 활성화되면 출생 증명서와 실제 지역을 즉시 표시.
- 일반 이용자는 기존 추첨 시간을 유지.

### 발견 4: 선택 결과가 불분명한데도 무조건 붙는 추상적인 감상

- 이전 코드는 선택 후 수치 변화가 없어도 ‘그날의 일은 마음 한편에 남았다’
  또는 ‘당장은 눈에 띄는 변화가 없었다’라는 후일담을 추가로 기록.
- 실제 삶의 사건 결과는 각 선택 엔진이 이미 기록하므로, 확인되지 않은
  감상이나 단정으로 연대기를 채우지 않도록 수정.
- 능력치·생업·재산의 즉시 변화가 있는 경우에만 수치 변화 기록을 추가.
- 가족·사건·살림의 장기 변화를 거짓으로 '없음'이라 단정하지 않음.

## 개선 3차 — 문장·엔딩 인과·픽셀 장면을 함께 검수

### 문장 편집 역할(사람이 재확인해야 하는 검수)

1. 누구에게 무슨 일이 있었는지 알 수 없는 ‘흔적’, ‘인연’, ‘새로운 가능성’ 같은 문장을 검출.
2. 역사 배경·장소·인물에게 실제로 일어난 일을 구분하고, 확인되지 않은 성과는 서술하지 않음.
3. 선택지에 실제 행동, 필요한 비용·시간·가족 사정이 보이는지 점검.
4. 고려·조선·근현대의 어휘 및 존댓말·시제 일관성을 확인.
5. 동종 사건·후일담이 반복될 때 동일 어구만 바꾸지 말고 **실제 선택의 결과가 다른지** 확인.
6. 교정 전후 사건 ID·효과·저장 포맷·사료 출처를 유지. 자동 치환 금지.

`node games/high_one_life/text-style-audit.cjs`로 어색한 문장 후보를
보고할 수 있다. 탐지는 사람이 읽을 후보일 뿐 모든 지적이 오류라는 뜻은 아니다.

### 엔딩 인과
- 같은 나이에 여러 선택을 하면 기존 엔딩이 `age`만 대조해 엉뚱한
  선택의 `decision-effect`를 보여줄 수 있었음.
- 정확한 선택에 연결된 기록만 후일담으로 표시하고, 결과가 없는 경우
  ‘그때는 무엇이 달라질지 몰랐다’라는 빈 문장을 새로 만들지 않음.
- 과거 기록에 인과 연결 ID가 없다면 거짓으로 연결하지 않음.

### 픽셀 장면(화면 실연과 별도 검증)
- 조선 농사 장면에서 괭이질만 시작하면 주민 그림을 `x=470`으로
  강제로 이동시켜 한순간에 화면 오른쪽으로 옮겨지는 현상을 수정.
- 실제 배치 위치를 고정하고, 괭이질하는 손 앞에 작은 텃밭과 새싹을 그림.
- 실제 농사 재고·수확물·부모나 가족 인원은 새로 생성하지 않는 **표현 전용** 효과.
- 가구의 생사·나이·부재·의복·그림자·충돌·가독성과 함께 테스트.

### 다음 픽셀 검수의 순서
1. 주요 시대·생업·가구 유형별 스크린샷에서 화면 구도, 텍스트, 색상 대비 비교.
2. 프레임 간 사람·도구 순간이동, 팔다리 부자연스러움, 가림 현상 조사.
3. 배경 소품이 **실제로 존재하는 사건·가족·생업 상태**를 보여 주는지 대조.
4. 360px 모바일 화면에서 인물·문구가 잘리는지, 움직임 감소 설정을 지키는지 확인.
5. 사용하지 않은 기존 에셋을 조사한 후 필요한 장면에만 연결.

## 검증 기준
- 코드 시뮬레이션: 모든 고려 지역을 표시하고 결과 선택을 바꾸지 않아야 함.
- 화면 내 재렌더: 같은 사건일 때 스크롤하지 않으며, 새 사건에 진입하면 이동해야 함.
- 움직임 감소: 추첨이 아닌 결과를 즉시 읽을 수 있어야 함.
- 수치 변화 없는 결정에 추상적인 후일담을 자동 생성하지 않아야 함.
- 각 선택 엔진의 실제 결정 기록은 유지되어야 함.
- 엔딩에서 같은 나이의 다른 선택에 잘못된 결과가 붙지 않아야 함.
- 픽셀 그림의 농사짓는 사람은 툴 애니메이션 중 순간이동하지 않아야 함.
- 기존 `one-life` 시뮬레이션과 CI, 가능하면 브라우저 검증이 통과해야 함.

## 비평 및 후속 단계
- 콘텐츠 양보다 개인의 과거 행동이 다음 사건에 실제로 반영되는지를 점검할 필요가 있음.
- 이번에는 인물 상태·경제·역사 확률에 영향을 미치지 않는 사용성 문제만 수정.
- 인과관계의 진정성, 높은 연령대의 반복 사건, 현대/고려/조선 기간의 선택 빈도는
  이후 별도 검증과 학생 플레이 피드백이 필요.

## 개선 반복 4 — 시대별 생활 표현과 픽셀 가족 묘사

### 언어 검수
- `곡식 N몫` 같은 표현은 역사적 실측 단위가 아니라 게임의 내부
  추상 수량이다. 이를 옛날의 실제 가마·되·석 등으로 임의 환산하면
  역사적 사실을 왜곡하므로 그러지 않는다.
- 고려의 곡식 재고·연간 살림 기록·엔딩 자산, 조선의 소작료·세금·환곡
  상환·전쟁 양식·상속·피란을 각각 실제 뜻이 드러나는 말로 정리한다.
- 정량 수치의 보존은 중요하므로 원래 게임 수치와 수령/지급 효과를
  변경하지 않고, 출력 문장과 표시 명칭만 조정한다.
- 이후 편집 시 원래 잘못된 표현이 재등장하지 않도록 전용 테스트와
  오프라인 스타일 검수 도구를 함께 운용한다.

### 픽셀 검수
- 근현대용 공통 픽셀 장면은 16세 미만이면 부모 두 명을, 혼자 지내는
  성인이면 관계가 확인되지 않은 인물 한 명을 무조건 그렸다.
- 가상의 가족·친구를 추가로 만들지 않고 학교·집·일터의 물건을 그려
  인물 주변을 채우도록 변경했다. 배우자·아이 표시 조건은 실제
  `profile.partner`와 `profile.child` 상태를 사용한다.
- 픽셀 표현은 장면의 사실 관계를 바꾸지 않으며 실제 플레이 기록은
  그대로 유지한다.

### 다음 검수 과제
- 고려 재고 수치에 시대별 정확한 계량단위를 붙일 수 있을지는 별도의
  사료·시뮬레이션 모델이 없으므로 미해결 상태로 남긴다.
- 시대별 실제 장면을 나란히 놓고 색상 대비·반복 소품·도구 방향과
  연령별 자세를 검토한다. 자동 테스트 통과가 시각적 완성도 검증은 아니다.
