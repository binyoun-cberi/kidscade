# 단 하나의 인생 — 생활감·자동 선택·삶의 갈래 검수

## 이번 연속 루프 (6회)

1. **말투 살피기** — 안내문과 회고에서 길고 반복적인 설명을 걷어내고 짧은 문장으로 정리했다.
2. **옛 단위** — 곡식은 말, 옷감은 필, 밭은 마지기, 살림 돈은 냥처럼 게임 속 말맛을 살렸다. 수치 체계와 경제 계산은 건드리지 않았다.
3. **자동 선택** — 직접 켜고 끌 수 있다. 현대·고려·조선의 선택과 회상을 한 번에 하나씩 처리하며 임의의 생성 모델을 호출하지 않는다.
4. **이어하기와 아이 이름** — 자동 선택 상태를 저장하고 이어받는다. 자동 선택 중 새 아이가 태어나면 원래 지어진 이름을 사용한다. 화면이 숨겨졌거나 일시정지 중이면 진행하지 않는다.
5. **정말 다른 출생** — 기존 모델에 이미 들어 있던 세계 여러 나라의 현대 출생을 화면에서 직접 고르거나 우연에 맡길 수 있게 열었다. 고려·조선 출생은 계속 한반도이며, 다른 삶 4명의 출생 국가도 주인공과 같게 맞춘다.
6. **검수** — 자동 선택의 재현성, 실제 선택지와 순서, 세계 출생·가정·성별·직업·연령별 서로 다른 결과, 말투와 단위의 간결함을 테스트했다.

## 기존 브랜치의 앞선 3개 개선

- 같은 출생으로 다시 살 때 원래 나라 유지
- 고려·조선의 경제와 가족 회고를 시대별로 구분
- 선택 기록 비교 시 한 나이의 여러 갈림길을 묶고 달라진 결과를 펼쳐 볼 수 있게 함

## 작품의 톤

초등학생이 흐름을 끊지 않고 읽는 것이 우선이다. 게임 화면에 도량형 환산 강의를 넣지 않는다.
예: `곡식 세 말`, `비단 한 필`, `밭 한 마지기` 같은 생활 속 말로 보여준다.
독립적인 별도 AI 모델이 이 글을 검수했다고 주장하지 않으며, 이번에는 코드 기반 편집 검수를 적용했다.
