# 《단 하나의 인생》 개선 루프 — 살아가는 장면 1차

## 참고 자료
- 사용자 제공 『80억 분의 1 (1in8b 공식) · 인생 시뮬레이션 게임 · 무작위로 태어나 한 번뿐인 삶을 살아보기』 PDF 1–5쪽.
- 사용자 제공 『80억분의 1인생 게임 만드는법 _바이브코딩_.. _ 네이버블로그(1)』 PDF 1쪽.
- 첫 번째 PDF의 상단 픽셀 장면·상태·기록·진행 조절(1쪽), 인생 지도와 생존 곡선(3–5쪽)을 **구성 원칙**으로만 참고했다.
- 두 번째 PDF는 부분 캡처로, 실제 구현 방법이나 저작자의 도구와 소요 시간은 확인할 수 없다.
- 원작의 픽셀 그림·이미지·코드·브랜드명은 복제하거나 다운로드해 사용하지 않는다.

## 1차: 현재 인생을 먼저 보여 주기 (이번 PR)
### 분석
- 실제 재생 화면에서 광범위한 역사·가족·정책 기록이 장면과 선택보다 먼저 나와 핵심 행동까지 스크롤이 길어짐.
- 건강/행복/배움/관계는 사이드 영역에 있지만 플레이 화면 첫 부분에서 함께 보기 어려웠음.
- 이미 존재하는 지도, 생존 곡선, 기록 비교를 재구현하면 중복 UI를 늘리게 됨.

### 구현
1. 유년기/시대 설명 바로 다음에 주요 픽셀 장면 배치.
2. 실제 `life.stats`에서 네 가지 상태를 읽어 장면 아래에 간결하게 표시.
3. 시간 조절과 생활 방향, 현재 서사·선택을 역사 상세 패널보다 앞으로 이동.
4. 기존 출생 기록·인생 지도·생존 곡선·다른 삶 비교 버튼은 주요 선택 바로 뒤로 옮겨 접근성을 높임. 자세한 역사 자료는 그 아래에 유지.
5. 480px 이하 모바일 및 움직임 감소 설정에 맞는 스타일링 적용.

### 검증
- HTML 문서 순서, 상태 요소 ID 단일성, 실제 상태와의 연결, 모바일 미디어쿼리를 테스트로 보호.
- 하나의 선택이 실제로 진행되는지, 모바일 360px에서 잘림이 없는지는 브라우저 확인 별도 필요.
- 고려 1200–1392 시대의 전용 화면은 별도의 렌더링 경로를 사용하므로 이번 일반 플레이 화면 재배치의 적용 대상이 아님.

## 2차: 보이는 일이 실제 인생과 일치하는가 (이번 PR)
### 분석
- 근현대 공통 픽셀 디오라마는 배경 변주가 있지만 생업이 실제 화면에 반영되는 상황이 제한적.
- 직업·가족의 실제 상태와 무관한 소품을 추가하면 시뮬레이션의 신뢰도가 떨어짐.

### 구현
- 나이 16–74세, 농촌 거주, 기록된 직업이 농사 관련인 경우에만 경작 중인 작은 밭과 괭이 표현.
- 다른 생업, 도시 거주, 어린이의 장면에는 밭을 억지로 추가하지 않음.
- 표현 요소의 렌더링에 따른 경제·상태·가족·저장 데이터 변형 없음.

### 검증
- 실제 직업·거주 환경·나이에 따른 픽셀 도형 생성 여부, 인물 데이터 무변경, 픽셀 스무딩 방지를 테스트.

## 다음 반복 권장
1. 여러 시대와 직업의 실제 브라우저 스크린샷 비교 (고려는 별도 뷰, 조선은 별도 픽셀 렌더러).
2. 선택 → 즉시 변화 → 몇 년 뒤 일어난 실제 결과를 연대기와 엔딩에서 정확히 연결하는 구조 검수.
3. 같은 나이에 여러 결정을 하면 회고 비교에서 기록이 사라지지 않는지 검증.
4. '몫'과 비슷하게 게임 내부 추상 단위를 실제 역사적 단위처럼 표현하거나, 추상적 결과를 임의로 보태는 문장 검수.
5. 통계 자료의 관측값·추정값을 시각적으로 구분. 동시 접속자·가상의 동년 출생 인물을 실제 인구 수처럼 표현하지 않기.
