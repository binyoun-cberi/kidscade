## 참고 자료
- 사용자 제공 『80억 분의 1 (1in8b 공식) · 인생 시뮬레이션 게임 · 무작위로 태어나 한 번뿐인 삶을 살아보기』 PDF 1–5쪽.
- 사용자 제공 『80억분의 1인생 게임 만드는법 _바이브코딩_.. _ 네이버블로그(1)』 PDF 1쪽.
- 첫 번째 PDF의 상단 픽셀 장면·상태·기록·진행 조절(1쪽), 인생 지도와 생존 곡선(3–5쪽)을 **구성 원칙**으로만 참고했다.
- 두 번째 PDF는 부분 캡처로, 실제 구현 방법이나 저작자의 도구와 소요 시간은 확인할 수 없다.
- 원작의 픽셀 그림·이미지·코드·브랜드명은 복제하거나 다운로드해 사용하지 않는다.

## 1차: 현재 인생을 먼저 보여 주기 (이번 PR)
### 분석
- 실제 재생 화면에서 광범위한 역사·가족·정책 기록이 장면과 선택보다 먼저 나와 핵심 행동까지 스크롤이 길어짐.
- 건강/행복/배움/관계는 사이드 영역에 있지만 플레이 화면 첫 부분에서 함께 보기 어려웠음.
- 이미 존재하는 지도, 생존 곡선, 기록 비교를 재구현하면 중복 UI를 늘리게 됨.

### 구현
1. 유년기/시대 설명 바로 다음에 주요 픽셀 장면 배치.
2. 실제 `life.stats`에서 네 가지 상태를 읽어 장면 아래에 간결하게 표시.
3. 시간 조절과 생활 방향, 현재 서사·선택을 역사 상세 패널보다 앞으로 이동.
4. 기존 출생 기록·인생 지도·생존 곡선·다른 삶 비교 버튼은 주요 선택 바로 뒤로 옮겨 접근성을 높임. 자세한 역사 자료는 그 아래에 유지.
5. 480px 이하 모바일 및 움직임 감소 설정에 맞는 스타일링 적용.

### 검증
- HTML 문서 순서, 상태 요소 ID 단일성, 실제 상태와의 연결, 모바일 미디어쿼리를 테스트로 보호.
- 하나의 선택이 실제로 진행되는지, 모바일 360px에서 잘림이 없는지는 브라우저 확인 별도 필요.
- 고려 1200–1392 시대의 전용 화면은 별도의 렌더링 경로를 사용하므로 이번 일반 플레이 화면 재배치의 적용 대상이 아님.

## 2차: 보이는 일이 실제 인생과 일치하는가 (이번 PR)
### 분석
- 근현대 공통 픽셀 디오라마는 배경 변주가 있지만 생업이 실제 화면에 반영되는 상황이 제한적.
- 직업·가족의 실제 상태와 무관한 소품을 추가하면 시뮬레이션의 신뢰도가 떨어짐.

### 구현
- 나이 16–74세, 농촌 거주, 기록된 직업이 농사 관련인 경우에만 경작 중인 작은 밭과 괭이 표현.
- 다른 생업, 도시 거주, 어린이의 장면에는 밭을 억지로 추가하지 않음.
- 표현 요소의 렌더링에 따른 경제·상태·가족·저장 데이터 변형 없음.

### 검증
- 실제 직업·거주 환경·나이에 따른 픽셀 도형 생성 여부, 인물 데이터 무변경, 픽셀 스무딩 방지를 테스트.

## 3차: 현재 장면의 문장 편집 (이번 PR)
- 실제로 확인할 수 없는 감상적 제목과 상투적인 비유를 구체적인 생애 단계 명칭으로 교체.
- 현재 인물에게 기록된 사건이 없을 때는 새로운 사건을 만들어 내지 않고 기록이 없다고 설명.
- 역사적 사건·나이·직업·선택 확률과 저장 데이터는 그대로 둠.
- 전용 회귀 검사로 비슷한 제목이 재등장하지 않도록 점검.

## 다음 반복 권장
1. 여러 시대와 직업의 실제 브라우저 스크린샷 비교 (고려는 별도 뷰, 조선은 별도 픽셀 렌더러).
2. 선택 → 즉시 변화 → 몇 년 뒤 일어난 실제 결과를 연대기와 엔딩에서 정확히 연결하는 구조 검수.
3. 같은 나이에 여러 결정을 하면 회고 비교에서 기록이 사라지지 않는지 검증.
4. '몫'과 비슷하게 게임 내부 추상 단위를 실제 역사적 단위처럼 표현하거나, 추상적 결과를 임의로 보태는 문장 검수.
5. 통계 자료의 관측값·추정값을 시각적으로 구분. 동시 접속자·가상의 동년 출생 인물을 실제 인구 수처럼 표현하지 않기.

## 4차 — 공개 오픈소스 구조 참고: 캐릭터 레이어·원경·동작 (이번 PR)
- 연구 참고: [Sprite Forge](https://github.com/paperhurts/sprite-forge)(상태에 따른 부위별 조합),
  [2d_chars](https://github.com/juanpe500/2d_chars)(정해진 JSON 외형),
  [Universal LPC](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator)(복식·부위 조합),
  [Cairn Runner](https://github.com/dswmlim/cairn-runner)(원경/전경 레이어),
  [Local Character Generator](https://github.com/JatCool/local-character-generator)(발 위치·외곽선·팔레트 검사).
- **레포지토리의 소스나 실제 캐릭터 이미지 파일은 복사하지 않았음.** 이 게임 전용
  `sprite-composer-v1.js`로 작은 팔레트·부위별 실루엣·3단계 포즈 규칙을 직접 작성.
- 외형은 `life.seed`로 고정하므로 같은 사람의 유년기·성년기·노년기 얼굴·머리색·옷 색조가 이어짐.
  나이별 머리·몸통 비율은 달라지고 노년기에는 제한된 색상 변화를 표현.
- 현재 `lifeScene` 캔버스(600×258)와 공존하도록 2픽셀 단위 조합·정수 좌표·픽셀 스무딩 해제를 우선 적용.
  320×180 캔버스로의 전체 변환은 기존 시대별 렌더러 구도와 테스트를 깨뜨릴 수 있어 별도 시각 A/B 검토 대상으로 남김.
- Canvas의 원경·가까운 언덕·건물·주인공·외곽 전경 소품을 레이어로 분리.
  실제 인물의 출생/직업 데이터가 바뀌지 않는 한 같은 외형이 반복되도록 구현.
- 단순 구분을 위한 걷기·일하기 2프레임 포즈를 구현하되 연속 애니메이션 루프는
  아직 추가하지 않았음. 기존 시간·저장 동작에 영향을 주지 않도록 의도적으로 제한.
- 이 경로는 **근현대 공통 픽셀 장면**에 연결됐으며, 고려·조선 전용 장면의
  스프라이트를 갈아 끼우는 작업은 아직 하지 않음.

### 라이선스 안전 기준
- Universal LPC 생성기는 GPL-3.0이고 개별 아트워크 라이선스와 저작자 고지가 다름.
  사전 승인/귀속 표기 없이 아트워크를 프로젝트로 복사하지 않는다.
- Pixelorama·Tiled 등은 **제작 도구로 사용하는 일**과 **프로그램 코드를 게임에
  복제하는 일**의 라이선스 영향이 다르다.
- 무료 오픈소스라도 학습용 코드의 설계 원리 참고와 파일 복사는 구분한다.

## 5차 — 역사 단위와 게임 내부 단위의 분리 (이번 PR)
- 게임 안의 곡식·땅·재산 숫자는 교육적 사실의 양을 나타내는 값이 아닌
  *추상 시뮬레이션 자원*으로 유지.
- 고려·조선 시대와 가까운 연도(1900년 이전)의 플레이 화면에 접을 수 있는
  도량형 안내를 추가. 복잡한 경제 규칙은 건드리지 않고 용어만 설명.
- 조선 전기 표준척: 주척 ≈20.62cm, 영조척 ≈30.80cm, 황종척 ≈34.48cm,
  포백척 ≈46.66cm(한국민족문화대백과사전 「표준척」). 현대의
  일상적인 한 자 30.3cm를 고려/조선 전체로 소급 적용하지 않음.
- 홉→되→말의 10진 관계는 설명하지만 당시의 용량을 현대 리터로
  고정 환산하지 않음. 특히 외부 자료의 '15말 또는 20말 = 180L'은
  그 자체로 산술이 일치하지 않으므로 게임의 환산 근거로 사용하지 않음.
- 토지 단위 결·마지기는 시대·과세·토질에 따라 의미와 실제 면적이 달라
  단일 제곱미터 환산을 만들지 않음.
- 더 구체적인 환산은 시기·지역·측량 기준과 신뢰 가능한 사료를 검토한 뒤
  **교육용 예제**로 추가해야 하며 인생 엔진 재화 계산에는 무단 연결하지 않음.

## 6차 — 9칸 시각 비교와 나이·도구 접촉 검수 (이번 PR)

### 관찰과 수정
- 이전 조합기의 70세는 일반 성인과 사실상 같은 키·자세여서, 노년기가 옷 색상으로만 구별될 위험이 있었음.
- 10세·30세·70세의 각기 다른 머리/몸통 비율과 노년기 약간 숙인 어깨, 흰머리 픽셀을 추가해 서로 다른 실루엣 확인.
- 농사 괭이는 이전에 캐릭터와 무관한 별도 좌표로 그려져 손에서 떠 보일 수 있었음.
  이제 두 프레임의 오른쪽 손 위치에 괭이 자루와 날을 함께 그리며,
  성인 농사일이 아닐 때는 도구를 표시하지 않음.
- 원래 방식의 괭이는 새로운 조합기가 비활성화된 브라우저에서만 그리도록
  하여 동일 도구가 두 번 나타나지 않게 수정.

### 직접 비교용 페이지
- `games/high_one_life/sprite-comparison.html`: 개발용 9칸 비교 시트.
- **한 가상의 1950년생**을 기준으로 10세(1960), 30세(1980), 70세(2020)를
  농촌 생활/도시 생활/농촌 농사 3개 조건에 배치함.
- '다음 프레임'은 `options.frame`만 변경해 손·발 포즈를 비교하고,
  인생의 연도·건강·재화나 저장 데이터를 건드리지 않음.
- 학교·일터·마을 같은 조건은 검수용 가상 설정이며
  실제 게임 기록을 근거 없이 바꾸거나 실제 한 사람의 이력을 주장하지 않음.
- 시각 비교실은 일반 게임 화면의 버튼에 연결하지 않음.

### 추가 검사
- 동일 시드의 나이별 외형 지속성·발 위치·나이대 실루엣 높이 비교.
- 작업 중에만 괭이 1개를 렌더링하고 아동/대기 자세에서는 표시하지 않음.
- 9개 비교 조건의 존재, 저장 API 미사용 및 게임 데이터 불변.
- **육안 디자인 평가를 실제로 완료했다고 주장하지 않음.**
  자동 테스트는 데이터 정합성과 위치 관계를 주로 검증하며
  픽셀 도형의 심미성·역사적 복식 정확성은 후속 검수 필요.

### 다음 루프

2. 조선은 한복 계열, 고려는 시대·지역을 고려한 별도 캐릭터 구성 패밀리로 분리.
3. 가정 형편과 가족 실제 동선을 장면의 사물 밀도·집 규모와 연결하되

## 7차 — 고려·조선 전용 픽셀 가족과 장면 검수

### 실제 문제
- 기존 고려 마을 장면은 누가 살고 누가 떠났는지와 무관하게 특정 좌표에
  동일한 사람 네 명을 고정으로 그렸음. 실제 가구 정보가 바뀌어도 그림은 그대로였음.
- 조선 인물은 시대별 의복 규칙이 잘 만들어져 있지만 가족들 얼굴이
  모두 같은 피부색·머리색으로만 보였음.

### 이번 구현
1. `historical-sprites-v1.js`는 **게임 전용으로 직접 만든** 오리지널
   고려 인물 외형·저해상도 계층형 배경 구성기임. 기존 근현대 캐릭터
   `sprite-composer-v1.js`의 복식을 가져다 쓰지 않음.
2. 인물의 외형은 `life.seed + person.id`로 유지함. 아동·성인·노년의
   비율은 다르되 동일 인물은 세대를 거쳐 특징이 이어지도록 구성.
3. 고려 장면에서 등장인물을 `g.people`의 **실제로 살아 있고 태어난 뒤
   집에 있는 인물**과 살아 있는 주인공으로만 그림.
   주인공이 집을 떠난 때는 가족을 따라 그리지 않음.
4. 고려의 내륙·해안과 임시 거처를 구분하며, 신분 차이는 소박한 옷감/집
   색감에서 힌트를 주도록 단순화. 이는 **교육용 추상화**이지 고려 복식의
   고증 완료나 과거 인물의 실제 의상 복원이라는 뜻이 아님.
5. 조선은 `OneLifeJoseonCulture.wardrobe`의 사모·철릭·전립·저고리
   길이 변화 등을 **그대로 유지**하고 인물 ID별 얼굴 색조만 공유 정체성
   생성기를 연결. 조선 복식이 근현대 복식으로 대체되지 않음.
6. `historical-comparison.html`에서 시대별 × 10/30/70세 × 일반/관료 가구의
   12가지 **가상 예시**를 나란히 보여주고 포즈만 전환해 비교할 수 있음.
   실제 사용자 저장/결정/재산 정보를 변경하지 않음.

### 회귀 검사 기준
- 고려: 생존·출생 연도·부재·집을 떠난 상태와 등장 인물 수 일치.
- 고려: 내륙과 해안의 구도 차이, 고정 시드에 따른 외형 지속,
  아동에게 성인 농사 소품을 주지 않는지.
- 조선: 기존 가구 분류·관복·군복 규칙 불변, 각 인물 고유 얼굴 색조,
  게임 데이터 불변, 테스트용 비교 페이지 브라우저 실행 가능.
- 두 시대 공통: 발 기준 위치, 정수 좌표·nearest-neighbor 및 자산 출처.
- 이번 루프의 **자동 회귀 검사와 시각적 미감 검수는 별개**로 취급.

### 제약
- 시대별 픽셀 실루엣은 시각적 구분을 위한 개념 시제품.
  역사 자료 없이 특정 시대 머리 장식·계층 복식을 완벽하게 재현했다고
  주장하거나 실제 관직 복식을 모든 관료 집안 사람에게 일괄 적용하지 않음.
- 오픈소스 이미지·스프라이트·프로젝트 코드를 복사하지 않았고
  기존 인생의 경제·출생 확률·가족·인물 수·저장 포맷은 바꾸지 않음.
