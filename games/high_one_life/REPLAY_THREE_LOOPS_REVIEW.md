# 《단 하나의 인생》 — 같은 출생 다시 살기 개선 루프 3회

2026-10-22, PR #680이 정상 병합된 main을 시작점으로 삼는다.

## 1차: 같은 출생에서 국가가 바뀌는 문제

- **검수 발견:** 이전에는 선택과 관계없이 "같은 출생으로 다시 살기"의 국가를 대한민국으로 강제했다. 처음 미국 등 다른 나라에서 태어난 인생은 새 출생과 달라졌다.
- **수정:** 보관한 실제 `snapshot.country`를 전달하고 `engine.Life`가 유효한 국가명을 받아 같은 국가로 다시 시작한다.
- **기존 원칙 유지:** 1200~1899년 역사 한국 출생은 계속 대한민국 국가 레코드를 사용한다. 새로운 임의 국가나 출생 확률 변경은 없다.
- **검증:** 미국 또는 실제 등록된 타국, 대한민국, 역사 연도, 미등록 국가, 같은 시드·연도·기존 출생 설정 비교.

## 2차: 역사 시대 살림을 현대 화폐로 잘못 표시

- **검수 발견:** 고려 `goryeo343.grain`이 `life.money.netWorth`로 대입되는데 비교창은 이를 현대의 최종 순자산 형식으로 그린다. 조선은 `joseon.capital`을 100배 환산한 `netWorth`를 사용한다. 시대와 관계없이 현대 "출생 주거"도 표시했다.
- **수정:** `ending-era-summary-v1.js`가 실제 고려 `grain/pocket/land`, 조선 `capital/joseon2.grain`을 별도로 기록한다. **모두 '게임 속 수치'**로만 표시하며 역사적 화폐·용량·면적 변환은 하지 않는다.
- **가족 정보:** 고려 `goryeo343.people`, 조선 `joseon4.people`의 생존 배우자/자녀 기록을 기준으로 표시한다. 미출생·사망·실종 인물은 제외.
- **호환성:** 기존 저장 기록에 시대별 정보가 없으면 `기록 없음`으로 남기며 소급 생성하지 않는다. 근현대 회고에는 기존 주거/직업/교육/순자산 표시를 유지한다.
- **검증:** 시대별 실제 값, 곡식 0과 음수 밑천, 생존 가족, 오래된 스냅샷, 저장 데이터 무변경.

## 3차: 긴 생애 선택 비교가 모바일에서 장황해짐

- **검수 발견:** 한 연령에 많은 선택을 남긴 기록까지 모든 문구를 그대로 펼쳐 보여, 중요한 차이가 읽히지 않을 수 있다.
- **수정:** 이전/이번의 전체 선택 수와 **달라진 연령 수**를 요약한다. 한 나이에 선택이 3개 이상이면 키보드로 펼 수 있는 `details/summary` 사용. **달라진 기록은 기본 펼침, 동일한 기록만 접기**로 차이를 숨기지 않는다.
- **기존 검증 유지:** 같은 연령의 모든 선택 및 고려·조선 특화 연령의 기록을 보존한다.
- **검증:** 중복 연령, 선택 누락/순서·갯수 변화, 요약 총합, details 접근성, 작은 화면 줄바꿈.

## 범위 / 결과의 정확한 의미

- 사용한 것은 **기존 ChatGPT + GitHub 코드 작업과 GitHub Actions**, 별도의 독립 AI 모델을 실제 호출한 작업이 아니다.
- PR #679의 로컬 AI 추론 도구는 닫힌 상태이고, 이 브랜치에는 포함되지 않는다. 아이폰/PC에 AI 모델 설치는 필요 없다.
- 게임의 경제 계산, 가족 출생 확률, 저장 파일 형식, 다른 게임·배포 설정·GitHub Secrets은 건드리지 않는다.
- `scripts/run-ci-tests.cjs`에 신규 3개 테스트를 등록하며 기존 전용 회귀 테스트도 계속 실행한다.
- GitHub CI와 브라우저 공통 감사는 별도로 확인하며, 실제 게임의 픽셀 미학을 실플레이로 검증했다고 주장하지 않는다.
