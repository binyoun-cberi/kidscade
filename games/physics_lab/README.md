# 와르르! 물리 연구소

StepOff의 **물건 줍기 → 던지기 → 충돌 → 연속 타격** 플레이 감각을 참고해 별도로 제작한 한국어 HTML5 Canvas 과학 액션 게임. 원본 Flash 소스, 에셋, 효과음은 포함하지 않음.

## 3차 개선: 24개 초반 단계의 개성 강화

- 처음 24단계를 단순 패턴 생성에서 각각 다른 목표·장애물·바닥·물건·힌트를 가진 개별 미션으로 교체. 기존 1~36번 ID와 보상 저장 키는 유지
- 9단계 카펫은 같은 물건이라도 더 가까이 이동하거나 힘을 높여야 목표에 도달하며, 얼음/나무/카펫 바닥의 감속 차이를 명료하게 조정
- 18단계는 쇠공의 질량으로만 작동하는 압력판 문을 추가하고, 22·24단계는 실제 벽/범퍼 반사 뒤에만 목표를 켤 수 있음
- 각 투척의 바닥 이동 경로·힘·이동 칸수·튀긴 횟수·완료 사유를 실험 일지에 기록(목표 명중·재집기·정지·7초 관찰)
- 조건에 못 미치는 충격에는 원인을 구분해서 안내하고, 반사형 스위치는 별도 아이콘으로 표시
- 압력판/연쇄 반응에 필수 투척 수를 메달 목표에 반영해 완벽한 플레이가 3성 불가능한 문제 해결
- Canvas 바닥 무늬를 패치 안에만 그려 화면의 흰 선이 다른 공간을 침범하지 않도록 정리

## 현재 구현 범위

- **총 36개 단계, 6개 구역**: 방향과 힘(1~6), 마찰(7~12), 질량과 충격(13~18), 반사(19~24), 도미노 연쇄(25~30), 컨베이어와 압력판(31~36)
- 5구역: 투사체로 첫 도미노를 타격하면 고정 간격의 도미노가 차례로 넘어지고, 마지막 조각까지 반응해야 닫힌 문이 열림. 단순 타이머로 자동 해제되지 않음
- 6구역: 질량 기준에 맞는 물건으로 압력판을 누르면 문이 열리고, 진행 방향이 다른 컨베이어에서 물체 속도가 바뀜. 역방향 벨트는 바깥길로 돌아 해결할 수 있도록 구성
- 진행 기록, 별, 24단계 이후 해금 체계는 이전 `kidscade.physics_lab.progress.v1` localStorage 키를 유지해 보존
- 무한 도전(움직이는 장난감 로봇, 콤보, 점수, 생명), Kidscade SDK 점수·결과 기록
- PC 키보드/마우스, 모바일 터치 조작, 게임 속도 고정 timestep 및 일시정지 지원
- 화면에 연쇄 진행 상황/압력판/문의 상태 표시. 힌트 버튼과 스테이지 완료 시 학습 관찰 문장 제공

## 조작

- 방향키 또는 WASD 이동, `Space`·`E` 집기, `Enter` 투척, `Q` 내려놓기, `Esc` 일시정지
- 캔버스에서 **누르고 끌며 조준한 다음 손을 떼면 투척**. 터치의 의도치 않은 즉시 발사 방지
- 모바일: 왼쪽 조이스틱 + 집기/던지기/내려놓기 + 힘 조절 슬라이더
- 실패 시 자유 재시도. 학습 결과는 과학 법칙의 정밀한 재현이 아닌 게임용 물리 모형임을 고지

## 검증

```bash
node --test tests/physics-lab.test.mjs tests/physics-lab-mechanisms.test.mjs tests/physics-lab-v3.test.mjs
```

- 기본 물리·게임 진행 8건, 연쇄 장치·압력판·컨베이어 8건, 초반 단계 다양성·반사 판정·실험 일지 회귀 검증 10건
- Playwright Chromium에서 실제 누르기/드래그/던지기: 25단계 PC 전체 클리어, 모바일 도미노 연쇄 및 문 열림, 31단계 PC 전체 클리어
- 브라우저 `pageerror` 관찰에서 오류 없음. SDK가 로드되지 않는 독립 렌더 테스트는 인라인 스크립트로 수행; 실제 배포 후 SDK 연동 확인 필요

## 프로젝트 내 위치

- `games/physics_lab/index.html` · `style.css` · `game.js` — 화면, 조작, 접근성, 점수 및 기록
- `games/physics_lab/sim.mjs` — DOM 독립 물리 시뮬레이션, 36개 단계, 도미노/벨트/문/압력판 상태 전이
- `tests/physics-lab*.test.mjs` — Node 회귀 테스트
- `data/games.json` — 키즈케이드 카탈로그에 기등록된 `physics_lab` 항목 유지

## 향후 개선

기본 24단계에도 독립적인 퍼즐 장치를 더하고, 자유 제작실 및 교사용 비교 실험 기록 기능을 추가하면 학습 깊이를 높일 수 있음. 현재 36단계는 최초 확장판이며 자유 제작실은 **미구현**.
