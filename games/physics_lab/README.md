# 와르르! 물리 연구소

StepOff의 **물건 줍기 → 던지기 → 충돌 → 연속 타격** 플레이 감각을 참고해 새로 만든 한국어 HTML5 Canvas 2D 과학 액션 게임. 원본 Flash 파일과 리소스는 포함하지 않음. 24개 단계(4개 구역 × 6단계), 무한 액션 챌린지, PC 키보드/마우스 및 모바일 터치 조작 제공.

## 조작

- 방향키/WASD 이동, `Space` 또는 `E` 집기, 화면 클릭/터치 또는 `Enter` 투척, `Q` 내려놓기, `Esc` 일시정지
- 모바일: 화면 왼쪽 아래 조이스틱, 아래쪽 집기/던지기/내려놓기 버튼, 물체를 든 상태에서 경기장 터치로 지정 방향 투척
- 손에 든 물체의 질량과 탄성, 바닥 마찰, 범퍼 반사, 스위치에 도달하는 운동량(게임용 근사값)이 조작 및 승리 판정에 실제 반영됨
- 실패해도 물건을 주워 재도전하거나 '처음부터'로 즉시 초기화 가능. 별/해금 정보는 브라우저 localStorage에 저장
- 최고 기록과 플레이 세션은 공통 `kidscade-game-sdk.js`와 연동

## 폴더

- `sim.mjs` — 의도적으로 DOM/Canvas와 독립된 시간 고정형 시뮬레이션. 플레이어, 물체, 벽, 범퍼, 스위치, 로봇, 콤보, 아이템 물성
- `game.js` — 입출력, 화면 묘화, 소리, 스테이지 선택, 게임 SDK, 접근성
- `style.css` — PC/모바일 반응형 레이아웃
- `index.html` — 게임 진입점
- `../../tests/physics-lab.test.mjs` — Node 기본 테스트 러너

```bash
node --test tests/physics-lab.test.mjs
```

## 과학적 표현에 관한 주의

이 게임에서 질량과 운동, 마찰의 관계를 체험하도록 실제 경향을 고려했으나, 계수와 거리/속도는 아케이드 플레이를 위한 간소화된 값이다. 실험 결과가 물리 법칙의 정밀한 재현이라고 표시하지 않는다. 특히 물체 속도와 질량을 연결하는 투척 모델은 게임용 수치이고, 위에서 내려다보는 공간의 발사 방향이므로 중력에 의한 포물선 궤적은 구현하지 않았다.
