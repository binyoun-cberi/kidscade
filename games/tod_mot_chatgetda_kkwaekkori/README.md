# 못 찾겠다 꾀꼬리

유아가 마우스나 손가락으로 입체 마을을 둘러보며 특정 주민을 찾는 키즈케이드 게임.

## 5차: 연결된 동네와 생활 흐름

- 8.5 간격의 엇갈린 구역과 연결 보행로. 화면의 길과 주민·버스의 경로가 같은 그래프를 사용
- 작은 마을은 단독 주택형 건물, 주택가·학교는 한 동과 마당으로 구성. 공원·주택·학교의 잔디와 외곽 초원·수목 군집 추가
- 빵집·시장 손님은 도착 순서대로 기다리고, 빈 진열대 자리로 이동해 5초간 빵을 고른 뒤 빵을 들고 이동
- 버스는 실제 연결 경로를 운행하며 정류장에서 18초간 정차. 배경 주민은 승차 지점까지 걸어가 탑승하고 다음 정차 후 순차 하차
- 승객은 승차 중 숨기며 클릭 대상에서도 제외. 정답·유사 인물은 승차하지 않고 계속 관찰 가능
- 저장 버전 5. 생활 흐름 진행 자체는 저장하지 않으며 이어하기 시 같은 주민·문제·찾은 기록으로 마을을 재구성

## 4차: 보행과 외곽 풍경

- 블록별 주민 수를 4·3·3·4·2·2명으로 다르게 배치하고, 건물 전면·측면의 여섯 활동 지점을 사용
- 배경 주민은 보행로를 따라 다른 장소로 이동하고 빈 활동 지점을 예약한 뒤 도착 후 활동. 이동 방향으로 회전하고 이동 중에만 걷기 동작 사용
- 정답·유사 인물은 문제 중 위치·외형·행동 유지. 활동 지점의 중복 예약 방지
- 넓은 초원과 외곽 수목, 대도시의 배경 건물, 블록 가장자리 녹지 추가
- 부분 관절 애니메이션에 static 기본 자세를 합성해 앉은 초기 자세가 걷기와 소품 동작에 남지 않도록 수정
- 배치 규칙 변경으로 저장 버전 4 사용. 이전 판은 새로 시작하며 버전 4의 이어하기 지원

4차는 이동과 풍경의 기반 작업이며, 장소별 생활 흐름은 위 5차에서 확장했다.

## 3차: 생활 장면과 관찰 문제

- 작은 마을 18명/1명 찾기, 중간 마을 45명/3명 찾기, 대도시 84명/5명 찾기
- 빵집(빵 고르기·배달·먹기), 공원(독서·공놀이·벤치 휴식), 정류장(기다리기·인사·지도 보기)의 생활 장면 9종
- 그림 비교·행동 비교·소품 비교의 난이도를 도시 크기와 별도로 선택. 중간·어려운 단계에서는 모든 정답에 의도적인 유사 인물을 배치
- 고유한 모델·활동·소품 조합. 배경 인물은 18~32초부터 활동을 순환하며 정답과 유사 인물은 문제 중 행동 유지
- Poly Pizza 도시 건물·상점·버스 정류장·자전거·우체통·화분, Kenney 가로등·인물·차량·음식 등 보유 에셋 활용. 건물은 가로·세로 2.6 이내로 제한해 보행로 확보
- 실제 대상의 3D 미리보기 회전, 카메라 90도 회전, 건물 너머 보기, 건물 터치 시 6초간 낮추기, 가려진 주민 선택 방지
- 얼굴을 비교할 수 있는 시작 배율, 모바일 가로형 찾기 카드, 클릭·터치, 지도 이동, 확대, 음성 단서, 세 단계 힌트
- 정답의 짧은 반응과 발밑 표시, 찾은 친구 도장, 비교 요소를 알려 주는 오답 안내, 완주, 자동 저장·새로운 하루
- 캐릭터·포즈·핵심 소품 로딩 확인 후 출제. 불러오지 못한 조합은 정답에서 제외. 생성 규칙이 다른 이전 버전의 저장은 이어받지 않음
- 잘못 선택해도 감점·시간제한 없음. 정답 인물은 게임 중 사라지거나 화면 밖으로 순간 이동하지 않음

## 구조

- `sim.mjs`: 3개 도시 설정, 생성 시드, 고유 주민 외형, 인도 경로와 이동, 정답 설명
- `game.js`: Three.js 입체 도시, 기존 GLB 로더와 캐시, 선택 판정, 터치 카메라, 게임 UI/저장
- `style.css`: 유아용 큰 조작 요소·터치 대응·화면 크기별 레이아웃
- `index.html`: 홈 게임 SDK 연결과 마을 선택 화면
