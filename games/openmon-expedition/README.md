# 키즈몬 | 첫 10분과 수집 루프 개선

기존 게임 ID `openmon_expedition`, 접속 주소와 브라우저 저장 키는 변경하지 않습니다.

## 첫 조우와 난이도
- 연구소에서 스타팅을 선택하고 오른쪽으로 이동하면 12번째 발걸음에 초원 풀숲에서 스타팅에 맞춘 **Lv.2 첫 키즈몬**을 만납니다. 풀은 멘델콩, 물은 파스칼방울, 바람은 케플올빼입니다.
- 강제 첫 조우는 저장되며 반복해서 발생하지 않습니다. 살살 공격과 키즈볼 사용을 안내합니다.
- 첫 네 번의 초원 전투에는 초심자 피해 상한, 초반 세 번의 승리에는 작은 연구원 회복이 적용됩니다.
- 파스칼집게 스타팅의 기본 HP를 5 올려 첫 초원 생존율 편차를 완화했습니다.

## 첫 화면의 탐험성
- 마을 연구소부터 초원으로 이어지는 길, 눈에 띄는 풀숲 관문, 방향 표지판을 배치했습니다.
- 지나치게 자주 반복되던 장식 타일을 줄이고 마을·숲·동굴마다 다른 식생과 색상을 적용했습니다.

## 102개 수집 경로
- 초기에 세 지역에서 야생 15종을 만납니다.
- **전투 승리 + 포획 합계 3, 7, 12회**마다 새로운 야생 후보가 세 지역에 추가됩니다.
- 원본 진화가 검증되지 않아 자동 진화를 잠근 Set 2의 두 번째 그림들도 나중에는 야생에서 출현합니다.
- **서로 다른 키즈몬 4종, 7종**을 수집하면 연구소에서 선택하지 않았던 스타팅을 각각 1마리씩 받습니다.
- 비밀숲의 분기견은 최소 24걸음의 간격을 두고 다시 나타납니다. 18개 분기는 각각 별도 개체를 육성해야 합니다.
- 연구소의 보관함에서 여섯 마리 이상의 개체를 선두와 교체할 수 있습니다. 파티 메뉴에서는 진화를 나중에 선택할 수도 있습니다.

102개 모두에 이론적인 입수 경로가 마련되었지만 100% 도감을 완료하는 데 걸리는 장시간의 플레이 검증은 추후 과제입니다.

## 정식 1대1 턴제 전투 (v2)

- 기본 명령: **싸우기 / 키즈볼 / 가방 / 교체**. 싸우기에서 키즈몬당 최대 기술 4개와 현재·최대 PP를 표시합니다. 살살 공격은 포획용 공통 행동이며, 도망은 가방 메뉴에서 선택합니다.
- 플레이어와 야생 키즈몬 모두 명령을 선택하며, **기술 우선도 → 실제 속도 능력치 → 동률 시 추첨** 순으로 행동합니다. 전투 AI는 공격 상성, 자신의 HP, 방어·회복·버프 효용을 보고 기술을 선택합니다.
- 속성 상성(2배/0.5배), PP, 기술별 위력·명중률, 화상·둔화·공격 약화, 공격력·방어력·속도 버프, 방어막, 회복, 두 번 공격을 지원합니다. 이 게임은 포켓몬의 이름·기술표를 복제하지 않고 독자적인 기술 이름을 사용합니다.
- 총 **41개 기술**이 등록되어 있고, 스타팅 전용 기술은 광합성 파동·파스칼 압력파·피보 연격입니다. 나머지 키즈몬도 10개 타입별 기술 4개를 보유합니다.
- 파티 HUD의 **기술 관리**에서 레벨업으로 배운 기술을 기존 슬롯과 교체할 수 있습니다. 기본 기술 4개 이외에 레벨 14/26 등에 새 기술이 해금됩니다. 기술 PP는 연구소 전체 회복에서 함께 회복합니다.
- `turn-battle.js`는 같은 종족·전투·포획 시스템을 사용하는 분리된 턴제 엔진이며, `game.js`의 전투 UI가 실행합니다. 기존 `kidscade.openmon.expedition.save.v1` 키는 유지되며 저장된 개체에 `moveSlots`와 PP가 없으면 로드 시 보완됩니다.


## 47계열 고유 기술·진화 기술 확장

- 기본 턴제 기술 41개에 더해 계열별 기술 99개를 등록하여 **총 140개 기술**을 사용합니다.
- **47개 진화 계열**마다 이름과 전투 효과가 있는 대표 기술을 지정합니다. 3개 스타팅은 기존의 `광합성 파동 / 파스칼 압력파 / 피보 연격`을 유지합니다.
- 2단계가 있는 일반 계열은 레벨 14부터 별도의 진화 기술을 배울 수 있고, 3단계가 있는 5개 계열은 레벨 26부터 최종 기술을 배울 수 있습니다.
- **분기견**의 18개 진화형도 각각 다른 타입과 이름, 전투 역할을 가진 기술을 배웁니다.
- 레벨에 도달해도 실제 형태가 진화하지 않은 경우, 진화 전용 기술은 미리 배울 수 없습니다.
- 진화할 때 기존 기본 기술 슬롯을 안전하게 교체할 수 있으면 새 기술을 자동 습득합니다. 기존의 사용자 지정 기술은 임의로 덮어쓰지 않으며 **파티 → 기술 관리**에서 수동 교체할 수 있습니다.
- 기존 저장 중 **수정하지 않은 옛 공통 기술 4종 구성**은 해당 계열의 대표 기술로 전환됩니다. 직접 바꾼 기술과 남은 PP는 보존합니다.
- **도감 → 기술 도감**에서 전체 140개를 36개씩 탐색하고, **계열 전용 기술 / 공통 기술**을 필터링할 수 있습니다. 실제 위력·명중률·PP·학습 형태 및 레벨은 전투 엔진에서 계산합니다.
- 고유기들은 선공, 2연타, 흡수, 약화, 둔화, 화상, 공격 강화, 보호막, 회복 등 서로 다른 역할을 가집니다. 동종 역할에서도 소규모 위력·PP 조정으로 개체별 차이를 둡니다.

**주의:** 원본 그림 파일 또는 출처상 진화 관계가 미확인된 Set 2의 임시 계열은 기존처럼 자동 진화시키지 않습니다. 두 그림은 서로 별도로 포획할 수 있으며, 고레벨 개체에서 계열 기술을 사용할 수 있습니다.
