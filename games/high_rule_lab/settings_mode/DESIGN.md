# 《내 말 좀 들어》 — 설정 탈출 모드 구현 노트

## 두 모드 구분
- **규칙 퍼즐(원본)**: 기존 60개 스테이지와 저장 키 `kidscade_game_v1:high_rule_lab:progress_v3`를 그대로 사용한다. 재실행(redo), 방향키 길게 누르기, 터치 길게 누르기, 글자/물체 설명, 승리 판정 중복 방지를 보완했다.
- **설정 탈출(신규)**: `settings_mode/`에서 별도 2D 플랫폼 액션으로 진행한다. 진행은 `kidscade_game_v1:high_rule_lab:settings_mode_v1`로 독립 저장한다.

## 레퍼런스 사용 범위
업로드된 ESC/APE 실행 파일의 정적 추출 보고서에서 확인된 메커니즘을 **아이디어 참고**로만 사용했다. 밝기로 숨겨진 방이 보이는 퍼즐, 소리로 감시자의 탐지 범위가 달라지는 퍼즐, 설정 창이 발판이 되거나 투사체를 막는 퍼즐, 화면 너비로 길이 늘어나는 퍼즐에 착안했다.

원본 추출 이미지, 캐릭터, 음원, 셰이더 및 기계어 코드는 저장소에 복사하지 않았다. 게임의 플랫폼 레벨, UI, 문구, 조작, 캔버스 그래픽은 이 프로젝트에서 새로 작성했다. 기존 키즈케이드 Kenney 플레이어 이미지 하나만 재사용한다.

## 스테이지
| 방 | 이름 | 주요 조작 | 클리어 조건 |
|---|---|---|---|
| 1 | 첫 발자국 | 방향키/점프 | 출구에 도착 |
| 2 | 어둠 너머의 문 | 밝기 조정 | 밝기 70 이상, 출구에 도착 |
| 3 | 조용히 지나가기 | 소리 조정 | 소리 20 이하, 출구에 도착 |
| 4 | 창을 딛고 | 게임 안 설정 창 드래그 | 창 위로 점프하여 틈 건너기 |
| 5 | 화면의 끝을 늘려라 | 화면 너비 조정 | 너비 72 이상, 다리를 건너 출구에 도착 |
| 6 | 날아오는 신호 | 설정 창으로 탄환 가로막기 | 2개 막고 출구 도착 |
| 7 | 모든 설정의 열쇠 | 밝기+소리+너비 결합 | 밝기 68 이상, 소리 20 이하, 너비 75 이상, 출구 도착 |

## 구현 주의
1. 게임은 브라우저의 **실제 OS 설정**을 바꾸지 않는다. 오른쪽의 게임 내 가상 설정 값만 월드 물리에 연결한다.
2. 게임 안 떠 있는 작은 설정 창은 4·6방에 등장하며, 포인터로 드래그하거나 핸들에 키보드 포커스를 두고 방향키로 이동할 수 있다.
3. 터치 이동은 버튼을 누르는 동안 유지된다. 점프는 한 번 누르면 점프 요청을 버퍼링한다.
4. `requestAnimationFrame` 델타 시간 제한, 점프 입력 유예, 가장자리 발 구름 유예를 사용한다.
5. 창 밖으로 떨어지거나 감시자·신호탄에 걸리면 같은 방에서 즉시 재도전한다. 진행 기록은 삭제되지 않는다.
6. SDK 기록은 같은 게임 식별자 안에서 원본 단계와 충돌하지 않게 신규 방에 101~107을 사용한다.

## 테스트 항목
`node --test tests/rule-lab.test.cjs tests/rule-lab-settings-mode.test.cjs`
- 60개의 기존 레벨 유지
- 7개 신규 스테이지 정적 검증
- 슬라이더에 따른 문 잠금/해제
- 감시 반경 변화 및 설정 창 투사체 차단
- 기존 되돌리기/재실행 갈래 처리
- SDK 연결, 내부 이미지 경로, 모드 이동 링크

## 추가 검증이 필요한 항목
브라우저 실제 키보드·터치 장치에서의 충돌 체감, 각 방의 실제 플레이 성공률과 난이도 조정, 다양한 화면 비율·성능 장치에서의 조작성을 수동/브라우저 테스트로 확인해야 한다. 특히 4방의 설정 창 배치와 6방의 투사체 타이밍은 실기기 테스트 후 조정 권장.
