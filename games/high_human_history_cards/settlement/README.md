# 한 줌에서 문명까지 — 생활·생산·교류로 배우는 역사

기존 《석기 시대에서 살아남기》 시작 화면에서 들어가는 별도 모드입니다. 기존 게임 ID·카드판 URL·로직·학생 기록을 교체하지 않습니다.

## 플레이와 배움

1. 움직이는 토끼·나무 채집에서 시작해 돌 1개로 작업에 맞는 뗀석기를 만듭니다. 공동 채집터를 지으면 일손 추가 없이 기초 생산이 이어집니다. 기존 주민 배치도 선택적으로 이용할 수 있습니다.
2. 뗀석기와 막집에서 시작해 강가 조사·간석기·농경·토기·움집으로 이어집니다.
3. 숯·구리·주석·청동을 생산하고, 철광석·제련·가공·철제 농기구를 연결합니다.
4. 역사 메뉴의 생활·생산 과제와 자료에 대한 생각 잇기를 모두 마쳐 배움을 기록합니다.
5. 삼국·가야, 통일 신라·발해, 후삼국을 비교한 뒤 고려의 건국·교류·인쇄로 이어집니다.

총 16개 과제: 구석기, 신석기, 청동기, 철기, 고조선, 고구려, 백제, 신라, 가야, 통일 신라, 발해, 후백제, 후고구려·태봉, 고려의 건국과 통일, 고려의 국제 교류, 고려의 기록과 인쇄.

고구려→백제→신라가 차례로 대체되는 구조가 아닙니다. 같은 시기 나라들은 함께 해금되며 순서를 골라 비교합니다. 고조선도 철기 다음에야 건국된 것으로 표현하지 않고 청동기 이후 철기 과제와 나란히 탐방합니다. 대표 연도별 공존 표에는 920년의 신라·발해·후백제·고려도 함께 표시합니다.

나라별 시설은 역사 탐방 전시 모형입니다. 같은 마을이 실제 모든 나라를 차례로 거쳤다는 설정이나 실제 영토 지도가 아닙니다. 비용·제련 비율·제작 시간·보상은 가상 수치입니다. 기술의 해금 순서도 실제 최초 발명 시기를 뜻하지 않습니다.

## 역사 내용의 구분

- 청동 의례품과 반달 돌칼 등 석기 농기구의 쓰임을 구분합니다.
- 건국 신화·유물·법 조항·생활 자료를 구분해 읽고 신분 차별을 개인 능력과 연결하지 않습니다.
- 신라·발해의 공존, 고구려/후고구려/고려의 차이, 918년 건국/936년 통일을 구분합니다.
- 팔만대장경의 목판과 직지의 금속활자를 별도 작업으로 다룹니다.
- 직지는 ‘현재 남아 있는 가장 오래된 금속활자본’으로 설명하며 활자 최초 발명과 혼동하지 않습니다.
- 출처는 history.js의 SOURCES에 모으고 각 과제·수업 자료에 링크합니다. 국사편찬위원회 우리역사넷과 국가유산 지식이음 자료를 확인했습니다(2026-10-28).
- 초등 사회·역사의 기초 주제를 다루며 특정 학년의 공식 성취기준 전체를 충족한다고 주장하지 않습니다.

역사 메뉴의 ‘수업 자료’에서는 잠긴 주제도 읽을 수 있습니다. 오답은 자원 손실 없이 설명을 보고 다시 생각할 수 있으며, 선택만으로 생활 과제를 건너뛸 수 없습니다.


## 구석기·신석기 클리커 연결

- 맨손 토끼 사냥 18회 → 주먹도끼 3회 → 기초 도구 후 슴베찌르개 2회. 지도 토끼와 고정 추적 버튼은 같은 진행·보상·입력 속도 제한을 사용합니다. 피·사체 표현은 없습니다.
- 맨손 목재 채취 6회 → 찍개 1회. 도구는 작업할 때 닳으며, 뗀석기는 돌 1개로 다시 만들고 간석기는 돌 1개를 준비한 뒤 6번 갈아 완성합니다. 갈기는 길게 누르기와 키보드도 지원합니다.
- 주먹도끼·찍개·긁개·뚜르개·새기개·슴베찌르개, 간 돌도끼·돌괭이·갈판과 갈돌, 청동기 배움 후 반달돌칼을 쓰임별로 연결합니다. 간석기 일반을 수확 도구와 동일시하지 않습니다. 모든 종류가 한 시기·한 지역에서 동시에 쓰였다고 주장하지 않습니다.
- 온기는 실제 기온/체온이 아닌 0~100 게임 지표입니다. 땔감이 없으면 서서히 식고, 20 미만이면 직접 채취만 25% 느려집니다. 주민 사망이나 진행 불능은 없습니다. 가죽옷은 식는 속도를 줄입니다.
- 조개를 모아 뚜르개로 장신구를 만들고 닳은 뗀석기와 교환합니다. 이는 가상 교환이며 한반도 구석기 화폐라는 사실로 가르치지 않습니다.
- 잡곡밭의 익은 곡식은 한 곳씩 수확합니다. 토기 후 주변 최대 3곳을 함께 담고, 갈판과 갈돌은 곡물 처리 보상을 높입니다. 돌괭이는 수확 대신 밭 일구기/성장에 연결합니다. 기존 농부의 자동 식량 생산은 유지하며, 새 작물은 별도 상호작용 층입니다.
- 공동 채집터는 건설 직후 기본 자동 생산, 석기 작업터·땔감 보관대·공동 곡물 처리터는 건설 후 관련 연구를 맞히면 자동 도구 보충·연료 보충·수확/곡물 처리를 엽니다. 추가 주민·직업 배치를 요구하지 않습니다. 오답에는 자원 손실이 없고 기본 기능과 생산은 계속됩니다.
- 자동 도구 보충은 한 번 완성해 본 도구에만 적용하며 돌을 소모합니다. 땔감은 목재 2개를 보존합니다. 원료·저장 공간이 부족하면 기다립니다. UI 생산량은 재료와 공간이 충분할 때의 예상 수치입니다.
- 근거: 국립중앙박물관 구석기 상설전시, 우리역사넷 토기의 쓰임, 국립중앙박물관 반달돌칼 큐레이터 자료를 생활 메뉴에서 연결합니다. 클릭 수·내구도·온기·교환 비율·자동화는 게임 규칙입니다.

이번 변경은 선사 생활과 자동화의 첫 연결입니다. 도시 규모 확장·계승과 청동기 이후의 시설 중심 자동화 전환은 아직 구현하지 않았습니다.

## 자동 생산과 저장

주민은 이동→작업→운반→입고를 반복합니다. 원료는 가공 시작 시 한 번 차감하고, 산출물은 창고에 입고한 때 재고와 생산 기록에 반영합니다. 작업을 바꾸면 미완료 원료를 반환하고 화물을 가진 주민은 입고 후 바꿉니다. 숯 생산은 건설용 목재 12개를 보존합니다.

도구는 작업 시간, 길은 이동 시간, 창고는 입고 거리·저장량을 개선합니다. 인쇄 방식은 목판/금속활자로 다시 선택할 수 있으며 이미 시작한 인쇄의 방식은 입고 때까지 유지합니다.

저장 키는 kidscade_game_v1:high_human_history_cards:settlement-v1을 보존합니다. 내부 스키마 v3가 기존 v1/v2 저장을 이관합니다. 새 생활 상태만 추가하고 기존 자원을 소모하거나 건물을 제거하지 않습니다. 기존 신석기 마을은 주민·재고·건물·진행 중 작업을 유지하고 청동기 배움부터 이어갈 수 있습니다. 손상·미지원 저장은 덮어쓰지 않습니다.

숨김·일시정지·도움말 중에는 진행하지 않습니다. 미접속 생산·환생·계승·전쟁 시뮬레이션은 이번 범위가 아닙니다.

## 파일과 공통 기능

- history.js: 출처·16개 과제·연대·제작·배움 조건의 공통 정의.
- history-ui.js: 탐방/수업 자료·공존 표·생산 패널.
- prehistory.js: 도구·내구도·수렵·온기·조개 장신구·작물·생활 연구·시설 자동화.
- prehistory-ui.js: 고정 추적·도구 선택·갈기·생활 연구와 자동화 상태.
- sim.js: Node/브라우저 공용 시뮬레이션과 저장 이관.
- view.js: 코드로 그린 픽셀 지도·주민·생산 시설·문화/교류 전시 모형.
- game.js: 입력·안내·운영·저장·SDK 연결.
- index.html/style.css: 반응형 화면과 명명된 조작 요소.
- 공통 KidscadeStorage·Game SDK의 음향·종료·일시정지를 재사용하며 외부 이미지·유료 API·새 의존성을 추가하지 않습니다.

기존 카드판의 시대 업적을 허위 보고하지 않습니다. 신석기 정착은 settlement_neolithic, 새 배움 기록은 history_chapter의 과제별 uniqueKey를 사용합니다.
