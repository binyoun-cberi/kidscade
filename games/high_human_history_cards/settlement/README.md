# 한 줌에서 문명까지 — 정착 모드

《석기 시대에서 살아남기》 시작 화면에서 진입하는 별도 미리보기입니다.
기존 게임 ID, 카드 게임 URL/로직, 학생 기록을 교체하지 않습니다.

## 이번 범위

- 자원 직접 채집, 동일 속도 상한의 탭/길게 누르기/키보드 작업.
- 두 주민의 일 배치, 이동→작업→운반→입고와 분당 예상 수지.
- 움집 수용량, 식량 소비와 합류 조건, 식량 부족에서의 무료 채집 복구.
- 도구·모닥불→강가 조사→점토·밭·토기→신석기 정착.
- 도구의 작업 시간, 길의 이동 속도, 저장고의 입고 거리·수용량 개선.
- 직접 공사 지원 또는 건설 담당 배치, 취소 시 일회성 재료 반환.
- 별도 버전 저장과 작업/운반 재개, 손상 저장을 덮어쓰지 않는 처리.
- 신석기 완료 후 계속 살기와 공동 저장고.

청동기·철기·교역·계승·미접속 생산은 포함하지 않습니다. 숨김·일시정지·도움말 중에는 진행하지 않습니다. 기본 생산지는 이 첫 구간에서 재생 가능한 생산 구역으로 단순화했습니다. 이 버전은 역사 시대의 실제 속도·보편적 경로를 재현하는 모형이 아닙니다.

## 파일과 공통 기능

- sim.js: 브라우저·Node 공용 순수 시뮬레이션/비용/해금 정의.
- view.js: 외부 이미지 없는 Canvas 픽셀 지도·주민 표현.
- game.js: 입력·운영 패널·안내·저장·SDK 연결.
- index.html/style.css: 반응형 화면과 키보드/명명된 조작 요소.
- 공통 KidscadeStorage, Game SDK, 음향·종료·일시정지 생명주기 재사용.
- 저장 키: kidscade_game_v1:high_human_history_cards:settlement-v1.
- 업적 이벤트는 settlement_neolithic이며 기존 카드판의 시대 업적을 허위 보고하지 않습니다.

## 재현 가능한 검사

프로젝트 루트에서:

    node --test tests/settlement-preview.test.cjs tests/settlement-preview-ui.test.cjs tests/game-exit-navigation.test.cjs tests/game-filenames.test.cjs
    npm run health:strict
    npm run test:ci
    npm run build

전용 시뮬레이션 검사는 일반 행동만으로 정착에 도달하는 경로, 운반 전 재고 미반영, 가득 찬 창고의 화물 보존, 예약·취소, 식량 회복, 도구·길 효과, 저장/재개 일치를 확인합니다.

UI 검사는 실제 game.js를 DOM/이벤트 어댑터에서 실행하여 길게 누르기, 공사, 직업 조정, 정착 완료, 일회성 milestone, 일시정지, SDK 종료, 손상 저장 보호를 확인합니다. 실제 브라우저 플레이·모바일 시각 검수를 대신하지 않습니다. 브라우저 검수는 검토 시 추가로 필요합니다.

현재 알려진 저장소 기준선 문제는 perfect-pitch 관련 미등록 저장 키 3개입니다. 이번 변경은 해당 파일이나 저장 레지스트리를 수정하지 않습니다. 별도 실행한 구형 stone-age-natural-exploration 검사의 두 문자열 기대도 기존 카드 게임 코드와 맞지 않으며 기존 game.js는 변경하지 않았습니다.

배포·원격 DB·키·과금 설정·학생 기록은 변경하지 않습니다. AGENTS.md에 따라 작업 브랜치와 PR로 검토하며 자동 병합/배포하지 않습니다.
