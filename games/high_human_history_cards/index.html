석기 시대에서
살아남기

두 사람과 숲·들판·강가·바위언덕만 가지고 시작합니다. 자연은 이용할수록 줄고, 쉬게 두면 일부는 다시 회복됩니다. 탐험과 채집으로 버티다가 부족해진 자연을 벌목장·밭·채석장 같은 안정적인 생산지로 바꾸며 정착지를 키우세요.

자연 탐험사람을 자연 카드 위에 올려 세계를 직접 발견해요.
사람이 행동력탐험·채집 중인 사람은 그 시간 동안 다른 일을 못 해요.
살아 있는 자연많이 이용하면 줄고, 재생 가능한 자연은 쉬게 두면 다시 회복돼요.
기본 조작

탐험하고, 발견하고, 개척하세요

👤 + 🌿느린 채집작은 나무에서는 맨손으로 나뭇가지만 모을 수 있어요.
🪨 + 🪨찍개같은 재료도 겹치면 제작이 일어날 수 있어요.
🌿 ×3끈카드 오른쪽 위 숫자가 스택 개수예요.
🌱 ×3농장작은 생산지 3개를 합치면 상위 시설이 돼요.
↔ ×2카드 분리겹친 카드는 상단 분리대에 끌어 한 장씩 꺼낼 수 있어요.
🌿 7/9자연 상태숲·들판·물가는 이용할수록 줄고 일부는 쉬게 두면 천천히 회복돼요.
👤 + 🌲자연 탐험사람을 자연 카드 위에 올리면 탐험이 시작되고 그동안 그 사람은 다른 일에 쓸 수 없어요.
🐺 ⚠야생의 위협3일차 이후에는 맹수와 다른 집단을 만날 수도 있어요.

대표 발전

🌿 사람+작은 나무 → 나뭇가지 / 돌×2 → 찍개 / 찍개+나뭇가지 → 돌도끼

🪓 사람+돌도끼 → 벌목꾼 / 벌목꾼+큰 나무 → 목재

🏹 돌날+섬유 → 돌화살촉 → 화살 / 힘줄+나뭇가지 → 활 → 활·화살 세트

🔱 뼈+힘줄 → 작살촉 → 작살 / 끈+돌 → 올가미 → 토끼 사냥

🧶 점토+돌 → 가락바퀴 → 실 → 베틀 → 직물 → 직물옷

🔥 간 돌+모닥불 → 돌화덕 / 말린 토기×2+화덕 → 점토 가마 → 숯 고온가마

🌰 도토리 → 갈돌·갈판 → 우리기 → 토기 → 화덕 → 도토리죽

🌾 조·기장·콩 씨앗 + 개간지 → 밭 ×3 → 각각의 농장

🌊 갯벌 → 조개·굴·껍데기 / 껍데기 → 조개칼·장신구

🐗 사슴·멧돼지·토끼 → 고기·가죽·뼈·힘줄·엄니

🐟 낚시·작살·그물·통발·저수지·민물고기 양식을 서로 섞어 발전

🐐 길들인 염소 + 울타리 → 염소 우리 ×3 → 염소 목장

🧭 숲·들판·강가·바위언덕 탐험 → 자원·동물·흔적·새 지역 발견 → 더 깊은 자연으로 확장

🐾 동물 길·큰 발자국·연기 흔적 + 사람 → 동물·동굴·낯선 집단을 추적해 발견

🪓 간돌도끼 + 숲 → 벌목장 / 돌괭이 + 들판 → 개간지 / 찍개 + 바위언덕 → 채석장

🌿 자연 상태가 낮아지면 자원·동물 발견 확률도 낮아짐 / 재생 가능한 자연은 작업하지 않을 때 서서히 회복

📦 나뭇가지·돌·먹거리 같은 산출물은 가까운 같은 카드에 자동으로 합쳐져 보드가 덜 복잡해짐

🐺 늑대·곰·적대 집단은 습격 전 카운트다운 표시 / 한 번 습격하거나 막히면 떠남

🛡 불·울타리·마을·대기 중 사냥꾼의 방어력을 합쳐 위협의 요구 방어력과 비교

🤝 낯선 집단은 토기·훈제고기·장신구와 최대 3회 교환 후 떠남

🏘 신석기 마을 + 곡물죽/훈제고기 → 24초 뒤 새 구성원 합류 / 주거만큼만 인구 증가

역사 메모: 빗살무늬토기·간석기·궁시·작살·낚시바늘·가락바퀴·잡곡 농경 등은 한반도 신석기 생활 자료를 바탕으로 단순화했습니다. 저수지·양식장은 샌드박스용 실험적 생활 기술입니다.
