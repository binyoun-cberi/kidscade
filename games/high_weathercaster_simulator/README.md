# 기상캐스터 시뮬레이터

기상 자료를 관측하고 오후 날씨를 판단한 뒤, 키즈케이드 아바타로 생방송을 진행하는 직업·과학 시뮬레이션입니다.

## v3 핵심 루프
1. 강수 / 기온 / 바람 / 대기·시야 화면을 모두 직접 확인
2. 핵심 날씨 / 기온 변화 / 생활 정보를 근거로 예보
3. 방송 지도 위의 지역을 직접 지목하며 생방송
4. 방송 중 기상 속보를 받아 기존 예보 수정
5. 07:00 → 10:00 → 13:00 → 16:00 실제 날씨 진행을 확인
6. 예보와 실제 변화, 첫 지역 지목, 속보 대응을 비교

## v3 리워크
- 시나리오 제목과 관측 문구가 정답을 바로 말하지 않도록 수정
- 서풍 / 남풍 / 북서풍 / 남서풍 / 남동풍을 실제 이동 방향의 바람 입자로 표시
- 황사와 안개를 강수 레이더에서 분리해 별도 대기·시야 자료로 확인
- 안개 시나리오에 '안개·낮은 시야 주의' 생활 정보 추가
- 지역 지목은 한 멘트당 첫 선택만 채점하여 반복 클릭 점수 획득 차단
- 지도 위 직접 지목 + 작은 화면용 보조 버튼 제공
- 점수 비중을 예보 판단 75 / 지도 설명 15 / 속보 대응 10으로 조정
- 외부 날씨 API 없이 6개의 시뮬레이션 시나리오 사용

저장 키: `kidscade_weathercaster_best_v1`  
진입점: `games/high_weathercaster_simulator/index.html`

## v7 뉴스룸 오디오·AI 음성
- 일반 방송용 뉴스룸 BGM과 긴급방송용 별도 BGM 연결
- 정답 반응에서 반복적으로 쓰이던 Yay 대신 짧은 UI 확인음(띠링 계열) 사용
- 여성/남성 한국어 TTS 선택 및 현재 상황 읽기 지원
- 생방송 프롬프터의 현재 멘트를 AI 시범 음성으로 듣거나 자동 낭독 가능
- 관측 화면 오른쪽에 AI 기상 데스크를 추가해 현재 자료를 짧은 방송 문장으로 요약
- 강수·대기 특이사항이 없을 때 지도 위 흰 글씨 대신 녹색 NORMAL 방송 상태 카드 표시
