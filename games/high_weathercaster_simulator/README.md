# 기상캐스터 시뮬레이터

기상 자료를 관측하고, 오후 날씨를 판단한 뒤, 키즈케이드 아바타로 생방송을 진행하는 직업·과학 시뮬레이션입니다.

## v1 핵심 루프
1. 레이더 / 기온 / 바람 자료 관측
2. 핵심 날씨 / 기온 변화 / 생활 정보 예보
3. 방송 프롬프터를 따라 지역을 가리키며 생방송
4. 방송 중 들어오는 기상 속보를 반영
5. 예보 판단 / 지도 설명 / 속보 대응 결과 확인

- 외부 날씨 API 없이 6개의 시뮬레이션 시나리오가 무작위로 출제됩니다.
- 키즈케이드 아바타 미리보기가 있으면 스튜디오 캐릭터로 사용합니다.
- 모바일 터치와 키보드 입력을 모두 지원합니다.
- 최고 점수 저장 키: kidscade_weathercaster_best_v1
- 진입점: games/high_weathercaster_simulator/index.html
