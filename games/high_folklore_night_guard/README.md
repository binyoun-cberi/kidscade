# 괴담 야간경비

학교 야간 경비실을 배경으로 한 2D CCTV 생존 공포 게임입니다.  
FNAF식 자원 관리와 카메라 추적, 이상현상 관찰, 세계 괴담 학습을 결합합니다.

## v8 위치 추적 리워크 핵심

- 지속형 위치 추적 AI
  - 그날 배치된 괴담은 근무 시작부터 학교 어딘가에 항상 존재
  - 귀신 스폰/소멸 이벤트 대신 각 존재가 자기 위치·이동 주기·AI 수치를 계속 유지
  - 6-1 교실 / 과학실 / 중앙 복도 / 방송실 앞 / 서쪽 복도 / 동쪽 복도 / 경비실을 실제 연결 그래프로 이동
  - 대응에 성공해도 사라지지 않고 다른 구역으로 후퇴하거나 다시 이동
- FNaF식 독립 이동 기회
  - 존재마다 별도 이동 주기와 0~20형 내부 AI 판정 사용
  - 시간이 흐를수록 AI가 강해짐
  - Director는 더 이상 귀신을 생성하지 않고 전체 긴장도와 이상현상 간격만 조절
  - 서로 모순되는 문 대응이 같은 문에서 동시에 강제되지 않도록 경비실 진입 충돌 방지
- 이상현상 시스템
  - 카메라별 시각 변화 풀
  - 이상 기록 버튼으로 현재 카메라의 변화를 판별
  - 정확한 기록은 점수/긴장도 보상
  - 오기록은 점수와 봉인력 손실
  - 귀신과 연결된 이상현상을 놓치면 해당 존재의 이동·침식이 빨라짐
- 봉인력 경제 개편
  - 아무 장치를 쓰지 않아도 기본 봉인력이 조금씩 감소
  - CCTV, 좌우 조명, 좌우 문 사용량을 0~5단계로 표시
  - 동시에 여러 장치를 사용할수록 소모율이 비선형 증가
  - 0%가 되는 즉시 사망하지 않고 모든 장치가 꺼진 암전 상태에서 무작위 침입 시점까지 버티게 됨
  - 6시가 먼저 오면 0% 상태에서도 생존 가능
- 방향성 오디오
  - 서쪽/동쪽 복도 위협은 스테레오 팬으로 방향 단서 제공
- 도감 단계화
  - 목격 → 관찰 → 대응 성공 → 숙련
  - 실패만으로 대응법이 자동 공개되지 않음
- 근무 진행
  - 연습 근무
  - 1~5일차
  - 특별 근무

## 현재 괴담

### 도깨비
- 역할: 환경 교란형
- 빈 교실 물건을 바꾸고 오래 방치하면 봉인력을 깎습니다.
- CCTV에서 변한 물건을 찾아 되돌리면 해결됩니다.

### 유키온나
- 역할: 환경 침식형
- 과학실에 성에가 차고 냉기가 심해집니다.
- 충분히 추워졌을 때 난방을 사용해야 효율이 높습니다.

### 처녀귀신
- 역할: 관찰 압박형
- 6-1 교실에서 시작해 학교 연결 경로를 따라 경비실로 접근합니다.
- CCTV로 관찰하면 이동이 멈추고, 충분히 관찰하면 후퇴합니다.
- 경비실까지 왔을 때는 서쪽 문으로 막아야 합니다.

### 달걀귀신
- 역할: 시선 회피형
- 근무 시작부터 카메라 구역 어딘가에 있으며 인접 구역으로 계속 이동합니다.
- 오래 바라볼수록 급속히 가까워지므로 발견 즉시 다른 카메라로 돌려야 합니다.
- 제대로 피하면 사라지는 대신 다른 카메라 구역으로 이동합니다.

### 저승사자
- 역할: 규칙 역전형
- 근무 시작부터 중앙 복도 계통 어딘가에 존재하며 이동 기회마다 경비실 쪽으로 전진합니다.
- 문을 열어 두어 통과시켜야 합니다.
- 통과시킨 뒤에도 학교 안에서 다시 경로를 잡습니다.

### 늑대인간
- 역할: 반응 속도형
- 근무 시작부터 복도 계통 어딘가에 존재하며 저승사자보다 짧은 이동 주기로 접근합니다.
- 방향성 소리를 듣고 해당 문을 짧게 닫아 막아야 합니다.
- 막아낸 뒤에도 중앙 복도로 후퇴해 다시 움직입니다.

## 봉인력

장치 사용량은 0~5단계입니다.

- CCTV +1
- 서쪽 조명 +1
- 동쪽 조명 +1
- 서쪽 문 +1
- 동쪽 문 +1
- 난방은 즉시 봉인력 7을 사용

동시에 많은 장치를 켜 둘수록 초당 소모량이 급격히 증가합니다. CCTV를 바꿀 때는 짧은 신호 잡음이 있으며, 그 시간은 실제 감시로 계산되지 않습니다.

## 도감

학생 플레이 난도를 낮추기 위해 도감은 처음부터 전체 공개됩니다.

- 모든 괴담의 이름과 분류 공개
- 실제 전승 정보 공개
- 게임 속 대응법 공개
- 반복 성공 횟수에 따라 숙련 별 1~3개만 진행 기록으로 남김

도감을 보는 동안 게임 시간은 멈춥니다.
