# 괴담 야간경비

학교 야간 경비실을 배경으로 한 2D CCTV 생존 공포 게임입니다.  
FNAF식 자원 관리와 카메라 추적, 이상현상 관찰, 세계 괴담 학습을 결합합니다.

## v6 리워크 핵심

- 실제 학교 연결 그래프 기반 이동
  - 6-1 교실 / 과학실 / 중앙 복도 / 방송실 앞 / 서쪽 복도 / 동쪽 복도 / 경비실
  - 처녀귀신, 저승사자, 늑대인간이 연결된 구역을 따라 이동
- Director 기반 사건 배치
  - 긴장도 0~100
  - 밤별 위협 예산
  - 고긴장 구간에는 신규 강공격 생성을 억제해 회복 구간 보장
  - 서로 모순되는 문 대응이 겹치지 않도록 복도 위협 동시 생성 제한
- 이상현상 시스템
  - 카메라별 시각 변화 풀
  - 이상 기록 버튼으로 현재 카메라의 변화를 판별
  - 정확한 기록은 점수/긴장도 보상
  - 오기록은 점수와 봉인력 손실
- 봉인력 경제 개편
  - CCTV, 좌우 조명, 좌우 문 사용량을 0~5단계로 표시
  - 동시에 여러 장치를 사용할수록 소모율이 비선형 증가
- 방향성 오디오
  - 서쪽/동쪽 복도 위협은 스테레오 팬으로 방향 단서 제공
- 도감 단계화
  - 목격 → 관찰 → 대응 성공 → 숙련
  - 실패만으로 대응법이 자동 공개되지 않음
- 근무 진행
  - 연습 근무
  - 1~5일차
  - 특별 근무

## 현재 괴담

### 도깨비
- 역할: 환경 교란형
- 빈 교실 물건을 바꾸고 오래 방치하면 봉인력을 깎습니다.
- CCTV에서 변한 물건을 찾아 되돌리면 해결됩니다.

### 유키온나
- 역할: 환경 침식형
- 과학실에 성에가 차고 냉기가 심해집니다.
- 충분히 추워졌을 때 난방을 사용해야 효율이 높습니다.

### 처녀귀신
- 역할: 관찰 압박형
- 6-1 교실에서 시작해 학교 연결 경로를 따라 경비실로 접근합니다.
- CCTV로 관찰하면 이동이 멈추고, 충분히 관찰하면 후퇴합니다.
- 경비실까지 왔을 때는 서쪽 문으로 막아야 합니다.

### 달걀귀신
- 역할: 시선 회피형
- CCTV 한 곳에 나타납니다.
- 오래 바라볼수록 급속히 가까워지므로 발견 즉시 다른 카메라로 돌려야 합니다.

### 저승사자
- 역할: 규칙 역전형
- 중앙 복도에서 좌우 복도를 거쳐 경비실로 이동합니다.
- 문을 열어 두어 통과시켜야 합니다.

### 늑대인간
- 역할: 반응 속도형
- 중앙 복도에서 좌우 복도를 거쳐 빠르게 경비실로 접근합니다.
- 방향성 소리를 듣고 해당 문을 짧게 닫아 막아야 합니다.

## 봉인력

장치 사용량은 0~5단계입니다.

- CCTV +1
- 서쪽 조명 +1
- 동쪽 조명 +1
- 서쪽 문 +1
- 동쪽 문 +1
- 난방은 즉시 봉인력 7을 사용

동시에 많은 장치를 켜 둘수록 초당 소모량이 급격히 증가합니다.

## 도감

도감은 실제 전승 정보와 게임용 대응 규칙을 분리합니다.

1. 목격: 이름과 기본 분류 공개
2. 관찰: 전승 정보 공개
3. 대응 성공: 게임 속 대응법 공개
4. 반복 성공: 숙련 별 1~3개 기록

도감을 보는 동안 게임 시간은 멈춥니다.
