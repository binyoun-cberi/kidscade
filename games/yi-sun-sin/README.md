# 이순신 — 옥포 해전 (무장·지휘·전투 연출 3차 개선)

독립적으로 실행되는 HTML5 Canvas 기반 2D 해전 게임. `games/yi-sun-sin/index.html`에서 시작한다.

## 플레이 흐름

1. 판옥선을 방향키 또는 WASD로 전후진·선회한다. 모바일 조이스틱도 위아래는 전후진, 좌우는 상대적인 선회로 동작하여 키보드와 동일한 항로를 따른다.
2. 적을 **내 배의 좌현·우현**에 놓고 급선회를 멈추면 자동으로 포격한다. 계속 급선회하면 포격할 수 없다. 게임 화면에는 측면 사격 범위를 표시한다.
3. 좌현과 우현은 각자 다른 화포를 장비할 수 있다. 기본 화포·속사 화포·대형 총통·근접 산탄·화염탄은 사거리, 재장전, 발사 수, 피해 방식이 다르다.
4. 적선은 사거리 확보와 측면 포격을 시도한다. 빠른 고바야는 지그재그로 기동하고, 세키부네는 측면 접근을 시도하며, 대형 아타케부네는 긴 사거리를 지킨다. 섬은 배와 포탄을 막는다.
5. **함대 명령 3종**은 기함과 협선이 함께 사용한다. `1`/`Space` 집결은 속사, `2` 집중 공격은 큰 적선을 우선 지정, `3` 엄호는 가까운 협선이 기함의 포탄·접촉 피해를 줄인다. 모바일에서는 하단 버튼으로 사용한다. 명령은 8초 지속, 24초 공동 대기시간이다.
6. 3차례 적선 공세 사이 선체를 75 회복하고 좌현·우현 무장 변경 및 아군 보강 중 하나를 선택한다. 격침된 협선은 정비 단계에서 충원할 수 있다.
7. 작은 화면에도 미니 레이더가 표시되고, 화포별 장전 상태와 지휘 명령·포격 가능 여부를 확인할 수 있다. 대형 포탄 충격, 화염, 침몰의 연기가 Canvas로 표현된다.

## 파일

- `sim.mjs`: 결정론적 함선 이동, 적 AI, 좌우 함포 판정, 충돌, 웨이브·강화·승패 처리. DOM과 독립.
- `game.js`: Canvas 묘화, 화면 정보, 키보드·터치 조작, 소리, 기록.
- `style.css` 및 `index.html`: PC와 모바일 레이아웃.
- Kidscade 게임 SDK `start/result/pause/resume` 이벤트를 연동해 출전 기록과 런 업적을 정식 집계한다.
- `../../tests/yi-sun-sin-sim.test.cjs`: Node 기본 테스트 러너로 실행하는 이동·포격·AI·교전·무장·함대 명령·화염 회귀 테스트.

## 역사 범위

1592년 옥포 해전을 바탕으로 만든 **재구성된 게임**이다. 정확한 함선 수, 적선 등장 순서, 전투의 세부 시간, 함포의 성능 및 화염 피해는 게임 규칙에 맞게 각색했다. 거북선은 옥포 단계에서 운용하지 않는다. 사천 해전의 거북선과 한산도의 학익진, 명량의 조류 등은 후속 개발 범위다.

## 3차 개선 검증 (2026-10-19)

- 신규 무장과 좌현·우현 독립 장착, 집중·엄호 지휘, 보강 후 회복, 화염탄 지속 피해까지 회귀 테스트 20개 통과.
- 64개 시작 조건을 실제 결정론적 전투 엔진에 적용: 지휘와 측면 기동을 활용한 플레이 **53승/64회**, 직진만 유지 **19승/64회**, 급선회만 유지 **0승/64회**. 측면 플레이의 승리 평균 약 **123초**.
- PC/모바일 실제 브라우저 수동 검수는 별도 확인이 필요하다. 자동 결과가 화면 렌더링·터치 조작감을 보장하지는 않는다.

## 참고 및 저작권

자체 작성한 HTML/CSS/JavaScript 코드와 SVG 아트로 구성된다. 설계 시 다음 공개 프로젝트의 방식을 참고했다. 해당 프로젝트의 코드를 직접 복사하지 않았다.

- [PirateShipGame](https://github.com/CuriousCrow123/PirateShipGame) (MIT): 측면 함포, 함선의 구성요소, 진행형 웨이브, 효과 분리 설계.
- [Vampire Survivors Clone](https://github.com/migalvalm/vampire-survivors-clone) (MIT): 자동 전투 및 강화 선택의 구성.
- [Survivors Starter Kit](https://github.com/DarkRewar/SurvivorsStarterKit) (MIT): 전투 중 적 성장·플레이어 강화의 기획 참고. Godot 4 C# 코드는 브라우저용으로 사용하지 않음.

원작 `GUNBOAT-8`의 코드·그래픽·음향은 포함하지 않았다.
