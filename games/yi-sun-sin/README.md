# 이순신 — 옥포 해전 (함종별 전술 AI·어려움 6차 개선)

독립적으로 실행되는 HTML5 Canvas 기반 2D 해전 게임. `games/yi-sun-sin/index.html`에서 시작한다.

## 플레이 흐름

1. 판옥선을 방향키 또는 WASD로 전후진·선회한다. 모바일 조이스틱도 위아래는 전후진, 좌우는 상대적인 선회로 동작하여 키보드와 동일한 항로를 따른다.
2. 적을 **내 배의 좌현·우현**에 놓고 급선회를 멈추면 자동으로 포격한다. 계속 급선회하면 포격할 수 없다. 게임 화면에는 측면 사격 범위를 표시한다.
3. 좌현과 우현은 각자 다른 화포를 장비할 수 있다. 기본 화포·속사 화포·대형 총통·근접 산탄·화염탄은 사거리, 재장전, 발사 수, 피해 방식이 다르다.
4. 적선은 사거리 확보와 측면 포격을 시도한다. 빠른 고바야는 지그재그로 교란하고, 세키부네는 **배에 올라타려는 도선 접근**을 시도한다. 아타케부네는 대형 지휘함으로 원거리 포격을 하며, 마지막 한 척이 남으면 결전에 나선다. 도선이 진행 중일 때는 밧줄과 진행 원호가 보이고 적선과 거리를 벌리면 해제된다.
5. **함대 명령 3종**은 기함과 협선이 함께 사용한다. `1`/`Space` 집결은 속사, `2` 집중 공격은 큰 적선을 우선 지정, `3` 엄호는 가까운 협선이 기함의 포탄·도선 피해를 줄인다. 모바일에서는 하단 버튼으로 사용한다. 명령은 8초 지속, 24초 공동 대기시간이다.
6. 협선은 경무장 호위·정찰, 사후선은 비무장 연락·정찰을 맡는다. 사후선이 살아 있으면 더 먼 적이 미니 레이더에 보인다. 3차례 공세 사이 선체를 75 회복하고 좌현·우현 무장 변경 또는 아군 보강을 선택한다. 격침된 협선·사후선은 정비 단계에서 충원할 수 있다.
7. 판옥선은 넓고 높은 갑판으로 도선 피해를 48% 줄인다. 함종마다 선체 폭, 뱃머리, 상부 누각, 갑판 포구, 돛대와 노가 달라 보인다. 대형 포탄 충격, 화염, 침몰의 연기가 Canvas로 표현된다.
8. 시작 화면의 **함선 일람**을 열면 양측의 함선 7종 역할과 간단한 역사 설명을 볼 수 있다. 거북선은 일람에만 소개되며 옥포에서는 등장하거나 선택할 수 없다.
9. **정박 노출**: 기함 속도가 낮은 상태로 6초 이상 머무르면 적선이 기함을 우선 공격하고 포격 피해가 증가한다. 화면 왼쪽 위에 위험 경고가 표시되며 전진으로 해소할 수 있다. 움직이는 기함은 일부 포탄 피해를 줄인다.
10. **교전별 전술 임무**: 1차 측면 함포 3회 명중 → 2차 기함 260m 기동 → 3차 함대 명령 2회 실행. 완수할 때마다 전공과 내구도 22 회복이 주어진다. 전술 임무 상태와 함종 이름표를 전투 중 확인할 수 있으며 레이더는 게임 메뉴 버튼을 가리지 않도록 배치했다.
11. **난이도 선택**: 출전 전 `보통` 또는 `어려움`을 선택한다. 어려움의 고바야는 기함의 측면으로 침투하고, 세키부네는 도선 진입·측면 압박을 전환하며, 아타케부네는 거리를 유지해 함포를 사용한다. 이동 중인 기함의 위치를 앞질러 예측하고 암초를 피하며, 최후의 적선은 끝까지 접근한다. 적 포격 주기·피해·증원 주기도 강화된다. 어려움은 **전공 30% 추가**와 별도 최고 기록을 제공한다. 승리·패배 후 난이도를 다시 고를 수 있다.

## 파일

- `sim.mjs`: 결정론적 함선 이동, 적 AI, 좌우 함포 판정, 충돌, 웨이브·강화·승패 처리. DOM과 독립.
- `game.js`: Canvas 묘화, 화면 정보, 키보드·터치 조작, 소리, 기록.
- `style.css` 및 `index.html`: PC와 모바일 레이아웃.
- Kidscade 게임 SDK `start/result/pause/resume` 이벤트를 연동해 출전 기록과 런 업적을 정식 집계한다.
- `../../tests/yi-sun-sin-sim.test.cjs`: Node 기본 테스트 러너로 실행하는 이동·포격·AI·교전·무장·함대 명령·화염 회귀 테스트.

## 역사 범위

1592년 옥포 해전을 바탕으로 만든 **재구성된 게임**이다. 정확한 함선 수, 적선 등장 순서, 전투의 세부 시간, 함포의 성능·화염·도선 수치·정찰 반경은 게임 규칙에 맞게 각색했다.

- **판옥선**: 위아래로 분리된 갑판과 높은 현측을 반영해 대포 위주의 조선 기함이 도선에 강하도록 했다.
- **협선**: 임진왜란 초기 판옥선 부속선으로 쓰였다는 기록을 바탕으로 경무장·호위·정찰 역할로 각색했다.
- **사후선**: 사료에서는 조선 후기 주로 **비무장 부속정**으로 설명하므로, 게임에서도 직접 화포 공격을 하지 않고 연락·정찰에 집중한다. 임진왜란 중 협선에서 사후선으로 부속선의 비중이 바뀌는 시기는 세부 해석의 여지가 있다.
- **고바야(小早)**: 작은 일본 배는 고바야로 표기한다. 입력 참고자료의 ‘테마마부네(小早)’는 같은 한자에 대한 통용 표기가 아니다.
- **세키부네·아타케부네**: 일본 군선의 기동·함상 접근 전술을 차별화했다. 배별 능력치와 AI는 역사 기록의 수량적 복원이 아니다.
- **거북선**: 옥포에는 배치하지 않으며 사천 해전의 후속 캠페인용 안내에만 등장한다. 덮개와 침입 방지 구조는 반영할 수 있지만 갑판 전체의 철판 장갑·쇠사슬 등의 세부 형태는 확정 사실로 제시하지 않는다.

## 6차 개선 검증 (2026-10-20)

- 난이도 선택 상태·함종별 전술 AI·기함 우선 표적·포격 속도/피해·증원 간격 차이·전투 교착 방지까지 **33/33 회귀 테스트 통과**.
- 동일한 64개 전투 시드에서 `보통` 전술 플레이 **44승/64**, `어려움` 전술 플레이 **34승/64**. 업그레이드만 고르고 정박하는 플레이는 보통 **8승/64**, 어려움 **1승/64**. 모든 교전이 제한 시간 안에 종료되었다.
- 두 난이도 모두 적 함선 수는 동일하다. 어려움은 함선의 행동·포격·증원 타이밍이 달라지는 모드이며, 예측 조준용 기동 AI는 선박별로 독립적인 결정으로 작동한다. 위 승률은 하나의 자동화된 전술 정책을 비교한 수치이고 인간 플레이의 실제 승률이 아니다.
- 난이도 선택 HTML과 HUD 코드는 문법·정적 검사를 마쳤다. 실제 기기 화면에서의 시각 검수는 배포 후 별도로 진행해야 한다.

## 5차 개선 검증 (2026-10-20)

- **29/29 회귀 테스트 통과**: 정박 노출·이동으로 해소, 기함 포탄 피해 차이, 3단계 전술 임무 보상 및 64개 시드의 무조작/전술 플레이 승률 차이를 추가 검증했다.
- 동일한 64개 결정론적 시드에서 업그레이드만 고르는 **정박 무조작 8승**, 항해·측면 선회·함대 명령을 사용하는 **전술 플레이 44승**. 양쪽 모두 교착 없이 종료된다. 이는 자동화 전략 간 비교로, 실제 학생들의 승률은 별도 플레이 검수가 필요하다.
- 게임 화면은 함선 확대, 함종 이름표, 피격 수치, 전술 임무 표시, 위험 경고와 레이더 위치를 개선했다. Node 구문 검사와 정적 레이아웃 검사 통과. 실제 데스크톱·모바일 시각 검수는 배포된 수정본에서 추가 수행해야 한다.

## 4차 개선 검증 (2026-10-19)

- 함선 분화, 사후선 정찰/비무장, 세키부네 도선·판옥선 피해 감소, 도선 중 이탈과 사후선 복구 등 **25/25회귀 테스트 통과**.
- 시드 64개에서 전술적 측면 기동+지휘 **60승/64회**, 직진 **35승/64회**, 제자리 급선회 **0승/64회**. 4분 내 교착 0건, 전술 승리 평균 약 **125초**.
- Node 구문 검사, Git diff 서식 검사 통과. 실제 브라우저 시각·모바일 터치 검수는 별도 수행해야 한다.

## 3차 개선 검증 (2026-10-19)

- 신규 무장과 좌현·우현 독립 장착, 집중·엄호 지휘, 보강 후 회복, 화염탄 지속 피해까지 회귀 테스트 20개 통과.
- 64개 시작 조건을 실제 결정론적 전투 엔진에 적용: 지휘와 측면 기동을 활용한 플레이 **53승/64회**, 직진만 유지 **19승/64회**, 급선회만 유지 **0승/64회**. 측면 플레이의 승리 평균 약 **123초**.
- PC/모바일 실제 브라우저 수동 검수는 별도 확인이 필요하다. 자동 결과가 화면 렌더링·터치 조작감을 보장하지는 않는다.
