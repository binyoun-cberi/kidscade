# 포물선 대작전 (v1)

- 주소: `games/low_parabola_battle/index.html`
- 게임 ID: `low_parabola_battle`
- 대상: 초등학생 중심, 수학·과학 활동
- 구성: 표적 연습 6단계, 컴퓨터 대전(먼저 3점), 같은 기기 2인 턴제
- 조작: 각도 5~85°, 세기 10~100, 발사. 화살표와 스페이스바, 슬라이더, 대포 근처 직접 드래그 조준
- 완료 화면: 스테이지 6개 완료 또는 대전 3점 달성 후 요약 카드, 같은 모드 다시 한 판/모드 변경
- 난이도: 쉬움=현재 예상+이전 궤적 / 보통=이전 궤적 / 도전=궤적 표시 안 함
- 바람: 기본 끔, 켜면 연습은 스테이지마다, 대전은 차례마다 방향과 크기가 달라짐
- 조준 비교: 연습에서는 실패 후 각도와 세기가 그대로 유지되고 직전 궤적/조건 확인 가능
- 대전 전용: 포탄이 땅에 떨어지면 부드러운 구덩이가 생김. 다음 차례에 지형 높이 재계산
- 포탄 2종: 기본탄(정확한 충돌), 펑펑탄(근처 땅을 때려도 폭발 판정), 펑펑탄 플레이어당 2회

## 과학·수학 설계
가로위치 `x(t)=x0+vx*t+0.5*wind*t²`, 세로위치 `y(t)=y0+vy*t+0.5*g*t²` (화면 좌표의 y는 아래 방향).
고정 시간 간격으로 포탄이 지형·과녁에 부딪혔는지 검사하며, 실제 물리 판정과
보이는 경로가 같은 함수 `physics.js`를 사용합니다.
게임 수치는 현실 단위가 아닌 화면 연출용 값입니다. 바람은 수평 가속도의 단순화 모형입니다.

## 내부 자산 재사용
기존 공용 `assets/game/2d/platformer-art/base/`의 배경·풀·돌·성 이미지뿐 아니라
구름·덤불·바위·깃발·폭탄·불꽃·별 이미지와 눈·모래·물 타일을 직접 로드.
스테이지에 따라 들판/바위언덕/골짜기/설원/사막 풍경으로 변화합니다.
발사 반동, 포탄 연출, 피격 화면 흔들림, 명중/승리 화면을 제공합니다.
쉬움에서는 예상 궤적의 최고점과 예상 탄착 지점을 눈으로 확인할 수 있습니다.
이미지 로드에 실패하면 캔버스의 기본 색상/도형으로 계속 플레이됩니다.
새 이미지를 다운로드하거나 기존 에셋을 복사하지 않습니다.
대포는 옆모습 정확도를 위해 캔버스 벡터로 구현했으며 향후 GLB 포탑 활용은 후속 작업입니다.

## 안전성·연동
- 외부 API, 유료 서비스, 추가 패키지 없음.
- 게임 SDK `start`, `result(stage / match / campaign)` 연동.
- 각도와 세기 변경 및 예측은 기록으로 저장하지 않음. 표적 명중과 승부 완료만 기록.
- 컴퓨터 대전은 구덩이가 반영된 현재 지형에서 목표를 맞힐 수 있는 후보를 시험하고 난이도별 오차를 넣습니다.
- 터치 화면/키보드 모두 지원. 도움말과 게임 모드 선택 제공.
