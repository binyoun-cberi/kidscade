# 관제탑 시뮬레이터 · 개발 및 검수 노트

## 목표

학생이 한 화면에서 여러 항공기의 위치·목적지·고도·기상 조건을 살피며 **순서를 정하고 미리 위험을 피하는 판단**을 하게 만든다. 원작과 별도의 독립 구현이며, 전문 항공관제 교재 또는 실제 항법 프로그램이 아니다.

## 참고 작품 코드 분석

- 원작: [mausimus/ld49 · AIROBICS](https://github.com/mausimus/ld49) (Ludum Dare 49, C++/raylib).
- 업로드된 `ld49-airobics.zip`: Windows 실행 파일, DLL, 이미지 1종, 효과음·음악, GLSL 셰이더가 포함됨. **C++ 소스는 ZIP에 없다.** 저장소의 `src/`를 별도로 검토했다.
- 원본 저장소에서 코드·에셋의 재사용을 허용하는 명시적 LICENSE 파일을 확인하지 못했다. 그러므로 **원본의 C++ 코드, 바이너리, 이미지·음원·셰이더를 복사하지 않았다.** 게임 규칙과 UX를 연구한 뒤 새 Javascript/SVG/Canvas를 작성했다.

| 원작 구조 | 소스에서 확인한 기능 | 독립 구현에서의 대응 |
|---|---|---|
| `Plane::Tick` | 각도 변화 제한, 속도와 고도 보간, 목표점을 통과하면 목적지 재지정 | `step`/점진 선회/고도 변경/경유점 자동 해제 |
| `Board::SpawnPlane` | 유형별 속도·콜사인·출현 위치·목적지 지정; 난이도에 따른 생성 빈도 | 항로 경계의 항공기 생성, 구분되는 항공기 유형 |
| `Board::Board` | 동서남북 항로와 SF/도쿄/런던의 서로 다른 공항 지형 | 가상 하늘빛/해안/도시 3구역, 1~3개 공항 |
| `Area::Tick`, `Board::SpawnArea` | 기상 구역 이동, 비행금지구역, 유지시간 | 시각화된 기상 구역·비행제한구역 |
| `GameScreen::Tick` | 항공기 선택→화면의 지점 지정, 1~4배속 | 클릭·터치·드래그 경유점, 1/1.5/2배속 및 일시정지 |
| `GameScreen::CheckPlanes` | 공항/항로 도착, 이탈, 악천후 감속, 지연 누적 | 관제 완료·이탈 처리, 날씨 감속, 점수와 지연 |
| `GameScreen::CheckCollisions` | 같은 화면 공간에서 거리별 접근 경고·충돌 판정 | 거리/고도 분리 경고, 자동 안전 개입, 비그래픽 실패 |
| `GameScreen::DrawPanels` | 현재 기체, 남은 시간, 경보, 전체 지연 | 선택 패널, 실시간 운항 목록, 기록, 근무 보고서 |

## 플레이 규칙

1. 레이더의 항공기 또는 우측 목록에서 한 대를 선택한다.
2. 레이더의 빈 지점을 누르면 새로운 경유점을 향해 **점진적으로 선회**한다. 경유점 통과 후 원래 목적지로 돌아간다.
3. 같은 고도의 항공기가 가까워지면 경고한다. 고도 1/2 단계 지시로 수직 분리할 수 있다. 실제 고도는 지시에 따라 점진적으로 변경된다.
4. 공항 착륙은 낮은 고도 단계가 필요하다. 활주로가 사용 중이면 자동으로 대기하고, 사용 가능해지면 재진입한다. 플레이어도 대기 선회를 지시할 수 있다.
5. 기상 구역은 감속, 비행제한구역은 감점이다. 경고·지연·안전 개입·도착 대수를 근무 종료 시 정산한다.
6. 안전 개입이 3회 발생하면 근무가 종료된다. 제한시간 동안 필요한 도착 대수를 달성하고 안전을 유지하면 완료된다.

세 지역: 하늘빛(150초·공항 1·필요 도착 4), 해안(175초·공항 2·필요 도착 6), 도시(195초·공항 3·필요 도착 8).
게임 배속 1/1.5/2, 일시정지, 키보드(1~3/Space/A/S/H)·마우스·터치 지원.

## 구성

- `index.html`: 관제 화면과 학습 안내, 게임 종료 보고서
- `style.css`: 모바일 대응 HUD·패널·레이더
- `simulation-core.js`: 외부 의존성 없는 결정적 시뮬레이션 (CommonJS + 브라우저 UMD)
- `game.js`: Canvas 렌더링, 사용자 입력, KidscadeGame 연동
- `tests/air-traffic-control.test.cjs`: 비행 상태·착륙·대기·충돌·전체 시뮬레이션 검증
- `assets/gate-image/high_air_traffic_control_cover.svg`: 독자 제작 벡터 표지

## 테스트와 개선 기준

- `node --test tests/air-traffic-control.test.cjs`
- `node --test tests/game-filenames.test.cjs`
- `npm run health:strict`
- 브라우저 실제 플레이: 좌측 터치 → 레이더 지점 지정 → 고도 지시 → 착륙 → 결과 기록, 모바일 가로/세로 화면 레이아웃, 일시정지 후 재개, 메인 홈 카드·게임 SDK 확인.

브라우저와 배포 테스트는 실행 및 결과 확인 전까지 **미검증**으로 기록한다. 
추천 후속 작업: 실제 플레이 영상/피드백으로 고도 변경 난이도와 근접 경고 빈도를 교정하고, 레이더 연습 임무·기상 정보 패널·항공편 우선순위 시나리오를 보강한다.

원본 코드의 라이선스 부재가 확인되는 동안에는 자체 코드를 유지하고 원본 리소스를 가져오지 않는다.
