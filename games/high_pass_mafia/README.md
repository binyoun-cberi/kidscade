# 누가 마피아? : 한밤의 마을

한 기기를 차례로 넘기며 플레이하는 Kidscade용 Pass & Play 마피아 게임입니다.

## 인원별 진행 모드

### 클래식 모드 · 4~16명

- 시민 / 마피아 / 경찰 / 의사
- 역할 확인 시 길게 누르는 동안에만 비밀 카드 공개
- 밤에는 모든 생존 플레이어가 기기를 전달받아 직업 노출 방지
- 마피아 표적 다수결, 경찰 조사, 의사 보호 자동 해결
- 낮 토론 → 전원 비밀 지목 → 최후 변론 → 처형 찬반 비밀투표
- 지목 동률 시 동률 후보 재투표

### 학급 모드 · 17~24명

대규모 인원에서 휴대폰 전달 횟수가 과도해지는 문제를 줄이기 위한 자동 진행 모드입니다.

- 17명부터 자동 활성화
- 추천 마피아: 17~21명 5명, 22~24명 6명
- 21명 기본 추천: 마피아 5 / 경찰 1 / 의사 1 / 시민 14
- 첫 역할 확인과 밤은 전원이 참여해 직업 노출을 막음
- 시민 밤 화면과 휴대폰 인계 문구를 짧게 표시하는 빠른 밤 사용
- 낮에는 학급 토론 후 공개적으로 최종 후보 2명을 선택
- 후보 두 명이 각각 짧은 변론 진행
- 후보 2명은 최종투표에서 빠지고 나머지 생존자만 휴대폰을 한 번씩 전달
- 최종 비밀투표 선택지: 후보 A / 후보 B / 둘 다 살린다
- 후보 동률 또는 '둘 다 살린다'가 최다득표(동률 포함)이면 처형 없이 밤으로 진행
- 대규모 낮 투표에서 추가 재투표를 만들지 않아 진행 시간을 제한

## 공통 기능

- 4~24명 플레이어 이름 등록
- 학급 명단 줄바꿈/쉼표 붙여넣기
- 인원 변경 시 역할 수 자동 재추천
- 사망 시 역할 공개 선택
- 시민/마피아 진영 승리 조건 자동 판정
- 같은 멤버로 재경기
- KidscadeStorage를 통한 진행 중 게임 자동 복구

## 설계 원칙

사회적 대화는 실제 공간에서 하고, 기기는 사회자 역할과 비밀 정보 처리만 담당합니다.
인계 화면에는 다음 플레이어 이름만 표시하고 역할 정보는 렌더링하지 않습니다.
경찰 조사 결과와 최초 역할 카드는 누르고 있는 동안에만 화면에 나타납니다.
학급 모드는 20명 안팎에서 기기를 두 번 이상 돌리는 낮 절차를 피하는 데 초점을 둡니다.
