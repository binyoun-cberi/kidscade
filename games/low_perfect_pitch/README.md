# 퍼펙트 피치

패드·휴대폰의 마이크를 게임 컨트롤러로 사용하는 음정 조절 게임입니다.

## 플레이
- 시작할 때 편한 높이의 “아~~~”를 약 1.5초 동안 측정해 개인 음역을 설정합니다.
- **노래길**: 3-2-1 카운트다운 뒤 `목소리 깨우기 → 멜로디 여행 → 반짝 피날레` 3막으로 진행합니다. 무작위 음 대신 난이도·막별 짧은 멜로디 패턴이 이어지고, 5콤보마다 FEVER가 발동하며 별 문에서 보너스 점수를 얻습니다.
- **무한 고음 계단**: 제한시간 없이 장음계 계단을 한 칸씩 올라가고 3번 실패할 때까지 최고 층을 갱신합니다. 7칸마다 보너스가 있는 구름 쉼터가 나오며, 높이에 따라 꽃구름→노을→별빛→오로라 배경으로 변합니다. 기존 최고 기록을 넘으면 즉시 신기록 연출이 나옵니다.
- 고음 계단은 음량을 점수에 사용하지 않습니다. 큰 소리보다 편한 발성으로 음정을 맞추도록 안내합니다.
- 초급 / 보통 / 도전 난이도는 판정 폭을 조절하며, 일반 모드에서는 문 속도와 제한시간에도 반영됩니다.
- 마이크 원본 오디오는 저장하거나 전송하지 않고 브라우저의 Web Audio API에서 실시간 분석만 합니다.

## 구현
- 진입점: `games/low_perfect_pitch/index.html`
- 런타임: `games/low_perfect_pitch/game.js`
- 음높이 인식기: `games/low_perfect_pitch/pitch-detection.js` (YIN 주기 검출, 2,048샘플 분석, 짧은 음정 흔들림 완화)
- 외부 음성 API 없음
- Game SDK: `low_perfect_pitch`
- 기록 키: `kidscade_perfect_pitch_v1`

## 한 판의 완결성
- 노래길 종료 시 통과율과 최대 콤보를 기준으로 0~3개의 별을 받습니다.
- 최고 점수·최고 콤보·최고 별·고음 계단 최고 층을 기기에 저장합니다.
- 피날레 구간은 속도와 별 문 빈도가 올라가 마지막 1/3이 클라이맥스로 느껴지도록 구성했습니다.

> 현재 리워크: 노래길 3막 진행 + FEVER + 별 문 + 계단 구간 연출.

## 목소리 인식 개선 (2026-10-14)
- 작은 소리를 과도하게 거르지 않도록 무음 기준을 낮추고, 무음/잡음은 주기 신뢰도를 통해 구별합니다.
- 44.1/48kHz 입력에서 낮은 음부터 높은 음까지 안정적으로 분석하며, 짧은 배음 튐은 최근 프레임 중앙값으로 완화합니다.
- 보정 화면은 실제 분석된 프레임만 세어 약 1.5초 분량의 유효 발성에서 음역을 정합니다.
- 고음 계단은 보정 시 불렀던 편한 음에서 출발합니다.
- 노래길의 문 통과는 한 순간의 음높이만이 아니라 통과 직전과 직후의 짧은 판정 구간에서 가장 가까웠던 음을 반영합니다.
- 게임 화면의 ‘현재 음’은 맞춤 음역 기준의 상대적인 도·레·미로 표시합니다.
- 마이크를 허용하지 않거나 다른 앱이 점유하면 브라우저·기기 설정을 확인해야 합니다. 실제 기기에서의 음향 검수는 별도로 필요합니다.

## 음높이 판정 개선
- 강한 배음 때문에 음을 한 옥타브 높게 잡는 일부 사례를 보정합니다. 완전한 옥타브 구분은 음색과 잡음에 따라 달라질 수 있습니다.
- 맞춤 기준은 측정한 음을 반음으로 반올림하지 않고 유지합니다. 도·레·미는 맞춤 기준의 상대음입니다.
- 노래길은 판정 구간에서 서로 다른 분석 프레임을 2개 이상 모아 오차의 중앙값으로 판정합니다.
- 반음(100센트) 차이로 성공하지 않도록 성공 범위를 초급 ±48, 보통 ±42, 도전 ±35센트로 조정했습니다.
- 자동 시험: `node games/low_perfect_pitch/pitch-detection.test.js`. 실제 기기와 교실 음향에서의 검수는 별도로 필요합니다.


## 나의 선율 모드
- 모드 선택 화면에서 「나의 선율」을 엽니다. 유튜브 공식 플레이어의 영상을 들으며 노래할 수 있습니다.
- 원음 녹음 없이 40ms 간격의 측정 음높이(Hz), 시간, 쉼을 기록합니다. 도·레·미로 양자화하지 않고 측정한 높이를 악기 음색으로 다시 재생합니다.
- 한 번에 최대 3분, 이 기기 최근 6개 선율 저장·불러오기·삭제와 재생 위치 이동을 지원합니다. 기기/브라우저를 바꾸면 기록이 공유되지 않습니다.
- 이어폰을 사용합니다. 마이크에 들어온 반주·주변 소음도 인식될 수 있으며 원곡 음정 추출이나 자동 채점 기능은 아닙니다.
- 영상 멈춤·버퍼링·탐색·화면 이탈 시 현재 기록을 마치고 마이크를 끕니다. 재생 속도를 바꿔도 실제 부른 시간 간격으로 기록합니다.
- 검수: 유튜브 링크 형식, 음높이/쉼 데이터, 저장/복원, 악기 재생, 영상 멈춤·마이크 종료를 DOM·영상·마이크를 모의한 통합 시험으로 검사합니다. 실제 유튜브 연결·실기기 음향 검수는 별도입니다.

- 자동 시험: `node --test games/low_perfect_pitch/melody-core.test.cjs games/low_perfect_pitch/melody-studio.test.cjs`
