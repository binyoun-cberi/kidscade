# 퍼펙트 피치

패드·휴대폰의 마이크를 게임 컨트롤러로 사용하는 음정 조절 게임입니다.

## 플레이
- 시작할 때 편한 높이의 “아~~~”를 약 1.5초 동안 측정해 개인 음역을 설정합니다.
- **음표 문**: 목소리 음정이 높아지면 공이 올라가고 낮아지면 내려가며, 다가오는 도·레·미 문을 cent 단위 판정으로 통과합니다.
- **무한 고음 계단**: 제한시간 없이 장음계 계단을 한 칸씩 올라가고 3번 실패할 때까지 최고 층을 갱신합니다. 7칸마다 자동으로 짧은 숨 고르기 시간이 들어갑니다.
- 고음 계단은 음량을 점수에 사용하지 않습니다. 큰 소리보다 편한 발성으로 음정을 맞추도록 안내합니다.
- 초급 / 보통 / 도전 난이도는 판정 폭을 조절하며, 일반 모드에서는 문 속도와 제한시간에도 반영됩니다.
- 마이크 원본 오디오는 저장하거나 전송하지 않고 브라우저의 Web Audio API에서 실시간 분석만 합니다.

## 구현
- 진입점: `games/low_perfect_pitch/index.html`
- 런타임: `games/low_perfect_pitch/game.js`
- 외부 음성 API 없음
- Game SDK: `low_perfect_pitch`
- 기록 키: `kidscade_perfect_pitch_v1`
