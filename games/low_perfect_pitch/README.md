# 퍼펙트 피치

패드·휴대폰의 마이크를 게임 컨트롤러로 사용하는 음정 조절 게임입니다.

## 플레이
- 시작할 때 편한 높이의 “아~~~”를 약 1.5초 동안 측정해 개인 음역을 설정합니다.
- **노래길**: 3-2-1 카운트다운 뒤 `목소리 깨우기 → 멜로디 여행 → 반짝 피날레` 3막으로 진행합니다. 무작위 음 대신 난이도·막별 짧은 멜로디 패턴이 이어지고, 5콤보마다 FEVER가 발동하며 별 문에서 보너스 점수를 얻습니다.
- **무한 고음 계단**: 제한시간 없이 장음계 계단을 한 칸씩 올라가고 3번 실패할 때까지 최고 층을 갱신합니다. 7칸마다 보너스가 있는 구름 쉼터가 나오며, 높이에 따라 꽃구름→노을→별빛→오로라 배경으로 변합니다. 기존 최고 기록을 넘으면 즉시 신기록 연출이 나옵니다.
- 고음 계단은 음량을 점수에 사용하지 않습니다. 큰 소리보다 편한 발성으로 음정을 맞추도록 안내합니다.
- 초급 / 보통 / 도전 난이도는 판정 폭을 조절하며, 일반 모드에서는 문 속도와 제한시간에도 반영됩니다.
- 마이크 원본 오디오는 저장하거나 전송하지 않고 브라우저의 Web Audio API에서 실시간 분석만 합니다.

## 구현
- 진입점: `games/low_perfect_pitch/index.html`
- 런타임: `games/low_perfect_pitch/game.js`
- 외부 음성 API 없음
- Game SDK: `low_perfect_pitch`
- 기록 키: `kidscade_perfect_pitch_v1`

## 한 판의 완결성
- 노래길 종료 시 통과율과 최대 콤보를 기준으로 0~3개의 별을 받습니다.
- 최고 점수·최고 콤보·최고 별·고음 계단 최고 층을 기기에 저장합니다.
- 피날레 구간은 속도와 별 문 빈도가 올라가 마지막 1/3이 클라이맥스로 느껴지도록 구성했습니다.

> 현재 리워크: 노래길 3막 진행 + FEVER + 별 문 + 계단 구간 연출.
