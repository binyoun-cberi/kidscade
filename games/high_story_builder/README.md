# 이야기 조립소

API 없이 브라우저에서 작동하는 초등 글쓰기 게임입니다.

## 핵심 루프
1. 난이도에 따라 2~4장의 그림/이모지 카드를 무작위로 뽑습니다.
2. 학생은 모든 카드 요소를 넣어 자유롭게 이야기를 씁니다.
3. 보통/도전 모드에서는 대화, 감정, 이유, 반전 같은 추가 미션이 붙습니다.
4. 글을 다 쓴 뒤에만 맞춤법 점검을 보여 줍니다.
5. 검사기가 글을 자동 수정하지 않고 힌트를 보여 주며 학생이 직접 고칩니다.
6. 완성 글은 그림책 페이지처럼 표시되고 로컬 '내 이야기책'에 저장됩니다.

## 맞춤법 검사
- 외부 API를 사용하지 않습니다.
- `data/spelling-quiz-expanded.js`의 기존 맞춤법 문제은행에서 틀린 표현/바른 표현 쌍을 추출합니다.
- 자유글에서 자주 필요한 표현은 별도 로컬 규칙으로 보완합니다.
- 규칙 기반 검사이므로 문맥을 완전히 이해하는 범용 한국어 교정기는 아니며, 결과 화면에도 이를 명시합니다.

## 동기 설계
새싹력, 제출, 순위 대신 다음을 보상으로 사용합니다.
- 랜덤 이야기 재료
- 카드 사용 체크의 즉각적 변화
- 추가 창작 미션
- 초고보다 정확도가 올라가는 변화
- 완성 글의 '책' 변환
- 기기 안 개인 이야기책 보관

진입점: `games/high_story_builder/index.html`  
로컬 저장: `kidscade_story_builder_v1`

## 발음대로 적은 표현 검사

- 자주 쓰는 활용형에서 ‘먹어요 → 머거요’처럼 받침이 뒤 음절로 이어져 들리는 형태를 생성하여 검사합니다.
- ‘머거써요 → 먹었어요’, ‘마싯게 → 맛있게’ 등의 자주 나오는 오류도 따로 검사합니다.
- ‘바다’처럼 다른 올바른 단어와 충돌하는 발음 표기는 자동 교정하지 않습니다.
- ‘말인게’처럼 뜻이 불확실한 경우에는 감점 없이 확인을 요청합니다.
- 검사는 모든 한국어 문맥을 판별하지 못하므로 점수는 ‘검사 기준 점수’이며, 오류가 없다고 모든 표현이 옳다는 의미는 아닙니다.

## 확장 검사 자료 (v4)

- 별도 로컬 파일 `spelling-extra.js`에 초등학생용 오류 예시 709개를 관리합니다.
- 기존 맞춤법 퀴즈 문제은행과 합쳐 현재 충돌 제거 후 검사 규칙 1,389개를 사용합니다(문제은행 갱신 시 변동 가능).
- 발음대로 적는 오류, 낱말 표기, 띄어쓰기, 어미 활용, 그림 카드 낱말과 조사 결합형을 다룹니다.
- `잼있게 → 재밌게`를 제안하며, `재미있게`도 올바른 표현으로 인정합니다.
- 어미·뜻에 따라 둘 다 맞는 `어떻게/어떡해` 등의 표현을 일률적으로 오답 처리하지 않습니다.
- 단어 경계를 확인하여 `할수`가 `할수록`의 일부일 때 잘못 고치는 문제를 줄입니다.
- `node --test tests/story-builder-spelling.test.cjs`로 대표 문장 33개와 전체 확장 자료의 오검출 여부를 검사합니다.
- 사전에 없는 새로운 오타·복잡한 문맥·임의의 띄어쓰기를 모두 잡아내지는 못하며 점수는 시험된 규칙 기준입니다.
