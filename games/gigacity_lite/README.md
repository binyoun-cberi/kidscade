# 기가시티 v6 — 추격과 반격

기존 소수 추격전과 자유 비행을 유지하면서 **비행 액션을 강화한 업데이트**입니다.

- 실시간 후방 레이더: 플레이어를 중심으로 전방/후방, 표적, 접근 거리, 조준 중인 적을 표시합니다. 모바일 가로·세로 레이아웃에 대응합니다.
- 네 종류의 적 전투기: 정찰기(6,10,15), 장갑기(8,12,49), 요격기(21,35,30), 지휘 전함(84,105). 이동 속도, 좌우 선회 폭, 공격 주기와 공격 피해량, 3D 외형이 다릅니다. 각 전투기는 빌딩 충돌 판정과 함께 추격합니다.
- 조준 예고: 숫자 표지가 붉어지고 **실제 예측 사격 지점으로 향하는 3D 조준선**이 표시됩니다. 경고음으로도 알립니다.
- 회피: 조준선을 본 뒤 급히 진로를 바꾸거나 빌딩을 엄폐로 활용하면 레이저가 빗나갑니다. 조준된 예측 위치로 쏘므로 그냥 자동 비행만 하면 회피되지 않습니다.
- 소인수분해 전투와 연계된 손상: 정답 소수탄마다 실제 전투기 장갑, 지느러미, 엔진 등의 3D 부품 하나가 떨어져 회전하며 추락합니다. 각 기체의 크기는 달라도 숫자 표지는 동일하게 읽히도록 보정했습니다.
- 경고·피격·회피 효과음, 작은 엔진 소리, 적중 시 화면 흔들림·붉은 테두리. Web Audio API 미지원 환경에서도 게임은 동작합니다.
- 자동차 뒤 시점은 선택한 추격기를 자연스럽게 보여주도록 시야를 약하게 보정합니다.
- 자동 비행 외에 좌우 조이스틱 조작 시 전투기 비행 속도를 유지해 회피 입력이 즉시 효과를 냅니다.
- **연습전 5대 / 일반전 11대 / 자유 비행**은 유지됩니다. 2·3·5·7이 정확한 소수이고 적 숫자가 1이 되어야 격추되는 수학 규칙은 변경되지 않았습니다.

검증: `node --test tests/gigacity-prime-chase.test.mjs`, `node tests/gigacity-visual-browser-audit.cjs`(가상 모바일 화면). 실제 iPhone Safari에서 장시간 발열·프레임 유지와 진동/오디오 장치는 별도 확인해야 합니다.

# 기가시티 — 소수 추격전 v5

- **연습전(5대):** 6 → 10·15 → 8·12. 초보자는 짧은 전투로 2·3·5·7 나눗셈을 익힙니다.
- **일반전(11대):** 6 → 10·15 → 8·12 → 21·35 → 30·49 → 84·105. 3분 제한이며 같은 소수를 반복하는 8·49, 다양한 인수를 가진 84·105가 등장합니다.
- 틀린 소수탄을 난사하면 재장전이 약 1.45초로 길어지고, 잘못된 횟수에 따라 방어막이 1~3% 감소합니다. 정답은 빠르게 다음 소수로 연속 발사할 수 있습니다.
- 적이 플레이어 뒤에서 출현해 좌우로 선회합니다. 발사 2초 전에 기체 표지가 붉어지고 경고가 나타납니다.
- 적의 조준은 현재 속도로 2초 뒤 위치를 예측합니다. **그대로 자동 비행하면 회피되지 않고**, 발사 직전에 방향을 바꾸거나 고도 변경, 건물 엄폐를 활용하면 공격을 피할 수 있습니다.
- 성공한 회피 횟수가 결과 화면에 표시됩니다.
- 저사양 브라우저에서 프레임 간격이 길어져도 이동을 0.05초 이하로 나눠 진행하고 전투 시간을 동일하게 계산합니다.
- 격추 폭발이 보이도록 약 1.15초간 승패 화면 표시를 늦춥니다.

검증: `node --test tests/gigacity-prime-chase.test.mjs`, `node tests/gigacity-visual-browser-audit.cjs`. 실제 iPhone 장시간 발열·FPS는 별도 확인이 필요합니다.

# 기가시티 — 소수 추격전 v4

기존 기가시티 도시 비행과 차량 운전석을 활용한 3분짜리 소인수분해 추격전입니다.
키즈케이드의 게임 목록 또는 `/games/gigacity_lite/index.html`에서 실행합니다.

## 플레이 방법

- 시작 화면에서 **소수 추격전 시작** 또는 **도시 자유 비행** 선택.
- 플레이어는 **소수 11**. 합성수 군용 비행체를 3분 안에 모두 격추해야 합니다.
- 합성수 전투기는 총 5대, 3차례 등장: **6** → **10·15** → **21·35**.
- 하단의 **2, 3, 5, 7 소수탄** 버튼을 누르면 자동 조준한 적을 그 소수로 나눕니다. 나누어떨어지지 않는 탄환은 방어막에 막혀 재장전 시간이 길어집니다.
- 적 숫자가 **1**이 되면 격추. 1은 소수도 합성수도 아닙니다. 여러 적 중 원하는 적은 상단 숫자 버튼으로 선택할 수 있습니다.
- 적 공격을 받으면 방어막 감소. 방어막이 0이 되거나 3분이 끝나면 패배. 적 5대 격추 시 승리.
- 숫자탄은 키보드의 숫자 2, 3, 5, 7로도 발사 가능.
- 자동차는 자동 비행으로 출발하므로 첫 플레이에서 계산에 집중할 수 있습니다. 조이스틱, 상승/하강, 빠른 이동으로 직접 회피도 가능합니다.
- 추격전 중 운전석/자동차 뒤 시점 전환. 기존 자유 비행 모드는 별도로 유지.

## 구현

`prime-chase.mjs`는 브라우저 의존성이 없는 전투·학습 규칙입니다. `prime-chase-view.js`는 가벼운 3D 전투기, 숫자 표지, 레이저, 폭발 효과를 표현합니다. 새 외부 에셋이나 대형 모델을 다운로드하지 않습니다.

테스트:
- `node --test tests/gigacity-prime-chase.test.mjs`
- `node --test tests/gigacity-lite.test.mjs`
- `node tests/gigacity-visual-browser-audit.cjs` (Chromium/SwiftShader 모바일 모사 테스트, 실제 전체 라운드 진행)

실제 iPhone Safari에서 10~15분 장시간 발열·FPS와 터치 조작은 별도 기기 검증이 필요합니다.

# 기가시티 — 미래형 비행차 v3

## v3 — 건물 충돌과 비행 교통

- 건물 옆면과 옥상에 대한 충돌 판정을 추가했습니다. 고속 비행에서도 이동을 여러 번 나누어 검사하므로 건물을 그대로 통과하지 않습니다.
- 건물 모서리에 비스듬히 접근하면 이동 가능한 축을 따라 미끄러집니다. 뒤따라가는 카메라 역시 건물 안으로 들어가지 않도록 앞당겨집니다.
- 자동 비행은 도로 중심을 따라 이동하므로 도심 빌딩 구획을 가로지르지 않습니다.
- 근처 비행차와 너무 가까워지면 속도가 줄거나 정지하며 한국어 경고가 나타납니다. 다른 차량은 고정된 항로와 서로 다른 차선으로 이동하고, 차체 아래쪽에 발광등을 배치했습니다.
- 충돌 판단은 기존 도시 시드와 완전히 동일한 건물 데이터를 사용하고, 계산량을 줄이기 위해 최대 48개 구역을 캐시합니다.
- 2분 자동비행 3종, 서로 다른 시간·위치에서 차량 4,104건, 고속 충돌 테스트 등의 회귀 검사를 추가했습니다.



키즈케이드 게임 목록 또는 /games/gigacity_lite/index.html 에서 실행합니다.

## 이번 업데이트

- **기존 외관 활용:** Kenney CC0 race-future.glb 한 대만 플레이어 전용으로 불러옵니다.
- **방향 일치:** 모델의 앞바퀴가 로컬 +Z에 있는 것을 실제 GLB 데이터로 확인했습니다. 게임의 진행 방향 -Z에 맞춰 모델을 180° 돌리고 크기와 중심을 맞춥니다.
- **운전석:** 원래 차량에는 좌석이나 계기판이 없습니다. 운전석에서는 닫힌 차량 외관을 숨기고, 새로 제작한 3D 실내(2개 좌석, 핸들, 대시보드, 넓은 앞유리 테두리, 측면 창틀, 입체 속도/고도 화면)를 보여줍니다.
- **시점:** 자유 비행, 자동차 뒤, 운전석 3가지.
- **조작:** 모바일 조이스틱·고도 조절·빠른 이동. 자동차 모드에서는 좌우 조이스틱이 차의 방향을 돌립니다. 운전석에서 손가락 드래그로 좌우 창밖을 둘러볼 수 있습니다.
- **성능:** 차량 모델 한 대만 추가하고 주변 자동차와 도시 배경은 기존의 가벼운 구조를 유지합니다.
- **안전장치:** 외관 모델 불러오기가 실패하면 간소화한 차체로 대체하며, 운전석 시점은 계속 사용할 수 있습니다.

## 확인할 사항

Node 테스트: node --test tests/gigacity-lite.test.mjs

실제 iPhone/iPad에서 10~15분간 프레임, 발열, 화면 방향 전환, 운전석에서 차체가 시야를 막는지, 주변 건물과 충돌하는지 반드시 확인해야 합니다. 실기기 테스트 전에는 성능이나 시각적 완성도를 확정하지 않습니다.

현재 버전에는 임무, 충돌 물리, 실내 문 개폐, 승객과 거울 반사 효과는 포함되어 있지 않습니다.
