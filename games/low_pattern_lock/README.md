# 패턴 락 — v6

친구가 걸어 둔 비밀 패턴을 찾아 잠금을 푸는 관찰·추리 게임입니다.

## 플레이

1. 단서 아래에 표시된 **모양 카드**를 눌러 미리 봅니다. 옆으로 스크롤하면 남은 후보를 모두 확인할 수 있습니다.
2. 점 수·비스듬한 선·시작점 등 눈으로 확인할 수 있는 단서를 비교합니다.
3. 알맞아 보이는 모양을 고르고 **잠금 풀기!**를 누릅니다. 직접 점을 이어 패턴을 만드는 조작도 유지했습니다.
4. 틀리면 단서와 오답 비교를 기준으로 맞지 않는 카드가 사라집니다. 막히면 **힌트 보기**로 후보를 줄입니다.

처음 두 단계는 4개 이내의 후보로 시작하고, 뒤로 갈수록 최대 6~10개의 후보를 보여 줍니다. 각 문제의 카드에는 정답이 항상 포함되며 위치는 섞습니다. 한 번에 정답을 찾으면 별 3개, 힌트나 재도전을 이용해도 별을 받을 수 있습니다.

## 변경 이유

기존의 '순차·선택·반복 횟수'는 화면의 선을 보고 직접 검증하기 어렵고, 후보 수만 표시되는 구조에서는 실제로 비교·추리할 대상이 없었습니다. v6에서는 게임 규칙을 **모양 고르기 → 단서 비교 → 잠금 해제**로 단순화하고, 눈에 보이는 특징 중심으로 안내합니다. 이전 별·진행 기록 `pattern_lock_v5`는 유지합니다.

친구 문제 모드에서는 4×4 패턴을 만들고 기기를 넘긴 뒤 친구가 후보 카드와 단서로 맞힙니다.
