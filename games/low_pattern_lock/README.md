# 패턴 락

휴대폰 패턴 잠금 화면을 모티프로 만든 SW·알고리즘 기억/재현 게임입니다.

핵심 목표는 **모든 점을 지나가는 길 찾기**가 아니라, 다른 사람이 실제로 그린 **시작점·점의 순서·방향·끝점까지 동일한 패턴을 맞히는 것**입니다.

- 18명의 가상 사용자가 서로 다른 잠금 패턴을 보여 줍니다.
- 패턴은 잠깐 애니메이션으로 나타난 뒤 사라지며, 플레이어는 같은 순서로 다시 그립니다.
- 오답은 손을 뗀 뒤 전체 패턴을 한 번에 비교하고, 어느 단계가 틀렸는지는 알려주지 않습니다.
- 3×3 → 4×4 → 5×5로 확장되며 대각선, 잦은 방향 전환, 복잡한 지그재그를 적극 사용합니다.
- 각 문제에 순차·선택·반복이 몇 번 사용되는지 구조 카드를 표시합니다.
- 선택 문제는 ★/●/◆/▲ 등의 조건 점과 선택 규칙을 사용합니다.
- 반복 문제는 `(↘ ← ↘) ×2`처럼 반복 묶음과 횟수를 단서로 제공합니다.
- 마지막 문제는 순차·선택·반복을 한 패턴에 섞은 종합 문제입니다.
- '친구에게 내 패턴 내기'에서는 한 사람이 4×4 패턴을 만든 뒤 화면을 숨기고 기기를 넘겨 다른 사람이 맞힐 수 있습니다.
- 다시 보기와 오답 횟수에 따라 별 1~3개를 기록합니다.
