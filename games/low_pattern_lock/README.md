# 패턴 락

휴대폰 패턴 잠금을 소재로 한 **숨은 패턴 추리 게임**입니다.

핵심은 정답을 보고 외우는 것이 아닙니다. 정답 패턴은 성공하기 전까지 한 번도 보여주지 않고, 플레이어는 주어진 단서와 자신의 오답 비교 결과만으로 숨은 패턴을 예상합니다.

## 핵심 플레이

- “찍는 점은 7개”, “대각선 이동 3번”, “시작점은 모서리” 같은 특징 단서를 읽습니다.
- 순차·선택·반복 구조가 각각 몇 번 사용되는지도 알고리즘 단서로 제시됩니다.
- 플레이어가 예상 패턴을 그리면 정답 전체와 비교합니다.
- 오답 시 정답 자체나 틀린 위치를 공개하지 않고 다음 정보만 제공합니다.
  - 점 개수의 많고 적음
  - 대각선 이동 수의 많고 적음
  - 같은 순서에 놓인 점의 수
  - 같은 선분의 수
  - 시작점/끝점 일치 여부
- 막히면 ‘단서 하나 더’를 열 수 있습니다. 추가 단서를 적게 쓰고 적은 횟수로 맞힐수록 별을 더 받습니다.
- 후반에는 5×5, 대각선, 잦은 방향 전환, 선택 구조, 반복 구조가 섞인 복잡한 패턴이 등장합니다.

## 친구 문제

한 사람이 4×4에서 비밀 패턴을 만든 뒤 기기를 넘기면 정답은 숨겨집니다.
게임이 해당 패턴을 분석해 점 개수·대각선·방향 전환·시작 위치 등의 단서를 자동 생성하고, 다른 사람이 단서만으로 패턴을 추리합니다.
