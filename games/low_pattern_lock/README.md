# 패턴 락

휴대폰 패턴 잠금 화면을 모티프로 만든 SW·알고리즘 퍼즐입니다.

- 순차: 시작점에서 출발해 모든 점을 한 번씩 지나 끝점에 도착합니다.
- 선택: 조건을 확인하고 번호가 붙은 점을 정해진 순서대로 통과하며 다음 길을 고릅니다.
- 반복: 같은 방향 이동을 ×2, ×3처럼 묶은 반복 카드를 보고 패턴을 실행합니다.
- 자유 모드: 직접 패턴을 만든 뒤 기억해서 다시 풀 수 있습니다.
- 3×3, 3×4, 4×4의 12개 캠페인 단계를 제공합니다.
- 터치/마우스 드래그와 키보드 조작을 지원합니다.
- 진행도와 단계별 별 기록은 KidscadeStorage에 저장합니다.
