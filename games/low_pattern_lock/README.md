# 패턴 락

휴대폰 패턴 잠금을 소재로 한 **숨은 패턴 알고리즘 추리 게임**입니다.

정답 패턴은 성공하기 전까지 한 번도 보여주지 않습니다. 플레이어는 단서와 자신의 오답 비교 결과를 이용해 가능한 후보를 줄이고, 숨겨진 패턴을 예상합니다.

## v5 핵심 구조

- 각 문제마다 정답 외에 같은 규칙으로 만든 가짜 후보 패턴을 최대 180개 생성합니다.
- 화면의 **후보 N개**는 현재 공개된 단서와 오답 비교 정보에 실제로 맞는 후보 수입니다.
- 기본 단서는 점 개수와 알고리즘 구조를 포함합니다.
  - 기초: 순차 명령 횟수
  - 선택: 선택 횟수 + 순차 횟수
  - 반복: 반복 횟수 + 반복 단위 길이
  - 종합: 순차·선택·반복이 함께 섞임
- 초기 단서는 후보가 대체로 7~18개 정도 남도록 구성합니다.
- ‘단서 하나 더’는 현재 후보를 대략 절반으로 줄이는 단서를 우선 골라 줍니다.
- 강한 단서까지 모두 열면 후보가 반드시 1개가 됩니다.
- 오답도 정보입니다. 다음 항목을 정답 후보 전체와 비교해 후보 집합을 다시 거릅니다.
  - 점 개수의 차이
  - 대각선 횟수의 차이
  - 같은 순서에 놓인 점 수
  - 같은 선분 수
  - 시작점/끝점 일치 여부

## 조작 개선

패턴을 그리고 손을 떼어도 자동 제출하지 않습니다. 되돌리기, 지우기로 수정한 뒤 **이 패턴으로 도전** 버튼을 눌러 제출합니다.

PC 키보드는 시작 전에 방향키/QEZC로 커서를 움직이고 Enter로 시작점을 선택할 수 있습니다. 패턴을 그리기 시작한 뒤에는 방향키/QEZC로 이어 그리고 Enter로 제출합니다.

## 친구 문제

한 사람이 4×4에서 비밀 패턴을 만든 뒤 기기를 넘기면 정답은 숨겨집니다. 게임이 비슷한 가짜 후보들을 자동 생성하고 점 개수·대각선·방향 변화·위치 같은 단서를 만들어 다른 사람이 추리하게 합니다.
