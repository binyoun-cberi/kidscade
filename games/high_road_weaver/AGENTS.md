# 로타리클럽 개발 가이드

이 폴더(`games/high_road_weaver/`)를 수정하기 **전에** 반드시 [GAME_DESIGN.md](./GAME_DESIGN.md)를 읽는다.
게임 이름은 **로타리클럽**, 게임 ID는 저장/진행 호환을 위해 `high_road_weaver`로 유지한다.

1. 매번 기획 문서의 요구와 실제 구현 상태를 대조하고 변경 목적/미구현 범위를 기록한다.
2. 교차로·회전교차로·고가도로·램프·교통섬은 장식이 아닌 실제 도로 그래프와 차량 행동으로 구현한다.
3. 사용자가 **교류 차량 수를 숫자로 보지 않고** 차량 움직임·시계·정체로 파악한다는 의도를 지킨다.
4. PC·모바일 터치 조작, 차량 대기·경로 탐색, 저장 호환 테스트를 최소 회귀 조건으로 한다.
5. 새 기능이 구현되면 `GAME_DESIGN.md`의 진행 상태와 `README.md`를 함께 갱신한다.
6. 상위 저장소 `AGENTS.md`의 보안, 비용, 브랜치, PR, 배포 금지 규칙이 우선이다.
