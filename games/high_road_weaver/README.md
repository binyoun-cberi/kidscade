## 현재 플레이할 수 있도록 구현한 것
- 첫 지도에는 햇살마을(베드타운)과 중앙업무지구(사무지구)가 등장한다. 정상적인 도로 연결과 누적 이동 성과에 따라 공업지구·상업지구·농업지구·관광지구·대형마트가 차례로 열린다. 새 지역이 길에 연결되지 않으면 다음 지역은 열리지 않는다.
- 클릭 두 번 또는 드래그로 폴리라인 형태의 도로를 건설한다. 2·4·6차로, 건설 자재, 확장, 되돌리기 제공.
- 시계는 아침 07:00–09:30, 퇴근 16:30–19:30을 강조한다. 교류하는 차량 수는 화면에 직접 노출하지 않는다.
- 차량마다 목적지와 차선 및 이동 속도가 있으며 신호와 앞차 간격에 따라 정체와 대기가 발생한다. 여러 차선에서 앞뒤 안전 간격을 확인하고, 앞차 때문에 막힐 때나 다음 도로 차선이 줄어들 때 차선을 바꾸도록 했다.
- 일반 평면 교차로: 같은 높이의 도로가 만날 때 연결되고 신호등을 설치할 수 있다.
- **회전교차로:** 교차로에 원형 일방통행 경로를 구성한다. 지상 도로는 원형 도로를 관통하지 않고 바깥쪽에 접속하며, 합류 차량은 회전 중인 차량에 양보한다.
- **교통섬:** 교차로의 모퉁이를 선택하면 우회전 전용 일방통행 연결도로가 생긴다. 차량은 교차로 중심을 건너뛰고 그 길을 직접 이용할 수 있다.
- **고가도로:** 지상과 높이가 다른 도로망이어서 단순히 서로 겹치는 것만으로 통행이 연결되지 않는다.
- **진출입로:** 지상에서 시작해 고가도로와 연결하는 실제 양방향 램프를 설치한다.
- 모바일 터치 두 점 조작 및 드래그, 지도 이동, 손가락 두 개 확대, PC 마우스 휠 확대를 지원한다.
- 기존 저장(v1·v2) 복원과 차량의 운행 상태까지 보존하는 신규 저장(v3)을 지원한다. 게임 ID와 기존 저장 키는 유지한다. 기존 신호등 저장 노드 ID도 새 고도별 노드로 변환한다.

## 개발 중인 부분 / 정확한 제한
- 회전교차로는 일방향 주행과 합류 우선권의 초기 모델이다. 정교한 충돌 예측·차로변경·보행자 우선은 후속으로 보강해야 한다.
- 교통섬은 **우회전 전용 한 방향**에 먼저 적용한다. 미리보기, 선택 방향 표시와 보행자 안전섬 등은 후속 작업.
- 고가도로는 높이별 그래프 구분이 구현되어 있지만 실제 높이차의 기하학적 경사와 유효 최소 반경 제약은 간략화되어 있다.
- 도로 수정 중인 차량은 이전 도로 조각을 따라 이동을 마치는 방식으로 처리한다.
- 공업지구·상업지구에 이어 농업지구·관광지구·대형마트 및 요일별 수요 차이를 초기 구현했다. 계절 변화, 지형 제약·신호 충돌·교차로 차량 차로변경은 후속 보강 사항이다.
- 도시 그래픽은 에셋팩 통합을 완료하지 않은 임시 장면. 실제 모바일 브라우저 시각 검수는 필요하다.

## 2026-10-25 품질 검수 루프 3회
**1차 — 도로 편집 안정성**: 차량이 운행 중인 상태에서 도로를 여러 차례 수정할 때 동일한 이전 도로망이 반복 보관되고 화면에 표시되는 문제를 재현하고 해결했다. 퇴역 도로를 실제 차량이 앞으로 통과할 구간만 보관하도록 수정했다. 또한 너무 복잡해 저장 파일 복원이 불가능한 자유곡선 도로는 건설 전에 이유를 안내하고 자재를 소비하지 않도록 고쳤다. 유효하지 않은 좌표를 안전하게 무시한다.

**2차 — 모바일 조작과 저장 안전**: 기존 도시가 저장된 상태에서 새 도시 시작 버튼을 한 번만 누르면 기록이 덮어써질 수 있었다. 기존 기록이 있으면 두 번의 명시적인 확인 단계를 거쳐 새로 시작하도록 고쳤다. 포인터 취소 뒤 이전 도로 시작점이 남아 의도치 않은 도로가 이어지는 문제를 해결했다.

**3차 — 실제 교통 상황의 신뢰성**: 연결되지 않은 새 지역의 출발 대기 차량까지 정체 숫자에 합산해, 도로에서 차들이 원활하게 움직여도 '심한 정체'가 표시되던 문제를 재현했다. 차량 자체의 주행 속도에서 정체 정도를 결정하고, 미연결 지역은 별도 안내로 표시한다. 차량 통행 숫자는 계속 화면에 보여주지 않는다.

`tests/rotary-club-qa-loops.test.mjs` 6개 신규 회귀 테스트 및 `tests/rotary-club-ui.test.cjs` 2개 신규 테스트를 포함하여 총 **41개(엔진 35개 + 모의 UI 6개)** 를 격리 환경에서 실행하고 통과했다. **정식 Node 전체 CI 검증 결과는 별도로 확인하고, 브라우저 실기기·실제 렌더링 검사와 구분한다.**

## 2026-10-25 — 플레이 시뮬레이션 기반 교통 리워크 (새 PR)

이전 46개 플레이 전략·추가 비교에서 밝혀진 결함을 해결하기 위한 개선이며, 별도 PR로 검토 후 병합한다.

- **불필요한 교차로 정체 해소**: 도로가 실제로 교차해도 상대 방향에서 차가 없다면 기존 직선도로처럼 통과한다. 같은 방향·맞은편 직진 등 일부 비충돌 통행을 허용하면서, 실제 충돌 가능 경로에는 양보 예약을 남긴다. 신호등도 경쟁 방향에 자동차가 없으면 불필요한 정지를 피한다. 복잡한 회전 충돌 예측은 후속 과제.
- **차량 저장 v3**: 주행 중인 차량 각각의 위치·속도·차선·경로를 간선 풀로 압축 저장한다. 도로 편집 중에 사용하던 옛 경로와 새로운 도로망을 구별해 저장 후 재개해도 차량이 사라지지 않는다. 기존 v1/v2 저장은 계속 불러온다. 저장 키 및 게임 ID 그대로 유지.
- **도로 배치 미리보기**: 건설 중인 도로가 지상의 기존 도로와 만나는 위치를 주황색 원과 '교차로 n곳 예상' 문구로 보여준다. 위험도를 단정하는 가짜 확률은 표시하지 않는다. 고가도로는 지상 도로와 단순 교차한다고 연결점이 생기지 않으므로 표시 제외.
- **차량 개성**: 농기계 속도를 일반 승용차의 약 절반 수준으로, 버스와 화물차도 개별 속도로 설정한다. 실제 차간 거리 규칙과 함께 적용.
- **시간대와 보상**: 토·일 관광/쇼핑 수요의 급격한 폭증을 낮췄다. 초기 자재를 445로 조정하여 첫 6차로 건설이 가능하다. 무조건 매일 70 자재를 주는 대신 실제 도착 실적에 따라 보상하는 방식으로 변경했다. 미연결로 완전히 막힌 상황에 대비한 낮은 자재의 구제 보상은 유지한다.
- **검증**: 기존 41개 + 신규 엔진 검증 10개 = 총 51개 테스트를 순수 JavaScript V8 격리 환경에서 실행했다. 신규 검증은 `tests/rotary-club-traffic-rework.test.mjs`. 실제 Node CI 및 브라우저/모바일 화면 검증은 별도 상태로 확인한다.

**남은 중요한 제한**: 교차로 이동 경로와 차량 스프라이트의 물리 충돌 판정이 정밀한 실도로 수준은 아니다. 도시 중심부는 동시 틱 충돌을 막고 나머지 구간을 다음 도로 진입 간격으로 처리한다. 저장된 미래 이동 경로의 잠재적 개편, 교차로 진입 예고 표시, 지역별 도전과제 및 플레이어 재미에 대한 현장 평가는 후속 과제다.

## 2026-10-25 추가 플레이 시뮬레이션 — 회전교차로
- 주말 7개 지역을 4차로 중앙 교차로 하나에 집중하면 게임 속 5시간 동안 목적지에 도착한 차가 302대. 동일 배치에 기존 2차로 회전교차로를 놓으면 170대로 감소하는 결함 확인.
- 5갈래 이상 고밀도 회전교차로에 4차로와 맞는 차로 표현·진입 간격·더 높은 공사비(95)를 적용했다. 일반 4방향 이하 회전교차로는 2차로, 자재 75로 유지.
- 같은 조건에서 회전교차로의 수송량이 249대로 개선, 출발 대기는 567에서 488대로 감소. **하지만 일반 중앙 교차로 302대보다 느릴 수 있다.** 학생에게 회전교차로는 만능 해결책이 아니며 우회도로가 필요할 수 있음을 안내한다.
- 3개 신규 회귀 테스트를 정규 CI에 편입: 혼잡한 회전교차로 4차로·저장 복원, 일반 회전교차로와 구형 저장 호환, 주말 통행량 하한. **총 54개 엔진/모의 UI 격리 테스트 통과**. 실제 브라우저 플레이, 실제 아이폰 터치, 교통공학 수준의 물리 충돌 검수는 수행하지 않았다.

## 2026-10-25 — 짧은 회전교차로 구간·화면 개선
- **환상 도로 충돌 완화**: 회전교차로가 아주 짧은 여러 그래프 간선으로 나뉘어 있어도 같은 차선의 앞차까지 전체 원호상 거리를 사용해 속도를 조절한다. 새로운 차량은 입구에서 앞·뒤로 도는 차량 간격을 검사한다. 4차로 환상로에서 2차로 출구로 갈 때 안전한 진입 간격을 검사하여 끝없이 차선 변경을 못 하는 문제를 방지한다.
- **둥글게 회전**: 매 간선 경계를 지날 때 캐릭터가 방향을 갑자기 바꾸는 일을 줄이기 위해 원형 차로의 접선으로 자동차 방향을 그린다. 큰 회전교차로는 더 넓은 반지름으로 건설한다.
- **화면 검수와 수정**: 저장소 HTML·CSS를 재현한 로컬 Chromium UI 배치 검사에서 휴대전화의 2·4·6차로·되돌리기 도구가 오른쪽으로 밀려 보이지 않는 문제 확인. 모바일 툴바를 2행으로, 도구만 가로로 넘기는 구조로 재배치하고 스크롤바 표시. 모바일 시간·자재·교통 상태를 좁은 화면에 맞춰 정리. 지도 전체 보기에서 자동차 및 지역 이름을 조금 크게 표현. 느린 차량 근처에만 붉거나 노란 약한 강조를 표시해 실제 병목 위치를 보여준다.
- **성능 근거**: 게임 속 주말 120초 동안 환상 도로 차량의 같은 차선 근접 표본 388→44회, 도착 차량 183→204대(기준 버전 대비, 위치 간격 13px 미만/매 4틱 검사). 표본은 충돌 대리 지표로 **실제 자동차 차체 충돌 판정이 아님**.
- **검증**: 교통 엔진 51개와 가짜 Canvas·DOM 화면 및 CSS 구조 8개로 **59개 JS 검사 격리 실행 통과**. 실제 Cloudflare 게임 페이지/아이폰 Safari의 화면을 열어 확인한 것은 아니며, 로컬 재현 화면과 실제 게임 Canvas를 구분한다.
