# 로타리클럽 (Rotary Club) — 2D 첫 번째 플레이 버전

키즈케이드의 2D 교통 설계 게임. 변경 전 명칭은 '도시를 잇다'이며 게임 ID 및 저장 키는 기존 사용자 기록 호환을 위해 변경하지 않는다.

> **개발 시 필독**: 기능 추가·튜닝·UI 변경 전에는 이 폴더의 `GAME_DESIGN.md`와 `AGENTS.md`를 반드시 확인하고 변경 내용의 수용 조건을 점검한다.
 플레이어는 도시 자체를 직접 건설하는 대신 도로와 신호등을 설계하고, 개별 차량이 그 위를 이동하면서 만들어 내는 교통체증을 관찰한다.

## 플레이 흐름

- 햇살마을(베드타운)과 중앙업무지구(사무지구) 두 곳에서 시작한다.
- 마우스/손가락으로 드래그해 도로를 그리거나 두 지점을 차례로 눌러 직선을 건설한다.
- 2·4·6차로를 선택하며 자재를 소비한다. 기존 도로를 눌러 차선을 확장하거나 교차로에 신호등을 설치한다.
- 출근 시간(07:00–09:30)과 퇴근 시간(16:30–19:30)에 차량 수요와 방향이 바뀐다.
- 1일은 실제 시간 약 2분이며 새로운 하루마다 건설 자재가 추가된다.
- 일정한 운송 실적을 달성하면 공업지구와 상업지구가 순서대로 등장한다.
- 자동차 수와 교통 수요의 내부 수치는 학생에게 보여 주지 않는다. 차들이 실제로 움직이고 늘어서는 모습을 통해 판단한다.
- 지도는 드래그 이동·두 손가락 확대, 페이지는 로컬 저장/이어서 하기 지원.

## 기술 구성

- \`sim-core.mjs\`: 별도의 DOM이 필요 없는 2D 도로 그래프·차량 시뮬레이션.
- \`game.js\`: Canvas 2D 렌더링, 사용자 입력, UI 및 로컬 저장.
- \`style.css\`: PC/모바일 반응형 HUD.
- \`index.html\`: 앱 진입점.
- \`tests/road-weaver-core.test.mjs\`: 경로 연결, 교차, 차선 비용, 수요 시간대, 저장 검증.

도로는 사용자가 그린 폴리라인을 그대로 저장한다. 도로끼리 교차하면 교점에서 도로 그래프를 분할한다. 차량은 경로를 탐색하여 개별 차선을 따라 이동하고, 앞차와의 간격 및 신호등에 따라 속도가 달라진다.

## 기존 에셋

\`assets/game/2d/vehicles/pixel/cars/\`의 Kenney 2D 자동차 이미지(승용차·버스·화물차)를 불러온다. 이미지는 원본을 복사하지 않고 기존 경로를 참조한다. 로딩에 실패하면 Canvas에서 단순한 차량 도형으로 대체한다. 도시 배경은 기존 Kenney 타일과 스타일을 맞춘 Canvas 지형/주택 실루엣이며, 차후 개별 타일의 모양 검수 후 도시 그래픽을 교체할 수 있다.

원본 Kenney Racing Pack 및 Pixel Vehicle 계열 사용 조건은 저장소의 \`CREDITS.md\`와 에셋 라이선스 기록을 따른다. 외부 코드를 복사하지 않고 직접 구현했다.

## 첫 버전 제한과 향후 작업

- 자유로운 곡선과 연결/교차는 지원하지만 지금은 도로의 고도 개념이 없어 도로가 교차하면 같은 높이에서 연결된다.
- 로터리, 교통섬, 고가도로, 다리, 방향별 가변차로는 후속 단계이다.
- 고급 차선 변경·진로별 회전 차선·정교한 신호현시는 아직 단순화했다. 신호등은 수평/수직 접근을 번갈아 제어한다.
- 교통흐름은 교육용 근사 모델이며 실제 도로 설계의 정답을 예측하는 시스템이 아니다.
- 도로망을 수정할 때 기존 차량은 이전 도로망을 따라 계속 주행하고 그 도로 일부는 임시로 흐리게 표시한다.
- 엔진 단위 테스트 외에 실기기·실브라우저 플레이 점검과 장시간 성능 검증이 필요하다.
