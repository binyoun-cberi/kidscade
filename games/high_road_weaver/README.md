## 현재 플레이할 수 있도록 구현한 것
- 첫 지도에는 햇살마을(베드타운)과 중앙업무지구(사무지구)가 등장하고, 이동이 안정되면 공업지구 및 상업지구가 열린다.
- 클릭 두 번 또는 드래그로 폴리라인 형태의 도로를 건설한다. 2·4·6차로, 건설 자재, 확장, 되돌리기 제공.
- 시계는 아침 07:00–09:30, 퇴근 16:30–19:30을 강조한다. 교류하는 차량 수는 화면에 직접 노출하지 않는다.
- 차량마다 목적지와 차선 및 이동 속도가 있으며 신호와 앞차 간격에 따라 정체와 대기가 발생한다.
- 일반 평면 교차로: 같은 높이의 도로가 만날 때 연결되고 신호등을 설치할 수 있다.
- **회전교차로:** 교차로에 원형 일방통행 경로를 구성한다. 지상 도로는 원형 도로를 관통하지 않고 바깥쪽에 접속하며, 합류 차량은 회전 중인 차량에 양보한다.
- **교통섬:** 교차로의 모퉁이를 선택하면 우회전 전용 일방통행 연결도로가 생긴다. 차량은 교차로 중심을 건너뛰고 그 길을 직접 이용할 수 있다.
- **고가도로:** 지상과 높이가 다른 도로망이어서 단순히 서로 겹치는 것만으로 통행이 연결되지 않는다.
- **진출입로:** 지상에서 시작해 고가도로와 연결하는 실제 양방향 램프를 설치한다.
- 모바일 터치 두 점 조작 및 드래그, 지도 이동, 손가락 두 개 확대, PC 마우스 휠 확대를 지원한다.
- 기존 저장(v1) 복원과 신규 저장(v2) 모두 지원한다. 게임 ID와 기존 저장 키는 유지한다. 기존 신호등 저장 노드 ID도 새 고도별 노드로 변환한다.

- 픽셀 승용차·버스·화물차: `assets/game/2d/vehicles/pixel/cars/` (Kenney 계열)

- 에셋 사용/표기 조건은 `CREDITS.md` 및 원본 라이선스 기록 우선. 외부 오픈소스 코드는 직접 복제하지 않음.

## 개발 중인 부분 / 정확한 제한
- 회전교차로는 일방향 주행과 합류 우선권의 초기 모델이다. 정교한 충돌 예측·차로변경·보행자 우선은 후속으로 보강해야 한다.
- 교통섬은 **우회전 전용 한 방향**에 먼저 적용한다. 미리보기, 선택 방향 표시와 보행자 안전섬 등은 후속 작업.
- 고가도로는 높이별 그래프 구분이 구현되어 있지만 실제 높이차의 기하학적 경사와 유효 최소 반경 제약은 간략화되어 있다.
- 도로 수정 중인 차량은 이전 도로 조각을 따라 이동을 마치는 방식으로 처리한다.
- 공업지구·상업지구까지만 현재 플레이 루프가 있고 농업지구·관광지구·대형마트·주말/계절 수요는 향후 단계.
- 도시 그래픽은 에셋팩 통합을 완료하지 않은 임시 장면. 실제 모바일 브라우저 시각 검수는 필요하다.

## 검증
```bash
node --test tests/road-weaver-core.test.mjs tests/rotary-club-interchanges.test.mjs
npm run health:strict
npm run test:ci
npm run build
```
엔진 코드를 격리 실행한 V8 기반 검증에서는 **기존 6개 + 신규 11개 총 17개가 통과**했다. 실제 Node CI와 게임 화면 브라우저/모바일 점검은 별도로 확인해야 하며, 실행하지 않은 검사를 통과했다고 주장하지 않는다.
