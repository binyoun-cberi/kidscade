## 현재 플레이할 수 있도록 구현한 것
- 첫 지도에는 햇살마을(베드타운)과 중앙업무지구(사무지구)가 등장한다. 정상적인 도로 연결과 누적 이동 성과에 따라 공업지구·상업지구·농업지구·관광지구·대형마트가 차례로 열린다. 새 지역이 길에 연결되지 않으면 다음 지역은 열리지 않는다.
- 클릭 두 번 또는 드래그로 폴리라인 형태의 도로를 건설한다. 2·4·6차로, 건설 자재, 확장, 되돌리기 제공.
- 시계는 아침 07:00–09:30, 퇴근 16:30–19:30을 강조한다. 교류하는 차량 수는 화면에 직접 노출하지 않는다.
- 차량마다 목적지와 차선 및 이동 속도가 있으며 신호와 앞차 간격에 따라 정체와 대기가 발생한다. 여러 차선에서 앞뒤 안전 간격을 확인하고, 앞차 때문에 막힐 때나 다음 도로 차선이 줄어들 때 차선을 바꾸도록 했다.
- 일반 평면 교차로: 같은 높이의 도로가 만날 때 연결되고 신호등을 설치할 수 있다.
- **회전교차로:** 교차로에 원형 일방통행 경로를 구성한다. 지상 도로는 원형 도로를 관통하지 않고 바깥쪽에 접속하며, 합류 차량은 회전 중인 차량에 양보한다.
- **교통섬:** 교차로의 모퉁이를 선택하면 우회전 전용 일방통행 연결도로가 생긴다. 차량은 교차로 중심을 건너뛰고 그 길을 직접 이용할 수 있다.
- **고가도로:** 지상과 높이가 다른 도로망이어서 단순히 서로 겹치는 것만으로 통행이 연결되지 않는다.
- **진출입로:** 지상에서 시작해 고가도로와 연결하는 실제 양방향 램프를 설치한다.
- 모바일 터치 두 점 조작 및 드래그, 지도 이동, 손가락 두 개 확대, PC 마우스 휠 확대를 지원한다.
- 기존 저장(v1) 복원과 신규 저장(v2) 모두 지원한다. 게임 ID와 기존 저장 키는 유지한다. 기존 신호등 저장 노드 ID도 새 고도별 노드로 변환한다.

## 개발 중인 부분 / 정확한 제한
- 회전교차로는 일방향 주행과 합류 우선권의 초기 모델이다. 정교한 충돌 예측·차로변경·보행자 우선은 후속으로 보강해야 한다.
- 교통섬은 **우회전 전용 한 방향**에 먼저 적용한다. 미리보기, 선택 방향 표시와 보행자 안전섬 등은 후속 작업.
- 고가도로는 높이별 그래프 구분이 구현되어 있지만 실제 높이차의 기하학적 경사와 유효 최소 반경 제약은 간략화되어 있다.
- 도로 수정 중인 차량은 이전 도로 조각을 따라 이동을 마치는 방식으로 처리한다.
- 공업지구·상업지구에 이어 농업지구·관광지구·대형마트 및 요일별 수요 차이를 초기 구현했다. 계절 변화, 지형 제약·신호 충돌·교차로 차량 차로변경은 후속 보강 사항이다.
- 도시 그래픽은 에셋팩 통합을 완료하지 않은 임시 장면. 실제 모바일 브라우저 시각 검수는 필요하다.

## 2026-10-25 추가 — 지역별 교통의 차이
- **농업지구:** 새벽 04:30~08:30 납품 집중. 기존 픽셀 트랙터·화물차 이미지를 활용한다.
- **관광지구:** 토·일요일 오전 관광지 도착 차량이 증가하고, 오후~저녁에는 귀가 차량이 증가한다.
- **대형마트:** 평일 퇴근 이후, 주말 낮과 저녁에 쇼핑 차량이 늘어난다.
- **도시 해금:** 지상 또는 고가·램프 도로망으로 현재 도시를 연결하고 누적 통행 성과를 달성해야 다음 도시가 열린다.
- **차선 변경:** 현재 차로의 앞차가 느리거나 다음 도로가 좁아질 때 이웃 차선의 앞·뒤 간격을 검사한다. 교차로에서 다른 차량이 동시에 충돌 구역으로 진입하지 않도록 단기 예약을 도입했고, 회전 방향에 따라 접근 차선을 선택한다. 완전한 충돌 예측과 우선순위 세분화는 추가 보강 사항이다.
- **성능:** 일곱 도시 간 출발 시도를 묶어 수행하고 경로 탐색 전에 현재 차선 점유를 한 번 집계한다.

## 2026-10-25 추가 — 교차로 우선권과 시각 개선
- 교차로에서 상충하는 접근 차량이 같은 순간에 들어오지 않도록 **약 0.75초 통과 예약**을 도입. 시간 경과 후 자동 해제되며 일반 출퇴근 도로망의 처리량을 유지한다.
- 좌회전 차량은 교차로 가까이에서 안쪽 차선, 우회전 차량은 바깥쪽 차선을 선호해 안전한 간격에서만 이동한다. 이는 강제적인 회전금지 차로 규칙은 아니라 초등학생이 막히지 않게 플레이할 수 있다.
- 실제 운행 차량의 전·후 도로 경로를 기준으로 곡선 보간하여 좌·우회전 시 차량 이미지 방향이 순간적으로 바뀌지 않게 했다.
- 잔디·차량 에셋은 이미 저장소에 있는 작은 PNG를 **추가 파일 복사 없이** 참조한다. 원본 2D 건물 이미지의 관측/스프라이트 배치 검수가 완결되지 않아 건물은 임시 도형을 유지한다.
- `tests/rotary-club-junction-safety.test.mjs`에 교차로 동시 진입·예약 만료·좌우회전 차로·이미지 위치 연속성 테스트 5개를 추가했다.
- 엔진 29개와 모의 UI 4개, 총 33개 격리 실행 검사 통과. **실제 브라우저 화면을 본 테스트는 아님**.

## 2026-10-25 품질 검수 루프 3회
**1차 — 도로 편집 안정성**: 차량이 운행 중인 상태에서 도로를 여러 차례 수정할 때 동일한 이전 도로망이 반복 보관되고 화면에 표시되는 문제를 재현하고 해결했다. 퇴역 도로를 실제 차량이 앞으로 통과할 구간만 보관하도록 수정했다. 또한 너무 복잡해 저장 파일 복원이 불가능한 자유곡선 도로는 건설 전에 이유를 안내하고 자재를 소비하지 않도록 고쳤다. 유효하지 않은 좌표를 안전하게 무시한다.

**2차 — 모바일 조작과 저장 안전**: 기존 도시가 저장된 상태에서 새 도시 시작 버튼을 한 번만 누르면 기록이 덮어써질 수 있었다. 기존 기록이 있으면 두 번의 명시적인 확인 단계를 거쳐 새로 시작하도록 고쳤다. 포인터 취소 뒤 이전 도로 시작점이 남아 의도치 않은 도로가 이어지는 문제를 해결했다.

**3차 — 실제 교통 상황의 신뢰성**: 연결되지 않은 새 지역의 출발 대기 차량까지 정체 숫자에 합산해, 도로에서 차들이 원활하게 움직여도 '심한 정체'가 표시되던 문제를 재현했다. 차량 자체의 주행 속도에서 정체 정도를 결정하고, 미연결 지역은 별도 안내로 표시한다. 차량 통행 숫자는 계속 화면에 보여주지 않는다.

`tests/rotary-club-qa-loops.test.mjs` 6개 신규 회귀 테스트 및 `tests/rotary-club-ui.test.cjs` 2개 신규 테스트를 포함하여 총 **41개(엔진 35개 + 모의 UI 6개)** 를 격리 환경에서 실행하고 통과했다. **정식 Node 전체 CI 검증 결과는 별도로 확인하고, 브라우저 실기기·실제 렌더링 검사와 구분한다.**
