# 싹싹! 정리왕 (3D 정리·청소 시뮬레이터)

기존 '청소 특공대' 액션 게임과 별도의 생활형 정리 게임입니다.

## 플레이
- 원룸의 약 50개 물건과 얼룩을 정리하면 주방 의뢰가 열립니다. 주방은 약 60개의 정리 대상이 있습니다.
- 마우스 또는 터치로 물건을 선택하고, 강조 표시되는 알맞은 정리 장소를 선택합니다.
- 책과 연필 → 책장 / 쿠션 → 빨래통 / 캔·병·종이팩 → 분리수거 / 오염된 봉투 → 일반쓰레기 / 그릇 → 싱크대 / 인형 → 장난감 상자.
- 바닥 얼룩은 여러 번 터치하거나 마우스·손가락으로 문질러 청소합니다.
- 화면 오른쪽 버튼으로 시점을 회전 및 확대·축소할 수 있습니다.
- 청소 완료율 100%가 승리 조건이며 제한시간이나 패배 조건은 없습니다.
- 실수로 잘못된 장소를 선택해도 감점하지 않습니다.
- 정리 한 건당 5코인을 얻고, 완료 기록과 코인은 기기의 localStorage에 저장합니다. **키즈케이드 서버 경제 코인과는 별개의 게임 내부 기록**입니다.

## 기술
- Three.js (사이트에 포함된 r160) / GLTFLoader로 동작합니다.
- 모델: Kenney Furniture Kit, Kenney food, Charming Kitchen, Styloo Classroom(GLB)
- GLB 로딩에 실패하면 물체를 기본 입체 도형으로 대체하여 진행 불능을 방지합니다.
- 같은 원본 GLB는 한 번만 로드한 뒤 복제합니다.
- 선택된 물건은 정리 장소로 날아가며 축소되고, 마지막에 반짝이 입자가 나타납니다.
- 인스턴스가 많은 스테이지의 추가 최적화, 현장 실기기 프레임 분석 및 모든 GLB 재질 육안 검수는 차후 과제입니다.

진입점: `games/sim_tidy_king/index.html`  
실행 스크립트: `games/sim_tidy_king/game.js`  
로컬 키: `kidscade-tidy-king-v1`
