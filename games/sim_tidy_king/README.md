# 싹싹! 정리왕 — 유아용 3D 정리 놀이

키즈케이드 **유아(toddler)** 분류에 등록된 생활습관·정리 놀이. 기존 '청소 특공대'와 별개 게임입니다.

## 유아용 기본 놀이 (기본 선택)
- 원룸: **18개 물건 + 얼룩 2개 = 총 20개**, 주방: **20개 물건 + 얼룩 2개 = 총 22개**
- 제한시간·실패·감점 없음. 잘못 놓으면 원래 자리로 돌아오며 그림과 색으로 다시 안내합니다.
- 물건을 누른 채 **실제 가구로 끌어다 놓고**, 얼룩은 손가락으로 문질러 닦습니다.
- 작은 물건의 집기 영역과 수납 장소의 자동 스냅 범위를 늘려 유아의 손 움직임을 고려했습니다.
- 시작 화면의 짧은 그림 안내, 큰 버튼, 간단한 칭찬, 반짝임 연출, 진행 막대.
- 240개 장식으로 된 네 개의 쓰레기 산은 그대로 보이되 실제 물건을 정리할수록 사라집니다. 장식만 별도로 정리할 필요가 없습니다.
- 원룸을 한 번 완수하면 주방이 해금되고, 이후 재접속해도 바로 주방으로 이동할 수 있습니다.

## 대청소 도전 (선택)
- 시작 화면에서 **🏔️ 대청소 도전**을 직접 선택할 때만 긴 의뢰를 플레이합니다.
- 원룸 **96개 물건 + 얼룩 7개 (103)**, 주방 **98개 물건 + 얼룩 9개 (107)**.
- 기존 드래그 판정, 코인, 업적·기록, 청소 전후 스크린샷 유지.
- 놀이 길이 선택은 게임 실행 전만 가능하므로 진행 중 다른 설정이 섞이지 않습니다.

## 모델과 저장
- Three.js r160 / GLTFLoader. 모델: Kenney Furniture, Kenney Food, Charming Kitchen, Styloo Classroom.
- 누락된 GLB는 단순 입체 도형으로 대체됩니다.
- 기기 저장: `kidscade-tidy-king-v1`; 서버의 공용 씨앗 경제와는 별개입니다.
- 기존 사용자의 누적 코인과 주방 해금 기록을 그대로 사용합니다.
