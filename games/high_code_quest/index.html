코드가 전투 규칙이 됩니다

1. 사방 이동

↑ → ↓ ← 명령으로 탑뷰 전장을 움직입니다. 벽과 적이 있는 칸은 지나갈 수 없습니다.

2. 적 AI 읽기

전장의 몬스터를 누르면 현재 조건과 행동 규칙이 표시됩니다. 어떤 조건이 실행 중인지 강조됩니다.

3. 전투 기술

검격은 근접 공격, 회전 베기는 주변 공격, 코드 볼트는 직선 원거리 공격입니다.

4. 방어와 타이밍

투사체나 공격 준비 상태를 센서로 읽고 가드·회피·기다리기를 조합하세요.

5. 조건과 반복

적이 가까울 때, 직선에 있을 때, HP가 낮을 때처럼 상황에 따라 다른 행동을 실행할 수 있습니다.

6. 나의 기술

자주 쓰는 이동·전투 로직을 기술 A/B로 묶어 여러 미션에서 재사용합니다.

7. 자원 미션

후반에는 데이터, 단말기, 충전 패드, 스위치를 전투와 함께 관리합니다.

8. 변형 전장

후반 미션은 재도전할 때 장애물과 적 배치가 달라집니다. 위치 암기보다 일반화된 코드를 만드세요.
