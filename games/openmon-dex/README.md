# Openmon 과학·수학 개념도감 제작실 (v2 — 탐험/육성 데이터 설계)

**진입:** `games/openmon-dex/index.html`  
**원본:** `assets/more assets/` (이미지 중복 복사 없음)  
**상태:** 편집용 도감. 아직 몬스터 전투·탐험 게임을 완성하거나 홈 카탈로그에 공개한 것은 아님.

## 원본 그림 118칸을 종족 118개라고 부르지 않기

| 출처 | 픽셀 셀 | 현재 역할 | 분류 근거 |
|---|---:|---|---|
| Set 1 | 18 | 몬스터 17 + 탐사선 1 | 원제작자 설명에도 배 그림 포함 |
| Set 2 | 18 | 몬스터 후보 18 (9개 인접 관계 후보) | 원제작자 설명은 9개 스프라이트라 하나 실제 PNG는 18칸; **앞·뒷모습이라고 추측하지 않음** |
| Set 4 | 12 | 몬스터 후보 12 | 저장소의 실제 PNG 기준 |
| Set 5 | 36 | 몬스터 후보 36 | 실루엣을 보면서 재작명; 진화 관계는 검증되지 않은 것은 고정하지 않음 |
| Wolf Line | 15 | Shibu 재해석 시안 15 | 원제작자의 Shibu 늑대 리메이크 설명 근거. 1:1 대응은 검증 전 |
| Shibu | 19 | 기본형 1 + 분기 진화 18 | 원제작자가 Eevee 스타일 계열이라고 명시 |

현재 **원본 이미지 118칸 / 게임용 수집 형태 102개(도감 번호 001~102) / 재해석 시안 15개 / 오브젝트 1개**이다. 실제 게임 개발을 위한 **47개 계열 그룹**을 편성했지만 이는 Openmon 원저작자의 공식 종족 분류가 아니라 키즈케이드의 기획안이다. 102개는 **고유 수집 형태 수**이며 독립적인 진화 계열 102개를 뜻하지 않는다. 예를 들어 Set 2의 한 쌍이 동일 개체의 다른 방향인지, 진화 전후인지, 별개의 종인지는 최종 확정되지 않았다.

### 인접 후보와 확정 진화를 구별하기

- `sprites`: 원본 118개 이미지 슬롯, 출처 파일명·64×64 좌표와 안정적 ID를 보존.
- `species` 및 `dexEntries`: 게임용 고유 형태 102개. `dexNo`는 001~102의 고정 번호이며 `id`는 별도의 저장용 안정 ID.
- `concepts`: 늑대 리메이크 15개, Shibu의 대체 디자인용. 당장은 도감 번호나 야생 출현 목록에 자동 포함하지 않음.
- `objects`: 배 그림 1개. 몬스터 도감·전투에서 제외.
- `role`: `monster`, `alternate-concept`, `object`.
- `familyId`: 관계가 있어 보이는 이미지 그룹. **진화라고 단정하지 않음.**
- `pairCandidate`: Set 2에서 이웃한 그림 사이 검토용 참조 ID. **앞·뒷모습 확정 아님.**
- `evolutionFrom` + `verifiedEvolution`: 근거를 확인한 스타팅 3계열 및 Shibu 18개 분기형만 연결.

### 이름을 만드는 원칙

1. 원본을 보고 동물·식물·기계·날씨·무늬 등 외형을 먼저 기록한다.
2. 그 특징과 연결되는 과학자·수학자 또는 개념을 찾는다.
3. 2~5음절 내외의 몬스터스럽고 기억하기 쉬운 이름을 짓는다. **동물이 아닌 그림에 '새'나 '양'을 억지로 붙이지 않는다.**
4. 도감 개념 설명은 검증된 과학 사실로 작성하고, 몬스터의 속성·기술에 연결한다. 과학 개념이 희귀도/공격력의 크기를 자동 결정하지 않는다.
5. **멘델콩, 켈빈맘, 피보참새** 등은 게임 창작 이름이고 원저작자의 공식 이름이 아니다.

## 편집기

1. 카드에서 118칸의 이미지와 이름을 확인한다.
2. 검색, 속성, 원본 아틀라스, 이미지 역할(도감 후보/재해석/오브젝트) 필터로 탐색한다.
3. 이름·속성·학습 개념·서식지·희귀도·진화 단계·메모를 바꾼다.
4. 이 기기의 로컬 저장소에 변경 사항이 기록된다. 기존 `kidscade.openmon.science-dex.edits.v1` 편집 데이터는 보존된다.
5. **전체 JSON 내보내기**는 변형·오브젝트 구분까지 포함해 118개 슬롯을 저장하며, 다시 불러오기는 118개 ID를 검사한 후 수정 가능한 필드만 반영한다.
6. 게임 내에서 돌아가기 버튼은 `kidscade:close-game` 메시지를 이용해 키즈케이드 iframe을 올바르게 닫는다.


## 게임 전투 및 진화 데이터 (v2)

도감 제작실에 다음 파일을 추가했다.

- `monsters.js` — 원본 이미지 118칸과 수학·과학에서 지은 이름, 타입, 지식 설명
- `roster.js` — **102개 수집 형태, 47개 계열, 도감 번호, HP·공격·방어·속도와 레벨 성장량, 야생 지역별 만남 목록**
- `combat.js` — 순수 계산 함수: 속성 상성, 레벨별 능력치, 결정적인 피해량, 포획 확률, 경험치, 진화 가능 여부
- `index.html` — 도감 번호와 레벨 선택(3/5/10/14/20/26/40)에 따른 능력치 비교

### 진화 출처와 잠금 규칙

`evolutionFrom`과 `verifiedEvolution`은 기존과 같이 **원본 출처에서 확인된 관계**에만 쓰인다.
게임에서 새로 기획한 진화는 `evolvesFrom`과 `evolutionCondition`으로 별도로 저장한다.

- **원본 구성이 확인된**: 스타팅 3계열과 Shibu 1→18 갈래
- **게임 기획으로 만든**: 실루엣이 자연스러운 Set 1/4/5 몬스터 계열. 공식 설정이라고 주장하지 않음
- **관계가 미확정인**: Set 2의 인접 9쌍. 같은 그룹으로만 표시하고 레벨 진화 기능은 잠금
- **기본적으로 진화하지 않는**: 단일형 몬스터와 늑대 재해석 스킨

진화 레벨의 초안은 첫 진화 Lv.14, 최종 진화 Lv.26이다. Shibu는 Lv.14에 18가지 중 하나를 선택하며, 무조건 무작위 진화시키지 않는다.

### 밸런스 기초 수치

- **레벨** 1~60. 네 능력치는 종족 기본값과 성장량으로 고정 계산한다. 개인별 가챠 능력치나 유료 재화 보너스는 없음
- **피해량**: `max(1, 공격 + 기술 위력 - floor(방어 × 0.75))`, 같은 타입 ×1.1, 유리한 상성 ×2, 불리 ×0.5 (최종 내림)
- **경험치**: 다음 레벨에 필요한 경험치 `8 + 4×레벨 + floor(레벨²/3)`. 적의 레벨에 따라 보상이 증가
- **포획**: 남은 HP가 작을수록 상승, 상태이상 및 개선된 포획구 보정. 실패는 계산 오답이 아님
- **첫 지역**: 여울마을에서 이슬초원 Lv.2~4 → 가지숲 Lv.4~7 → 잔돌동굴 Lv.7~10 → 비밀숲에서 Shibu 확정 발견 이벤트(추후 제작)
- **초기 스타팅 삼각관계**: 풀 → 물 → 바람 → 풀

지역 만남 목록은 레벨업과 도감 확장의 출발점이다. 이 폴더만으로 실제 맵 탐험, 야생 전투 UI, 포획 애니메이션이 구현된 것은 아니며 실제 1시간 플레이의 난이도 검증도 별도 필요하다.
