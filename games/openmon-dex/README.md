# Openmon 개념도감 제작실 (v1)

**진입:** `games/openmon-dex/index.html`  
**원본 이미지:** `assets/more assets/` (중복 복사 없음)  
**상태:** 개발자 편집용 도감. 아직 학생용 포켓몬라이크 게임을 완성한 것은 아님.

## 사용 방법

1. 좌측 스프라이트 카드를 눌러 원본 그림을 확인한다.
2. 오른쪽에서 이름, 속성, 연결되는 과학·수학 개념, 서식지, 희귀도, 진화 단계, 메모를 고친다.
3. 변경 사항은 현재 브라우저의 `localStorage`에 자동 저장된다. **다른 기기에는 공유되지 않는다.**
4. 상단 **도감 JSON 내보내기**로 118개 전체 기록을 보관한다. **JSON 불러오기**는 동일 118개 ID를 검사한 뒤 편집 가능한 필드만 가져온다.
5. 편집용 이름·속성은 원제작자 공식 설정이 아닌 창작 초안이다.

## 이미지 집계

모든 몬스터 이미지는 원본 파일의 투명하지 않은 64×64 셀을 기준으로 등록했다.

| ID | 이미지 | 셀 | 특징 |
|---|---|---:|---|
| set1 | OpenmonSprites1.png | 18 | 스타팅으로 추정되는 3×3 진화계열 포함 |
| set2 | Openmon Set 2.png | 18 | 초원·해안 후보 |
| set4 | Openmon Set 4.png | 12 | 보스·고급 몬스터 후보 |
| set5 | Openmon-Set-5.png | 36 | 전 지역 후보 |
| wolf | Openmon-Wolf-Line.png | 15 | 늑대형 변종 이미지, 진화 관계 미확정 |
| shibu | ShibuLine.png | 19 | 기본형 1 + 분기형 18 |

**118개는 이미지 수이다.** 진화형·분기형을 포함하므로 실제 게임 종수와 일치하지 않는다. 수작업으로 일부 계열을 묶었다. 근거가 부족한 다른 계열은 `stage=0`과 `verifiedEvolution=false`로 둔다. 분기형을 무조건 높은 종족값으로 만들지 않는다.

**도감 임시 이름 원칙:** 외형 → 위인/수학/과학 단어 → 짧은 2~5음절 이름 → 과학 사실 → 게임 속 기술·특성 순으로 연결한다. 이름이 과학적으로 오해를 부르지 않도록 사실 설명은 실제 개념의 뜻을 말한다.

## 게임 밸런스와의 관계

본 제작실은 **전투 능력치와 포획 확률을 확정하지 않는다.** 적은 이름과 속성을 먼저 정하고, 이후 게임 쪽의 전투 데이터에 도감 JSON을 연동한다.

첫 번째 지역은 스타팅 3계열에서 각각 1형태를 고르게 하고, 12~15개 안팎의 야생 조우 풀을 제공하되 저레벨 기본종 위주로 편성한다. `set4`의 위력 높은 외형을 초원에 무작위로 뿌리지 않는다. 배울 수 있는 과학 개념이 희귀도나 기본 위력을 직접 결정하게 하지 않는다.

**학습 목표:** 멘델콩을 잡기 위해 계산 문제를 억지로 풀게 하는 것이 아니라, 전투에서 남은 체력 계산과 상성·확률 비교가 자연스럽게 발생하게 한다.

## 라이선스 주의

- Openmon 관련 에셋의 CC0 표기는 **개별 원배포 페이지**에서 확인하고 프로젝트의 귀속 문서에 기록해야 한다. 이름과 세계관은 키즈케이드 창작안이며 원제작자 설정을 대표하지 않는다.
- `BerryPlants.png`는 CC BY이며 **이 제작실에서는 사용하지 않는다.** 추후 사용할 경우 출처 표시를 별도로 기록한다.
- 이미 확보한 Kenney Tiny Town / Tiny Farm 16×16 타일맵은 CC0이며, 향후 **오버월드 탐험 전용**으로 활용한다. `Forest_Background` / `Cave_Back` / `Lab_Background`는 전투 배경 그림이므로 필드 타일셋과 혼동하지 않는다.

## 검증

```bash
node --test tests/openmon-dex.test.cjs
```

이 테스트는 프레임 수, 셀 절단 좌표, 중복 ID·이름, 과학 출처, 제한적인 진화 관계, UI 필수 컨트롤과 JavaScript 구문을 검사한다. 실제 브라우저 렌더링과 학생용 전투 루프의 동작까지 검증했다는 뜻은 아니다.
