# Openmon 과학·수학 개념도감 제작실 (v1.1)

**진입:** `games/openmon-dex/index.html`  
**원본:** `assets/more assets/` (이미지 중복 복사 없음)  
**상태:** 편집용 도감. 아직 몬스터 전투·탐험 게임을 완성하거나 홈 카탈로그에 공개한 것은 아님.

## 원본 그림 118칸을 종족 118개라고 부르지 않기

| 출처 | 픽셀 셀 | 현재 역할 | 분류 근거 |
|---|---:|---|---|
| Set 1 | 18 | 몬스터 17 + 탐사선 1 | 원제작자 설명에도 배 그림 포함 |
| Set 2 | 18 | 몬스터 후보 18 (9개 인접 관계 후보) | 원제작자 설명은 9개 스프라이트라 하나 실제 PNG는 18칸; **앞·뒷모습이라고 추측하지 않음** |
| Set 4 | 12 | 몬스터 후보 12 | 저장소의 실제 PNG 기준 |
| Set 5 | 36 | 몬스터 후보 36 | 실루엣을 보면서 재작명; 진화 관계는 검증되지 않은 것은 고정하지 않음 |
| Wolf Line | 15 | Shibu 재해석 시안 15 | 원제작자의 Shibu 늑대 리메이크 설명 근거. 1:1 대응은 검증 전 |
| Shibu | 19 | 기본형 1 + 분기 진화 18 | 원제작자가 Eevee 스타일 계열이라고 명시 |

현재 **원본 이미지 118칸 / 게임용 몬스터 도감 후보 102개 / 재해석 시안 15개 / 오브젝트 1개**이다. 102개는 *확정된 독립 종족 수*가 아닌 몬스터 후보 **이미지 슬롯 수**다. 예를 들어 Set 2의 한 쌍이 동일 개체의 다른 방향인지, 진화 전후인지, 별개의 종인지는 최종 확정되지 않았다.

### 인접 후보와 확정 진화를 구별하기

- `sprites`: 원본 118개 이미지 슬롯, 출처 파일명·64×64 좌표와 안정적 ID를 보존.
- `species`: 게임 도감에 활용할 몬스터 이미지 102개 후보. **최종 종족 ID가 아님.**
- `concepts`: 늑대 리메이크 15개, Shibu의 대체 디자인용. 당장은 도감 번호나 야생 출현 목록에 자동 포함하지 않음.
- `objects`: 배 그림 1개. 몬스터 도감·전투에서 제외.
- `role`: `monster`, `alternate-concept`, `object`.
- `familyId`: 관계가 있어 보이는 이미지 그룹. **진화라고 단정하지 않음.**
- `pairCandidate`: Set 2에서 이웃한 그림 사이 검토용 참조 ID. **앞·뒷모습 확정 아님.**
- `evolutionFrom` + `verifiedEvolution`: 근거를 확인한 스타팅 3계열 및 Shibu 18개 분기형만 연결.

### 이름을 만드는 원칙

1. 원본을 보고 동물·식물·기계·날씨·무늬 등 외형을 먼저 기록한다.
2. 그 특징과 연결되는 과학자·수학자 또는 개념을 찾는다.
3. 2~5음절 내외의 몬스터스럽고 기억하기 쉬운 이름을 짓는다. **동물이 아닌 그림에 '새'나 '양'을 억지로 붙이지 않는다.**
4. 도감 개념 설명은 검증된 과학 사실로 작성하고, 몬스터의 속성·기술에 연결한다. 과학 개념이 희귀도/공격력의 크기를 자동 결정하지 않는다.
5. **멘델콩, 켈빈맘, 피보참새** 등은 게임 창작 이름이고 원저작자의 공식 이름이 아니다.

## 편집기

1. 카드에서 118칸의 이미지와 이름을 확인한다.
2. 검색, 속성, 원본 아틀라스, 이미지 역할(도감 후보/재해석/오브젝트) 필터로 탐색한다.
3. 이름·속성·학습 개념·서식지·희귀도·진화 단계·메모를 바꾼다.
4. 이 기기의 로컬 저장소에 변경 사항이 기록된다. 기존 `kidscade.openmon.science-dex.edits.v1` 편집 데이터는 보존된다.
5. **전체 JSON 내보내기**는 변형·오브젝트 구분까지 포함해 118개 슬롯을 저장하며, 다시 불러오기는 118개 ID를 검사한 후 수정 가능한 필드만 반영한다.
6. 게임 내에서 돌아가기 버튼은 `kidscade:close-game` 메시지를 이용해 키즈케이드 iframe을 올바르게 닫는다.

- [Set 2 제작자 설명](https://screensmith.itch.io/openmon-monster-sprites-set-2-fakemon): 9개 배틀 스프라이트로 기재. 현재 18개 차지하는 셀과 차이가 있어 인접 관계는 미확정.
- [Shibu 제작자 설명](https://screensmith.itch.io/shibu-front-sprites-openmon-monster): 기본형 1개와 각 타입으로 진화하는 분기형 18개.
- [Wolf Line 제작자 설명](https://screensmith.itch.io/openmon-monster-sprite-wolf-line): Shibu 늑대형 리메이크.
- Openmon 원본 PNG는 각 원배포 페이지의 CC0 표기를 검증하여 사용한다. `BerryPlants.png`는 CC BY라 도감에서 미사용.
- Kenney Tiny Town/Tiny Farm은 별도의 16×16 CC0 탐험용 타일맵. Openmon 전투 배경을 탐험 맵 타일로 오용하지 말 것.
