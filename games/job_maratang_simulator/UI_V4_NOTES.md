# Maratang DX UI v4

- Mobile gameplay order: current cooking task → ingredients → waiting orders → compact summary.
- Waiting orders use a horizontal swipe strip instead of stacking vertically.
- Ingredients use two compact horizontal rows.
- Embedded Kidscade play hides the duplicate in-game header on mobile.
- 3D stage height is reduced for phone screens.
- Primary cook/serve actions stay in a safe-area-aware fixed bottom bar.
- Undo/clear remain available as compact secondary actions.
- Start screen is shortened and the asset-explanation block is hidden on phones.
- Result/help dialogs become mobile bottom sheets.
