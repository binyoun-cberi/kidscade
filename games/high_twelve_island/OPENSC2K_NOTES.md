# OpenSC2K-inspired city core

촌장 시뮬레이터 v9의 도시계획 코어는 OpenSC2K의 공개 구조를 연구해 **도로 네트워크, R/C/I 수요, 구역 성장, 교통·지가·오염 데이터맵**이라는 설계 개념을 KIDSCADE용으로 새로 구현했다.

- 참고 프로젝트: `nicholas-ochoa/OpenSC2K`
- OpenSC2K 프로젝트 코드 라이선스: MIT
- 이 디렉터리의 `city-core.js` 수치·규칙·JS 구현은 KIDSCADE용 신규 구현이며 OpenSC2K Rust/Godot 코드를 직접 복사하지 않았다.
- SimCity 2000 원본 그래픽·텍스트·사운드·음악은 포함하지 않으며, 해당 원작 자산에 대한 권리를 주장하지 않는다.
- 현재 1차 이식 범위: 연결 도로망, 주거/상업/산업 구역, 자동 성장/쇠퇴, RCI 수요, 지가·오염·교통·성장 오버레이, 공원·학교·진료소 서비스 효과.


## v10 확장 참고
OpenSC2K의 공개 구현에서 다음 구조를 추가로 연구했다.

- 통근: 구역에서 호환 목적지까지 도로 경로를 찾고, 성공한 경로에 교통량을 기록하는 방식.
- 전력/수도: 공급원에서 상하좌우 네트워크를 탐색해 연결된 타일에 공급 상태를 전달하는 방식.
- 공공서비스: 경찰·소방·학교·보건 시설의 지역별 서비스 범위와 예산 영향.
- 예산: 교통·기반시설·공공시설이 유지비를 만들고 세입과 균형을 이루는 구조.

KIDSCADE 구현은 위 설계 개념만 참고해 JavaScript로 새로 작성했다. OpenSC2K의 Rust/Godot 코드, SimCity 2000 데이터 테이블, 수치 상수, 그래픽·음향·문구는 복사하지 않았다.


## v11 확장 참고
OpenSC2K의 교통 검색은 경로 길이뿐 아니라 이동 모드별 비용과 버스 사용 여부를 기록하며, 성공한 경로에 교통량을 남긴다. 재난 시스템은 사건 마커와 출동 유닛을 별도로 관리해 현장 대응이 시뮬레이션에 영향을 준다.

KIDSCADE에서는 이 설계 개념만 참고해 다음을 독립 구현했다.

- 도로 경로에 정류장 2곳 이상이 포함되면 버스 통근으로 간주하고 체감 통근 비용과 도로 부하를 낮춤.
- 화재·신고 사건은 도시 타일 좌표와 상태를 저장하고, 가장 가까운 정상 소방서·경찰서에서 실제 연결 도로 경로를 계산해 출동.
- 출동이 도착할 때 사건을 해결하고, 도착하지 못한 화재는 구조물 피해를 누적.
- 지가 상태는 원본 그래픽을 사용하지 않고 KIDSCADE 자체 캔버스 건물 외형 차이로 표현.

OpenSC2K의 이동 비용 상수, 원본 SimCity 2000 건물 데이터, 그래픽·사운드·문구는 사용하지 않았다.
