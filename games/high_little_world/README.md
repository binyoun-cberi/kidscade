# 작은 세계

WorldBox/Populous/From Dust 계열의 감각을 키즈케이드의 기존 3D 자산과 생태 시뮬레이션으로 재해석한 과학 샌드박스입니다.

## 1차 버전 핵심
- 32×24 타일 기반 높이 지형
- 비가 높은 곳에서 낮은 곳으로 이동하는 간단한 물 흐름
- 수분·온도·비옥도에 따른 식생 성장과 바이옴 변화
- 식생 → 초식동물 → 포식동물의 개체군 시뮬레이션
- 물과 먹이를 보고 스스로 성장하는 정착지
- 정착지 사이 자동 도로
- 땅 올리기/내리기, 비, 햇빛, 식물, 동물, 사람, 축복, 번개, 불, 가뭄, 운석
- 정지 / 1× / 2× / 3× / 6×
- 자동 저장 및 이어하기

## 구조
- `sim.js`: Three.js/DOM과 독립된 세계 규칙
- `game.js`: Three.js 렌더링, 입력, UI, 키즈케이드 저장 연동
- 대량 개체는 데이터로 계산하고 대표 개체만 3D로 렌더링합니다.
- 기존 Kenney 자연/도시 모델과 Cube Pets, people 캐릭터 GLB를 재사용합니다.

## 후속 확장 후보
문명 간 교역·갈등, 기술 단계, 계절, 종별 적응/진화, 더 큰 맵과 지역 시나리오는 1차 핵심 루프 안정화 이후 추가합니다.
