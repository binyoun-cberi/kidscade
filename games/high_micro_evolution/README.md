# 마이크로 에볼루션

스포어의 세포 단계에서 영감을 받아, **세포 단계만 계속 플레이하는 과학·진화 샌드박스**로 확장한 키즈케이드 게임입니다.

## 핵심 루프

환경 선택/랜덤 생성 → 먹이와 에너지 확보 → DNA 획득 → 세포 편집 → 세대 변화 → AI 종 변이 → 환경 사건 → 다시 적응

## 구현된 생태계

- 햇빛 연못
- 탁한 습지
- 얕은 바다
- 심해
- 열수구
- 빙하 아래
- 고염 호수

각 환경은 빛, 온도, 산소, 염도, 먹이, 물살, 탁도 수치가 다르며 같은 세포라도 환경에 따라 효율이 달라집니다.

## 세포 부품

### 섭식
- 포식 입
- 여과기관
- 광합성체
- 기생 흡착기

### 이동
- 편모: 배치 방향에 따라 추진 효율이 달라짐
- 섬모: 회전과 미세 이동 강화
- 위족: 이동과 먹이 섭취 보조
- 부착기관: 강한 물살에 저항

### 감각
- 광수용기: 빛이 좋은 방향 탐지
- 화학수용체: 먹이 화학 신호 탐지
- 기계수용체: 큰 생물의 진동 탐지
- 촉각섬모: 가까운 접촉과 흐름 감지
- 온도수용체
- 전기 감각

### 방어
- 두꺼운 막
- 가시
- 독소낭
- 위장색소

## 생태적 지위

직업을 직접 고르지 않습니다. 플레이어가 선택한 기관 조합을 바탕으로 게임이 다음과 같은 생활 방식을 판정합니다.

- 추격형 포식자
- 여과섭식자
- 매복 포식자
- 방어형 부착생물
- 광합성 유영생물
- 숙주 추적 기생생물
- 감각 특화 탐색자

## 진화와 AI

한 세대는 약 55초입니다. 세대가 바뀌면 AI 생물도 속도, 방어, 감각 형질에 작은 변이를 얻습니다. 물살이 강하거나 먹이가 줄어드는 등 환경 압력이 생기면 관련 형질의 변화 폭이 커집니다.

환경 사건으로 폭우, 강한 햇빛, 탁도 증가, 산소 증가, 증발, 플랑크톤 번성 등이 발생합니다.

## 과학적 표현에 대한 주의

이 게임은 초등학생이 진화와 생태 적응을 체험하도록 실제 생물학을 단순화했습니다.

- '광수용기 → 눈', '기계수용 → 귀', '화학수용 → 코'처럼 감각의 기능적 연결을 보여 주되, 현대의 눈·귀·코가 단순히 한 종류의 세포 기관에서 곧바로 만들어졌다는 뜻은 아닙니다.
- 두꺼운 막, 온도수용체, 전기 감각 등의 효과는 게임 플레이를 위해 여러 실제 현상을 묶어 단순화했습니다.
- 진화는 생물이 필요에 따라 원하는 형질을 얻는 과정이 아닙니다. 게임에서 AI 종의 변이는 무작위성을 포함하고, 환경에 더 잘 맞는 형질이 다음 세대에서 유리하다는 방향으로 표현합니다.

## 참고 프로젝트

설계 시 오픈소스 프로젝트의 공개 구조와 아이디어를 참고했습니다.

- Revolutionary-Games/Thrive: 세포 기관, 화학수용체, 편모/섬모, 환경 적응 구조
- InauguralSystems/Tidepool: Spore-inspired cell stage, DNA 기반 변이/부품, 세대 진행
- dotlonely/CellStageCPP: Spore cell stage를 축소 구현한 이동·세포 표현 사례

현재 게임 코드는 키즈케이드용으로 새로 구현했으며 위 프로젝트의 코드나 에셋을 복사하지 않았습니다.

## 전략 리워크 v8

- 시작 세포는 포식자가 아니라 약한 **원시 섭식구 + 편모**로 시작합니다.
- 먹이는 맵 전체에 균일하게 흩어지지 않고 플랑크톤·영양분·고기 군집을 형성합니다.
- 포식 입은 떠다니는 먹이 효율이 낮고, 실제 생물을 사냥할 때 큰 생체량과 DNA를 얻습니다.
- 여과기관은 플랑크톤 군집에서 높은 효율을 냅니다.
- 광합성체는 밝은 수역에서 에너지와 생체량을 함께 생산합니다.
- 기생 흡착기는 숙주에게 붙어 에너지·생체량·DNA를 지속적으로 빼앗습니다.
- 위장색소는 가만히 있을 때 포식자의 실제 탐지 거리를 낮춥니다.
- 환경 사건은 영구 누적되지 않고 일정 시간이 지나면 원래 생태계 수치로 회복합니다.
- 내부기관도 제거하고 DNA 일부를 회수할 수 있어 이전 진화 선택을 다시 설계할 수 있습니다.


## 형태·군체 진화 v9

### 자유 외형 설계
진화 편집기에서 DNA 비용 없이 다음 외형을 자유롭게 조정할 수 있습니다.

- 몸 형태: 둥근형 / 타원형 / 유선형 / 아메바형
- 대칭: 좌우대칭 / 방사대칭 / 비대칭
- 몸색 / 강조색
- 무늬: 없음 / 반점 / 줄무늬 / 발광 테두리
- 몸 길이 / 폭 / 투명도
- 각 외부 기관의 크기와 회전 각도

외형 편집은 기능 기관 구매와 분리되어 있어 같은 생존 전략이라도 예쁘거나 기괴한 생물을 만들 수 있습니다.

### 군체 진화
군체 단계는 단순 레벨업이 아니라 세 가지 형질을 순서대로 획득해야 열립니다.

1. 세포 접착
2. 세포간 신호
3. 세포 분화

세 형질을 모두 가진 뒤 번식하면 단세포 단계에서 군체 단계로 전환됩니다. 군체는 여러 세포가 붙은 모습으로 렌더링되며 이동과 회전은 조금 느려지는 대신 감각과 방어가 강화됩니다.

현재 군체 단계는 이후 초기 다세포 진화를 위한 기반 단계입니다.
