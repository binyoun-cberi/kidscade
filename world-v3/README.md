# Kidscade World v3

생활 월드의 새 기본 렌더러입니다. World v2의 저장 구조를 그대로 읽고 쓰되, 화면은 **2D Deluxe 아바타 + 실제 3D Kenney 환경**으로 구성합니다.

## 비주얼 원칙
- 플레이어 아바타만 2D Sprite/CanvasTexture로 유지
- 집, 자연, 농장, 자원, 제작대, 상자, 실내 가구는 Three.js 3D
- 고정 3/4 Orthographic 카메라가 플레이어를 부드럽게 추적
- 2D 아바타는 항상 카메라를 향하는 billboard이며 3D 오브젝트 깊이 판정에 참여
- v2처럼 3D 모델을 2D 스프라이트로 굽지 않음
- Tiny Farm/Town 반복 타일은 v3에서 사용하지 않음

## 저장 호환
- `../world-v2/kidscade-world-storage.js`
- `../world-v2/kidscade-world-bridge.js`

`kidscade_world_v2` 저장값의 체력, 인벤토리, 도구, 씨앗, 작물 상태를 그대로 사용합니다. Deluxe 아바타도 기존 `kidscade-avatar-studio-preview` 또는 live avatar API를 읽습니다.

## 현재 연결된 생활 행동
- 3D 집 출입
- 3D 실내 침대 휴식 / 체력 회복
- 3D 냉장고·상자 인벤토리 확인
- 3D 제작대 돌도끼·돌곡괭이 제작
- 3D 나무 벌목 / 바위 채광
- 3D 연못 낚시
- 6칸 자유 재배 밭에서 감자 / 당근 / 토마토 / 딸기 / 옥수수 / 호박 선택 → 물주기 → 성장 → 수확
- PC WASD/방향키 + E/Space
- 모바일 방향패드 + 행동 버튼

## 기본 진입
생활 월드 UI에서는 v3만 사용합니다. 기존 v2 파일은 저장 호환과 이력 보존을 위해 저장소에 남아 있지만 **2D 안정판 버튼은 제거**했습니다.

## 주요 파일
- `kidscade-world.html` : v3 화면/UI
- `kidscade-world-v3.js` : Three.js 씬, 2D 아바타 billboard, 이동/충돌/상호작용


## v3.1 배치·아바타 애니메이션
- v3 내부에 숨김 `avatar-studio.html` 런타임을 두고 `renderPreviewFrame(idle/walk/smile)`을 직접 호출
- 프레임 API가 늦거나 잠시 unavailable이어도 billboard 자체의 보폭 바운스 / squash / 그림자 변화가 동작
- 좌우 이동 시 캐릭터 이미지 즉시 반전
- 야외를 집 앞 마당 → 마을길 → 연못 휴식 구역 → 농장 작물 구역 → 작업장 제작 구역으로 재배치
- 나무는 외곽 숲, 바위는 동쪽 채광 구역 중심으로 묶어 랜덤 테스트맵 인상을 줄임
- 실내를 침실 / 거실 / 주방·식탁으로 구획하고 중앙 이동 통로를 비움
- 기존 v3 좌표와 충돌하지 않도록 `LAYOUT_VERSION=2`에서 이전 v3 위치 저장을 안전하게 재설정


## 생존 확장
- 렌더러는 매 프레임 color / depth / stencil 버퍼를 강제로 clear하여 카메라 이동 시 잔상 방지
- 허기 0~100, 체력, Day/시간 저장
- 약 8분 단위의 낮/밤 흐름과 조명/하늘 변화
- 야외 밤에는 모닥불에서 멀수록 체력이 조금씩 소모
- 음식: 구운 생선 / 구운 감자 / 채소 수프 / 버섯 수프
- 집 가스레인지와 남쪽 야영지 모닥불에서 요리
- 돌도끼·돌곡괭이 → 철도끼·철곡괭이 업그레이드
- 철도구는 내구도와 채집 효율 증가

## 연결된 지역
- 중앙 씨앗하우스 / 농장 / 연못 / 작업장
- 서쪽 깊은 숲: 목재, 버섯
- 동쪽 돌산: 돌, 철광석
- 북쪽 강가: 실제 3D 나무다리
- 남쪽 야영지: 모닥불, 야외 요리와 휴식
- 중앙에서 각 지역으로 이어지는 표지판

## Cube Pets
- 별도 `나의 정원` 시스템은 폐기하고 펫 소유권을 `progression.cubePets`에 저장
- 활성 펫은 실제 Cube Pets GLB가 있는 종만 사용: 강아지 / 고양이 / 토끼 / 돼지 / 소 / 병아리 / 여우 / 사슴 / 앵무새 / 비버
- 강아지는 첫 친구, 나머지는 농장·깊은 숲·북쪽 강가 등 실제 월드에서 만나 길들임
- 길들이기에는 각 동물이 좋아하는 작물·물고기·버섯·자원 등이 필요
- 친구가 된 Cube Pet 중 소 / 돼지 / 병아리 / 토끼는 농가 옆 목장에서 생활하고, 나머지는 집 옆 펫 마당에서 생활하며 대표 한 마리를 모든 지역에 동행시킬 수 있음
- 펫마다 이동·농사·낚시·벌목·야간 활동 등에 작은 생활 보너스 제공
- 예전 정원/펫 세이브는 최초 1회만 읽어 Cube Pets와 정확히 대응되는 강아지·고양이·토끼·앵무새·돼지만 이전
- 햄스터 / 이구아나 / 거북이 / 염소 / 슈가글라이더 등 Cube Pets 활성 로스터에 없는 구형 펫은 이전하지 않음
- 마이그레이션 후에는 `kidscade_garden_v1`을 다시 참조하지 않음

## 구형 정원 폐기
- `garden.js`는 더 이상 `garden-core.js`, `garden-life.js`, `pet-art.js`를 로드하지 않음
- 메인 사이드바의 기존 쑥쑥랜드/정원 진입은 생활·생존 월드 v3로 바로 연결
- 구형 펫 상점, 햄스터 집, 정원 room 탭은 UI에서 숨김
- 기존 파일은 v2 안정판/이력 확인을 위해 당장은 저장소에 남기되 기본 실행 경로에서는 사용하지 않음


## 씨앗마을 도시 확장
- 남쪽 야영지 아래에 같은 3D 월드로 연결되는 씨앗마을 중심가 추가
- 실제 `assets/game/characters/people/character-*.glb` 인간 모델을 NPC로 사용
- NPC: 민지(마트), 준호(철물점), 하늘(카페), 도윤(일자리), 유나(주민), 태호(아케이드)
- 상점: 씨앗·도시락 구매, 목재·돌·철·물고기·작물·버섯 판매
- 철물점: 목재/돌 구매 및 돌도끼/돌곡괭이 직접 구매 가능
- 일자리: 마트 진열, 카페 설거지, 광장 정리 / 하루 1회
- 놀거리: 키즈 아케이드, 도시 벤치
- 코인 / 재미 / 주민 친밀도 저장
- 실제 Kenney Suburban 건물, Roads, Market Pack 소품 사용
- NPC는 고정 마네킹이 아니라 자기 자리 주변을 조금씩 걸어다님

## 시작 자원 루프
- 도구 제작 전에도 집 주변의 떨어진 나뭇가지와 작은 돌을 맨손으로 줍기 가능
- 시작 지역에 목재 5개 + 돌 5개를 확보할 수 있는 채집 포인트 배치
- 돌도끼(목재3+돌2)와 돌곡괭이(목재2+돌3)를 둘 다 최초 제작할 수 있는 수량
- 각 채집 포인트는 약 45초 뒤 재생성
- 철물점에서 코인으로 재료나 기본 도구를 구매하는 우회 루트도 제공


## 씨앗마을 도시 생활 확장
- 남쪽 야영지 너머에 실제로 걸어서 들어갈 수 있는 연속형 도시 구역 추가
- 실제 인간 GLB 사용: `character-female-a~f.glb`, `character-male-a~f.glb`, 마트 `character-employee.glb`
- 주민: 민지, 준호, 하늘, 도윤, 유나, 태호, 소라, 현우, 나리, 우진, 서연, 민석, 마트직원
- 시설: 씨앗마트 / 튼튼 철물점 / 하늘 카페 / 키즈 아케이드 / 마을회관 / 마을 도서관 / 튼튼 보건소 / 씨앗버스 정류장
- 상점별 영업시간 적용
- 농작물·물고기·버섯·광물·목재·돌 판매
- 씨앗·음식·기초 재료·돌도구 구매
- 일거리: 마트 진열 / 카페 설거지 / 광장 정리
- 실제 배달 퀘스트: 현우에게 상자를 받아 하늘 카페에 전달
- 주민 일일 대화와 친밀도
- 아케이드 가위바위보와 일일 첫 승리 상품
- 도서관 일일 생활 팁 / 보건소 체력 회복 / 광장 벤치 휴식
- 씨앗버스로 집 앞·숲·돌산·야영지·중심가 빠른 이동
- 주민은 낮에는 각 시설 주변, 저녁에는 일부 주민이 광장에 모이는 간단한 생활 스케줄 사용

## 초반 자원 데드락 방지
- 집 주변에 맨손으로 주울 수 있는 떨어진 나뭇가지 5개와 작은 돌 5개 배치
- 각 자원은 일정 시간이 지나면 다시 나타남
- 첫 1회만 여는 초보자 보급 상자에서 목재 5 + 돌 5 지급
- 따라서 새 세이브에서도 돌도끼와 돌곡괭이를 모두 제작할 수 있음
- 철물점에서도 목재·돌·돌도구를 구매할 수 있어 두 번째 안전장치 제공


## 3D 집 꾸미기 1단계
- 집 안의 가구 창고에서 보유 가구를 선택해 플레이어 앞에 실제 3D 미리보기로 배치
- 이동으로 위치를 잡고 회전 / 배치 / 취소 가능, 모바일에서도 전용 배치 버튼 제공
- 배치한 가구는 다시 옮기기 / 90도 회전 / 창고 회수 가능
- 가구 위치와 방향, 보유 수량을 `progression.housing`에 저장
- 첫 가구 창고 이용 시 나무 의자 + 화분을 집들이 선물로 지급
- 제작 가구: 나무 의자 / 작은 협탁 / 화분 / 낮은 책장 / 커피 테이블 / 라운지 의자
- 상점 가구: 씨앗마트의 둥근 러그·곰 인형, 튼튼 철물점의 플로어 램프·모던 TV
- 고정 침대·주방 등 기존 생활 기능은 유지해 기존 세이브와 생활 루프를 깨지 않음
- 가구 배치는 실내 벽·고정 가구·출입구와 겹치지 않도록 충돌 검사


## 3D 집 꾸미기 2단계 · 기본 가구 자유배치
- 기존 실내에 고정되어 있던 책상 / 책장 / 소파 / 식탁 / 거실 러그를 `progression.housing.placed` 기반의 이동 가구로 전환
- 기존 세이브도 최초 1회 같은 좌표에 자동 배치되어 집 모양이 갑자기 비지 않음
- 이후에는 해당 기본 가구도 옮기기 / 회전 / 창고 회수가 가능하며, 회수 후 다시 자동 생성되지 않음
- 소파 / 책장 / 식탁 / 책상은 배치 위치가 바뀌어도 가구 메뉴의 사용 동작이 유지됨
- 침대 / 가스레인지 / 싱크대 / 주방 캐비닛 / 냉장고는 생활 루프 안정성을 위해 이번 단계에서는 고정 설비로 유지
- 가구 저장 버전을 v2로 올리고 `defaultLayoutMigrated` 플래그로 중복 마이그레이션을 방지


## 3D 집 꾸미기 3단계 · 기능성 가구
- 침대 / 냉장고 / 가스레인지 / 싱크대 / 주방 캐비닛도 고정 오브젝트에서 이동 가능한 저장 가구로 전환
- 기존 가구 마이그레이션 여부와 별개로 `functionalLayoutMigrated`를 사용해 기존 사용자에게도 기능성 설비를 최초 1회 같은 위치에 안전하게 이전
- 침대는 옮긴 위치에서 잠자기 / 냉장고는 보관함 / 가스레인지는 요리 / 싱크대는 손 씻기 / 주방 캐비닛은 식재료 보관함 기능을 유지
- 모던 TV는 실제 사용 가능하며 시청 시 재미 +15, 게임 시간 20분 경과, 허기 소폭 감소
- 기능성 가구도 이동 / 90도 회전 / 창고 회수 / 재배치가 가능
- 실내 고정 오브젝트는 집 꾸미기 시스템을 여는 가구 창고 상자와 건축 구조물만 남김
- 가구 저장 버전을 v3로 올리고 기본 가구 마이그레이션과 기능성 설비 마이그레이션을 분리


## 주민 역할 · 친밀도 · 희귀 보상
- 모든 이름 있는 주민은 이제 주민 카드에서 역할 / 현재 친밀도 / 다음 보상 / 전용 서비스 / 대화를 함께 확인
- 하루 첫 대화는 해당 주민 친밀도 +1, 같은 날 추가 대화는 정보 확인만 가능
- 친밀도 3: 주민 성격과 직업에 맞는 실용 보상
- 친밀도 7: 주민 역할과 연결된 영구 특전
- 친밀도 12: 해당 주민에게서만 받을 수 있는 전용 3D 희귀 가구
- 민지: 씨앗마트 / 마트 할인 / 시장 화분
- 준호: 철물·도구 / 철물점 할인 / 작업 스툴
- 하늘: 카페·요리 / 카페 할인 / 카페 테이블
- 도윤: 마을 일자리·행정 / 알바 보수 증가 / 마을 벤치
- 유나: 농사·마을생활 / 작물 수확량 +1 / 작은 화초
- 태호: 키즈 아케이드 / 이용료 할인 / 레트로 게임 TV
- 소라: 도서관·생활지식 / 독서 체력 회복 증가 / 고전 책장
- 현우: 배달 / 배달 보상 증가 / 배달 서랍장
- 나리: 보건소·회복 / 진료비 할인 / 진료실 램프
- 우진: 숲 채집·탐험 / 버섯 채집량 +1 / 숲 휴식의자
- 서연: Cube Pets 돌봄 / 길들이기 요구량 감소 / 펫 의자
- 민석: 씨앗버스 / 북쪽 강가 노선 해금 / 여행 벤치
- 마트직원은 상점 분위기를 위한 보조 NPC로 유지하며 별도 친밀도 트랙은 없음


## World v3 맵 정리 패치
- 씨앗마을을 상업가 → 메인도로 → 보행 광장 → 공공시설 → 버스 구역의 읽기 쉬운 구조로 재배치
- 메인도로는 4m 그리드로 통일하고 북쪽 광장으로 이어지던 불필요한 아스팔트 가지와 실제 차량 없는 신호등을 제거
- 씨앗마트 과일/빵/계산대/카트/ATM은 마트 앞 야외 판매 코너로 묶고, 벤치·화분은 도로가 아닌 광장 가장자리로 이동
- 버스정류장 / 표지판 / 자전거 / 민석을 동쪽 교통 구역에 모아 기능과 시각적 의미를 일치
- 유나(낮 농장), 우진(낮 숲 입구), 서연(낮 Cube Pets 마당), 현우(배달·우편 구역)는 역할에 맞는 생활 위치를 사용하고 저녁에는 일부 주민이 광장에 모임
- 이동하는 주민 모델의 상호작용 좌표와 이름표가 실제 위치를 매 프레임 따라가도록 수정
- 야생 Cube Pets에 `pond / farm-pasture / deep-forest / riverbank` 서식지 정보를 부여하고 도시 영역 진입을 방지
- 토끼 / 돼지 / 소 / 병아리는 밭 위에서 제거해 농가 옆 작은 초지로 이동, 고양이는 연못 둑, 비버는 강둑으로 재배치
- 소유 Cube Pets는 집 옆 울타리와 표지판이 있는 전용 마당에서 생활하며 동행 펫만 플레이어를 따라다님
- 개발용 `validateMapLayout` 검사로 주요 건물 / 도로 / 광장 / 장식 구역 겹침을 콘솔에서 감지
- 대규모 좌표 변경에 맞춰 `LAYOUT_VERSION=3`으로 올려 이전 위치에 저장된 플레이어가 건물 안에 끼는 일을 방지


## v3.13 맵/AI 회귀 수정
- 스크린샷에서 확인된 주민/동물의 떠있음·지면 파고듦 원인을 수정: GLB마다 계산한 실제 `groundY`를 유지하고 이동 애니메이션은 그 기준 위에서만 적용
- 야생동물과 펫 마당 동물에 일시정지 → 목표 선택 → 걷기 → 방향 전환이 있는 간단한 roaming AI 적용
- 동물들이 한 방향만 보는 문제를 없애고 이동 방향으로 회전, 정지 중에는 미세한 둘러보기 동작 사용
- 유나/우진/서연/현우가 도시 밖 역할 지점까지 장애물을 무시하고 직선 횡단하던 스케줄을 폐기하고, 길찾기 도입 전까지 도시 안의 안전한 역할 거점만 사용
- 이동 주민의 이름표와 상호작용 좌표는 실제 모델 위치를 추적하며, 이름표는 가까이 접근했을 때만 작게 표시
- 도시 진입 시 이동 입력을 한 번 해제하고 실제 키를 놓은 뒤 다시 입력하도록 하여 keyup 유실로 인한 무한 이동 방지
- `blur / visibilitychange / pagehide / pointercancel`에서도 이동 상태 초기화
- 패널 열기/닫기, 버스 이동, 실내외 전환 시에도 입력 상태 초기화
- 카메라가 도시/강가 끝에서 월드 바깥의 파란 배경을 물처럼 노출하던 문제를 막기 위해 야외 지면을 82×96으로 확장


## v3.14 농장·목장·오디오 정리
- 화면의 `2D 안정판` 버튼 제거, 생활 월드는 v3를 기본 진입점으로 사용
- 기존 3개 고정 작물 밭을 6개 자유 재배 밭으로 재구성
- 빈 밭에서 감자 / 당근 / 토마토 / 딸기 / 옥수수 / 호박 중 보유 씨앗을 직접 선택
- 씨앗마트에서 딸기 / 옥수수 / 호박 씨앗도 구매 가능, 수확물도 판매 가능
- 제작대와 보관 상자를 밭 오른쪽 별도 제작 패드로 이동해 작물 구역과 겹치지 않도록 수정
- 남쪽 야영지 모닥불을 중앙 통행로에서 서쪽 잔디 공간으로 이동
- 북쪽 나무다리를 강을 건너는 방향으로 90도 회전
- 3D 사람 NPC를 모델 자체가 아닌 지면 앵커 그룹에 넣어 발밑 기준으로 세우고 그림자를 추가
- 소 / 돼지 / 병아리 / 토끼는 친구가 된 뒤 농가 옆 목장을 기본 생활 위치로 사용
- 목장 생산물: 소 우유(매일), 병아리 달걀(매일), 돼지 트러플(2일마다)
- 목장 생산물은 씨앗마트 판매 품목과 연결
- 월드 BGM은 프로젝트에 라이선스 기록이 있는 Pixabay `newmusical` 잔잔한 기타 루프 사용
- 채집 / 채광 / 벌목 / 낚시 / 수확 / 제작 / 구매 / 판매 / 알바 등에 로컬 SFX 연결
- 월드 오버레이를 닫으면 BGM도 일시정지하고 다시 열면 재개
- 대규모 농장 좌표 변경에 맞춰 `LAYOUT_VERSION=4`로 올려 기존 저장 위치 끼임 방지

## v3.18 주민 본체·도시 진입로 심층 수정
- 실제 `character-female-a.glb`를 바이너리 수준에서 확인한 결과 UnityGLTF SkinnedMesh 2개와 `idle`, `walk`, `sprint` 등 다수의 원본 애니메이션을 포함
- 기존 World v3 로더가 `g.scene`만 캐시해 애니메이션 정보를 버리던 구조를 `loadGLTF()` 전체 캐시로 변경
- 주민 복제는 `SkeletonUtils.clone(gltf.scene)`을 사용하고, 다른 게임에서 정상 동작 중인 사람 모델 파이프라인과 동일하게 최대 축 기준 스케일 → X/Z 중심 정렬 → 발바닥 Y=0 순서로 정규화
- 각 주민에 `AnimationMixer`를 연결해 Idle/Walk 원본 애니메이션 사용
- 사람 GLB의 Walk 애니메이션에 `root.position` 루트 모션이 포함된 것을 확인해 해당 트랙만 제거: 앵커/이름표는 도시로 이동하는데 몸체가 원점 근처에 남거나 이탈하는 현상 방지
- SkinnedMesh는 애니메이션 이동 중 잘못된 프러스텀 컬링을 피하도록 `frustumCulled=false`
- 씨앗마을 진입로를 기존 1.8~2.2m 조각 길에서 폭 3m의 하나의 연속 보행로로 교체
- 진입로 양옆 `(-2,10)`, `(2,10)` 나무를 제거하고 중앙 표지판도 옆으로 이동
- 중앙 보행로는 `isProtectedRoute()`로 지정해 자연물 collider 생성에서 제외하고, `isBlocked()`에서도 통행 우선 처리
- 따라서 향후 자연물 배치가 바뀌어도 집/농장 → 야영지 → 씨앗마을 중앙 도로는 보이지 않는 충돌체로 막히지 않음

## v3.21 정사각형 구획 월드
- 월드의 기본 규격을 20×20 정사각형 셀로 통일하고 `kidscade-world-grid.js`를 단일 좌표 기준으로 사용
- 중앙 생활권 한 줄: 깊은 숲(-30,0) / 집(-10,0) / 농장(10,0) / 광산(30,0)
- 북쪽 생활·자연권: 해변(-30,-20) / 북쪽 강가(-10,-20) / 목장(10,-20)
- 남쪽 확장권: 야영지(-30,20)와 씨앗마을 4개 셀
- 씨앗마을 4분할: 상점가(-10,20) / 광장·놀이(10,20) / 공공시설(-10,40) / 교통·보건(10,40)
- 각 셀은 19.6×19.6 실제 바닥을 사용하고 셀 사이 틈으로 경계가 자연스럽게 보이도록 구성
- 모든 셀 연결은 변의 중앙을 지나는 약 3m 폭 표준 통로만 사용
- 빈 미사용 셀은 이동 불가로 막아 플레이어가 개발되지 않은 공간으로 빠지지 않음
- 집 구역은 집·연못·초보자 자원·펫 마당, 농장은 6칸 자유 재배·제작대, 목장은 생산 펫, 숲/광산은 자원 채집으로 역할을 분리
- 강 전체를 한 구역 안에 넣고 다리를 셀 중앙에 배치, 해변은 별도 모래 셀과 해안 낚시터로 분리
- 야영지를 도시 진입로에서 떼어 독립 정사각형으로 이동
- 도시 도로는 4개 셀 경계인 x=0 / z=30에 맞춰 십자형으로 배치하고 각 셀의 출입구를 중앙에 통일
- 버스 목적지에 목장과 해변을 추가
- 대규모 좌표 재편에 맞춰 `LAYOUT_VERSION=6`으로 올려 이전 저장 위치를 안전한 집 구역으로 재배치


## v3.22 개척 흐름 리워크
- 예전 가구 마이그레이션 흔적이 있는 저장값을 집 3단계·수도 3단계로 자동 승격하던 `legacyComfort` 경로 제거
- 기존 씨앗·코인·게임 트로피·Cube Pets·주민 친밀도는 유지하면서, 생활 개척 진행만 최초 1회 새 시작 상태로 재정렬
- 새 시작은 단칸방 / 바닥 이불 / 임시 상자 / 밭 1칸 / 강물 운반부터 시작
- 목수공방 0단계에서는 완성 건물이 보이지 않고 빈 기초 터만 보이며, 건설 후 실제 건물이 나타남
- 성장판은 현재 생활에서 발견한 발전 항목만 순차 공개하여 미래 콘텐츠가 처음부터 전부 보이지 않도록 변경
- 빠른 이동 지도도 아직 만들지 않은 과수원·목장·해변을 미리 노출하지 않음
- 밤 야외 자체의 지속 체력 피해를 제거하고 허기·작업 피로 중심으로 생존 압박을 완화
- 마트 진열 / 카페 설거지 / 광장 정리 알바를 즉시 보상 버튼에서 각각 3단계 실제 작업 흐름으로 변경
- 캐시 버전을 World v3.33 / storage v7 / economy v15로 갱신


## v3.23 배치 겹침 정리

- 집 연못·우물·펌프와 겹치던 초반 나뭇가지/돌, 보급상자·연못과 겹치던 장식 꽃 재배치
