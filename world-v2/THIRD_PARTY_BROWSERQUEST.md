Kidscade World v2 can optionally load visual assets from Mozilla BrowserQuest while the art pipeline is being evaluated.

The `client/img/3` assets are BrowserQuest's 3x pixel-art set for 48×48 map tiles. Any BrowserQuest art copied into this repository, and adaptations made from that art, must keep the required attribution and applicable CC BY-SA 3.0 terms.

Kidscade World v2 engine code is kept separate from the imported/adapted art layer so the engine can later use original Kidscade artwork without depending on BrowserQuest assets.
