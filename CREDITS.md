## 5. Developer rules

1. Check this file and `assets/game/licenses/` before introducing an asset into a new game.
2. CC0 assets need no attribution.
3. CC-BY assets must retain creator + license attribution in the game/site credits.
4. Mixed bundles must be checked **per model**.
5. Pixabay content may be used in Kidscade creative works but must not be redistributed as a standalone media pack.
6. Unknown/unverified files must stay marked as such until evidence is recovered.
7. When adding a new asset pack, record source URL, author, license, and any required credit at import time.
