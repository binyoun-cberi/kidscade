# newmusical - license verification required

These files were supplied without a license/readme inside the ZIP.

They are intentionally stored under `assets/audio/incoming/newmusical/` and are **not** added to the active Kidscade audio catalog. Do not ship them in a game until the original source page and license for each file are confirmed.

The filenames suggest creator/source information, but filenames alone are not sufficient evidence of reuse rights.
