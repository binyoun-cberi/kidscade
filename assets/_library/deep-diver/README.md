# Deep Diver GitHub-ready assets

This folder documents the public-repository-safe subset prepared for Kidscade.

## Included
- Sergeant_Slash — 32x32 Animated Shark Sprite
- 1 atlas PNG
- 8 animation frame PNGs

## Intentionally excluded
The following source was present in the input pack but is **not included** in this public-GitHub package:

- RehanDev — `400 + Pixel Underwater loot and junk`
- Original `props/` assets
- Original `landmarks/` assets
- Preview images derived from that pack

Reason: the source terms permit use in projects but prohibit redistribution of the raw asset files. A public GitHub repository would expose the raw PNGs for download.

## Install
Extract this ZIP at the root of the `kidscade` repository and allow the `assets/` folders to merge.
