# Attribution required for some 3D assets

This add-on intentionally contains both **CC0** and **CC-BY** assets.
If a game uses one of the CC-BY assets below, keep the corresponding credit in the game/site credits.

Central credits: `CREDITS.md` and `credits.html`.

## Scifi Turrets

- **Zsky — Scifi Turrets** — Creative Commons Attribution.
- Source: https://poly.pizza/bundle/Scifi-Turrets-zFn6sCt0U0

## Charming Kitchen set

- **Isa Lousberg — Charming Kitchen set** — mixed CC0 / Creative Commons Attribution.
- Source: https://poly.pizza/bundle/Charming-Kitchen-set-DsYQKb1K4M
- The per-model `license` field in `assets/game/manifest/3d-library-v4-catalog.json` tells you which files require attribution.
