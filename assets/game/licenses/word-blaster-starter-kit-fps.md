# Word Blaster Starter Kit FPS assets

Source: https://github.com/KenneyNL/Starter-Kit-FPS

Word Blaster reuses selected 3D assets from Kenney's Starter Kit FPS:
- models/blaster.glb
- models/cloud.glb
- models/enemy-flying.glb (renamed to letter-drone.glb)
- models/grass.glb
- models/grass-small.glb
- models/platform-large-grass.glb

The Starter Kit code is MIT licensed. The included 2D sprites, 3D models, and sound effects are stated by Kenney to be CC0 licensed.

The Word Blaster runtime is a Kidscade Three.js implementation and does not copy the Godot gameplay scripts.
