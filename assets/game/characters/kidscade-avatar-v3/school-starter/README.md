# KIDSCADE 학교 탐험가 v3 기본 세트

## 적용
1. 현재 프로젝트 JSON을 저장해 백업합니다.
2. 관리자 아바타 제작실의 전체/파츠 JSON 적용에서는 `school-starter.json`을 사용합니다.
3. 공개 꾸미기 화면은 `manifest.json`과 검수된 파츠 카탈로그만 읽으며 JSON 가져오기/내보내기는 노출하지 않습니다.

- 128×128, 좌상단 원점, ROOT_X=64, GROUND_Y=118.
- maple-lite-body-v3의 23프레임(STAND 2, WALK 4, JUMP 1, ATTACK 5, HURT 2, DEAD 4, SIT 2, PICKUP 3)을 사용합니다.
- 피부색은 7개 원본 프레임(STAND 2, WALK 4, JUMP 1)의 얼굴 피부 샘플에서 프레임별 팔레트를 잡고, `frameSources` 계보를 따라 ATTACK/HURT/DEAD/SIT/PICKUP까지 23프레임 전체에 적용합니다. 기본 BODY 8색 명암 비율은 기준으로 유지합니다.
- 기본 헤어·입·귀걸이·교복 상하의·운동화·자·교과서는 기존 school-starter 세트를 유지합니다.

## 눈 파츠
- `eyes/catalog.json`이 공개 눈 카탈로그입니다.
- `basic-eyes-01` 기본형에 JSON 픽셀 파츠 10종을 추가해 총 11종입니다.
- 각 눈은 PNG가 아니라 128×128 좌표 픽셀 JSON이며, 기본 눈을 지운 뒤 BODY 피부색을 복원하고 새 눈을 합성합니다.
- `frameTransforms`는 현재 제작실의 파생 동작 규칙과 동일합니다. STAND/WALK/JUMP 기준 눈을 ATTACK/HURT/DEAD/SIT/PICKUP에 변환하므로 동작마다 별도 PNG를 중복 저장하지 않습니다.
- 피부색을 바꾼 뒤에도 눈 아래 복원색은 현재 프레임에서 샘플링하므로 얼굴에 원래 피부색 사각형이 남지 않습니다.

## 사이트 연결
- 공개 `avatar-studio.html`의 눈 탭에서 11종을 바로 선택할 수 있습니다.
- 선택값은 `kidscade-avatar-v3` 상태의 `assetIds.eyes`에 저장되고 로비 미리보기 API에도 그대로 전달됩니다.
- 눈 썸네일은 얼굴 부분을 확대해 비교할 수 있습니다.
- JSON 편집 기능은 공개 꾸미기에 추가하지 않았습니다.

## 검증
- 카탈로그 항목 수, 10개 추가 JSON의 좌표/RGBA 범위, 23프레임 변환 규칙, 공개 UI 연결, 상태 저장 및 피부 팔레트 8색·7개 원본 프레임 탐색·23개 frameSources 계보·명암 비율·상태 저장을 테스트합니다.


## 헤어 파츠
- `hair/catalog.json`이 공개 헤어 카탈로그입니다.
- `basic-tousled-hair-01` 기본 더벅머리 1종과 JSON 픽셀 헤어 32종, 총 33종을 제공합니다.
- 추가 스타일: 단정 숏컷, 옆가르마, 가운데 가르마, 보브컷, 긴 생머리, 포니테일, 양갈래, 곱슬머리, 스파이크, 바가지컷.
- 새 헤어 적용 시 기존 더벅머리 영역을 BODY 피부/외곽선/투명 배경으로 복원한 뒤 새 픽셀 헤어를 합성합니다.
- 피부색을 바꾼 경우 얼굴 복원색도 현재 피부색을 샘플링하므로 기본 피부톤이 비치지 않습니다.
- 자·교과서·귀걸이처럼 헤어보다 앞에 있어야 하는 기존 레이어 색은 보호해 공격/이동 동작에서도 앞뒤 순서를 유지합니다.
- STAND/WALK/JUMP 7개 기준 자세와 16개 파생 동작 변환을 공유해 총 23프레임에서 동작합니다.


- 만화형 10종: 히어로 스파이크, 왕자 스파이크, 닌자 스파이크, 까마귀 스파이크, 폭발 스파이크, 설원 스파이크, 반반 투톤, 스타 스파이크, 메가 트윈테일, 히어로 컬리.
- 캐릭터 고유명이나 표식을 복제하지 않고 실루엣 중심의 오리지널 스타일로 구성하며, 기존 공용 염색 시스템을 그대로 사용합니다. `반반 투톤`은 오른쪽의 밝은 포인트 톤을 유지하면서 왼쪽 컬러가 염색됩니다.

## 상의 파츠
- `upper/catalog.json`이 공개 상의 카탈로그입니다.
- `basic-school-uniform-upper-01` 기본 교복 상의에 JSON 상의 10종을 추가해 총 11종입니다.
- 추가 상의: 크림 가디건, 민트 맨투맨, 코랄 후드 상의, 라벤더 니트, 네이비 체육복, 하늘 스트라이프, 포레스트 바시티, 블랙 그래픽, 핑크 세일러, 머스타드 탐험 재킷.
- 실제 `school-starter.json` 상의 레이어에서 추출한 23개 프레임 범위와 원본 7색만 정확히 치환합니다.
- 자·교과서처럼 상의보다 앞에서 합성된 픽셀은 원본 상의 7색과 다르므로 보존됩니다.
- 선택값은 `kidscade-avatar-v3` 상태의 `assetIds.upper`에 저장됩니다.


## 하의 파츠
- `lower/catalog.json`이 공개 하의 카탈로그입니다.
- `basic-school-uniform-lower-01` 기본 교복 하의에 JSON 하의 10종을 추가해 총 11종입니다.
- 추가 하의: 데님 블루 팬츠, 네이비 슬랙스, 베이지 치노, 올리브 팬츠, 블랙 조거 팬츠, 그레이 팬츠, 브라운 코듀로이, 스카이 블루 팬츠, 카멜 팬츠, 차콜 팬츠.
- 실제 `school-starter.json` 하의 레이어에서 추출한 원본 2색과 23개 프레임 범위만 정확히 치환합니다.
- BODY 자세와 하의 실루엣은 건드리지 않으므로 STAND/WALK/JUMP/ATTACK/HURT/DEAD/SIT/PICKUP 23프레임이 그대로 유지됩니다.
- 선택값은 `kidscade-avatar-v3` 상태의 `assetIds.lower`에 저장됩니다.


## 학교 액세서리 확장
- 신발은 기본 운동화를 포함해 11종이며, 파란 운동화·하이탑·캔버스화·러닝화·단화·로퍼·슬립온·실내화 등으로 구분됩니다.
- 귀걸이는 기본 구리 링을 포함해 11종이며, 골드 스타·초승달·실버 링·진주·하트·꽃·번개·물방울·리본·에메랄드 형태를 제공합니다.
- 도구는 기존 자를 유지하면서 연필, 색연필, 사인펜, 크레파스, 붓, 단소, 리코더, 청소빗자루, 물로켓, 가위, 별모양 마법지팡이, 축구공, 농구공, 배구공을 추가했습니다.
- ‘책’ 탭은 ‘교구’로 바꾸고 기존 교과서를 유지하면서 지우개, 이로미, 쓰레받기, 연필깎이, 곰돌이인형, 베개를 추가했습니다.
- 도구는 왼손, 교구는 오른손 앵커를 따라가며 23프레임에서 동작합니다. ATTACK 02에서는 도구 전체가 BODY 뒤로 넘어가고, 나머지 동작은 기존 앞/뒤 장비 레이어 주변을 기준으로 가림 순서를 나눕니다.
