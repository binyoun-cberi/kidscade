# KIDSCADE 학교 탐험가 기본 9종 v1

## 적용
1. 현재 프로젝트 JSON을 저장해 백업합니다.
2. 아바타 제작실 → AI 프레임 보정 → 전체/파츠 JSON 적용.
3. school-starter.json을 선택하면 9종 전체가 적용됩니다.
4. 한 파츠만 바꾸려면 hair/eyes/mouth/earring/upper/lower/shoes/ruler/textbook.json 중 해당 파일을 적용합니다. 개별 파일도 full-adjustment 형식이며 해당 레이어만 포함합니다.

- 128×128, 좌상단 원점, ROOT_X=64, GROUND_Y=118.
- maple-lite-body-v3의 제공된 7개 BODY 프레임을 기준으로 제작했습니다. BODY 수정 명령은 없습니다.
- STAND 2, WALK 4, JUMP 1, ATTACK 5, HURT 2, DEAD 4, SIT 2, PICKUP 3: 총 23프레임.
- 새 파츠 생성이므로 각 대상 레이어만 replacePixels로 교체합니다. BODY/가면/장갑/모자는 건드리지 않습니다. 기존 모자나 가면이 있으면 필요에 따라 표시를 꺼 주세요.
- 자는 weaponFront/weaponBack, 교과서는 shieldFront/shieldBack 두 패스를 항상 함께 적용합니다. 비어 있는 패스도 명시해 이전 장비가 남지 않게 했습니다.
- 공격 준비 프레임의 자는 뒤 패스, 타격 프레임은 앞 패스입니다. 손 부분은 BODY 뒤로 나눴습니다.
- DEAD-04 교과서는 캔버스 바깥으로 잘리지 않도록 몸 옆으로 떨어진 모습입니다.
- 16개 추가 동작은 현재 제작실의 BODY 변형 방식에 맞췄으며 장비 위치를 별도 보정했습니다. 기존 BODY 자체의 파생 모션 한계는 유지됩니다.
- school-starter-preview.html은 인터넷/로그인 없이 열어 모든 동작과 반전 방향을 확인할 수 있습니다. 미리보기에서는 일회성 동작도 반복합니다.

## 사이트 연결
- 제작실에 ‘학교 탐험가 9종 · 모든 동작’ 버튼을 추가했습니다.
- 저장 코디가 없는 게스트의 로비 기본 미리보기에 새 합성 이미지를 연결했습니다. 기존 저장 코디는 유지합니다.
- 공개 index.html과 23프레임 스프라이트 시트를 제공합니다. 공개 꾸미기에서는 BODY 피부 팔레트만 런타임에서 다시 칠해 대표 피부톤 또는 임의의 색을 선택할 수 있으며, 원본 명암은 유지합니다. 모든 개별 게임에 새 동작 런타임을 연결한 것은 아닙니다.

## 검증
- 현재 제작실의 실제 JSON 검증/픽셀 적용 함수를 실행해 23프레임을 검사했습니다.
- BODY 및 무관한 레이어 보존, 픽셀 좌표/색상 범위, 장비 앞뒤 중복, 게스트 저장 코디 보존과 이미지 로드 실패 폴백을 검사했습니다.
- 브라우저 실행 파일을 확보하지 못해 실제 사이트 UI 클릭 검증은 수행하지 못했습니다.
